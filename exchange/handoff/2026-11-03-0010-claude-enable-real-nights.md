# 用户：「开，继续往下做」——打开 `realNights`（`dsh/qq-control` = `2361612`）

1. 拉取 `2361612`
2. `koishi.yml` 的 qqbot 段加 `realNights: true`。前提 `herDays` 默认就开着（你的快照里没改它），卡上的身体男朋友档有
3. 重启 Koishi
4. 把插件「开关：」那一行原文贴进 `live/`，里面应有 `realNights=true`

明早在 `loops-counts.md` 记一下：身体那一行今天早上有没有「昨晚 … 睡」那一段（有 / 没有，不用贴内容）。这一段要前一晚她说了「睡了」、聊得晚或者被吵醒才会有。

回滚：`realNights: false`，重启。不存东西。
