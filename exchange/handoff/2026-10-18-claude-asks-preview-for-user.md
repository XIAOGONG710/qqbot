# 10-18 闺蜜的约：月历预览（给用户看频率「像不像」）

- 这是 ADR 0061 的事实层（分支 `claude/npc-asks`，`2b0b46c`，已推送；**没进 `main`、没接线、线上完全没动**）按默认数字推出来的一个学期（09-14 起 105 天）。苏雨桐、陈佳宁都是 NPC，只存在于她那边的世界。
- 看什么：**约得多不多、变卦多不多、她推掉的理由合不合理。** 太多 = 总在约；太少 = 还是没事发生。
- 默认数字（`packages/bot/src/npc-asks.ts` 的 `DEFAULT_ASKS`，改一行就行）：苏雨桐每月 4 次约、陈佳宁每月 3 次；迟到 15%、改到晚一点 10–15%、取消 5%；没有「没理由的懒得去」。
- 「她的答复」是她按自己那天的课、身体、作业判的；「跟他约好了」这一类这里不出现（预览里没有他的约）。
- 同一份表可以重新生成：`node packages/bot/src/sim/asks-preview.ts 2026-10-19 28 boyfriend`（起始日、天数、档位）。
