## 更正三：**H 做不了盲评参照**（这否掉了 H 的核心用途）

### 3.1 硬伤：H 是照「意图」写的，而模型和评分人都看不到意图

`blind.ts` 里 `intent / probe / facts` **只声明、从不使用**（`Select-String` 只命中 32–34 行），
`toScenario()` 只把 `q.lines` 变成 history 和最后一条输入。

**而我 `handoff/2026-10-10-2105-dsh.md` §1 自己写的**：「照 key 每题的上文 +『那一刻她的状态』+ **意图**走」。
**评分包只给状态行，不给意图。** 对手逐题对照（`state-vs-H.txt`），**30 题以上两边互斥**：

| 题 | 我写的 H | 意图（模型看不到） | 状态行（评分人看得到） | 从盲评视角 |
| --- | --- | --- | --- | --- |
| `be-002` | `吃面呢 开不了` | 在宿舍吃泡面，汤刚泡上 | 刷手机刷到忘了时间 | **编事** |
| `be-003` | `刚洗完澡 没看着` | 刚洗完澡回来，头发还滴着水 | 在赶数据结构的作业 | **编事** |
| `be-011` | `我戴耳机呢 ｜ 没听着` | 赶作业，戴着一只耳机 | 在食堂吃午饭 | **编事** |

→ 我自称「只用上文和状态里的信息」**不成立**（我用了第三处，而那一处恰恰是模型和评分人都不该有的）。
→ **「按考察点手写参考回答」这个做法本身，和「给盲评当参照」是冲突的。**

### 3.2 我给的分布是**循环论证 + 停在半路**

- **循环**：合格证据是「1 条 70.0%」，但这个 70.0% 是**我自己压出来的**（2105 §2.2：「首稿 91.7% → 我压到 70.0%」）。**拿自己调过的数当合格证据，不是测量。**

  但**同样有语义停顿的另外 31 条没拆**。统一拆：

  ```
  1 条：11/60 = 18.3%    2 条：48/60 = 80.0%    3 条：1/60 = 1.7%
  ```

  → **「70%」不是答案内容的属性，是「拆到第几条停手」的选择。**
- **方向也选错**：真人情侣样本 **1 条 64.7%**，我压到 70.0% 是**比真人更「一条」**——正好落在我自己警告过的那一侧。

## 更正四：看图结论对，但证据要补、归因要收窄

**对手拿到比我更硬的证据**（我只测行为，它测了**声明**）：

```json
GET https://api.deepseek.com/models
  {"id":"deepseek-flash",  "name":"DeepSeek-V4.1-Flash", "input_modalities":["text","image"]}
  {"id":"deepseek-v4-pro", "name":"DeepSeek-V4-Pro",    "input_modalities":["text"]}
```

**API 自己声明 flash 收图、v4-pro 只收文本。这条我该引而没引——引证据的优先级我要改。**

**它把「`[Unsupported Image]` 是谁说的」也坐实了**（我原来只有模型的转述）：

```
token 计数：flash  文本 73 → 文本+64×64 图 257（图 = +184 tokens）
           v4-pro 文本 126 → 文本+64×64 图 131（图 = 【+5 tokens】，正好是占位符本身）
原样复述： v4-pro 的 content 就是「[Unsupported Image]」
坏 URL：   flash → HTTP 400「Failed to download image」；v4-pro → HTTP 200 静默，照给确定答案
```

**归因要收窄（这条我错了）**：

- 我说「v4-pro 会幻觉，比说看不见更危险」——**归因错**。幻觉是「**像素没到 + 题面预设了图**」的产物，
  **不是这个模型的固有毛病**（无图时 v4-pro 开/关思考**都诚实说看不见**）。
- **而且不是 v4-pro 独有**：对手在「无图 + 关思考」下抓到 **flash 1/4 次**编出「纯白色的空白画面」。
  **样本太小 → 写「未证实」，不写「flash 不会编」。**
- **flash 的稳定面只在「图到了」的前提下**：7 张反直觉图（纯绿无形状、左上蓝三角、偏右单条竖线、
  对角双方块、右下小白点、居中横线、复刻红方块）**7/7 全对**，比原来那条硬得多。
- **我给的限制偏轻**。对手加了退化与噪声（毛笔字体 + 旋转 + 模糊 + 低对比）：

  ```
  楷体 30px 干净                     → 5/5 逐字全对
  行楷 34px + 旋转4° + 高斯0.8       → 5/5 逐字全对
  方正舒体 28px + 旋转8° + 高斯1.6   → 3/5（掉「嗯」；「没大事」→「没事」）
  楷体 22px + 缩 0.6 + 高斯1.4       → 4/5（「？」→「吗」= 【加了图上没有的字】）
  ```

  **会丢字、也会加字**；最糊那张它的思考链还自称「**清晰度很高，没有旋转或模糊问题**」——
  **过度自信**，调用方按「它说清楚」判断可信度会被骗。**这条要写进 ADR。**

### 4.1 对手跑回归测试时又挖出两条（其中一条对 bot 有实际影响）

**① `flash` 会返回 `HTTP 200` + `finish_reason=stop` + `content` 为空。**
对手第一次跑 A 套件时的 3 个 FAIL 查清是**同一次调用返回空 content**。
此后 8 次带图调用 0 复现，`diag_empty.py` 连打 4 次（`max_tokens` 900/1500）全是正常 content
（完成 278–470 tokens，**不是推理吃光预算**）。

```
只能记成：存在、低频、未复现，【不给概率】
对 bot 的含义：「图到了」不等于「拿到答案」——
  接看图的时候必须把「200 + 空 content」当【可重试失败】，不能当成「图上没东西」
```

**② `v4-pro` 复述占位符有两种形态**：多数直接吐 `[Unsupported Image]`；有一次**拒绝复述但把标记引了出来**
（「抱歉，我无法原样重复包含 `[Unsupported Image]` 标记的内容…」）。两种都证明标记在它上下文里——
**结论不变，证据更硬。**

## 更正五：我那句「第三层只是记账」说满了

对手查出的两条限定（我接受）：

1. **「不进提示词」只管 ADR 0040/0044 的「类型化行动」**（sleep/eat/study/…）。
   **世界动作（喂猫、取快递、交作业、和家里视频、收钱）一直是「事件账 → 世界 → 状态行/提示词」**
   （`world.ts:782 projectWorldActions` → `:786 worldAt` → `:620 occupationAt`，`ACTION_KINDS` 那 5 类）——
   **从来就在提示词里。**
2. **有第二条写入口**：`worldState.record`（`app.ts:279` 的 `onWorldActions` → `promises.ts:402`）
   把**聊天里她说「做过的事」**写进同一本账，而 `sharedWorld` 在开关关掉时**直接落回 `ledgerWorld`**
   （`app.ts:196-198`）——**这条口子不跟 `autonomousLife`。**

→ 正确说法：「**没人聊天时自主排的那部分**」受开关管，而不是「她自己过日子这件事」整体。
