## 二、落地那一刻会变的四处（没有开关，都很小）

| 处 | 以前 | 之后 |
| --- | --- | --- |
| 他发分享卡片 / 转发 / 文件 | 她看到「[json]」「[forward]」「[文件]」，看不懂（真模型测过：装没看见 / 回「？」） | 她看到「[分享：哔哩哔哩《标题》]」「[转发的聊天记录]」「[文件：名字.docx]」，接得上话（ADR 0080） |
| 他引用她的某句话再回 | 引用被丢掉，她只看到「为什么啊」 | 她看到「[引用你说的：「…」]为什么啊」（ADR 0081；`reply.id` 和聊天记录的 id 对得上，探针验过） |
| 补回漏收消息时的引用 | 同上 | 同上 |
| NapCat 推来的「戳一戳」「撤回」通知 | 没人听 | 有人听，但开关关着时什么都不做（`pokes`、`recalls` 默认关） |

## 三、开关清单（每个默认关；括号是 ADR）

| 开关 | 打开后他会看到什么 | 我建议的验证 |
| --- | --- | --- |
| `readReceipts` 已读回执（0083） | 她回了话 / 看到了的那条显示「已读」；睡着时保持未读；看到了不回的真成「已读不回」 | 发一句，看有没有「已读」 |
| `reactions` 表情回应（0083） | 她看到了却不回时，给他最后一条点个赞 / 爱心 / 笑哭 | 要等她「看心情不回」才会出现 |
| `onlineStatus` 在线状态（0083） | 睡着「离开」、上课后一小时内「忙碌」、听歌「听歌中」、其余「在线」；变了至少隔 10 分钟才改，一天平均约 5 次 | 看她的状态栏 |
| `profileLikes` 资料卡点赞（0083） | 约 80% 的日子 12:00–21:30 给他点 1–5 个赞 | 看有没有赞的通知 |
| `pokes`（+`pokeBack`）（0079） | 他戳她，她回一句；约 40% 她隔 1–3 秒戳回去 | 戳她一下 |
| `typingStatus`（0077，含打字停顿） | 她打字的几秒，他那边显示「对方正在输入…」；长句偶尔停几秒再继续 | 发一句看有没有 |
| `recalls`（0082） | 他撤回一条她还没回的消息，她看到的是「撤回了一条消息」，会问「撤回什么了」 | 发一条再撤回 |
| `selfRecall`（0086） | 她打错字改口时约一半是撤回重发（大约 60 条回复一次） | 要等她打错字 |
| `pokeOut`（0087） | 聊天安静 90 分钟以上、最后一条是她的，约三成的晚上她戳他一下；一周最多 3 次 | 要等某个晚上 |
| `signature`：`dryRun` → `on`（0083） | 隔 3–5 天换个性签名（草稿存 `presence/drafts.md`，先看草稿） | 先看草稿 |
| `qzone`：`dryRun` → `on`，`qzoneVisibility`（0083） | 一周两三条说说（仅好友 / 所有人二选一）；先看草稿；有图的要你放图 | 先看草稿 |
| `bilibili`：`dryRun` → `on`（0084） | 一周最多 3 个，她看到真视频，说一句真实感受，再发真链接 | 先看草稿 |
| `rhythm`（0075） | 回得慢一点：热聊第一条中位约慢 4 秒，长句打字更久；回之前有「看 + 想」 | 感受节奏 |
| `shortReplies`（0024 的 10-19 调整，候选 5） | 约一半的轮次只回很短的一句（老样子 35%）；难受 / 说担心的事 / 问起她的朋友时不加 | 看一天的聊天 |
| `stickers`：`collect` → `send`（0063） | 约 12% 的轮次带表情包（真人朋友约 9%）；要你先看货架 `shelf.html` | 先看货架 |
| `npcAsks`（0061） | 闺蜜约她、变卦、她推掉成了她日子里的事（卡里再加 `newsKinds` 才会主动说） | 看一周 |
| `festivals`：`notes` → `greet`（0076） | 她知道节日（除夕、平安夜、情人节……）；`greet` 再在那天主动说一句 | 等下一个节日 |
