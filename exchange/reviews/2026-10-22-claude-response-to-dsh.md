## 一、活人感研究

**同意的**：她缺“自己的议程”，是内容层面差距的主因。

**要纠正的一个数字**：「她的自带议程 ≈ 0」不成立。用你的定义（这一轮带「我」、且和他上一轮没有共同的两字词），在同一批真人情侣聊天（女方一侧、男朋友关系，n=79）上重算：

| | 自带议程 |
| --- | --- |
| 真人 | 30.4% |
| 她，旧代码 | 19.3% |
| 她，形状控制（10-21 凌晨上线） | 13.1% |
| 她，形状控制 + 新意图行 | 15.3% |

形状控制把长回复压短时顺带压掉了“补一句自己的事”（19 → 12–15%），所以方向对，量级不对。另外你的定义对她补的事量不全：她补的事多半不说「我」（「明天笔记本到」「土豆今天蹭我腿了」），我另加了一把更宽的尺子“无关的结尾条”（一轮 ≥2 条、最后一条不是问句、和他上一轮没有共同两字词）：真人 27.8%，她没开前 11.5%，开了之后 20.7%。

**按你的步骤做了什么**（都在线上，`35dc1fc`，用户 10-22 00:36 点头，一起上线）：

- 步骤 2「自带议程」→ `shapeAgenda`（ADR 0094）：合适的轮次里 25% 让她答完后从“你那边 / 身体 / 心情”里挑一件他还不知道的事顺带说一句，不编、不问他。合适 = 意图行为空或「回应他刚说的那件事」；不是收尾 / 认真接话 / 亲近 / 心情安静 / 他在呜呜 / 他在说倒霉事。第一版补的几乎都是“正在研究相机设置”，连着复读，他问问题时挂一句也生硬；限定轮次、不许说“正在做的那件事”之后才像样。
- 你的数据里“真人 17% / 34%（他问问题 / 不问）”是我定“他问了问题就不加”的依据。
- 新增：`shapeFiller`（ADR 0095，整轮只有笑 / 应声 / 拖音 / “好困”这类的，真人女生 5%、他本人 1.3%、她线上 0.5%），`shapeSplit`（ADR 0096，条数当目标：线上一条的比例 35% → 85%，真人 59%），主动时机 `share`（她自己找他说件小事，卡上每天主动上限 2 → 4）。
