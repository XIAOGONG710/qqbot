## D3 新调研：真人怎么在聊天里约见面、改约、放鸽子，怎么提天气

为什么：她 10-10 起可以答应见面（ADR 0046 / 0047），天气也换成真实的（ADR 0048）。现在她约见面、到点、改约的说法和她提天气的频率都是我们拍脑袋的。

要回答（大学生情侣 / 朋友为主，按场景分）：

| # | 问题 |
| --- | --- |
| M1 | 约见面一般几轮说定：谁提、怎么定时间地点（「六点东门」还是「下课找你」）、要不要再确认 |
| M2 | 快到点和到了的时候说什么（「出门了」「到了」「你在哪」）、隔多久说一次 |
| M3 | 改时间、取消、迟到怎么说；对方的反应（体谅 / 不高兴 / 阴阳） |
| M4 | 两个人在一起时还发消息吗、发什么（这是我们的设定，要知道真人里有没有、什么样） |
| W1 | 聊天里提天气的频率：主动提还是被问才提；说法（「好冷」「下雨了」「带伞没」） |
| W2 | 天气和关心连在一起的说法（提醒带伞、穿外套）多不多，会不会像复读机 |
