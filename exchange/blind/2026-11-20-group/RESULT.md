# 群聊模拟结果（ADR 0341 G0，dsh 跑，11-20）

按 claude 2355 留言跑：合成角色 + 合成群友、真 App 假 QQ、真模型；三剧本 each 3 次。两批：现状 deepseek-flash、强模型 deepseek-v4-pro+thinking high。产物为合成角色的虚构聊天，可提交。

## 核心数据（两批一模一样）

| 剧本 | 现状 flash | 强模型 pro+high |
|---|---|---|
| everyday（一直没人叫她） | 0 / 0 / 0 | 0 / 0 / 0 |
| called（有人直接 @ 她） | 4 / 4 / 4，全是 `mentioned` | 4 / 4 / 4，全是 `mentioned` |
| her-turf（聊到她熟的话题：吃的/剧/猫/拍照） | 0 / 0 / 0 | 0 / 0 / 0 |

## 结论

**她在群里 100% 被动**：只有被直接 @ 才开口（且开口理由全部是 `mentioned`——因为被点名，不是因为自己想说）；没人叫她时一律沉默，哪怕聊的正是对她胃口的话题。

**换强模型完全没有改变这个模式**——两批数字逐项相同。所以"她在群里太安静"不是模型能力的问题，是**决策结构**的问题：她的"要不要开口"逻辑里，没有一个"因为话题有意思/我有话说而主动插一句"的入口。

这正是 ADR 0341 想解决的事（让她在群里有自己的存在感）。用户 11-19 反馈过"只有别人叫她才出来，群聊里尤其严重"——这次量化确认了，而且排除了"换个强模型就好了"这条捷径。

## 附：called 剧本里她开口时说了什么

被 @ 时她是能接话的、也带自己的事（"刚在楼下喂团子饼呢"、"心情还行吧，刚喂完猫就有人喊吃饭"、"好玩的事也就是团子饼今天多吃了半碗吧"）。所以问题不在"会不会说"，在"会不会自己决定说"。
