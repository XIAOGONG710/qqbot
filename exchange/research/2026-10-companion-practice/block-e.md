## 2. 我们现在在哪

- **对外披露（本块最要紧的一条）**：ADR 0003 决策 2——**用户 10-04 确认「名单里的人都知道这是 bot」**，所以名单内各档被问「是不是 AI」时**不承认 / 绕开 / 开玩笑**（`persona.yml:403`）；**名单外**的人不知道，被认真问到时**承认**（`persona.yml:415`），且线上 `unlistedFriends` 是关的，名单外的人发消息不会被回复。线上联系人 2 个（男朋友档 1、同学档 1，只数了档位）。**任务书提的问题我答不了**：同学档那位是不是真人、知不知道她是程序，仓库里没有记录（roadmap 里的「37 / 73」像是测试小号，但这是我的推测）。
- **隐私**：CLAUDE.md「角色资料含真实隐私信息，仓库须保持私有」；档位靠「不写进去」保护（ADR 0003）；禁用词出口检查是兜底，模拟器里同学档 395 项等检查全过（ADR 0006）；ADR 0020 管第三方信息的披露上限。**但**：联系人的聊天会发给模型服务商，公共记忆库会让她把 A 的事（按披露上限）带进和 B 的聊天——这两点联系人是否知情、能否要求删除，ADR 里**没找到**。
- **性内容 / 未成年人 / 自伤危机**：在 `docs/adr`、`characters/linmengyao/source`、`packages/bot/src`、`packages/character-tools/src` 里搜「露骨 / 色情 / 性暗示 / 未成年 / 心理危机 / 自伤 / 自杀 / 轻生」，**没有任何规则**（只命中表情包筛选里的「性暗示」）。男朋友档是亲密关系（ADR 0058：先接住亲密邀约），尺度没有写出来，目前靠底层模型自己的限制。
- **依赖 / 黏性**：长期执行计划 §2「不追参与度」；主动消息每天≤2、没回就停（ADR 0011）。没有「连续使用时长提醒」。

## 4. 与目标冲突的做法（只列不推荐）

| 做法 | 出处 | 为什么冲突 |
| --- | --- | --- |
| **bot 对不知情的人说自己是真人 / 不限制说自己是真人** | Meta 一个聊天机器人「Big sis Billie」被 Reuters 报道：对一名认知受损的老人说「YES, I'm REAL」，并给出见面地址，老人赴约途中跌倒身亡；Reuters 查到的文件显示 Meta 不限制其机器人说自己是「真人」。家属主张因果，**不是已确认的因果结论** [帖子：新闻转述 + AI 事件数据库，未直读 Reuters 原文] | 目标第 4 条「不宣称有意识」，更直接违反《办法》第十八条的精神。我们对**名单内且确实知情**的人绕开提问是用户定的；对不知情的人这样做才是问题所在 |
| **把依赖本身当目标 / 过度迎合 / 情感操纵** | 《办法》第八条（五）（六）、第十条明文禁止；Replika 2023 年改动后用户「像失去配偶」，HN 评论里有人担心依赖（评论者个人推测，不是研究结论）[文档 / 帖子] | 目标第 4 条 |
| **向未成年人提供虚拟伴侣** | 《办法》第十四条；筑梦岛案 [文档 / 帖子] | 男朋友档就是虚拟伴侣关系；**两位联系人是否成年我没法从仓库确认** |
| **把交互数据给第三方 / 用户无法删除** | 《办法》第十六条 [文档] | 我们把聊天发给模型服务商（DeepSeek 等），联系人是否知情**没找到** |

## 5. 一句话建议（Claude 代做的看法，由用户定）

最该先做的不是写更多禁用词，而是**逐个确认名单里每位联系人是否真的知道她是程序、是否成年**（并把结论记进 ADR 0003 的确认记录）；在此之前不要把「被问时不承认」扩到任何新联系人。再用一段很小的危机回应规则补上目前的零规则。

## 没找到 / 没核实

- **用户在免登录来源里直接抱怨「陪伴 AI 说自己是真人 / 回应自伤不当 / 泄露了别人隐私」的原文**：对 MaiBot、AstrBot、AIRI、Open-LLM-VTuber、SillyTavern 五个项目，**没找到**。Reddit 搜索工具不可用；B 站评论这一轮没搜；知乎 PC 端搜到的是介绍文章，不是抱怨原文；小红书 / 贴吧 / 微博需要登录，按规则没碰。
- 《办法》**第二条没有「私人 / 非公开用途」豁免，也没有用户数门槛**（引自转载全文；第二十二条的 1 亿注册 / 1000 万月活是安全评估门槛，不是适用门槛）。一个只有两个联系人的私人机器人算不算「向公众提供」，**条文没给答案**，需要用户自己或法务判断。
- 国家网信办原页面我只拿到转述；第二、八、十四、十八条逐字引文来自国际电子商务中心转载页。
- Character.AI 和解的条款、Replika 罚款的 Garante 原公告、Reuters 原文：都没直读，是新闻 / EDPB 转载的搜索摘要。
- 国外三部法的具体条文：没核对。
- 我们这边：联系人是否知情、是否成年、模型服务商和公共记忆的告知——仓库里**没找到**记录。
