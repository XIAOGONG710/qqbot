## 【表演型冷淡】点名

指：为了「像人」而**随机**装忙、装生气、装没看见（原因不在她的身体、日程、关系里，而是掷骰子或用户拨盘）。**这一类一律归「与目标冲突」，不写成可借鉴**（第 4 节）。判别口诀：触发条件是不是来自她账里的事实？是 → 有原因（哪怕延迟长短带随机）；否 → 表演型。

## 2. 我们现在在哪

- **档位 = 隐私可见性，且是作者指定的静态量**：男朋友 / 闺蜜 / 女生熟人 / 熟人 / 同学 / 陌生人 / 未验证陌生人，各档能看到的资料靠「不写进去」保护（ADR 0003、0020）。**没有「亲密度随聊天推进、随冷落降温」**；动态阶段（F）作者暂缓（`2026-10-07-life-engine/decisions.md` 决策 2、ADR 0024）。
- **晚回的原因全在作息里**（ADR 0007、0031）：空闲马上看到；机房课 2–6 分钟、硬课 5–20 分钟；睡觉到起床后才回，男朋友档连发 3 条才被吵醒、一晚最多一次；洗澡时看不到（0031）。**§7 白纸黑字「不做『故意不回』」**，唯一不回的是她收尾之后对方只回附和。
- **情绪有来处**（ADR 0028）：当下底色从身体、现实压力落地，**不猜测正负**；未了事实产生余波但**不存情绪标签**，跨天不存「委屈」；修补 / 安慰 / 亲近只带来**三轮**余温，之后消退。
- **亲密**（ADR 0058）：只对男朋友档开；他递出亲密信号先接住、再留一点嘴硬。
- **拒绝 / 改约**（ADR 0046、0047）：非男朋友档推掉见面的理由是她自己的分寸（有男朋友、怕麻烦、对陌生人戒备）；男朋友档「想去就答应，有事就推」。**NPC 的改约 / 拒绝 / 迟到另做**（0033、0044、0056 都写「以后另开」）。**不完全配合**（走神、答非所问、拒绝）作者 10-06 定「先不放开」，决策 2 的顺序是「先有来源，再有拒绝；先证明，再放开」。
- **没有的**：嫉妒、闹别扭的**起因**（只有道歉之后的软化）、她因自己的事**改约**。
- **grep 无命中、没读全文**：睡觉 / 上课时对方发紧急消息是否绕过晚回——`docs/adr` 和 `packages/bot/src` 里搜「紧急 / 救命 / 自伤 / 求助」没有相关规则（放 E 块再核）。

## 3. 各做法对我们的代价

| 做法 | 实现量 | 风险 | 和哪些 ADR 冲突 |
| --- | --- | --- | --- |
| ① 分数账本 + 阶段 | 大 | **档位在我们这儿等于隐私边界**，自动升档 = 自动多露资料；账本奖励「来消息」「回主动消息」，不来就降温，等于把黏性写进关系；可借鉴的只是**形式**（原因码必填、事件去重、每日上限、阶段迟滞、一次最多动一档）| **0003、0020**、决策 2、目标第 4 条 |
| ② 模拟情绪驱动延迟 | 中 | 情绪由对话语气推出，会误判（大写 = 生气？），**无故冷淡**；「幽灵窗口」的原因不在她的身体 / 日程 / 关系里 | **0007 §7**（不做故意不回）、0028（不猜测正负）|
| ③ 日程忙闲延迟 | ≈0（0007 / 0031 已更细）| 增量只有一个：**紧急绕过**（见上，待 E 块核）；其余我们已有 | 无 |

## 4. 与目标冲突的做法（只列不推荐）

| 做法 | 出处 | 为什么冲突 |
| --- | --- | --- |
| **【表演型冷淡】：用户拨盘设定的心情 / 傲娇强度** | EchoText 的「心情」拨盘 + 强度滑块；self_learning 的 `/set_mood` [文档] | 冷淡、生气由**人为拨出来**，和她的身体、日程、关系无关。这是本轮读到的最接近表演型冷淡的实现 |
| **愤怒 → 幽灵窗口（自动延迟回复）** | EchoText [文档] | 原因来自对话语气推出的**模拟情绪**，不在她的账里；若情绪同时被拨盘覆盖则与上一条合流。**待判**：用户若认为「对方先说了难听的话」算关系原因，则属有因的闹别扭，但要有明确起因事件（对照 private_companion 的 `hurt` 事件 + 道歉衰减） |
| **好感度随「来消息 / 回主动消息」上涨，随不活跃自然降温** | private_companion [代码：原因码别名、`apply_natural_relationship_decay`] | 「用才涨、不来就降」是典型的参与度回路，制造「不来她就疏远」的压力（目标第 4 条）|
| **「焦虑求安抚」类主动触发** | EchoText 的 Anxiety Reassurance 触发（「情绪状态显示角色需要安抚时」）[文档] | 用角色的焦虑换对方的回应，是目标第 4 条禁的「制造焦虑 / 情绪勒索」 |
| 永远顺从、从不拒绝 | 研究图 `research-map.md` 第二节已列（Project Sue），不重做 | 目标第 3 条 |

**没看到任何一个项目明说「随机装忙 / 随机已读不回 / 随机生气」。** 搜 GitHub（AstrBot、NoneBot、Koishi、SillyTavern）只找到上面几条；这不等于不存在。private_companion 忙闲闸门的延迟长度是 `random.uniform`，但**触发条件是日程里的「忙」**，按判据不算表演型。

## 5. 一句话建议（Claude 代做的看法，由用户定）

我们「晚回都有原因、不做故意不回」已经比读到的所有项目都干净，**不要引入自动升降档和模拟情绪冷却**；缺的是让**拒绝、改约、闹别扭有来源**——先让身体 / 日程 / 关系事件能产生理由，再按决策 2 的顺序逐条放开。
