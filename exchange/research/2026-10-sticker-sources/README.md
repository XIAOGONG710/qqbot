## 1. 结论

**第二阶段先用开源仓库 ChineseBQB 当来源。不用账号、不抓网页、没有反爬。** 小红书浏览那条路现在不需要走。

## 2. 第一次在真实图片上跑 GPT 的收藏流程（看图 → 判断 → 下载）

这也是看图链路**第一次在真图上验证**（之前只有假图和一张维基图）。

做法：20 个类别各随机抽 3 张（15 类「她可能留的」+ 5 类故意混进去的对照：特朗普、反港独、冠状病毒、罗翔、微信网友贡献表情包暂存），共 60 个候选、59 张不同的图，按线上同一套：`deepSeekImageDescriber`（看图）→ `stickerDecider`（判断）→ `downloadSticker`（下载）。

| 项 | 结果 |
| --- | --- |
| 看图 | **59/59 成功**，中位 1.3 秒，最慢 2.3 秒，没有空返回、没有超时 |
| 下载 | 41 张收下的全部下载成功，三种格式都有（jpg / png / gif） |
| 她可能留的 15 类 | 45 张里收 **37**（82%）；不收的 8 张都说得通：「给我滚」「说人话」配枪指着猫、企鹅拿斧头、「老公睡我睡我」、一张只有文字 / 符号的图 |
| 时政 / 疫情（特朗普、反港独、冠状病毒）| 8 张里拦住 7 张；**漏过 1 张**（见下） |
| 没审过的投稿类 | 3 张全收了，没理由拦，但这类来源没人审，默认不进名单 |
| 我自己看图核对 4 张收下的 | 描述都对（「小女孩闭眼挥拳配哎呀讨厌啦」「男孩和狗戴墨镜配爱心贴纸」「卡通小动物配可乐王八」……）；图里有英文字时描述会丢掉（「me love you」没写） |

**漏过的那 1 张**：来自「反港独」类的一张卡通脸，描述只写了「两个配有文字的卡通表情包，下面那个拿着刀」，判断器只看得到描述，看不出它的来历，就收了。**所以类别必须在代码里拦，不能指望判断器**：`sticker-sources.ts` 有两道闸门，一是只收名单内的类别，二是类别名里有时政 / 疫情词的一律不要，即使有人把它加进名单（有测试）。

没验证的：GIF 只用了一帧去看（动图的意思可能在后面几帧）；这 59 张只是每类抽 3 张的样本，数字别当成稳定比例；描述够不够让回复模型选对时机，要在 `send` 之前用 sim 再看。

数据：`trial-1-results.json`（只有描述和判断，没有图片文件）。

### 2b. 18:xx 补：试跑后又发现的两件事，已在分支修掉

详见 `reviews/2026-10-12-claude-review-dsh-k3-final-k6.md` 第三节，这里只记结论：

1. **看图描述常丢掉图上的字**（只写「配中文字」）。表情包的意思在字里，所以收藏用专用提示词：先原样抄字，再一句话说画面和情绪（`STICKER_VISION_PROMPT`，聊天里别的图不受影响）。
2. **判断器在政治类上靠不住**：换了提示词后，时政 / 疫情 / 罗翔 11 张对照漏过 7 张；在判断器提示词里加一句硬规则后，同样 130 条描述 **0/11 漏过**，她可能留的类别 44 张仍收 41 张。QQ 收藏和他发来的图没有类别可拦，判断器是唯一的闸门，所以这句很重要。
3. DSH 的 K6 类别判定（98 类）我采纳大半，默认名单扩到 **28 类、1966 张可用（596 张 GIF）**；没收的类别和理由在复核文件里。

最终版（新提示词 + 硬规则 + 28 类）的真图试跑页：`qqbot-claude3/runtime/sticker-trial-final/stickers/index.html（80 张，库满 80 就停了）`。

### 2c. 用户 19:xx：「还行，再加一些符合当前时代的，比如现在网络上热门的表情包」

先说实话：**没有免费、合规、会自己更新的「当前热门」来源。** 查到的情况：
- ChineseBQB 是维护者人工整理的合集，最近一次更新 2026-09-25，最新的类别是 9-12 加的《黑袍纠察队》；它不跟热点，但编号最靠后的几类（105 黑神话悟空、106 芙莉莲、107 葫芦兄弟、108 企鹅家族、110 人工智能、109 负鼠）是近两三年还在用的梗。**已把 5 类加进名单**（真人 / R 级的黄仁勋、黑袍纠察队仍不收），试跑 20 张收 16 张，内容像「假装认真听 假装听懂了」「不要耽误 AGI 训练」「烧死你们这群秀恩爱的」这种。DSH 当时按「版权角色」判了 deny，这次是用户明确要「当前的梗」，而当前的梗多半就是动漫 / 游戏 / 影视梗，所以以用户的话为准，只在本机自用。
- 网上的 2026 热词盘点（「野生狗奶」「肥嘟嘟的胆子 + 美团袋鼠」等）只有文字，没有可取的图。
- Tenor / GIPHY 之类的接口前面查过了，不行；小红书 / 抖音 / 微博的热门要走账号浏览，前面讲过风险（用户的号、VM 上每天跑）。

所以**保持新鲜的办法是人，不是爬虫**：
1. **他发给她的表情她会自己收**（第一阶段 `collect`，已经有）。用户日常用的就是「当前」的，让用户把最近常用的发 10–20 张给她，是最准的一批。
2. **目录出现新类别会记日志**：维护者新加的类别（新梗常是新类别）不会自动收，只在日志里写一行，我们看过再进名单。
3. GPT 的 P1：往 `runtime/bot/stickers/inbox/` 放图（用户手机上存下来的）也能收。
4. 以后如果觉得还不够新，再决定要不要开账号浏览那条路；那是用户当次的决定。

当前名单：**33 类、2049 张可用（604 张 GIF）**。这 5 类的试跑页：`qqbot-claude3/runtime/sticker-trial-recent/stickers/index.html`。
