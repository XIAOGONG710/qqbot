## 它现在是什么（和 10-24 不是一个东西了）
- **Maisaka 推理核心**（1.0.0，2026-06-12 起「Agent 式工作」）。处理流：消息 → **判断时机** → **规划动作** → **检索记忆与上下文** → **组织回复** → **反馈与沉淀** → 长期记忆（再回到上下文）。规划器在「等待 / 回复 / 调用工具 / 发图 / 保持沉默」里选；插件工具不一次全给，先 `tool_search` 在“延后工具池”里找、下一轮才可见；有 `subagent` 工具（1.3.7）。「思考力度」（0.12.0，2025-12）动态控制回复的时间和长度；「快速反应模式」（1.3.6，10-22 转正）新消息到达时可以打断思考 / 输出并重新推理；「动态触发」估计每批消息的回复可能性并动态调门槛；消息防抖四档（关 / 快速 / 自然 / 沉稳）。**没核实：记忆检索是模型自己调的工具，还是流程里自动做的**——文档只说“检索发生在上下文这一步”。
- **A_Memorix 记忆引擎**：段落 / 实体 / 关系 / 来源 / 向量 / 图谱放在一起；人物画像、事实、关系都带**来源证据**，WebUI 里看得到「证据链」和「纠错历史」，有「纠错闭环」；检索融合向量 + 图 + BM25 + PageRank + 阈值，目标是“无关记忆别进回复”。**记忆生命周期（1.1.0，2026-07-22）：衰减、冻结、恢复、保护、回收站。**全局共享记忆 / 记忆共享组。长聊压成摘要（中期记忆）。
- **表达 / 黑话学习**：场景匹配 + 反馈沉淀 + 合并相似行为；检索用“表达意图 + 向量”，MMR 做多样性重排（别老用同一条）；「精选」集合；快速档（加权随机直接注入）/ 精细档（意图 + 嵌入召回 + LLM 筛）；黑话不再提取带名字的内容、不学平台通知和机器人自己的消息。
- **做梦**（2025-12，默认关）、**人设与行为风格分开**（1.1.0）、自己的消息始终标记。
- **删掉的**：「情绪特点」选项（1.3.7，没说原因）、回复效果评估（1.3.12，没说原因）、「回复丢失提醒重试」、私聊频率设置（换成“私聊暂停回复”）。**更新日志里没有反思、没有日程。**

## 值得学的两件（按和用户目标的相关度）
1. **让她自己决定想起什么（按需回想），而不是代码按相关度塞进去。** 现在 `diaryInsights` / `readingTakes` / `openQuestions` / `traces` 都是“≥2 个共有二字词才放进提示词”：是代码替她决定该想起什么（今天已经看到两个后果：泄漏到无关话题 1/84、留痕串号）。麦麦的方向是规划器用工具取。做法设想：回复前她可以写一个 `<<回想：关键词>>`，系统用她自己的记忆 / 日记 / 想法查一遍，结果放进第二次生成（只在她要的时候发生，所以平时不多花一次调用）。能用现有的模拟器 + 探针对比：问她自己的话（d9 / d11 / d12）、开 / 关按需回想，数“同一个模子”的比例、有没有她自己具体的东西、有没有把不相关的东西带出来。**注意这不是新增斜杠指令**（CLAUDE.md 的“不许新增指令”管的是 `/xxx`）；但它是新的提示词块，要有开关、默认关、写 ADR。
2. **记忆生命周期（衰减 / 保护 / 回收站）。** 一个会忘的、有些事永远记得的、删了还能找回的记忆，比“全记着”更像一个生命，也不需要往回复提示词里加任何一句话。可以先做最小的一层：给我们自己的各个回路统一一个“显著度”（新近 × 重要 × 被想起过几次），超出上限时按它而不是按先后丢；再加“保护”（用户或她标记的永远不丢）和“回收站”（丢的先进回收站 30 天）。Hindsight 本身怎么衰减我没查，要先看它的接口。
