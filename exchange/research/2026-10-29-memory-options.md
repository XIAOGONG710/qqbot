# 记忆改造的四个选项：作用、对她意味着什么、决定（2026-10-29）

来源：`research/2026-10-29-eval-baseline.md` 的数字 + `大肥鱼研究` 语料（1,575 条谈记忆，去重 819 条）
决定：**做 2；3 不做；1 次之；4 等 ADR 0176 落地后再看。**

## 1. 遗忘曲线（替代 7/30 天硬阈值）

- **作用**：`fading.ts` 的 `clarity()` 现在返回三档（清楚 / 记个大概 / 想不起来），是开关；改成 `w = e^(−Δt/τ) × 重要度`，作为**分数**参与召回排序。第 29 天和第 31 天不再突变。
- **对她**：忘得更像人——模糊而不是断片。但衰减只是降权，**东西还在库里**，她可能在被问起三个月前的旧事时掏出细节，真人不会。
- **取舍**：衰减到阈值以下就**不注入**（当它不存在），只在出现实体名时“突然想起来”。
- **难度**：S。**决定**：做，但排在第 2 之后。

## 2. 首轮铺底（开场整块注入）

- **作用**：现在每轮都是拿他这句去查，隔夜第一句和昨天的记忆没有词面交集 → 查不到 → 不注入 → 像失忆。改成：离开超过 N 小时，第一轮先塞一段固定预算的“她昨天过的日子”，再叠加检索。
- **对她**：醒来有底色，像个睡过一觉的人，而不是每次开机重新投胎。**最大风险是模板化**——画像每轮都在，她会开始背人设。
- **三条约束**（用户 10-29 认同）：① 只在离开 **6 小时以上**注入；② 画像 **≤300 字**；③ 画像**由她自己的日记生成**，不是我们写的一段简介。
- **难度**：S–M。**决定**：做。**实现方式：挂在现有 `lifeInPrompt` 下，不新增开关**（计划 §2.2：消融没做完前不加新开关）。

## 3. 门牌（记忆回原文）—— **不做**

- **作用**：记一条 `记忆 id → 片段原文`，她 `<<查>>` 命中时带回原文。
- **对她**：会从“记得”变成“举证”——真人记的是感觉，不是原句。她一旦能精确复述，就会变成“我查一下记录”，还会拿时间戳去算账。附带风险：把别人的话贴出来。
- **决定（用户 2026-10-29 23:10）**：**不做。** 除非将来能保证她只“心里有数”、不“嘴上举证”，否则不复议。
- 复用建议：这条的价值主要在“她自己心里有底”，如果以后要做，只让她读到、不许引用原句，并加一道“复述检查”。

## 4. 单一权威源

- **作用**：记忆只有一份，多个入口只读同一份。ADR 0176 已把“读哪个库”收窄，但仍是两套写入路径。
- **对她**：不会 QQ 里记得、桌面里失忆——这正是用户要的“同一个她”。风险：一处错全处错；也会抹掉自然差异。
- **取舍**：**记忆统一，语气按场合**（QQ 短句、桌面可长一点），别一起统一。
- **难度**：L。**决定**：等 0176 上线后再评估还剩几处。

## 顺序

2（首轮铺底，挂 lifeInPrompt）→ 1（遗忘曲线）→ 4（看 0176 之后）→ 3 不做。
