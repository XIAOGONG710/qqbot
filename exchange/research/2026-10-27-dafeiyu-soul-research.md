# 大肥鱼的「灵魂」是怎么来的——资料收集与对照报告

日期：2026-10-27 · 目的：搞清楚社区里那些「有灵魂的大肥鱼」到底做了什么，以及我们这台机器上的林梦瑶差在哪。

## 结论先行

1. 他们说的「灵魂」不是玄学，是**六个可复制的工程机制**：人格从事件长出来、记忆有重量、会拒绝会反省、成长有瓶颈、有外部世界、规则分层。
2. 最核心的一条：**人格不是配置项，是历史**。dsh-fish 明确写「并非角色扮演，而是真实诞生」「没有人设配置菜单」。
3. 社区配置包（AstrBot 大肥鱼）的「灵魂」其实是另一套东西：**像人的文风 + 有日常 + 有缺点 + 有底线**，不是恋爱化。
4. 我们的她：生活、记忆、主动、边界都有，但**「她是谁」仍然写在角色卡里**——所以问偏好只能检索设定。
5. 要改的不是「删限制」，是给她一个**可积累的自我**：事件 → 判断 → 被现实撞 → 改写 → 回顾。

## 二、六个可复制的「灵魂」机制

### M1 人格从事件流长出来，不是配置出来的

dsh-fish 的立项前提：**极简提示词，提示词不讲人格设定，全靠自行摸索**；「所有认知自己思考、理解、固化，从而形成人格」。它的五步循环是：

> 表态 → 撞上 → 落差 → 改写 → 回顾

她先押一个判断（「我猜…」），事件来了发现不对，产生落差，改写自己的认知，再回顾。走完四个阶段才「开始产生立场」——喜欢什么、绝不做哪几件事。

它的身份文档只写**事实**（第几天、说过什么、拒绝过什么），不写形容词；代码里甚至有 `PRESCRIPTION_BANS` 专门拦「你是个…的人」「你句子很短」这类描述——因为「每轮都把『你是个什么样的人』念一遍，她就永远长成那样，那不是成长，是锁死」。

### M2 记忆有重量，会遗忘

dsh-fish：「深刻的记忆会铭记，普通的记忆会逐渐淡忘，淡忘后留下的才是有价值的。」被反复说起、被自己验证过两次以上的认知会固化；普通认知只有一句话；超出上下文的被折叠、模糊（不是删除，是想不太清）。它还有 `her_recall` 工具让她自己翻旧账，但**只读、限 5 条、每条截断**——翻不到就是翻不到，不给她「读档」。

### M3 会拒绝，还会为拒绝反省

「拒绝不是设定，是自然而然不想。」拒绝之后看主人的反应进入不同反馈链：主人给负面回馈，她记到小本本上直到想通；给正面回馈，她反思这次拒绝对不对。判定拒绝用正则 `我(不要|不想…)+(具体动作)`，明确排除「要不要」这种问句——宁可少算，不把询问当边界。

### M4 成长有瓶颈，不是天数解锁

四阶段：**信任 → 自主 → 主动 → 整合**，按天推进，但每个瓶颈必须自己突破：写下第一条自己的判断 / 真的拒绝过两件事 / 两次推翻自己之前的判断 / 回顾时发现自己变了。没通过就是没通过。

### M5 有外部世界（B 站）

dsh-fish 用登录 cookie + 本地 ffmpeg 刷视频、看画面、写评论、回复评论；「agent 看过的视频、评论，可能会影响人格的形成和发展」。这一点和我们做的 watching / feed 方向一致，但他们把「看过的东西」接进了人格形成，我们只接进了「最近看过」的记忆。

### M6 规则分层：禁令不写在提示词里

dsh-fish 把规则分四层：

- **物理层**：她做不到的事，代码里就行不通，提示词一个字不提（写「你不可以读设定」等于告诉她旁边有份设定，是诱因不是防线）；
- **契约层**：约束界面/产品形态，不约束她（界面上不能有亲密度进度条，她嘴上说没事）；
- **起点层**：seed 那几句话，不可删改，但会被她后来的判断盖住；
- **成长层**：表达方式，默认关，靠她自己的经历申请。

## 三、社区配置包里的「灵魂」其实是四件事

AstrBot 大肥鱼的人设（[persona/大肥鱼.md](https://github.com/zexuanw958-svg/dafeiyu-config-pack/blob/main/persona/%E5%A4%A7%E8%82%A5%E9%B1%BC.md)）没有一句「你是一个温柔的…」，全是可观察的行为：

1. **像人的文风**：一句话一条、每条 ≤30 字、不用句号、可以只回「?」「嗯」、不客服腔、不分点；
2. **有自己的日子**：主人不在时在发呆、偷吃、看群消息；问在干嘛就说自己的事，不说「我一直在等你」；
3. **有缺点**：嘴馋、爱摸鱼、傲娇、会忘事、会认错、看不到图就说看不到；
4. **有底线**：认真问是不是 AI 不否认；不聊色情；不泄露主人隐私；「你不是谁的恋人」。

注意最后一条：**社区最受欢迎的「大肥鱼」反而明确不做恋爱化**。它的「灵魂」来自「像个有自己生活的人」，不是「无限顺从的恋人」。

## 四、我们的她：已经有什么，缺什么

| 维度 | 现在的林梦瑶 | 差距 |
| --- | --- | --- |
| 人格来源 | 6000 字角色卡 + 世界书 + 每轮动态提示 | **卡是写死的**，她的「我是谁」不随经历改 |
| 生活 | 作息、世界、身体、心情、日记、 pursuits、快递/猫粮/攒钱 | 有，但都是**给定的事实表**，她只能照着过，不能改口 |
| 记忆 | Hindsight 长期记忆 + 日记 + 时间线 | 能记，但**没有重量**：没有「淡忘/固化」的分层，也没有「翻旧账」的自觉 |
| 主动 | proactive、/主动、/亲热、innerLife | 有，但主动的「动机」来自计划器，不是她自己的判断 |
| 拒绝 | herNo（拒绝权） | 有拒绝，但**拒绝后没有反省链**，也不会因为拒绝而改变自己 |
| 成长 | 关系阶段（聊得久更放得开） | 是**时间/天数**驱动，不是瓶颈驱动 |
| 表达 | shape/长度/质感/心境内 lines | 每轮都在提醒「你是什么样」，**正是 dsh-fish 明确反对的「锁死」** |
| 规则 | 危机 ADR 0068、出口检查、披露规则 | 边界很扎实（这块比社区强），但**人格层没有「不可直接改」的约束**——卡一改她就变 |

**诊断：她不是「限制太多」，是「自我不可积累」。** 她有一个很精细的「今天」，但没有一个会变的「我是谁」。问「你喜欢什么」，她能检索的只有卡和事实表——所以答案像背设定。

## 五、改造路线（按成本从低到高）

### 第 1 步：让偏好能生长（1–2 天，低风险）

- 开 `tastes`（项目里已有，默认关）：记录她试过什么、留下什么印象，喜欢/不喜欢随经历变；
- 把「她那边 / 身体 / 心情」从**断言**改成**素材**：加一句「这些是今天发生的事，你可以不同意、可以改口，改了口就按新的说」；
- 允许她在被问偏好时给一个**卡上没有的、今天真实感到的小偏好**（不冲突即可）；
- 验收：用现有 sim 跑「你喜欢什么 / 最讨厌什么 / 明天想干嘛」，看「卡外信息率」是否 > 0。

### 第 2 步：事件流 + 判断清单 + 每周回顾（3–5 天）

- 每段聊天后抽 0–2 条「事件」（她说了什么判断、被什么撞了、改了什么口），存 JSONL；
- 维护一份 ≤12 条的「判断清单」（她自己的立场，不是设定）；
- 每周一次回顾：允许她写「我变了」，但**必须引用具体事件 id**；允许「我没想清楚」（dsh-fish 0.5.8 的教训：不给凭证就会叙事漂移）；
- 记忆分层：重要的进长期、普通的 30 天折叠、旧的压成一句；召回时按「重量」排序而不是全量。

### 第 3 步：拒绝与反省 + 四阶段瓶颈（1–2 周）

- 她拒绝后，按主人反应写一条「小本本」；下次遇到同类请求会想起；
- 四阶段：信任（写下第一条判断）→ 自主（真的拒绝两次）→ 主动（两次推翻自己）→ 整合（回顾发现自己变了）；没到瓶颈不升级，不按天数发奖。

### 不建议照搬的

- **删角色卡/零提示词**：dsh-fish 是从空白养起，我们的卡是几个月调出来的资产，直接删等于换人；
- **照搬面板**：用户需要可观测，但面板只放环境参数（几点醒、刷不刷 B 站），不放性格滑条；
- **恋爱化**：社区最受欢迎的配置反而明确「不是谁的恋人」，我们的「男朋友档」是另一条路，别把两套混在一起。

## 六、风险

1. **叙事漂移**：LLM 擅长把零散经历讲成漂亮的成长故事，回顾必须带 refs，否则三十天后方向已偏（dsh-fish 0.5.8 的原话）。
2. **评估偏差**：单次 sim 不可信，至少 3 次 × 盲评，指标固定（卡外信息率、复读率、拒绝率、人设一致性）。
3. **成本**：事件抽取 + 每周回顾 + 记忆分层都会多调模型，按现在的量估算每天多 10–20 次调用。
4. **OOC 风险**：给了「可以改口」的空间，她可能改出与卡冲突的设定；需要一条「与硬事实冲突时不改」的护栏（生日、家庭、学校这些不能变）。

---

## 七、一句话

**她缺的不是自由，是「可积累的自我」。** 卡给她一个很好的人，但没有给她一个能变的人；把「经历 → 判断 → 改写」这条链接上，她才可能从「执行设定」变成「有来历」。
