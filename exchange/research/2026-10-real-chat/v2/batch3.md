## 3. 动作②里**收不下**的（本批最要紧的发现）

| 图 | 为什么收不下 |
| --- | --- |
| `0bb0890bd166`（晚安这么说才有趣） | **图上只有他一个人说话**——他把「睡觉—聊天—梦见你」说完，她一个字都没露面 → **她这一侧 0 轮**，按 schema 不成段 |
| `969a92354c01`（和男朋友聊天没必要太正经） | 同上：三条白气泡全是对方的，帧面停在她还没回话的时刻 → 0 轮 |
| `9c2c3640c53b`（樱花妹撒娇） | 日文 LINE 界面，**语域不符**（我们只要中文语域） |
| `3448f186bff8`（异地恋我想你） | 5 张图全是长文卡/语录卡/街拍，**没有一张聊天截图**（标题说「聊天记录」，内容不是） |
| `15f81f1b51bf`（不知道怎么拒绝别人） | 教学卡「万能公式」 |

> **「单侧独白帖」是这类话题的主流形态**：标题写着「晚安这么说才有趣」「和男朋友聊天没必要太正经」，
> 点进去是**女生晒「他对我多好」**——截图里只有男朋友的话，她自己没出场。
> 这类帖**再高赞也补不了我们的语料**，因为我们要的正是**她那句话**。
> 因此往后的采集判据要加一条：**先看「她有没有露面」**，没有就直接跳过（省下开图和抄录的时间）。
