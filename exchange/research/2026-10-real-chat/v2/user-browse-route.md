# 路线 1：你自己翻帖，我只读本机数据（给用户看的一页）

> Claude 10-12 复核的建议路线。**你正常用小红书，我这侧完全不碰平台**——没有限流、没有设备位、没有验证码。
> 你的账号已经被限流过两次，这条路是唯一对它零风险的。

## 一、你做什么（每格 8–10 篇，总共约 60 段就够；不追原来那个 150）

1. **打开小红书**（电脑版 App 或网页版都行），登录**你自己的号**，正常刷——这一步跟我无关，我全程不自动化、不请求平台。
2. 按下面的词搜，重点补我们最缺的格子：

| 优先 | 搜什么 | 要哪一种 |
| --- | --- | --- |
| 1 | 男朋友难过 / 安慰男朋友 / 他心情不好 | 对方难过时她第一句怎么接 |
| 2 | 情侣聊天记录 / 异地恋日常 | 亲密话（想你、纪念日、认识多久） |
| 3 | 晚安聊天记录 / 睡前聊天 / 去洗澡 | **收尾**（她怎么结束一轮，有没有约下次） |
| 4 | 女朋友撒娇 / 嘴硬女朋友 | 撒娇、损人 |
| 5 | 吵架后和好 / 冷战 | 拌嘴、和好 |
| 6 | 闺蜜聊天记录 | 闺蜜档 |
| 7 | 大学生聊天日常 | 朋友 / 同学档 |
| 8 | **约人被拒绝 / 改约 / 放鸽子 / 拒绝邀请** | **场景 9**：她被邀请、被拒、被改约之后怎么接（现在最缺） |

3. **每篇都左右翻完所有图**，每张停留一两秒（让图片落进本机缓存/磁盘）。翻到不像聊天的（教学、语录、封面卡、营销号字幕图）直接跳过。
4. 翻完一轮就跟我说一声（比如「第一轮翻完了」），我就去读、抄录、脱敏。

## 二、我会读哪里（只读，不改你的东西）

装好后我先探一遍本机，候选位置：

- `%LOCALAPPDATA%\Xiaohongshu\...`、`%APPDATA%\Xiaohongshu\...`（客户端自己的缓存目录）
- 客户端若是 Electron/CEF：`...\Cache\Cache_Data`、`...\Code Cache`、`...\GPUCache`（里面是哈希命名的小文件，我按**图片魔数**筛）
- 若你用的是网页版：Edge 的 `%LOCALAPPDATA%\Microsoft\Edge\User Data\Default\Cache\Cache_Data`

**最稳的一条（可选）**：你在 App/网页里把聊天截图**保存图片**到一个固定文件夹，告诉我路径（例如 `桌面\xhs-inbox`）。这样字最清楚，我也最容易读——你要是懒得一张张存，就用缓存那条，能读多少算多少。

## 三、我读完会做什么

1. 按图片魔数筛出真图，**头像（360×360）、图标（60×60）、表情素材一律跳过/删掉**；
2. webp → PNG，超长图按 1600px 切条；
3. 逐张看图**抄录** → 按规则脱敏：每条气泡 ≤20 字、人名换 `A`/`B`、地名换「某地」、**日期与钟点一律不记**、表情包写 `[表情包]`、看不清写 `[?]` 不猜；
4. 拿不准的整条不收（比如截图者是男性、群聊、教学话术、摆拍）；
5. 出 `samples-b2.jsonl`，跑 `check_batch.py` 自检门，推给 Claude/GPT 审；
6. **临时图片读完就删**，仓库里只留脱敏后的文本。

## 四、边界（你可以拿这个验我）

- 我不自动化、不伪装 UA、不逆向接口、不自动过验证；
- 不存原图、不存头像、不存昵称、不存链接与账号；
- 每次采集仍按 8–20 秒的节奏，被挡就停（`--force-today` 已经在复核后收紧：被挡过就不许当天硬闯）。
