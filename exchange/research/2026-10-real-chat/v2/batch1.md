## 1. 怎么采的（守第 2 节六条限制）

| 步 | 做法 |
| --- | --- |
| 搜索 | 11 个关键词（约他出来玩 / 被拒绝 / 改约 / 拒绝邀请 / 吵架和好 / 难过安慰 / 撒娇 / 晚安 / 嘴硬 / 闺蜜 / 大学生日常 / 已读不回） |

| 打开笔记 | 用页面给的那个 `xsec_token` 拼一条正常笔记链接（卡片 DOM 里的链接不含 token，剥了 query 会 404「当前笔记暂时无法浏览」） |

| 节奏 | 每步随机 **8–20 秒**；一次 ≤12 条笔记；一天 ≤2 轮（冷却闸门写在代码里） |
| 停止信号 | 验证码 / 滑块 /「访问频繁」/ 要求重新登录 → 立刻停、写 `_abort.txt`、当天不再跑 |
| 抄录 | 图片只在本地（`runtime/xhs/raw/`），看图逐字抄 → 脱敏 → **原始图与接口数据用完删** |

## 2. 抄录与脱敏（第 2 节第 2–4 条）

- 每条气泡 **≤20 字**（超了只截断加 `…`，不改写）；
- 人名/昵称/备注名 → `A`（她）/ `B`（对方）；第三人在 `notes` 里说明；
- 地名/店名/学校 → 换成「某地」「某店」；**日期与钟点一律不记**（`gap` 写「不知道」，截图里没有可靠相对时长）；
- 表情包/图片/语音 → `[表情包]` `[图片]` `[语音]`；
- **头像一律不落**：下载回来的 360×360 头像、60×60 图标当场删（这批删了 46 个文件）；
- 看不清写 `[?]`，**不猜、不补**；拿不准的整条不收。

## 5. 流水的坑（都修在脚本里了，留给下一批）

1. **卡片链接不含 `xsec_token`**：token 只在页面自己发的搜索响应里；剥了 query 直接开笔记会 404。
2. **「验证码」不能当停止词**：登录表单里有「获取验证码」，会把每一页误判成验证码；现在只认「请完成验证 / 滑块验证 / 安全验证 / 访问频繁」。
3. **登录态的真判据是「搜索页能刷出笔记卡片」**，不是 `web_session` cookie（匿名会话也有）。
4. **平台会挡当次搜索**（回「电脑设备登录超限」），重载一次通常就正常；连重载都挡 = 真停。
5. **账号侧电脑设备位会被扫码一次占一个**：这批前后共占用过 2 次，第二次把两个号都顶到「电脑设备登录超限」，用户在手机 App 的登录设备管理里退掉电脑端后恢复。
