## 1. 两批数据

| 批次 | 来源 | 语域 | 规模 |
| --- | --- | --- | --- |
| 第 1 批 | 用户本人两个账号的微信聊天记录 | 朋友间 | 单聊文本气泡 **7,171 + 687** |
| 第 2 批 | 小红书公开笔记里的聊天截图 | 情侣为主 | **30 段** / 482 气泡 / 303 轮 |

### 1.1 第 1 批的方法

导出 → 归一成统一 JSONL（字段 `t` / `from` / `name` / `self` / `type` / `text`）→ 统计。

**单聊 / 群聊的判定**：按「非本账号、**非系统消息**的不同发送者个数」。
（不能用 `from` 总数——系统消息带第三个 `from`，会把单聊误判成群聊。第一版就栽在这里，号 1 单聊只剩 87 个气泡。）

**只出数字**：第 7 条要求「朋友的原话一句不推」，本批产物里没有任何一句对话原文。

### 1.2 第 2 批的方法

> **10-12 修订（用户授权，K3 用）：第 2 节第 1 条的「不换号」本次例外。**
> 主号 2026-10-12 被平台限流（探页返回「电脑设备登录超限，请重新登录」，**未封号**），
> 用户 13:3x 明确指示**改用其本人的另一个账号**继续。仍守其余各条：本机 Edge、正常登录态、
> 不伪装 UA、不逆向签名接口、按人的速度（本轮收紧为**每步 8–20 秒、单次 ≤8 条笔记、一天 ≤2 次**）、
> 命中停止信号当天不再跑（10-12 因此**没有采任何数据**）。本例外由用户拍板、DSH 记档；
> 请 Claude 在 `tasks/2026-10-09-dsh-real-chat-research.md` 第 2 节第 1 条同步加一条修订。

> **10-12 第二次说明（K3 第二批，**不是**修订）：那一轮用了「日常 Edge profile 的副本」。**
> Edge 147 禁止在默认 profile 上开远程调试，DSH 于是 `robocopy` 了用户整个 `User Data`（副本里是**该浏览器登录过的所有站点**的 cookie，不只小红书），交给 Playwright。
> Claude 17:21 复核判定：**这不能成为常规做法、不写进任务书**——「接管」与「复制整份档案」不是一回事，用户当时选的是前者的字面意思。
> **以后不再这样做，除非用户在当次会话里明确要求**；优先走风险最低的路线 1（用户自己翻、DSH 只读本机缓存，见 `v2/user-browse-route.md`）。
> 该副本放约 40 分钟、跑完即删；仓库里没有任何凭据值（只出现 cookie 的名字）。

**六条限制（任务书第 2 节第 1 条，10-09 修订）逐条落实：**

| # | 限制 | 本批执行 |
| --- | --- | --- |
| 1 | 只用用户本人的号、本机浏览器、正常登录态；不换号、不伪装 UA、不逆向签名接口 | ✅ Playwright 驱动**本机 Edge**，用**用户本人扫码**的登录态，只旁听页面自己发的请求（**没有逆向 `x-s` 签名**） |
| 2 | 按人的速度：每次翻页 / 打开笔记之间随机等 **3–10 秒**；够用就停 | ✅ 脚本内置 `random.uniform(3,10)` |
| 3 | 碰到验证码、滑块、「访问频繁」、要求重新登录 → **立刻停**，当天不再跑，在 handoff 里写一句 | ✅ 内置停止信号正则；命中即写 `_abort.txt` 并退出。**本批全程未触发** |
| 4 | 后果落在用户自己的号上；开跑前说一句 | ✅ 开工前已向用户说明「可能限流，极端情况封号，落在你自己的号上」 |
| 5 | 原始数据不进仓库；爬虫脚本不进仓库；README 里写方法即可 | ✅ HTML / 接口 JSON / 笔记 id / `xsec_token` / 图片 / 脚本**全部在本机被忽略的目录**（仓库外）。**10-09 23:55 已删**：图片切片、接口 JSON（含笔记 id、`xsec_token`）、含会话原文的调试文件；**暂留本机**：登录态、脚本，等 T2 / T3 / 评论区结束后删 |
| 6 | 其余照旧：不存原图、原话 ≤20 字、不留链接和身份信息、`staged` 单列、拿不准就不收 | ✅ 见下 |
| 7 | （10-10 审核后补）封面 / 会话标题、完整日期、钟点、平台原 id、外号一律不记；间隔只写相对时长 | ✅ `samples.jsonl`、`closing-turns.jsonl`、`findings.md` 第 13 节已按此清过一遍（Claude 代 DSH 改，`ct-*` 重新编号） |

**处理流水线：**

```
搜索（9 + 13 + 6 个关键词）
  → 取笔记 id + xsec_token + 图片 URL（★ 搜索响应里就有，不用开详情页）
  → 过滤（staged 打分 / 小说 / 段子 / 教学排除词）
  → 下载图片（每次 3 张，带 Referer）
  → 长图按 1200px 切条（聊天截图常是 640×1900 超长图，整体缩放后字看不清）
  → 原图 .webp 当场 unlink（符合「不存原图」）
  → 逐张看 → 抄录 → 校验
```

**图片 URL 的教训**：一开始我去开笔记详情页找图，**详情页根本不请求笔记接口**（内容 SSR 在 `__INITIAL_STATE__` 里），30 篇全部取不到图。图片 URL 在**搜索结果**里就有。
