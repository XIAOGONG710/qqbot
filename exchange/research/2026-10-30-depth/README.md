# 她的「深度」：12 个需要有东西可说的时刻，两遍（2026-10-30，Claude）

用户 10-30：「怎么让她有深度？」。先量，再说。**合成对话，不是真聊天；没读她任何私人文件。** 复跑：
`QQBOT_CONFIG=<线上 config.json（只读）> node packages/bot/src/sim/run.ts depth-probe.json --runs 1 --no-memory --ask --long --deliberate --tag X`（强制版换 `depth-probe-forced.json`）。

## 结论

1. **深度的瓶颈首先是路由，不是模型。** 「这一轮要认真」的判断是关键词（`OPINION_ASK`：你觉得 / 怎么看 / 为什么……、`DELIBERATE_MARKS`、`invitesLong`），很多真正需要深度的时刻没有这些词（「我爷爷认不得我了」「怕被关掉」「是不是套路」「你觉得我变了」），不但没走深思，反而被抽到「一两个字就行」的轮次。走对路径时质量明显上来。
2. 就算路由对了，还有四个缺口：
   - **没有自己的看法可说**：书、视频她只有情节 / 进度，没有「我想了什么」；`0ef01dc` 又去掉了作者写的感受，她该自己攒，现在没有地方攒。
   - **编他的事**：没有记忆支撑时会补「你数学不差」「你高中刷那么多题」「我有些同学也……」。深度必须落在记忆 / 当下聊天里的事实上。
   - **谈自己是什么**：每次现编、而且用人的口吻（「半夜睡不着」）。没有她自己写下的、一致的自我看法；怎么对待这类问题（诚实地说不确定 / 以角色身份答）是用户要定的。
   - **深了就容易「不是 X，是 Y」**：强制版里「怕的其实不是考不上，是怕毕业之后没着落」「成熟不是什么都自己扛，是怕了还往前走」——金句句式，AI 腔。自然版那句「能自己扛事吧，出了事不指望别人来兜底」反而更像人。深度 ≠ 警句。
3. 做法的顺序见我给用户的回复（语义路由 → 落在事实上 → 她自己的看法 → 自我看法 → 句式监测 → 评估）。
