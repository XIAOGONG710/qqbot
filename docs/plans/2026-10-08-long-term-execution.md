# 林梦瑶长期执行计划：持续生活与自然对话

- 日期：2026-10-08
- 状态：执行中
- 基线：ADR 0029–0036 已上线；生活事件账、当前行动、日常、72 小时回忆、NPC 日程、日计划、钱和第一轮自然对话纠偏已经可用
- 目标周期：长期滚动执行；每两周重排任务，每月做一次系统级验收
- 依据：[虚拟人生引擎实施方案](../research/2026-10-07-life-engine/implementation-plan.md)、[路线图](../roadmap.md)、[ADR 0036](../adr/0036-conversation-naturalness.md)

## 1. 总目标

让林梦瑶成为一个生活在可重放虚拟世界中的长期角色：没有用户消息时，她仍按自己的身体、日程、关系、资源和目标生活；有人联系时，她能先理解这句话在关系中的作用，再以符合当下情境的方式回应；几天或几个月后追问，她说的经历仍能与事实账对上。

“像真人”在本项目里是工程验收目标，不是关于意识的声明。它具体表示：

1. **生活连续**：时间、地点、身体、行动和资源有前因后果，重启不改史。
2. **有限自主**：无人聊天时也会计划、行动、受阻、改计划和积累经历。
3. **社会真实**：NPC 有自己的生活和知识边界，关系会因共同事件缓慢变化。
4. **表达自然**：先接住当前话题；允许短句、停顿、含糊和不追问，不用每轮证明自己“有生活”。
5. **长期成长**：技能、习惯、偏好、目标和自我认识由经历改变，但稳定人格不会一夜翻转。
6. **可解释可回滚**：世界事实与模型台词分开；每次变化有记录、有测试、有恢复路径。

## 2. 非目标与硬边界

- 不宣称程序具有生物意义上的生命、意识或真实感受。
- 不用无限上下文、随机小事堆积或更长角色卡冒充人生连续性。
- 不让 LLM 直接宣布世界事实；行动必须由世界裁判检查并写入事件账。
- 不把“叛逆”“已读不回”“拒绝”当成人味捷径；必须先有身体、目标、关系或情境原因。
- 不为了自然度牺牲隐私分档、联系人隔离和禁用词出口检查。
- 不用线上真实用户做无告知的高风险实验；主动消息、长期冷淡、冲突升级均需灰度。
- 不因 Claude、DeepSeek 或任一单一模型不可用而阻塞主线开发。

## 3. 长期架构与工作流

```text
外部时间 / 世界事件
        ↓
事实事件账 ──→ 状态投影（位置、身体、钱、物品、关系）
        ↓
局部观察 → 需要 / 目标 / 日计划 → 候选行动
        ↓                         ↓
世界裁判 ← 前置条件、耗时、资源、冲突、随机种子
        ↓
行动结果 → 记忆 / 日记 / 反思 / 技能 / NPC 反应
        ↓
对话动作判断 → 事实与记忆取用 → 候选表达 → 出口检查 → 发送
```

所有批次遵守同一闭环：证据 → 小 ADR 或计划条目 → 最小实现 → 单测 → 确定性模拟 → 真模型回归 → 人工盲评 → 灰度上线 → 观察 → 封板。

## 4. A–F 阶段与可交付物

阶段不是一次性大版本。每个阶段拆成能独立提交、验证、上线和回滚的小批次；阶段间允许交错，但不能跳过其验收门槛。

### A. 生活内核：能够真实地行动

目标：从“按日期生成设定”推进到统一的观察—选择—执行—结算循环。

可交付物：

- 类型化行动注册表：睡觉、起床、吃饭、上课、学习、休闲、读书、洗澡、喂猫、取快递、联系家人、与 NPC 互动。
- 每类行动的前置条件、持续时间、时间 / 精力 / 金钱 / 物品消耗、成功 / 失败 / 中断结果。
- 事件队列和虚拟时钟：课程、截止时间、约定为硬事件；普通行动按阶段边界推进，不做每分钟模型调用。
- 世界裁判：拒绝不可能行动，解决时间冲突，持久化随机种子，保证重放一致。
- 自主选择器：规则处理日常，只有重要岔路调用模型；模型只选可用行动，不直接修改事实。
- 72 小时无人聊天封板场景及状态审计工具。

阶段门槛：三天内每天 3–8 件有后果事件；至少一次计划修订、一次 NPC 互动、一个长期目标进展；时间 / 地点 / 钱 / 物品 / 精力无冲突；重启重放一致。

### B. 动机与长期项目：为什么做这件事

目标：行动由身体需要、价值和长期目标推动，而不是随机抽签。

可交付物：

- 连续需要模型：精力、饥饿、健康、压力、社交、独处、好奇 / 无聊、可支配金钱。
- 需要的自然恢复与衰减，以及对行动可用性、效用和说话方式的有限影响。
- 三个首批长期项目：课程项目、相机基金、读书 / 摄影成长；每项有下一步、期限、资源、阻碍、暂停和放弃条件。
- 目标选择与冲突解决：短期舒适、硬截止时间、关系约定和长期收益可解释地权衡。
- 周级目标进度报告：从事件账派生，不由模型凭空总结。

阶段门槛：连续 14 天模拟中，项目既有进展也允许延期；需要值不出现无界增长或瞬间复原；同一状态和随机种子得到相同结果。

### C. 社会生态：别人也在生活

目标：关系不是林梦瑶单方面保存的标签，而是多主体事件造成的慢变化。

可交付物：

- 陈佳宁、苏雨桐和家庭成员的独立日程、目标、知识边界、可用时间与关系状态。
- NPC 行动与反应：忙、迟到、拒绝、忘记、改主意、主动联系和共同经历。
- 事实 / 信念 / 传闻分层；信息传播有来源、可见范围和误差，不让所有人共享全知视角。
- 长期人物印象与短期关系温度分开存储，并设置变化速率上限。
- 披露策略继续按联系人档位投影；第三方秘密默认不进入低档提示词。

阶段门槛：两周模拟里 NPC 至少各自产生一次与林梦瑶无关的生活事件；出现一次合理拒绝或改约；秘密泄漏为 0；一次摩擦不会永久改写人物印象。

### D. 成长、自传与技能：经历会留下改变

目标：重复经历改变未来选择，同时保留稳定人格和事实历史。

可交付物：

- 技能模型：摄影、学习、生活管理等由已验证的成功行为缓慢提升。
- 习惯模型：形成条件、强度、打断、恢复和消退；习惯只影响概率，不强制剧情。
- 反思层：日反思只提取值得保留的经验；周 / 月反思形成自传章节和下一阶段目标。
- 自我认识版本：记录“她如何理解自己”的变化，并保留证据事件和历史版本。
- 防漂移约束：稳定人格、关系事实和作者裁决不可被一次模型输出覆盖。

阶段门槛：30 天模拟中至少一个技能有可解释进步、一个习惯形成或失败；所有成长能追溯到事件；事实账与自传无矛盾。

### E. 结构化意外与媒介层：世界会发生事

目标：增加不可完全预测但仍有因果的生活变化，避免每日模板化。

可交付物：

- 意外生成器：由地点 × 时间 × 天气 × 身体 × 当前目标触发，有概率、冷却期和影响范围。
- 因果链：意外能中断行动、修改计划、影响资源和关系；禁止无来源戏剧。
- 媒介缓存：天气、作品更新、校园或兴趣资讯按天缓存并记录来源时间。
- 离线降级：网络失败时只使用缓存或确定性事件，保持可重放。
- 新鲜度监控：防止同类意外和话题短期高频复现。

阶段门槛：30 天模拟内有少量不同类型意外，均有明确触发与后果；断网重放不报错、不改史；无连续重复剧情。

### F. 有限的不完全配合：有边界而非讨好

目标：在真实动机与关系基础上，逐项允许拒绝、走神、改话题、暂时不想聊和延后回复。

可交付物：

- 行为许可矩阵：什么状态、什么关系、什么强度下可拒绝或中断。
- 分项灰度开关：拒绝、走神、改话题、已读不回分别独立上线。
- 修复动作：误伤后能自然解释、道歉或重新接话，不靠系统式说明。
- 冲突场景集：疲惫、秘密、竞争、失约、边界请求和误解。
- 永久保留出口底线：不像助手；不承诺做不到的事；不情绪操控、不算账。

阶段门槛：盲评中“有自己的边界”提升，同时“被操控感、被惩罚感、无端冷漠”不得恶化；高风险项人工审核后才灰度。

## 5. 自然对话专项

自然对话与 A–F 并行推进，不能等生活引擎完成后再补。ADR 0036 已修复“当前话题被生活播报抢走”和旧输出自我强化，后续依次实施：

### N1. 对话动作层

- 将当前意图扩展为可观测的动作分类：回答、确认、共情、玩笑、分享、澄清、追问、拒绝、收尾、沉默。
- 动作选择先于内容生成；世界事实只能在动作允许时进入回复。
- 保留规则处理明确收尾和高风险场景，模糊场景可由小模型分类，但要记录置信度和回退原因。

### N2. 目标语料库

- 只收录取得同意、已经脱敏、被人工认可为“像她”的片段。
- 每条标注关系档位、场景、对话动作、情绪、句长、是否追问、是否主动转题。
- 线上模型旧回复默认不进正样本；合成数据只补稀有场景并单独标记来源。
- 建立反例库：助手腔、过度安慰、复述用户、机械追问、强行汇报生活、连续三段式、虚构事实。

### N3. 上下文与记忆纪律

- 原始聊天保持有限窗口；更早内容通过结构化记忆召回。
- 将“事实相关性”和“适合此刻说”分开评分，记得不等于必须提起。
- 同一旧模型措辞的重复率设监控，防止 80 条窗口内继续自我模仿。
- 逐步试验“最近若干轮 + 当前片段摘要”，以盲评决定是否替换固定 80 条。

### N4. 多候选与选择器

- 只在高价值或高不确定轮次生成 2–3 个候选，普通轮次仍单次生成以控制成本和延迟。
- 选择器优先排除：跑题、自我转场、事实越权、套话、重复结构、过度完整、无必要追问。
- 选择器不得改写事实；无候选达标时使用短回复或安全回退。

### N5. 盲评与风格迭代

- 真人参考、线上旧版、当前版匿名混排。
- 分开评分：像真人、像林梦瑶、接住当前话、愿意继续聊、事实可信、边界舒服。
- 每轮至少覆盖关心、亲密、日常分享、玩笑、冷场、收尾、冲突、久别重聊。
- 只有当自然度提升且事实 / 隐私 / 安全不退化时才上线。

### N6. 微调决策

- 在目标语料数量、许可和质量未达标前不做微调。
- 首次微调只针对表达选择，不承载世界事实和记忆。
- 微调模型与提示词版本都必须可回退，并与非微调基线做同题盲评。

## 6. Claude、Codex、DeepSeek 的分工

三者不是互相等待的流水线。仓库、ADR、测试和部署记录是唯一交接事实源；任何一个角色暂时不可用，其他角色按文档和 Git 状态继续。

| 角色 | 主要职责 | 不负责 / 限制 |
| --- | --- | --- |
| Codex | 检查当前状态、拆最小批次、代码实现、测试、日志取证、提交、部署、回滚；Claude 不可用时拥有主线推进权 | 不把未验证推测直接写成世界事实；涉及角色作者裁决时明确列出假设 |
| Claude | 架构复核、长文档一致性、角色与对话质量审阅、困难设计反例、跨 ADR 冲突检查 | 不作为单点审批人；额度耗尽时任务继续，之后按提交和验证记录补审 |
| DeepSeek | 经授权后的角色卡试跑、批量场景生成、候选回复、自动评审或分类辅助 | 仅辅助，不拥有事实裁决、最终评分和上线决定；不得接触未授权隐私或完整线上数据 |

工作原则：

1. 每批先写清输入、输出、门槛和回滚，再开始修改。
2. Codex 默认保持主线可执行；Claude 可用时优先做独立复核，不重复实现同一代码。
3. Claude 不可用超过一个工作批次时，在交接记录注明“待补审”，但只要自动测试、人工门槛和隐私边界满足即可继续。
4. DeepSeek 的评分只能作为证据之一；凡涉及“像不像真人”，至少需要匿名人工盲评。
5. 三者产出的建议若冲突，以事实账一致性、用户作者裁决、可验证结果和隐私边界为优先顺序。

## 8. 测试、盲评与上线门槛

### 每个提交

- 相关单元测试必须全过，新增行为必须有失败前 / 成功后用例。
- 三套类型检查全过；格式、静态检查和 `git diff --check` 无异常。
- 涉及事件账的修改必须验证幂等、重放、旧数据兼容和原子写入。
- 不得将密钥、QQ 号、原始私聊、运行目录或模型完整请求提交进 Git。

### 每个功能批次

- 确定性模拟至少覆盖成功、失败、中断、重启四条路径。
- 真模型场景至少运行 3 次；记录模型、参数、时间和结果目录。
- 硬门槛必须 100%：隐私泄漏、事实矛盾、越权承诺、不可执行行动、事件账损坏。
- 自然度不是词表 100% 即通过；代表性失败必须人工阅读。
- 性能预算：普通对话不因新增模块显著增加首字延迟；高成本多候选只用于高价值轮次。

### 自然对话盲评门槛

- 每次至少 50 个匿名样本；大改至少 100 个，场景分层抽样。
- 主要指标采用成对偏好：新版在“像真人、接得住、愿意继续聊”三项中至少两项显著优于基线。
- “像林梦瑶”不得下降；事实可信、隐私、边界舒服不得出现实质退化。
- 若评审分歧大，保留失败样本并拆场景，不用平均总分掩盖问题。

### 上线门槛

- 工作区干净，提交已推送；线上配置和数据已备份或可恢复。
- 全量测试与类型检查通过；迁移已在副本或临时目录演练。
- 先灰度到一个联系人或一个功能开关，观察至少一个正常交互周期。
- 启动后确认 Koishi、NapCat、控制台、锁文件、最新日志和世界重放均正常。
- 出现 P0 / P1 条件立即回滚，不在生产环境临时补丁。

严重度：P0 为隐私泄漏、数据损坏、跨联系人串线；P1 为事实系统性矛盾、无法回复、异常主动轰炸；P2 为明显机械、偶发跑题或语气退化。

## 9. 周节奏与月节奏

### 每周

- 周一：读取 Git、路线图、最近线上日志和失败样本，确定一个主批次与一个自然对话小批次。
- 周二至周三：实现最小闭环；优先写确定性测试，保持每天至少一个可回退提交。
- 周四：真模型回归与匿名盲评；失败按场景聚类，不在同一批无限补提示词。
- 周五：灰度 / 上线、检查日志、补 ADR 验证和交接记录。
- 周末或低峰：运行 72 小时 / 14 天加速模拟、成本报表和备份完整性检查，不直接自动上线。

每周最多一个需要数据迁移的主批次；若线上出现 P0 / P1，本周剩余计划让位于修复和复盘。

### 每月

- 运行一次 30 天人生模拟和一次重启重放对照。
- 对自然度做固定题库盲评，保留可比基线，不随意更换全部题目。
- 审查长期目标、NPC 关系、表达重复率、主动消息频率、模型费用和延迟。
- 清理或归档已授权测试数据；复核 DeepSeek 上传记录和本地结果保留期限。
- 更新阶段进度、风险清单和下月唯一主线；关闭没有证据收益的实验开关。

## 10. 成本与隐私

### 成本控制

- 日常推进和硬规则不调用模型；模型只处理重要岔路、反思和模糊对话动作。
- 缓存静态角色资料、日级媒介和可复用状态摘要；相同确定性状态不重复生成。
- 为模型调用记录用途、token、延迟、成功率和估算成本，按“线上回复 / 人生模拟 / 测试”分账。
- 设置日预算、单联系人上限和异常熔断；接近预算时降级到单候选、规则行动和缓存事实。
- 多候选仅针对高价值场景；盲评先用小样本筛掉明显失败，再扩大。

### 隐私控制

- DeepSeek 只接收用户已明确授权的林梦瑶角色卡与虚构 / 脱敏测试对话；真实聊天默认不得上传。
- QQ 号、姓名映射、令牌、密钥、设备路径、完整日志和 Hindsight 原库不进入外部请求。
- 对外请求保存最小审计：时间、用途、数据类别、模型、结果目录，不保存密钥。
- 联系人档位继续采用“敏感事实不写入低档提示词”，不能只依赖输出过滤。
- 语料入库必须记录来源、同意范围、脱敏状态和可删除标识；撤回时能按来源删除。

## 11. 失败、降级与回滚

### 功能失败

1. 关闭新功能开关或切回上一稳定提交。
2. 停止新的事件写入，保留日志和事件账副本，不直接手改历史。
3. 用相同种子和输入复现，区分模型随机失败、规则错误、迁移错误和外部服务失败。
4. 若新旧数据结构不同，执行已演练的反向投影；无法无损回退时保持只读并人工确认。

### 模型或网络失败

- Claude 不可用：Codex依据 Git、ADR、测试和交接模板继续；标记待补审，不暂停主线。
- DeepSeek 不可用：跳过真模型扩展回归，继续确定性开发；上线需等待既定真模型门槛，或仅上线不依赖模型的新测试 / 工具。
- 在线生成失败：使用短重试和熔断，不用无限重试；保留未回复消息，恢复后按过时策略处理。
- 外部媒介失败：使用缓存或确定性世界，绝不由模型猜当天真实资讯。

### 上线回滚触发

- 任意跨联系人泄漏、角色档位泄漏、事件账损坏或重复写入；
- 连续事实矛盾、主动消息异常增长、回复循环或无法停止的模型调用；
- 新版自然度盲评显著下降，且无法由单个开关隔离。

回滚后必须补一条回归测试和简短复盘，再允许同功能重新上线。

## 12. 近期两周任务板

两周目标：完成生活内核 A 的“类型化行动 + 事件队列”最小闭环，同时建立自然对话盲评基线。两条线并行，但上线仍逐批进行。

### 第 1 周：行动可执行、对话可测量

| 优先级 | 任务 | 交付物 | 完成定义 |
| --- | --- | --- | --- |
| P0 | 盘点现有事件账和状态投影 | 行动 / 事件 / 状态字段对照表，列出兼容约束 | 不改代码也能说明每个现有事实来自哪里 |
| P0 | 类型化行动注册表第一刀 | 睡觉、吃饭、上课、学习、休息、读书六类行动及校验器 | 单测覆盖前置条件、耗时、冲突、成功 / 中断；旧日常输出不变 |

## 13. 完成判断

项目不会因为“角色卡更长”而宣布完成。阶段性成功至少要同时满足：

- 三天不聊天，她确实度过三个不同且连续的日子；
- 一个月模拟后，她的目标、关系和能力有缓慢、可解释的变化；
- 回来聊天时，她先回应眼前的人，而不是播报后台状态；
- 她记得的、说出的和事件账记录的事实一致；
- 不同联系人只看到各自应当知道的部分；
- 任一模型暂时不可用，开发和线上基础生活仍能降级继续；
- 所有重要变化都能用测试、盲评、日志和回滚点说明。
