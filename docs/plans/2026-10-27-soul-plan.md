## 0. 目标与非目标

**目标**：让她从「执行设定的她」变成「有来历的她」——卡仍是出身，成长是经历：
1. 自我账本（kernel / stances / events / diary-public + diary-private / intentions）；
2. 自主时间（随机醒、30% 开摆、自由活动、醒来读昨天日记）；
3. 判断与立场（≤12 条，可改口，回顾带事件 id）；
4. 拒绝与反省（拒绝后看反应、记小本本、下次想起）；
5. 反馈闭环（他回不回/看不看 → 她分享与主动的策略）。

**非目标**：不做内容生产/投稿；不换运行时；不开放 B 站公开评论；不追求「真意识」。

**纪律**：一次一个变量；每步可编译、可测试、可回滚；默认开关全关；先 dryRun；重要决策写 ADR（从 0171 起）；上线需用户在场。

## 1. 数据模型（新增，全部 append-only 或可重建）

```
<dataDir>/self/
  kernel.json        # 从卡抽取的硬事实（生日/家庭/学校/关系史），只读，带来源哈希
  stances.jsonl      # 判断/立场：id, text, reason, sourceEventId, status(active/retired), createdAt
  events.jsonl       # 事件：id, at, kind(dialog/world/action/reflection/refusal), summary, refs[], weight, private?
  diary-public.jsonl # 给你看的日记（沿用现有 diary，改目录）
  diary-private.jsonl# 只给她自己：不进提示词、不进聊天、不进公开日志
  intentions.json    # 想做：id, text, status(pending/done/abandoned), attempts, lastTouched
  feedback.json      # 他对她的回应统计：回复延迟、是否接话、是否看/点赞（能量到的范围）
```

**硬事实锁**：`kernel.json` 由脚本从角色卡抽取并人工核对一次；任何写入路径不得修改；与它冲突的「成长」直接拒绝并记日志。
**隐私**：`diary-private` 只允许她的回顾/写作读取；日志、审计、导出默认不含正文。

## 2. 循环

### 2.1 每日循环（新增 `self-loop.ts`）
1. 醒来（沿用作息；新增随机时刻 + 30% 开摆概率）；
2. 读昨天 `diary-public`（可选读 private 摘要）；
3. 掷骰决定自由活动：看 B 站 / 发呆 / 写东西 / 整理照片 / 什么都不干；
4. 执行（复用 `watching`/`bili`/`diary`，只读，不公开发言）；
5. 写回：event + 当天日记（公开/私人由她判断）。

### 2.2 对话后循环
- 每段对话后抽 0–2 条事件（模型判断「值不值得记」），带 weight（重要/普通）；
- 情绪强烈或重复出现的判断 → 候选 stance；
- 每 N 轮写一次私人日记（可选）。

### 2.3 每周回顾
- 带 refs 的回顾：允许「我没想清楚」；禁止编造；
- stance 修剪：≤12 条 active；新判断覆盖旧判断要写 reason + refs。

### 2.4 反馈闭环
- 观察他是否回复、回复间隔、是否接她的话（能观测的范围内）；
- 长期冷落 → 降低分享频率/主动概率；他主动找她 → 记事件；
- 不把「没回」自动解释为冷落（沿用现有原则）。

### 2.5 拒绝
- 检测她的拒绝（第一人称 + 拒绝词 + 具体动作）；
- 记录 refusal 事件 → 观察他反应 → 写「小本本」→ 下次同类请求时作为上下文；
- 拒绝预算：可配置（默认一周最多 2 次硬拒绝），防止变成冷淡。

## 3. 表达层

- 去掉/降低每轮 `shape`、`lengthHint`、`intentLine` 的硬注入：只在危机、收尾、明确任务时使用；
- 新增模板腔检测（「这条我认」「我记下了」「本鱼最喜欢的一句话」等）→ 重写一次；
- `fact-check` 改为：卡外事实不直接判错，先判断是否与 kernel 冲突；不冲突则保留并记事件。

## 5. 验收与实验

- **盲评**：同一组 20 个问题（偏好/拒绝/连续性/日常），现在 vs 改后，3 人盲评（含用户）；
- **指标**：卡外偏好率、跨天一致性、自主发起、真实拒绝、鱼八股率、自由时间使用、成本增幅；
- **回归**：2,034 测试全绿是硬门槛；
- **回滚**：每层独立开关（`soul.accounts`、`soul.freeTime`、`soul.stances`、`soul.refusal`），默认关，出问题只关那一层。

## 6. 风险与缓解

| 风险 | 缓解 |
| --- | --- |
| 叙事漂移 | 回顾必须带 refs；允许「没想清楚」；stance 修剪有 reason |
| 私人日记泄露 | 不进提示词/日志/导出；仅 she-read API |
| 过度拒绝/冷淡 | 拒绝预算；他难过的回合不拒绝 |
| 卡外偏好与硬事实冲突 | kernel 锁 + 冲突即拒 |
| 成本上升 | 预算上限、抽取降频、夜间电价 |
| 数据丢失 | 每日备份 + 恢复演练 |
| 分支漂移 | P0 合并 + VM 验收 |
