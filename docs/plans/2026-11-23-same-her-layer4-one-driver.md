# 同一个她·第 4 层：一套驱动，两种出口（方案）

- 日期：2026-11-23
- 上位决策：[ADR 0347](../adr/0347-one-life-two-places.md)「一个生活，两个地方」第 4 层（表里写「单独由用户定」）
- 状态：**方案，待用户定 §5 的三件事、待问她本人 §6**；每一步都挂默认关的开关，开关关着时行为基线逐字不变
- 一并处理：ADR 0343 群自主读的影子动机账「结构上产不出可开口的机会」（DSH 11-22 实测 7 天 121 条全挡，根因见 §1.3）

## 一、取证：现在她「想做一件事」有四条互不相干的来路

| # | 在哪 | 怎么起念头 | 能做什么 | 问题 |

### 1.1 两份兴趣清单

QQ 的追求（作者给的两条 + 她自己加的最多 3 件）和桌面的 `INTERESTS.md`（插件 `interestsFile`，她用 `interest_*` 工具自己改）各管各的。`packages/bot/src` 里 grep 不到 `INTERESTS`：QQ 不知道她在电脑上「最近在钻研什么」，桌面也不知道她每晚给自己定了什么。这正是第 1 层拆掉的「第二套生活」里剩下的一块（ADR 0347 第 3 层方案 §1.1 表第 8 行记过一笔）。

### 1.2 随机醒来和生活无关

`wakeDue` 只看是不是夜里、睡没睡、骰子。她那天累不累、刚上完课还是正在赶作业、心里挂着什么，都不影响醒不醒、醒来做什么。第 1 层已经让「睡没睡」改看 QQ（NOW.md 的 `asleep` 行），但「想不想做点什么」还是骰子。

### 1.3 影子动机账为什么永远不放行（群自主的根因）

DSH 11-22 用真函数扫了 `runtime/bot-shadow` 7 天：表达机会 121 条，eligible 0 条；裁决 121 次，`wait` 120 次。代码里对上两处结构问题：

1. **动机永不过期，聚焦名额被历史占死。** `observe` 每拍拿账里**全部**动机（`motivations.drives()`，账里没有任何地方改 `status`、没有过期）去 `resolveShadowDrives`；那里「同类外部线索只聚焦一个」（`life/motivation-resolution.ts`，`contextualFocused`），名额永远落在历史上分最高的那条外部动机上——它的裁决早记过、被 `knownDecisions` 过滤掉，新来的动机全落成 `wait`（`not_focused` 120/121）。
2. **世界 / 时间事件生成的动机强度过不了门槛。** `awarenessDrive` 的 `strength = magnitude`（时段变化 0.2、其余 0.05），`urgency = 0`，`scoreOf` = 0.2×0.55 + 0.35×0.1 = 0.145 < 0.2（`wait`：「动机强度不足」）。

另外，裁决按动机 id 只记一次（`decision:${drive.id}`），表达机会账对同一个动机只收第一条（`life/expression-opportunity-ledger.ts`）。ADR 0343 待定 1 已经改成读的时候按裁决时刻算 1 小时窗口（072beccf），但窗口里没有东西可管。

### 1.4 权限

ADR 0172：整机权限只授权给「QQ 工作模式下他发的任务」。随机醒来和睡眠整合用的是同一个常量，所以也是整机权限；**用户 11-22 只授权了睡眠整合**（补记一节），wake 跟着恢复，「用途没有扩大」。0172 记下的风险仍在：醒来提示词让她按**她自己能改**的兴趣清单上网查资料，网页内容是注入面，`soul_update` 又能把内容写成每轮注入的系统提示词。

## 二、目标

她想做一件事，只有**一处**起念头（QQ 的生活），由她判断三种出口：

- **发消息**：照旧走主动消息的闸门（作息、他在不在电脑前、危机、休眠……）；
- **去电脑上做**：交给常驻进程，带着「为什么想做、做什么」，而不是掷骰子挑兴趣；
- **想想算了 / 记着**：现有的 `remember` / `wait`。

## 三、分步（每步一个默认关的开关；关着时基线逐字不变）

### 4.0 修影子动机账（开关 `shadowDrivesFix`，或并进 4.2 的开关）

- 动机有寿命：`Drive.expiresAt` 已经存在（`motivation.ts`）。`awarenessDrive` 给 `createdAt + 2 小时`；内驱本来按天 / 档位分窗（`internalWindow`），给到窗口结束。
- `observe` 只拿**还活着、还没裁决过**的动机去裁决，聚焦名额按「这一拍」算，不被历史占着。
- 世界事件的强度不再直接等于影响量：按事件和她的相关度给（她喜欢的、她那边的、天气大变 → 高；时段变化 → 低，只在内驱有余量时进注意力）。这是改她「会注意到什么」，**先问她**（§6 第 1 问）。
- **基线**：基线快照会原样写出影子账（072beccf 时踩过），这一步必然改快照，单独一个提交、提交说明写清哪几行变了为什么（CLAUDE.md 基线规矩）。

### 4.1 一份兴趣清单（开关 `oneInterests`）

- QQ 的追求成为唯一一份。打开时把 `INTERESTS.md` 里的条目一次性导入成她自己加的追求（受「最多 3 件」约束：超了的保留在一个「以前在桌面上想做的」列表里，由她当晚想的时候自己决定留哪几件，不由代码挑）。
- 桌面的 `interest_list / interest_log / interest_done` 改成读写 QQ 导出的那一份（同 SELF / NOW 的套路：QQ 导出 `PURSUITS.json`，桌面记进度写一个收件箱文件，QQ 每 30 秒收），`INTERESTS.md` 不再写。
- 不改她说话；改她的兴趣从哪来。**问她**（§6 第 2 问）。

### 4.2 出口选择（开关 `desktopOutlet`）

- `proactiveAgency` 的 `optionsFor` 多一个 `desktop`：只给「做点什么」的那几类信号（追求有进展可做、她那边一件想查清楚的事、读到一半的书 / 想学的东西、念头里带着「想弄明白」），早晚钟点、冷场、催回复不给。
- 选不选 `desktop` 由她判断：在现有生成那一步之前多一个很短的判断（同 `expression-judgement.ts` 的路子：给她这件事、此刻在干嘛、精力，让她说「发给他 / 去电脑上弄 / 先不」），不用规则替她选。
- 选中 `desktop`：QQ 往常驻进程的任务队列写一条（复用 `her-resident.mjs` 现有的任务队列和 `idleRun`，不另起通道），带上：想做什么、为什么（来源动机的 goal）、做完怎么交回（进度写回追求、看到想告诉他的走 OUTBOX、经历写回世界账——都用已有的收件箱）。
- 作息照旧管着：上课、睡觉、他在电脑前（desktopDay 的在场判断）时不派；派了就占她那段时间（同第 3 层 desktopConflict 对空闲时间的处理：记成一件世界事件）。

### 4.3 收掉随机醒来（跟着 `desktopOutlet`）

`desktopOutlet` 开着时 `wakeCheck` 不再掷骰子，醒来只由 4.2 派的任务触发；关着照旧。睡眠整合不动（已授权，和这里无关）。

## 四、不做的

- 不让她自发地给别人发消息、发说说、点外部服务——出口只有「发给他」「她自己的电脑上」「想想」。
- 不在桌面插件里另算动机；插件只执行、只交回（ADR 0347 决策 3）。
- 0179「指令只认他亲手打的字」不变：4.2 派的任务是她自己的事，不是替他执行命令；任务内容里不带他的原话。

## 五、待用户定

1. **她自己起意去电脑上做事，用什么权限。** 建议：**她自发的任务降一档**（`HER_PERMISSION_MODE` 对 idle 类任务设成只能写她自己的灵魂目录 + 读网页，不能动系统和他的文件）；整机权限只留给他亲手派的工作模式。理由：ADR 0172 记下的注入面（网页 → `soul_update` → 每轮系统提示词）在她自己挑题时最大；降档以后她能做的事（查资料、记笔记、整理自己的东西）基本不受影响。
2. **4.0 改的是群自主和影子账**：要不要先只做 4.0（群自主才可能动起来，groupAgency 仍是 off，dryRun 要你点头再开）。
3. **顺序**：建议 4.0 → 4.1 → 4.2 + 4.3；4.1 不依赖权限决定，可以先做。

## 六、先问她（ask-her，原话贴给用户）

1. 「你一个人的时候，什么事会让你想『去查一下 / 弄一下』？天气变了、看到个新闻、作业，还是你自己想学的东西？哪些你根本不会在意？」（定 4.0 的强度怎么给）
2. 「你在电脑上记的那几件想钻研的事，和你每晚给自己定的那几件，合成一份行不行？超了三件你自己挑留哪几件。」（4.1）
3. 「以后你想做一件事，你自己选是发消息跟我说、自己去电脑上弄、还是先放着——这样你愿意吗？有没有什么事你不想一个人在电脑上做？」（4.2 的边界）

## 七、验证

- 4.0：合成影子账上，旧动机过期后新动机能聚焦；世界事件强度按相关度；`groupOpportunity` 在合成一天里有非零的可开口分钟；DSH 用 `scripts/measure-group-opportunity.mts` 在真账上重量（只读）。
- 4.1：导入幂等（跑两次一样）；超 3 件不丢；桌面工具读写的是 QQ 那份。
- 4.2 / 4.3：开关关着基线逐字不变；开着时上课 / 睡觉 / 他在电脑前不派；派出去的任务提示词里没有他的原话；任务做完的进度回到追求、世界账多一件事。
