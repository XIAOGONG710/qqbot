# 0.3.1 交付说明

本补丁细化 0.3.0 的人格成长层，重点修正证据关联并提高控制台和自动评测的可解释性。

## 行为变化

- 主动分享精确绑定事件编号与有效期；同类型事件不会再让动态草稿引用到较旧的一条。
- 日记、照片、语音和动态意图带有形成原因与到期时间，继续保持“只生成待审核意图”的边界。
- 共同经历需要相邻对话中的双方回应；单方面计划不再被算成共同事实。
- 人生线增加升温、持平和降温趋势；偏好增加证据稳定度，并允许较新的重复表达逐渐修正早期看法。
- 反思保留来源事件编号用于结构审计，但 QQ、DSH 和控制台仍只收到脱敏类型摘要。
- Koishi 控制台用中文展示具体人生线、偏好、共同经历、反思和待审核创作，不显示内部枚举串。
- 人格一致性评测新增近似复读、模板化开头和记录时间倒序检查。

## 兼容性

没有新增持久状态格式。DSH 的成长摘要新增字段均向后兼容：读取旧摘要时使用安全默认值，未知字段继续被白名单移除。Android 正式包版本更新为 0.3.1（versionCode 4）。
