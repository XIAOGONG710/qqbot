# 0.3.2 交付说明

本补丁统一 DSH 桌面与 QQ 的记忆清晰度，减少无意义长期记忆，并保护她明确决定记住的内容。

## 行为变化

- DSH 与 QQ 都按清楚、模糊、一提想起、忘记和长期五档处理同一条记忆。
- 重复提到的事实保留更久；重要、长期和未来计划不会按普通旧事遗忘。
- 超期旧事只在明确实体线索下复苏，不再因常见二字词碰巧重叠而错误召回。
- `<<记住>>` 和 DSH `memory_save` 加重要保护；日记仍按日期自然变淡。
- 双方都是纯寒暄时不写长期库，但跨端最近对话仍保留，连续性不受影响。

## 兼容性

没有新增持久状态格式，也不重写既有 Hindsight 数据。协议与状态 schema 版本不变。Android 正式包版本更新为 0.3.2（versionCode 5）。
