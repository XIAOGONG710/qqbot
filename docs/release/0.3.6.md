# 0.3.6 交付说明

本补丁完成第一个“说话”模块的首轮分析，并修复完整问题被无谓澄清反问打断的问题。

## 行为变化

- 没有指代歧义时，她会直接回应已经说清楚的部分，不再为了保险问“你指哪件”。
- 只有一个上下文候选时优先按该候选理解；多个候选确实无法区分时才简短确认。
- 即使需要确认，也会先回应已明确部分，不把整轮只回成反问。
- `openQuestions` 场景增加端到端回归，确保她自己后来想过的内容能与直接回答规则同时进入提示词。

## 兼容性

没有新增外部请求、配置、协议或状态 schema，也没有改变危机与联系人安全边界。Android 正式包版本更新为 0.3.6（versionCode 9）。
