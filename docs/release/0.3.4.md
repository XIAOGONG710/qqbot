# 0.3.4 交付说明

本补丁修正 Koishi 中文控制台对组合功能的状态判断，避免“开关打开但功能实际没有运行”仍显示为已启用。

## 行为变化

- 功能总表同时声明明确的前置能力，状态页与配置解释共用同一份定义。
- 缺少前置能力的功能显示黄色“还需开启其他功能”，悬停可看到缺少的简短中文名称。
- 功能分组和总览分别统计真正生效与尚未生效的数量。
- 能力概览不再把缺少前置能力的开关计入可用能力。
- 页面不会自动开启其他功能，也不会展示内部配置键或代码值。

## 兼容性

没有修改配置格式、协议或状态 schema。现有配置保持原样，只改进只读状态解释。Android 正式包版本更新为 0.3.4（versionCode 7）。
