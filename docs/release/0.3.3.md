# 0.3.3 交付说明

本补丁增强 DSH、QQ 与手机伴侣之间短期上下文的故障一致性，并让上线前状态检查覆盖真实运行时格式。

## 行为变化

- DSH 问答只有在短上下文成功写盘后才进入当前进程记忆；磁盘故障不再留下用户未实际完成的“幽灵问答”。
- 问题和回答在持久化前统一处理空白、空文本和长度边界，写出的文件保证能够在重启后重新读取。
- 离线 `state-check` 会按 DSH 连续上下文 schema 校验角色、内容、时间和容量，提前报告运行时会隔离的状态。
- 状态检查继续只操作数据副本，不修改原始运行目录。

## 兼容性

协议与 `dshContinuity` schema 版本保持为 1，现有合法状态无需迁移。Android 正式包版本更新为 0.3.3（versionCode 6）。
