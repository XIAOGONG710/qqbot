# 0.2.0 交付说明

本版本收口十项能力：跨端总演练、Android 构建预检、实时语音转写回同一 DSH 对话、真实生图验收回执、长期记忆隔离恢复回执、世界事实多来源裁决、官方平台适配器边界、控制台一键体检、双窗口拟人回归和正式发布门禁。

## 自动验收

```powershell
npm ci
npm run typecheck
npm test
npm run verify:cross-end
npm run release:check
```

## 需要现场环境的验收

- Android：设置正式 `COMPANION_URL`，执行 `npm --workspace @qqbot/mobile-companion-android run preflight:release`，再用 Android Studio/Gradle 构建并在真机检查录音、断网、返回键和配对。
- AI 照片：配置供应商和视觉审查后执行 `ai-photo smoke --confirm-live ... --report <新文件>`；结果只进入待审核区。
- 长期记忆：把完整备份导入专用空库 `qqbot_restore_drill_*`，使用 `--report <新文件>` 留下不含连接串的回执。
- 贴吧、抖音、小红书：只有官方 SDK/开放 API、账号授权、人工批准和本次发布确认同时满足时才能调用；不确定结果必须人工核对。

这些项目缺少设备或凭据时应标记“未实测”，不得用模拟测试冒充线上成功。
