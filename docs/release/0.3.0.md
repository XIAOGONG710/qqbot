# 0.3.0 交付说明

本版本把原本分散的生活账、关系值、情绪、日记、小梗与长期记忆接成统一的人格成长层：长期人生线、自主决策、关系阶段、主动分享、连续情绪、审美观点、生活创作、共同经历、成长反思和人格一致性评测均使用同一份事实来源。

## 行为变化

- QQ 每轮会从既有事实重算一段自然语言生活脉络；不会展示内部数值，也不会把它当成必须汇报的话题。
- DSH 与 Koishi 控制台得到同一份脱敏摘要，只包含阶段、方向和计数。
- 创作能力只产生绑定生活事件编号的待审核意图，不会自动生成、发送或发布内容。
- 关系修复和情绪恢复有过程，不因一句道歉或一条好消息瞬间归零。
- 审美只从她自己的明确表达形成；用户的偏好不能被复制成她的偏好。

## 自动验收

```powershell
npm run typecheck
npm test
npm run release:check
```

人格一致性数据可使用以下命令检查；报告只输出比例和计数：

```powershell
npm run eval:personhood -- --input runtime/eval/personhood.jsonl --fail
```

## 升级与回滚

本版本没有新增持久状态格式，成长层由现有生活事件账和聊天记录重算。升级前仍按标准流程备份；回滚到 0.2.0 不需要迁移或删除状态文件。Android 正式包版本更新为 0.3.0（versionCode 3）。
