# 0.3.7 交付说明

本补丁继续深挖“说话”模块，修复运行时背景或置顶示例可能把当前消息挤出上下文的问题。

## 行为变化

- 提示词预算始终先为最新一条聊天及日期标记留出空间。
- 运行时背景按“泛背景在前、当前轮次规则在后”的顺序取舍，预算不足时保留连续的高优先级后缀。
- 置顶真人示例仍可优先，但不能挤掉她正在回答的最后一句。
- 发生取舍时日志只显示省略段数，不记录被省略的内容。

## 兼容性

预算充足时提示词内容和顺序不变。没有新增配置、协议、外部请求或状态 schema，也没有改变安全边界。Android 正式包版本更新为 0.3.7（versionCode 10）。
