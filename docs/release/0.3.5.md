# 0.3.5 交付说明

本补丁让 Koishi 控制台的现实世界数据摘要同时显示安全来源、覆盖范围和最近更新时间。

## 行为变化

- 天气、空气质量和日照显示覆盖地点、缓存量、已知来源与更新时间。
- 法定日历显示覆盖年份、来源与更新时间。
- 交通显示覆盖地点、来源与更新时间。
- 时间使用本地中文短格式，不再要求用户辨认 ISO 时间串。
- 未知供应商、未知地点、接口详情、错误正文和自定义线路说明继续隐藏。

## 兼容性

没有新增外部请求，也没有修改协议、配置或状态 schema。Android 正式包版本更新为 0.3.5（versionCode 8）。

```powershell
npm run typecheck
npm --workspace koishi-plugin-qqbot test
npm run release:check
git diff --check
```
