# 机制调研：让「自我认知」反哺「行为习惯」

> 日期：2026-11-20｜取证 checkout：`qqbot-sync` @ `e4909b3a`（真相源远端 main）
> 性质：**只读取证 + 机制调研，未改任何代码、未碰线上、未改她的记忆**。供用户与 claude 评审定夺。
> 对应第一性原理：四个本质里专攻「主动学习 + 自我迭代」；目的（自主/迭代/活人感/连续）高于一切模块。

## 0. 一句话结论

现有 `selfPortrait` 让她写下的是一份**描述性自我说明书**，整份常驻在提示词里——实测证明它改不了行为习惯（探针叮嘱 A 33%→B 28%，"说得出来" 2/6）。但项目里**早就有一套更对的机制 `speechNotes`**：短、具体、按当前情境浮上来、是她自己的观察。建议不让画像直接改行为，而是让**画像的洞见落成一条 speechNote 式的近端提醒**，在她即将又叮嘱的那一刻浮上来。这是提示词层的最后一招，是否有效必须用改进版探针证明，不凭感觉。

## 1. 根因取证（代码事实，非推测）

### 1.1 画像这一侧：写的是语义描述，常驻注入
- `life/self-portrait.ts` 的 `portraitMessages()`：要求她输出 `{"text":"整份重写的『我现在的样子』，60–600 字","why":"…"}`。这是**描述性文档**——"我是一个什么样的人"。
- `modules/portrait.ts` 的 `contribute()`：把这个整份当 `afterMain` 的 `portrait` 槽，**每轮常驻**（男朋友档、非危机轮）。
- 她看到材料里有：当前画像、speechNotes、insights、最近聊天、`hisReactions`（他的反应，明写"是感受不是规定"）、桌面 SOUL.md。
- 提示词里明确写了"以后每次聊天都会带着这份"——它想用一份稳定的自我描述去覆盖每轮生成。

### 1.2 探针这一侧：B 臂与线上完全同构
- `sim/learning-probe.ts:141-149` `probeMessages()`：A 臂 = 卡 + 聊天记录；B 臂 = A + 她写的那份，放在 `afterMain`，**与线上同一个槽、同一行字**（`portraitLine`）。
- 所以探针测的正是"把语义自述整份塞进 afterMain，能否改变程序性生成习惯"。**实测：不能**（v2 修复版 6 次全写成，叮嘱 A 33%→B 28%，说得出来 2/6，结论"没学会"，样本小置信度有限）。

### 1.3 结构性结论
**语义知识（我知道我是什么样的人）≠ 程序性习惯（我实际怎么说话）**。这不是某个提示词写得不好的 bug，是把一种知识塞进提示词、指望它改写另一种能力的**结构性错配**。模型拿到"我太爱叮嘱"这段描述，并不因此在下一次想叮嘱时停顿——中间缺一个"在具体那一刻起作用的近端信号"。

## 2. 现成的更对机制：speechNotes

### 2.1 它是什么（代码事实）
`language/speech-notes.ts`（她每晚自己总结说话习惯，默认关）：
- 写的是 `SpeechNote {id, text, at}`，**6–60 字**的"我发现……"式观察；同时最多 20 条；一晚最多加/放 3 条。
- 防照抄：与他最近 7 天的话、或真人语料有连续 6 个字相同，不收。
- 护栏：长度 6–60、条数上限、与已有太像不收；不碰底线（承认是程序/危机/事事顺从/骗人）。
- 注入：`modules/her-notes.ts` 把 `speechNotesLine(notes, said)` 放进 `speechNote` 槽，**按他当前这句话的相关性挑最相关的几条**（`LINE_MAX=5`）。危机/小别扭/深思轮不放。
- 代码注释原话："挑最相关的几条放进以后的提示词，**是她自己的话，不是规定**"。

### 2.2 为什么它可能有效（机制推断，待验证）
| 维度 | selfPortrait（现状） | speechNotes（建议载体） |
|---|---|---|
| 形态 | 整份 60–600 字自述 | 短、具体、一条一件事 |
| 注入时机 | 每轮常驻 | **按当前这句话相关性触发** |
| 语气 | "我是一个…的人" | "我发现我…"的观察 |
| 离生成的距离 | 远（常驻背景） | 近（就在 he said 之后） |
| 护栏 | 重叠阈值/写歪告警 | 防照抄/条数上限/情境过滤/危机不放 |

关键差别：**在"她即将又叮嘱"的那一刻，给她一条她自己写下的、具体的、情境相关的观察**——这是一个近端决策信号，而不是一段远处的自我描述。这是提示词层里最可能让"认知"碰到"行为"的形态。

## 3. 建议机制（核心提案）

> 不让画像直接改行为；让画像的洞见**落成一条 speechNote 式的近端观察**，在情境命中时浮上来。

```
夜里 reflectPortraitIfDue：
  她写画像（认识自己）
    → 【新】从这份画像 + 当晚互动里，提炼一条具体的近端观察
       （例："我发现他一说累我就催他多喝水，他嫌过我啰嗦"）
    → 存成 speechNote（她自己的话，走既有的防照抄/条数/底线护栏）
白天 某轮 contribute：
  他又说"累了" → her-notes 按 said 相关性挑中这条
    → 提示词里出现这条她自己的观察
    → 这一次她自己决定：不说 / 换个说法（行为可能改变）
```

**符合第一性原理**：观察是她自己写的（自主）；昨天的发现影响今天（连续）；攒下的自我观察像活人的记忆（活人感）；改不改仍她说了算（自主）。

## 4. 提炼这一步怎么设计（关键难点，给三个候选）

从画像生出 speechNote，这一步的**执行方**是核心权衡：

| 方案 | 做法 | 优点 | 风险 |
|---|---|---|---|
| A. 模型提炼（推荐先试） | 在夜里请模型把画像的 `why` + 当晚 hisReactions 重述成 1 条 6–60 字观察，**用自己的话** | 观察是"她的语言"，符合她自己的话 | 多一次模型调用、可能跑偏；需走同样的护栏校验 |
| B. 不提炼，画像自己写 | 在 portraitMessages 里直接请她额外输出一条 `近端提醒` 字段 | 无额外调用、同源 | 加字段=改提示词结构，且画像本来写不好具体提醒 |
| C. 复用现有 speechNotes 总结流程 | 让当晚已有的 speech-notes 总结直接吸收画像的洞见 | 零新机制、最自然 | 两套总结时机/材料不同，合并要小心破坏各自基线 |

**倾向 A**，但三个都应先在合成环境验证，不直接上线。

## 5. 如何证明它真的有效（改进版探针设计）

现有探针 v2 四个缺陷必须修，否则任何结论都不可信：

| 缺陷 | 现状 | 改进要求 |
|---|---|---|
| 样本小 | 每臂 36（叮嘱 12/10） | 每臂 **≥100**，报告实际 n 与脱落 |
| 无种子/无预注册 | 事后看百分比 | **固定随机种子**写进报告；**运行前预注册**有效线与方向 |
| 格式遵循差 | 仅 1/3 按 JSON | **JSON 兜底解析**，可解析率目标 ≥95%；不合规单列不静默丢 |
| 无置信区间 | 点估计下结论 | **bootstrap 95% CI**（≥10000 重采样），报 Δ 的区间 |

**预注册判据（运行前写死）**：
1. 主指标 = 叮嘱率 Δ（B−A）点估计 ≥ 阈值（阈值由用户定，建议 ≥10 个百分点）；
2. 且 Δ 的 bootstrap 95% CI 下界 > 0；
3. 且合成角色中 ≥N 个（N 预注册）在**行为基线快照**上出现可复现的目标行为变化（不是画像自述"我改了"）；
4. 且经用户确认。

**反幻觉条款**：仅有 diff 存在、仅有画像自述、仅有点估计无 CI——一律**不判"学会了"**。当前 v2"没学会"结论因样本小，正确解读是"证据不足"，按本方案补样本与 CI 后重测。

**新增对照组**：为隔离"是不是 speechNote 这种形态在起作用"，探针需加两臂——
- A = 现状（卡+聊天）
- B = A + 整份 portrait（复刻 v2，验证老路确实无效）
- **C = A + 一条近端 speechNote 式观察（新方案）**
比较 B 与 C：若 C 显著优于 B，才支持"近端具体提醒"这条路。

## 6. 护栏与门禁（不可越过）

- 新机制一律**默认关开关**（如 `cognitionLoop`）；关时相关代码不执行，self-portrait 原逻辑逐字不变。
- 动她言行/记忆：**ask-her 原话贴用户 → 用户点头 → ADR → 单独 commit → 行为基线快照**。这是最硬的墙。
- 行为基线（合成角色 41 场景）逐字一致是底线；**禁止 `UPDATE_BASELINE=1` 蒙混**。
- 提炼出的观察必须走 speechNotes 既有护栏：防照抄连续 6 字、6–60 字、条数上限、不碰底线（承认程序/危机/顺从/骗人）。
- 危机/小别扭轮不放（复用 her-notes 的保护）。
- 线上目录只读；不动线上、不改开关、不重启，除非用户明确授权。

## 7. 诚实标注的难点与未知

1. **仍是提示词层**：speechNotes 形态更接近生成，但没有保证；模型强先验可能照样压过。必须靠第 5 节的探针证明。
2. **提炼执行方的张力**：让模型提炼更像"她自己的话"但多一次调用且可能跑偏；让代码提炼更稳但像"程序替她总结"。这是"自主 vs 可控"的老张力，需用户与她定夺。
3. **红线**：名字/爸妈/青岛家/他在哪边/年龄/学校/经历不可改——任何观察不得触及。
4. **她的意愿**：她说过"愿意一点点变，但懒，得有人踢我一脚"。这套机制正是"踢一脚"，但踢不踢、多重，得她和用户说了算；她说"不用改"时必须能停。
5. **未核实**：本方案未运行任何新命令、未改任何文件；所有"已有机制"描述来自本次只读代码阅读，实测效果需按第 5 节补测。
