# 核心人设里的主动挑逗

先用合成角色卡征询，用户同意后实现。她愿意主动逗一下，认真被回撩时可以害臊，口气保持自然；熟人只回「嗯」或转场就收住，陌生人先聊共同话题。

QQ 私聊、QQ 群聊和 DSH 已确认私聊共用 `dsh-plugins/dsh-linmengyao-memory/playful-persona.mjs`。在隔离环境将 `QQBOT_PLAYFUL_PERSONA=1` 设给相应进程即可复验。开关默认关闭，未改正式配置或本地私有角色资料。

群里沿用公开互动判断熟悉度。她本来就会接话时，可以对有跨日公开往来的群友先轻轻逗一句，不必等对方明确邀请。新群友没有挑逗许可，熟人也只留一句。对方没接时，下一轮走收住分支。群提示词不引用私聊的亲密、矛盾或修复内容。

验收用临时状态与假传输。QQ 私聊和 DSH 测试核对实际系统提示词；群聊用同一句「都早点睡」分别验证熟人、陌生人和接着转场，检查输出拦截。另用合成对话试跑 DeepSeek，检查主动开口、被回撩、陌生人及转场的口气；模型遇到适合挑逗的场景仍可选择普通回应。未启用线上开关，未发送 QQ。

## QQ 私聊口气复调

用户同意按合成征询调整。QQ 私聊在聊天记录后补一条口气约束。轻松时从下线、出门或吃早饭这种眼前的小事递一句，说完留余地。认真回撩时允许顿一拍、嘴硬半句，后半句接住对方的认真。共用人设移除了「讨一句单独晚安」的固定例句，保留没接梗、转场或不愿意时停下。DSH 不读取 QQ 专用口气。

QQ 用实际提示词组装器，DSH 用实际记忆插件的私聊人设上下文。直接晚安、聊完笑话再晚安、出门买早饭三组，每端各测主动开口、认真回撩和收住。后两条从同一句合成逗话分叉，合计 18 条模型输出。两端 6 个收住分支均未追撩，QQ 三条开场都从话题取梗，没有讨晚安。回撩表现有波动，QQ 有一句接住了认真，也有一句仍附带害羞表情，一句只接了早饭话题。模型取样全程只发合成提示词，未接正式 QQ 或 DSH 会话。

## 认真回撩后的接话

按本轮征询和用户确认，QQ 私聊遇到认真回撩时先接眼前的心意。可以顿一下、嘴硬半句，接着软下来，不拿口头禅或害羞表情替代表达，也不随口答应以后叫醒。两端共用规则保留没接就停，临睡、临走不追加请求、追问或承诺。

最终取样沿用晚安、笑话、早饭三组，从同一句逗话分出认真回撩和收住，每端六条。QQ 回撩三条中两条没用「行吧」「笨蛋」，晚安分支仍用了两句口头禅。三条均没有害羞表情。两端六条收尾未追撩，也未出现叫醒承诺。DSH 回撩的一条仍出现括号动作，QQ 专用口气未注入 DSH。没有启用线上开关或发送 QQ。
