# K 观察、隐私和质量门槛

按用户要求直接做。验收使用合成数据和假传输，线上服务与 QQ 不参与。

`QQBOT_DECISION_AUDIT=1` 默认关闭。开启时，新记录使用随机轮次 ID 和固定标签。私聊判断、质量拦截与确认的出站可以按同一 ID 对照。群聊记录开口类别。此模式暂停原有 App 自由文本日志、旧提示词指纹清单和敏感提示词转储。正常私有聊天数据仍在原处。

测试让假模型重复声称要打电话。出口拦下全部不合格回复，假传输没有被调用。下一轮合法文字通过，并在收到假传输回执后才记录送达。日志、原始审计和导出均搜索了私聊标记、账号和被拦措辞。额外向导出输入塞入这些字段，导出会重建允许字段。

本地导出入口为 `node scripts/export-decision-audit.mjs <dataDir>/logs/decision-audit-YYYY-MM-DD.jsonl`。旧日志和旧导出没有被改写或清理。此模式不是第三方 SDK 日志或整份数据目录的脱敏工具。

合成入口验收、类型检查和 39 项默认行为基线均通过。专项回归通过 72 项，既有 4 项停用旧规则测试保持跳过。未启用线上开关。
