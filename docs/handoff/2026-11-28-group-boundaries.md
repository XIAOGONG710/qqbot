# H 关系、群聊、亲密与修复

用户授权直接做。只使用合成对话、角色卡和假传输。线上服务和 QQ 出站不参与验收。

`QQBOT_GROUP_BOUNDARIES=1` 启用 H，默认关闭。熟悉度用同群近 30 天跨日的公开回复关联计算，未绑定的历史互动不用于升级分寸。QQ 私聊关系标签、原话和角色卡里的私密背景不进入此模式的群提示词。判断基于可识别的邀请、拒绝和回复证据，并在出站前再检查一次。

合成 App 场景用同一句「来逗我两句」分别给陌生人和熟人。陌生人的追逗稿被拦，只留下普通群聊回复。熟人明确邀请时只出一句。回「嗯。」后转场，继续追逗的草稿被拦。私聊亲密称呼、矛盾原话和情侣标签均未出现在群提示词。全部传输使用测试替身。
