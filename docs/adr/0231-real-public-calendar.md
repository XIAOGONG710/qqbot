# ADR 0231：现实法定节假日与调休

状态：已实现，默认关闭（`realCalendar: false`）。

## 决定

增加一个只读的中国法定日历适配器，默认从 `holiday.ailcc.com` 的年度接口读取当前年和下一年的法定休假日、调休上班日。该站点声明数据依据国务院办公厅节假日安排整理，并提供结构化的 `holiday=true/false`、名称和日期字段；最终安排仍以国务院最新通知为准。

日历只投影成 `WorldNow.publicHoliday`，不直接修改角色卡里的学校课程、假期或补课。学校实际安排继续由 `schedule.holidays` 与 `schedule.makeups` 决定，避免把全国法定日历误当成她学校的课表。

## 边界

- 独立开关控制，缓存 7 天；失败、不完整、过期或响应过大时不写进世界；
- 只接受日期、名称和休/班类型，限制最多 366 天；不把外部正文、链接、QQ 或聊天内容写入提示词；
- 当前年和下一年分开请求，单年失败不覆盖已有缓存；
- `publicHoliday` 只用于环境描述和审计，不能自动创造出行、停课或消费事件；
- 调休上班只作为现实背景，学校是否上课仍由本地课表决定。

## 为什么这样接

国务院年度通知同时包含放假和补班日期；只接“节日名称”会漏掉周末补班，直接改学校课表又会把不同学校的安排混在一起。因此先做独立、可关闭、可过期的事实层，后续若需要再由用户明确配置“法定日历是否影响她的学校作息”。
