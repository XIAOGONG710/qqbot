# ADR 0233：环境事实参与行动选择

状态：已实现。

## 决定

把世界快照里的真实空气质量传给“今天的打算”结算器。只有 AQI 大于 200（重度或更严重污染）时，出门活动才改用 `plans.outings[].indoors`，并留下“空气质量差，不想出门”的原因；雨、身体状态、作业等既有规则仍按原顺序执行。

日照目前只作为事实传入，普通晚间计划不会因为天黑被擅自取消。缺少实时数据、数据过期或 AQI 在 200 及以下时，保持角色卡原计划，避免把不完整的外部数据变成强行为决定。

## 边界

- 状态行、生活执行器、日记和按日回顾共用同一份 `PlanFacts`，不另存一份“环境决定”；
- 只影响已经标记为出门的活动，不改学校课表、法定日历、约定和生活事件账；
- 规则是可重放的纯函数，不调用模型、不写状态；
- 供应商失败或缓存过期时世界不提供该事实，行动选择自动回到原有规则。

## 为什么这样接

环境数据最适合先作为事实进入既有规则层。将高污染作为明确阈值、将日照保持为观察事实，可以让她的选择更像真人，同时保留白名单、可关闭、可审计和回放一致性。
