# ADR 0034：她的一天有打算，也会改

- 状态：实现，真模型验证中（2026-10-08）
- 日期：2026-10-08
- 关联：[ADR 0007](0007-schedule-and-reply-timing.md)（作息、空闲活动）、[ADR 0021](0021-her-world.md)（她的世界）、[ADR 0025](0025-her-body.md)（身体）、
  [ADR 0026](0026-diary-of-her-day.md)（日记）、[ADR 0029](0029-life-event-ledger.md)（生活事件账）、[ADR 0030](0030-doing-now-follows-her-world.md)（此刻在做的事）、
  [ADR 0032](0032-she-remembers-her-days.md)（问到过去哪一天）、[实施方案](../research/2026-10-07-life-engine/implementation-plan.md) 批次 A3、第 6 节「计划修订：至少 1 次因冲突或意外修改」

## 背景

空闲时干什么是作息里按「日期 + 时段」固定挑一条（`schedule.yml` 的 free），和那天的事实无关：下大雨她「去图书馆占座」，肚子疼得厉害她「打独立游戏」，
明天要交的作业一个字没写她「在追一部剧」。她也没有「今天打算干什么」——真人会说「本来想去图书馆，下雨就在宿舍写了」。

读代码时还发现，同一时刻不同的人看到的不是同一件事：
- 挑法是 `哈希 % 列表长度`，可同学档的列表少了两条只给 BFGK 的（修片、刷摄影区），同一时刻男朋友看到「修昨天拍的片子」，同学看到「打独立游戏」；
- 聊天时并上了在读的书（「窝在床上看《药屋少女的呢喃》」），日记没并，聊天里那晚在看书，日记写的是「在追一部剧」。

## 决策

1. **挑出来的那条就是她早上起来对这一段的打算**（`day-plan.ts` `dayPlan`）：上午、下午、晚上各一段，整段都在上课、睡觉的没有。
2. **到时候按那天的事实结算**（`world.yml` 新块 `plans`，谁都看得到）：
   - 肚子疼得厉害（生理期头一天痛经，ADR 0025）：什么都不干，`rest`「躺在床上刷手机」；
   - 要出门的（`outings`：去图书馆占座、在图书馆赶作业）：下雨、感冒、身上不舒服就换成在宿舍（`indoors`）；
   - 晚上：明天要交的作业还没写、打算的又不是写作业（`study` 以外的），先赶作业，写完回到原来的打算。
   - 结果是「照打算做了」或「本来打算 X，因为 Y，改成 Z」。说不出口生理期的档位只说「身上不太舒服」。
3. **进提示词只给事实**：
   - 状态行：空闲又没有 ADR 0030 的事（喂猫、视频、洗澡……）时写「本来打算去图书馆占座，下雨了，在宿舍写作业」；
   - 时间块多一行 `[你今天的打算（…）：上午…；下午本来打算…，下雨了，…；晚上…]`，醒着时才有；和人聊天时说过实际干了别的，以说过的为准；
   - ADR 0032 问到过去某天时，那天各段的打算和改了的也在流水账里；日记的「空闲时」换成同一份（改了的照实写）。
4. **同一时刻各档是同一件事**：看不到的空闲活动不删，换成 `cover`（「窝着刷手机」），列表一样长，挑到同一格；日记和聊天一样并上在读的书。
5. 规则驱动、按日期可重放，不调模型、不存状态。

## 不做的

- 不写进生活事件账（ADR 0029）：打算和结算都能从日期、天气、身体、作业推出来，写账就成了两个事实源（实施方案第 3 节纪律 1）。等打算真的由模型来定（早晨规划）时再写账。
- 不让模型早上规划（实施方案「低频调用 LLM：早晨规划」）：先用规则把「会改」立住。
- 不改世界里的小事：「去图书馆没占到靠窗的座」这类小事还是按概率，和她那段打不打算去图书馆无关（以后接上）。
- 陌生人、名单外档没有书，空闲活动列表短一截，和别的档可能挑到不同的格；这两档几乎不聊作息，先不管。

## 实现时的调整

1. `study` 加「熬夜赶作业」：晚上的空闲活动里本来就有这条，没算进去时出了「本来打算熬夜赶作业，……作业明天要交，先赶作业」。
2. **日记按同学档的作息算**：日记进公共库，同学档也会想起来。它的世界本来就用同学档的卡，作息却是最亲那一档的——`worldAt` 按它算出来的作业带课名，
   新加的「晚上本来打算……，Linux操作系统、MySQL数据库应用的作业明天要交」把课名写进了日记（`diary.test.ts` 抓到）；
   「空闲时」也一直按男朋友档挑，可能写进「修昨天拍的片子」（同学档以下不该知道她拍照）。有了 cover 以后同学档挑到的是同一格，日记改用同学档的作息（`worldSchedule`）。
