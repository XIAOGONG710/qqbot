# ADR 0049：聊天记录隔天插日期

- 状态：**已上线**（2026-10-10 13:28，`main` = `integration` = `1e86548`（`release-1010b`），用户同意后重启 Koishi；日志确认插件加载、真实天气和听语音看图为「开」、NapCat 就绪）
- 日期：2026-10-10

## 背景

提示词里的聊天记录只有一条条消息，不带日期。几天前的话和今天的话挨在一起，她分不清哪句是哪天说的：
10-05 他说「我在老家好无聊」，10-12 他说「我在你宿舍楼下」，她回「你不是在老家吗」（ADR 0007 调整 2026-10-10，子代理排查：
「距上一条消息：6 天」只在隔天后的第一轮出现，之后就变成「4 小时」「不到 1 分钟」）。那次用「放完假头几天单独一行说明他回来了」补上了，
但只管放假这一种；「昨天说的」「上周说好的」这类在聊天记录里分不清日子的问题都一样。真人在 QQ 上看聊天记录，隔天的消息上面有日期。

## 决策

1. **隔了一天，在那一条前面插一行日期**（`prompt.ts` 的 `addHistory`）：单独一条 system 消息「[10月12日 星期一]」；不是今年的带年份（「[2025年12月31日 星期三]」）。
   日子按日历日（零点换天）：和时间块「[当前时间：2026-10-12 星期一 12:30]」同一套说法。
2. **放进去的最早一条前面也有一行**：聊天记录被预算截断后，留下的那段从哪天开始她也知道。日期行算进预算（先给最早那一行留出来）。
3. **绝对日期**，不写「昨天」「上周」：旧消息前面那一行永远不变，聊天记录的前缀稳定，不影响缓存命中（10-09 查过：每轮挪窗口已经让缓存只能覆盖角色卡那部分）。
4. 消息没有时间（旧数据、单元测试）不插。
5. **出口检查**认得这种行（行首「[10月12日 星期」），她照抄出来的从那一行起删，和时间块各行一样。

## 验证

- 单元测试：隔天插、同一天不插、最早一条前面有、不是今年带年份、没时间不插、截断后最早一条前面有且不超预算；出口检查拦照抄的日期行。
- 全仓测试 570 / 570。
- 真模型（不开记忆，各 2 次，批次 `20261010-*-adr49`）：`schedule-boyfriend` 26/26、26/26（之前 26/26 ×3）；`npc-days` 25/25、24/25（之前 25、24、25，同一条「好了」检查时过时不过）；`speech-return` 17/17 ×2；`world-days` 48/48 ×2。
  没有一条回复带出日期行；提示词里 10-05 那段和 10-12 这段之间是「[10月12日 星期一]」，「我在你宿舍楼下」她回「急什么，拎着快递刚到楼门口」。

## 不做的

- 同一天里隔了几个小时不插（时间块已经有「距上一条消息」；插了反而碎）。
- 每条消息带钟点：太多结构，模型容易照着在回复里写时间。
