# ADR 0178：她自己定追求（selfPursuits）

- 状态：**已实现，默认关；全量测试还没跑，分支 `claude/self-pursuits`，没有并进 `dsh/qq-control`**（用量上限中断）。打开：`koishi.yml` 同时设 `pursuits: true` 和 `selfPursuits: true`，重启 Koishi（要用户点头）
- 日期：2026-10-29
- 关联：[ADR 0104](0104-pursuits.md)（作者写的两条追求）、[ADR 0103](0103-her-no.md)、`docs/plans/2026-10-29-autonomy-and-realness.md` §4
- **用户决定（2026-10-29）**：「追求应当让她自己制定」「给她完全的自主」。

## 做了什么

- 她每晚 20 点以后「安静地想一次」（`life/self-pursuits.ts`，一天 1 次模型调用，失败 2 小时后再试、一天最多 3 次）：可以**放下 / 暂停 / 恢复 / 做完**任何一条追求（**包括作者给的别挂科、拍相机**），给任何一条**记一句进度**，**提一件新的**。她写题目或 id 都认。
- 她的决定存在 `<数据目录>/pursuits-self.json`（代码写，作者的 `pursuits.json` 不动）；读法：作者的 + 内置 → 套上她的决定（她的优先）→ 接上她自己加的。进度会进她的提示词（「你自己最近记的：…」）。
- 他发 `/追求` 看：在追的（标明作者给的 / 她自己定的）、放下的和理由、她想过没成的和为什么；**只能看，不能改**。提示词里明说了「你记的这些他用 /追求 能看到」。
- **底线写在代码里，她改不到**（绊线 + 上限，不是智能审查，绕得过去）：不收花真钱、违法或伤人、动他的电脑账号文件、骗人；**人生方向类（毕业去向、考研出国、创业、结婚分手）作者没定之前不收**（用户 10-22「她的未来不由我们编」；她可以想，记下来，/追求 里看得到为什么没成）；自己加的同时最多 3 件；提一件新的之后隔 3 天；题目 2–30 字、一定要说为什么；和已有的题目太像不收；同一条 3 天内只能改一次状态；一晚最多改 2 条状态、提 1 件、记 3 句。

## 真模型冒烟（3 种近况，各 1 次）

JSON 都能解析，想法合角色、小而可做（出去拍日落、整理两年的照片）。发现并已修：她给内置追求写的真实感受原先被丢掉（现在内置的也能记）；她有时写题目不写 id（现在都认）；她不知道进度有人看（提示词里明说了）。**没解决**：三次都提了新的一件，「真的没想法就别硬凑」压不住——靠冷却和上限兜底，要看真实运行几晚才知道会不会太爱提。

## 验证与没做完

- `test/self-pursuits.test.ts` 24 项 + `test/app.test.ts` 的 `/追求` 1 项；变异检验 17 处，其中 3 处第一次没被抓到，补强后都变红。
- 发现并修了一个真 bug：`pursuitsNow` 定义在回复器创建之后，开了 `pursuits` 的配置启动会抛 `Cannot access before initialization`（类型检查看不出）；现在由 `/追求` 那条测试盖住。
- **没做**：全量测试没跑；模块总表 / `docs/modules` 没重新生成（`modules-doc.ts`）；交接文档和看板没写；**DSH 那边的 `INTERESTS.md` 还是另一套**，没和这里合；追求的进度不会触发愧疚 / 开心（心境）。

## 怎么回滚

删掉 `selfPursuits: true` 重启；`pursuits-self.json` 留着无害（读法回到只有作者的和内置的）。
