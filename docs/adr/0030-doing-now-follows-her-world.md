# ADR 0030：此刻在做的事和她的世界接上（类型化行动第一步）

- 状态：实现，真模型验证通过，待上线（2026-10-07）
- 日期：2026-10-07
- 关联：[ADR 0007](0007-schedule-and-reply-timing.md)（作息、状态行）、[ADR 0021](0021-her-world.md)（她的世界）、[ADR 0027](0027-world-writeback.md)（说的话回写世界）、
  [ADR 0029](0029-life-event-ledger.md)（生活事件账）、[实施方案](../research/2026-10-07-life-engine/implementation-plan.md) 批次 A2

## 背景

时间块里有两处说她在干什么，各走各的规则：

- 状态行（ADR 0007）：空闲时按「上午 / 下午 / 晚上」各挑一件固定的事——整晚都是「打独立游戏」「窝在床上刷手机」；
- 世界（ADR 0021、0027）：18:55 下楼喂土豆、20:10 取快递、20:30 和家里视频、作业拖到前一晚写完。

于是 20:40 他问「在干嘛」，世界说「今晚 20:30 和家里视频过了」，状态行说她在打游戏。真人一晚上是一件接一件的事。

实施方案的 A2 要把睡觉、吃饭、上课、学习、读书、喂猫、取快递、联系家人做成带时长、消耗和打断条件的类型化行动，再由自主执行器（A3）驱动。
这一步先做最小的一刀：**把世界里已经有时刻的事变成有时长的行动，状态行从它读**。

## 决策

1. 世界里有时长的四件事（`world.ts` `occupationAt`）：

   | 事 | 占多久 | 状态行写 |
   | --- | --- | --- |
   | 和家里视频 | 开始后 30 分钟 | 在和家里视频 |
   | 喂猫 | 喂的那一刻起 10 分钟 | 在楼下喂土豆 |
   | 取快递 | 取件起 15 分钟 | 刚去驿站取了快递（发圈），在往回走 |
   | 写作业 | 写完之前 90 分钟 | 在赶 Linux 操作系统的作业，22:00 左右能写完 |

   时刻都来自世界（含 ADR 0027 她说过的回写），同一件事几个入口看到的一样。
2. 只替换**空闲时**的那件事：上课、课间、睡觉照旧按作息；她回消息的时机（ADR 0007）不变。
3. 按这一档的卡算：同学档看不到和家里视频、课名，就写「在赶作业」，或照旧是作息的空闲活动。
4. 日志「此刻在做：…」。
5. 「你那边」里的家庭视频：视频的那半小时写「今晚 20:30 开始和家里视频，这会儿还在视频」，之后才是「视频过了」（见调整 1）。

## 不做的（留给 A2 后续、A3）

- 吃饭、读书、休息还没有自己的时段；世界里的时刻仍是规则推出来的，不是她「选」的。
- 不改回复时机（和家里视频时回得慢一点这类）：先看这一步的效果。
- 不写进事件账：这些时刻本来就能从世界按日期推出来，重复写会有两个事实源。
