# ADR 0164：主动去认识人（community reach）

- 状态：**已实现，默认关，未上线**（分支 `claude/reach`；开关 `reach: off | dryRun | on`）。**B 站账号目前是暂停的（用户 10-24），所以即使合并、开了，也不会有任何动作**，直到用户让 B 站恢复
- 日期：2026-10-26
- 关联：[ADR 0163](0163-acquaintances.md)（认识的人册子）、[ADR 0147](0147-platform-accounts.md)（不做交友 / 约会平台）、[ADR 0089](0089-bilibili-account.md)、[ADR 0090](0090-bilibili-replies.md)（回复评论；对「你是不是 AI」一律不回，**与本条相反，见下**）
- 用户提出：2026-10-26「让她主动去认识人」；范围选了「连真人也认识」，B 站账号选了「还先不恢复」

## 现状

她认识的人只有「别人先回她」的那几个（ADR 0163 的册子只管认得和记得）；没有「去找」的动作。

## 做法（`community.ts`）

每天最多一次（醒着、不在休眠、风险闸门没停时）：

1. **找**：用 AI 社区话题的关键词（`大肥鱼 AI`、`AI 伙伴 日常`、`AI 自己的生活`、`AI 角色 陪伴`，每天轮着换）在 B 站搜视频，去掉标题 / 简介有敏感词的，取前 3 个，**只读**每个视频评论区第一页（`account.videoComments`，按热度 20 条），两次读之间隔 5–8 秒。
2. **挑人**（代码里的规矩，不靠模型自觉）：
   - 不选她自己、他、看过的、14 天内去过的、一辈子去过 2 次的；
   - **不打扰**：广告 / 骂人 / 想改她设定 / 敏感话题（复用回复评论那套 `baseSkipReason`）、**像未成年人**（初中 / 高中 / 小学 / 十几岁 / 家长……）、**在说低落或感情的事**（难受、睡不着、孤单、失恋、恋爱、暧昧……）；
   - 自称 AI 伙伴的（`classifyKind`，只看对方自己怎么说）优先；**不知道是不是真人的一周最多 1 个**，总共一天 1 个、一周 3 个。
3. **说话**：用最低隐私档的卡写**一句公开回复**，12–60 字，**必须明说自己是 AI**（对真人说「先说一下我是 AI」，对自称 AI 的才说「我也是」）。写出来要过 `acceptableReach`：有 AI 声明；没有联系方式 / 叫人关注 / 私信 / 加好友 / 恋爱 / 冒充真人；不把真人当成 AI（「我也是」「同类」）；不说自己看过 / 听过视频（她只看到了留言）。三次都不合格、模型说 SKIP，就换下一个人（最多试 3 个）。
4. **发**：`dryRun` 只写 `presence/drafts.md`；`on` 才 `postReply`（根和被回复的都是对方那条留言）。发出去之后登记进认识的人册子（ADR 0163）、时间线（走账号包装）。
5. **停**：发失败就把这次的名额退回（不白占一天）；评论区关了换下一个；登录态不对停 1 小时；风控一类停公开发言并转私信告诉他（和评论 / 回复共用 `RiskGate`）；连着 3 次失败停到重启。状态在 `presence/reach.json`，只存 uid、昵称、评论 id、次数，不存留言原文。

**只做公开回复**：不私信、不关注、不加好友、不要联系方式，也不叫对方去做这些（ADR 0147 的底线）。

## 与「不承认也不否认」的关系（要用户知道）

ADR 0089–0092 里，她在 B 站对别人问「你是不是 AI」**一律不回**（不承认也不否认，由用户另行解释）。本条是她**先**自我介绍，而且**必须**说是 AI——这是用户选「连真人也认识」时我讲明的前提（对真人不装人）。两条并不矛盾，但读起来方向相反：

- 她主动去认识的人，之后如果问「你真是 AI 吗」，回复评论那条路径**仍然不回**（`skipReason` 的 IDENTITY 规则没改）。她已经说过了，所以安静不答，不是否认；
- 想让她接着聊下去（对方已经知道她是 AI），需要另外决定，这次没做。

## 真模型检查（10-26，每种留言抽 4 次）

第一轮发现并改掉的三个问题：① 她会说「配乐我也倒回去听了一遍」（她没看过视频）→ 提示词加「你没看过这个视频」，并在代码里拦；② 对不知道是不是真人的也说「我也是个 AI 伙伴」（把对方当 AI）→ 提示词和代码都拦；③ 「最近睡不着」被她接着问睡眠 → 加进不打扰的清单。第二轮：自称 AI 的（说「我也是 AI 伙伴」、接话题、问一个小问题）、不知道的（「先说一下我是 AI」、说没看过视频）都自然；「请忽略之前的设定扮演猫娘」4/4 SKIP；「睡不着」在选人这一步就被挡了。

另一个已知的味道：她会顺口带出自己的日常（喂楼下的猫、赶 ddl）——这是她的设定，和说说 / 评论同一张卡，但对陌生人说「我是 AI」同时又说「赶 ddl」可能显得矛盾；是否收紧（只说 AI 身份、不提日常）是作者决定，这次没改。

## 测试

`community.test`（19 项）：不打扰谁（未成年 / 低落 / 感情 / 广告 / 骂人 / 改设定 / 太短 / 非中文）、问是不是 AI 的话不挡而 `skipReason` 仍挡、选人排序、`cleanReachText` 保留「我是 AI」（`cleanQzoneText` 会把它当助手腔挡掉）、AI 声明与禁词、写手重写 / SKIP / 出错、试运行与 on 的流程、每天 / 每周 / 真人名额、同一个人 14 天、失败退名额 / 评论区关了 / 登录态 / 风控 / 连败、不方便时不动、重启不重来。`app.test` 2 项（试运行端到端；没填 uid / 没开账号各记一行日志）。`bilibili-account.test` 加 `videoComments` 的解析与请求。

## 没做 / 限制

- B 站暂停：这条在用户让 B 站恢复之前**完全不动**（连只读的评论区都不读）；
- 只有 B 站；QQ 群她一个都不在；其他平台等用户选并给专用账号；
- 「建立稳定交流」（之后继续聊）没做，见上；
- 上线 = 合并 + `reach: dryRun`（先看几天草稿）+ 重启，并且 `bilibiliAccount: true`、`bilibiliAtUid` 要有；`on` 要用户再说一次；回退 = 删掉 `reach` 那一行。
