# ADR 0230：假期事实进入世界快照

状态：已实现。

## 决定

`WorldNow` 除了 `atSchool` 外，明确带上当天命中的假期名称、起止日期和地点信息。来源仍是角色卡已经裁剪过的 `schedule.holidays`，不另造一份日历，也不把普通周末或学期外的无课日误称成假期。

世界描述和摘要可以直接使用这条事实，日记、行动选择和状态行继续沿用同一个 `stateAt` / `herDay` 判断。

## 边界

- 只读角色卡里的假期，不自动改变课程表；调休仍由 `schedule.makeups` 负责；
- `holiday` 为空时保持旧的 `WorldNow` 结构，兼容没有假期配置的卡；
- 不把伴侣位置、私密备注或其他档位不可见内容复制进世界账；
- 假期信息只作为事实描述，不自动生成旅行、消费或聊天事件。

## 为什么需要

此前世界只记录“在不在学校”，调用方需要再次读取作息才能知道是国庆、寒假还是普通周末，容易让世界描述、状态行和日记出现不同说法。把假期元数据投影到同一快照后，所有模块都能按同一事实工作。
