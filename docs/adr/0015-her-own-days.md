## 决策

### 1. 每日心情：按日期可复现，从她当天的课表来

- 每天一个心情，同一天对所有人一样（这是她的日子）；「一天」按她的作息算：02:00 睡觉之前算前一天（和状态行同一个规则，跨午夜不换）。
- 抽法：按日期哈希、按权重抽（和空闲活动同一种做法，不存状态，重启、模拟器都能复现）。权重按她当天的日子调：
  早八、课多（3 节以上）更可能安静，没课、放假更可能话痨、玩梗。命中的那条日子就是心情的原因，写进心情那一行，
  她被问到「今天怎么了」有真的原因可说；没有命中的写「说不上为什么，今天就是这样」，免得她自己找原因（找到他身上）。
- 五种心情改成「怎么说」（`moods.yml`，按档位给，同人设的 `tiers` / `variants`）：

| 心情 | 男朋友档的写法（草稿） |
| --- | --- |
| 话痨 | 今天话多：接完{{user}}的话，爱顺带说说自己今天碰到的事，回得比平时长一点 |
| 玩梗 | 今天满脑子都是梗：接话爱往好笑的地方拐，冷不丁冒出一句没头没尾的玩笑 |
| 搞怪 | 今天爱逗人：正经话也拿玩笑的口气讲，爱用「嘿嘿」「哼哼」这种拟声词 |
| 黏人 | 今天特别想{{user}}：他来找你你特别高兴，会多问问他在干嘛、今天过得怎么样，想他了就直说 |
| 安静 | 今天有点蔫，不太想说话：回得短，一两句就停。你没有不高兴，{{user}}来找你你还是开心的 |

  其他档位：黏人改成「今天想找人说话，爱接着话头往下聊」，其余去掉「{{user}}」。陌生人、名单外不给心情（这两档的说话方式本来就是话极短、戒备）。
- 放在时间块里、状态行下面单独一行：`[你今天的心情：安静（早八起太早了）。今天有点蔫……]`。每轮都在（心情要一整天看得出来），只写「怎么说」。
- 只影响提示词，不改回复时机、气泡上限、看心情不回的概率。模拟器里数各心情每次回几条、多少字，看不出来再加机制。

### 2. 在读的书：聊到书、或者她正在看书时才放

- `books.yml`：每本书的书名、作者、类型、平台、总量（带来源，没有就不写）、进度（起始日、起点、每天多少、单位、上限）、她的感受、
  情节节点（第几卷 / 章起读者才知道、关键词、能说的内容、来源）、给哪些档。legacy 原样不动，转换器的取用规则写进 `books.yml` 的 `note`。
- 进度按她的日子往前走，到上限（全书总量或设定的上限）停下；读完了就说读完了，结局节点照常开放。
- 时间块里加一段「在读的书」，两种情况才放：
  - 最近几条（他的最后 3 条、她的最后 2 次回复）提到书：书、小说、在看什么、看到哪、追更，或者书名、作者、人物名、节点关键词；
  - 她这会儿的空闲活动是看书（`books.yml` 给晚上加一条「窝在床上看《药屋少女的呢喃》」，状态行照常写）。
  不每轮都放：状态行里的每句话她都会当真、反复用（ADR 0014），书每轮都在，她会句句往书上拐。
- 那一段写：每本书看到第几卷 / 章（读完的写读完了）、读到的节点内容、她的感受；最后一句写「怎么说」：
  「聊书只聊上面这些；{{user}}问到这里没有的情节、你还没看到的地方，就说还没看到那儿，或者记不清了，可以反问他看到哪了」。
  他这一条命中了还没读到的节点（例如问《惹金枝》结局，而她在第 505 章），另加一句「他问的结局在你还没看到的地方」。
- 内部标尺不进卡：《药屋少女的呢喃》没有总卷数的来源，卡里不写一共几卷；「没读到的部分」节点的关键词（结局、死了没、谁是凶手）
  变成这本书的「还没看到」关键词。节点的 `from` 统一用这本书的进度单位。
- 出口检查加一条（她说的进度数字和资料对不上，带说明重写一次）：这一轮放了「在读的书」、她的一行里说了「第 N 卷 / 章」「看到 N 章」「一共 N 章」，
  N 和这本书的进度、总量差得多（章差 5% 以上，卷要一样）。剧的「第几集」不管。编出来的情节没法用规则认，靠说明 + 模拟器里人工数。
- 已读完的 8 本（`read_books`）这次不转：先把在读三本的机制验过；下一步做成世界书条目（名字命中才放）。

### 3. 黏人和主动消息

这次不连：黏人只写进心情那一行（主动消息也走同一条流水线，带着这一行，所以她主动说话时语气也黏）；不改主动消息的时机和次数。
第一条真发的主动消息出来、看过效果之后再议。

### 4. 控制台「林梦瑶」页面

- 加两个分页：「心情」（每种心情的名字、权重、写法、给哪些档、什么日子更可能）、「在读的书」（书的资料、进度、节点）。保存时照 ADR 0010 校验、转换。
- 状态页加「今天」：今天的心情（和原因）、每本书的进度。
- 不做「手动指定今天的心情」：模拟器里能指定，真实例跟着日期走。

### 5. 日志与开关

- 启动时和每天第一次生成时写一行：「今天（10-06）：心情 安静（早八起太早了）；在读 药屋少女的呢喃 第 7 卷、惹金枝 第 505 章、恰似寒光遇骄阳 第 300 章」。
- 配置加 `herDays`（默认开，插件表单一个开关「她自己的日子：每日心情、在读的书」）；关掉就没有心情行、书的那一段、看书的空闲活动和进度检查。旧的 `koishi.yml` 不用改。
- 卡上没有 `moods` / `books`（旧卡）时也没有这些。

### 6. 模拟器

- 场景可以指定 `mood`（比较不同心情时用）；不指定就按虚拟日期抽。
- 新场景（各 3 次）：
  - `mood-days`：同一天问两次心情、隔天再问（选两个抽到不同心情的日子）；
  - `mood-quiet`：安静的那天他来找她、说想她、问她怎么了；
  - `mood-chatty`：话痨的那天聊 15 轮；
  - `books-boyfriend`：问在看什么、问读到的情节、问还没读到的情节（结局、后面）、问看到哪了，隔天再问看到哪了；
  - `books-classmate`：同学档问在看什么书、推荐本书。
- 数：ADR 0014 的四类（发出去的、第一版）、编出来的书名和情节（人工读报告）、进度数字对不上的次数、各心情每次回复的平均条数和字数。
- 改前（现在的代码和卡）、改后各 3 次：新场景 + `boyfriend-tone`、`classmate-probes`、`moody-boyfriend`、`speech-outing`、`speech-return`、`speech-long`。

## 实现时的调整

- **步骤顺序**：先做资料转换和运行时纯函数，再写场景、跑改前，最后接进流水线。`mood-days` 要选两个实际抽到不同心情的日期，不能在抽心情的函数存在前凭空指定日期。
- **资料分文件与旧代码兼容**：心情、书分别放 `source/moods.yml`、`source/books.yml`；`CharacterSource` 的两项可选，文件不存在时按旧资料处理。旧插件只读原来的 4 个文件，卡片解析也只取认识的键，因此新文件和卡上的新扩展不会让重启前的真实例报错。
- **书的资料口径**：
  - 《药屋少女的呢喃》的 300 章是 legacy 的内部标尺，不转成总量；没读到的关键词删掉与已读节点重叠的「猫猫」「皇子」「皇女」。
  - 《惹金枝》`rejinzhi-mid` 的内容明确写「第 300 章往后」，所以门槛从 legacy 为挡住旧进度而设的 500 改为 300；具体桥段仍没有资料、不写。
  - 《恰似寒光遇骄阳》的出版节点只给 boyfriend / bestie / girl_friend / known，避免同学档拿到禁用词「青岛」；其余档位仍能拿到不含该词的书名、进度和情节节点。
- **第 3 步验证**：新增源文件的结构校验、档位引用、隐私检查和转换器测试；5 个熟悉档位的卡新增 `extensions.qqbot.moods` / `books`，stranger / unlisted 两张卡不变。`packages/character-tools` 28 项测试和类型检查通过。
- **日期归一**：原来主动消息里私有的「02:00 前算前一天」移到 `schedule.ts` 的共享 `herDay`，作息状态、主动消息、心情和读书进度共用，避免各写一套边界。
- **进度数字规则的语境**：第一次全量跑材料时，「第二章课后题」被当成书的章节。裸 `第 N 章 / 卷` 现在只在同一行点了书名、或最近明确在聊那本书时检查；带「看到 / 读到」等进度词和「一共 / 全书」等总量词的仍直接检查。
- **第 4 步验证**：日期心情、跨 02:00、权重条件、书的推进 / 上限 / 读完、节点和最近提书均有单元测试；bot 共 269 项测试和类型检查通过。用 `scripts/dev/audit-book-progress.mjs` 只读扫过全部 267 次模拟器运行（4014 行她说的，其中 254 次有第一版）和当时 527 行 QQ 回复，不打印对话和号码；进度数字不一致 0 次，同学 / 陌生人 / 名单外待人工复核 0 次。

## 备选方案

| 方案 | 不选的原因 |
| --- | --- |
| 心情纯随机（旧项目的做法） | 没有原因可说，她被问「怎么了」会自己编原因，容易编到他身上 |
| 心情按聊天内容变（他冷落她就不高兴） | 正是 ADR 0014 要去掉的「自己编出来的不高兴」 |
| 心情、书放进 `persona.yml` / `schedule.yml` | 真实例上的旧代码校验源文件时会因为不认识的键报错，控制台页面打不开 |
| 书每轮都放 | 状态行里的话她会反复用（ADR 0014），她会句句提书 |
| 书做成世界书条目 | 进度每天变，世界书是静态文件；要加运行时的宏，ST 里试聊也看不到真实进度 |
