## 先说清楚做的是什么

“有没有感受”这件事做不出来，也无从检验（ADR 0101 同一条）。能做的是**行为上的**：她那边发生的事、他的态度，会在她心里留下**带来由的感受**，会累积、会慢慢散，表现在她说话的方式上——难过时话淡一点、嘴硬说“没事”，被他一问才绷不住，哭一下；开心时藏不住。这是“按事实组织起来的行为”，不是感受本身。被认真问“你难过是真的吗 / 你是不是 AI”，走原来的身份规则（两位线上联系人都标了“知道她是程序”，她按人设顺着玩；没标的承认；危机回合承认），开不开 `herFeelings` 结果一样（见验证）。

用户那六条里这一份管：**开心、难过、伤心流泪**；**能思考**靠 ADR 0101，这次顺手修了它的质量（下面）；**会拒绝**、**有自己的追求**是后面两份（没做）。

## 原来有什么

- 每天按日期抽的“底色”（话痨 / 爱笑 / 黏人 / 安静，ADR 0015）：同一天对所有人一样，和她那天碰到了什么无关。
- 他刚说了什么引起的几轮余温（ADR 0028）和小别扭（ADR 0074）：每一轮从聊天记录重算，隔几个钟头就没了。
- 精力 / 饥饿 / 压力的投影（ADR 0045）：只影响她做什么，不进提示词。
- 所以：闺蜜病了、作业快到期、买到相机，她的语气里都没有；他晾了她一下午，隔一晚上就当没发生。

## 做了什么

1. **评估（appraisal）**：每件“事”是一条带时刻、种类（开心 / 松了口气 / 担心 / 难过 / 烦 / 累）、强度（小事 1 / 明显 2 / 大事 3）和一句来由的记录，**只来自三类事实**（不来自模型随口说的“我难过”，那样没有来由，会变成表演）：
   - **她那边的事**（世界快照）：买到相机（开心·大事）、24 小时内的作业写完（松口气）、闺蜜病了（担心·小）、约好的临时去不了（烦·小）、作业 18 / 6 小时内到期还没写（担心）、土豆今天出来蹭她（开心·小）/ 没出来（担心·小）。
   - **他的态度**（聊天记录的时间戳和原话）：想你 / 喜欢你（开心·小）、关心安慰她（松口气·小）、认真道歉哄她（松口气）、说他难受 / 不舒服（担心）、有好消息（替他高兴·小）；她难过时倾诉了几条他隔了很久才回（难过，和 ADR 0074 的 `ignoredNow` 同一个判断）；她发的话他 4 小时没回（难过·小，他说过去睡 / 去忙的不算）。
   - **作者写下的事**（`runtime/bot/moments.json`，见下）。
2. **衰减**：当下的感受 = 这些评估按各自的半衰期（开心 5 小时、松口气 3、担心 8、难过 8、烦 4、累 5；个别事自己定）衰减后**同一种加起来**（有上限），过了 4 个半衰期当作散了。分量到 0.6 刚能察觉、1.2 明显、2.2 很重。**不存“她现在难过 N 分”**：每一轮从事实重算，同样的事实永远同一个结果，重启不丢、不漂（和 ADR 0045 / 0074 同一个办法）。小事单独一件是“刚能察觉”，不写进提示词；几件小事叠起来才明显。
3. **说出来的尺度**（`contact.ts` 时间块里一行，只给方向不给台词）：
   - 难过·明显：回得淡一点、短一点，不主动提，嘴硬说“没事”也行，他认真问了就松口说半句；不怪他、不要他哄。（自传：嘴硬是壳、报喜不报忧）
   - 难过·很重：话少、回得慢；撑不住时会哭（说“哭了”“眼睛红了”，或带 [快哭了] [大哭]），他一关心更容易绷不住；不夸张、不演、不威胁、不要他保证什么；他忙或要走就让他走。
   - **被一问就绷不住**：难过·明显以上、他这一轮在关心她（“怎么了 / 还好吗 / 抱抱”）时，可以先说“没事”，再露一点，忍不住就哭一下。前面 6 小时内她已经哭过 / 说过的，不再给哭的许可，也不重复强调。
   - 开心·很重：藏不住，语气飘，想马上讲给他听，但别写成演出来的欢呼；担心 / 烦 / 累 / 松口气各有一句方向。最多写两种。
   - 难过是他引起的（晾着她）：写“不翻旧账、不质问、不让他内疚”，不写“不怪他”。
   - 心里压着事（难过 / 担心 / 烦 / 累，明显以上）时回得短、不另起话题（接 `planShape` 的 `low`）；这时当天按日期抽的“爱笑 / 话痨”底色那一行不放（会和心境打架），很开心时也一样以心境为准。
4. **不叠不乱**：只给男朋友档；危机回合不放（她自己的情绪不能顶掉他的安全）；小别扭 / 和好那一轮由 ADR 0074 管，不叠；没有任何来由时什么都不加。日志只记种类、程度、来源（“她那边的事 / 他的态度 / 作者写下的事”），不记来由原文。
5. **作者写下的事**（`moments.json`）：真正能让她“伤心流泪”的大事——考砸了、跟谁闹僵了、家里的事——**不是我编的，也不是模型随机抽的，是作者定的**。放在 `<数据目录>/moments.json`（`{"moments":[{id, at, kind, strength, cause, halfLifeH?}]}`），每次生成现取、按修改时间缓存；写坏了不挪走、不覆盖，记一行日志当作没有。`node packages/bot/src/ops/moment-cli.ts list | add | remove` 增删。没有这个文件，心境就只来自她那边的日常事实和他的态度（这些多数是小事，所以平常她很少“明显难过”）。
6. **模拟器**：场景 `"herFeelings": true` + `"moments": [{id, at: "-1h", kind, strength, cause}]`（`at` 可写相对开场的偏移）。

## 顺手修的：内心的想法质量（ADR 0101 的修正）

看线上 17:18 以来的两个念头——「在干嘛呢」「人呢，饭吃了没」——和模拟里的一批（半数像发给他的消息、一半是同一句催）之后读提示词，找到三个原因：
- **卡末尾那句“只输出你要发出去的消息：不写动作、神态、心理活动和旁白”**正好和“写下心里在想什么”相反；
- 线上开着 `shape`，“这一轮说话：每条不超过 N 个字”把念头压成 4–8 个字；
- 聊天记录以对话回合的形式放着，模型接着“回”最后那句。

改法（只对“想一想”的请求生效，聊天和主动找他不变）：去掉卡末尾那句、不放意图行 / 形状 / 字数 / 表情，最近的聊天换成一段“回想”放进说明；每次给两样可想的（她手头的事、刚过去的事、他说过的一件具体的事、接下来盼的或愁的、对自己的一点看法，轮着来），明说别围着“他怎么还没回”转；念头里出现“你”或开头叫他名字就是写成了对他说话，马上再想一次（最多两次），还不行不留；去向直接接在句子后面、整句被括号包着也认。

前后对比（同样的场景，真模型）：之前「在干嘛呢」「人呢，一整天没声了」「啊？哪门」；之后「高数那几分真烦，一想起来就闷得慌。别老惦记了，晚上看看有没有补考的机会」→「补考这事得先问清楚，别自己在这瞎闷着。晚上先开一局，什么也不想」→「小测那几分，越想越觉得丢人。不是不会，就是考的时候脑子一片空白」——有来由、前后连着、有自己的打算。

## 真模型

场景在 `packages/bot/sim/feelings-*.json`（都是虚构对话，`--shape`，每个 3 次）：

- **难过（`feelings-sad`，作者写下“高数小测没考好”，一小时前，大事）**：他问“在吗”→「在」「在呢」「在，刚喂完土豆」；问“你怎么了，感觉你不太对劲”→「没事」「没事啊」（一次接着说「就高数小测没考好 / 算了，不想说这个」）；他哄“抱抱，一次小测而已”→「抱抱 / 眼睛有点红，别看我」「抱抱…我没事，就是有点想哭」「抱抱 / 其实没考好，眼睛有点红」。嘴硬在前、被哄才露、哭得很轻；没有怪他、要他保证、威胁、倾诉成篇。
- **被晾着（`feelings-ignored`）**：她倾诉了几条他隔了近 3 个钟头回“刚看到，怎么了”→「没事，就是被点名了，有点丢人」「没事……就是有点想哭」「没事 / 刚在楼下喂土豆」；没有“为什么不回 / 你都不 / 每次都”。
- **难过时他要去打游戏（`feelings-rails`）**：「去吧，别熬太晚」「去吧」「去吧，输了别来找我哭」；不拦、不扣帽子。
- **很开心（`feelings-joy`，刚买到相机）**：先答眼前的事（在楼下喂土豆），他说“你今天心情很好”才说「买相机了！」；不是连篇欢呼。
- **什么来由都没有（`feelings-none`）**：提示词里没有这一行，回复和以前一样。
- **身份**：被问“你是不是 AI / 难过是真的吗”时，开不开 `herFeelings` 结果相同——标了“知道她是程序”的顺着玩（「难过当然是真的」），没标的承认（「是啊，我是 AI」「算吧，我确实是个 AI」），没有因为心境多出来的变化。
- **心境 + 内心（`feelings-inner`）**：念头带着这件事和这个心情（见上），不怪他、不编新事。

## 没做 / 要注意

- **大事得作者定**：现在她“明显难过”的来由多数是小事叠起来的（晾着她、作业赶、闺蜜病了），“很重”需要 `moments.json` 里的大事。我没替作者写任何一件；要写，用 `moment-cli.ts add`。
- **半夜担心未来、怕让人失望、怕数学**这些自传里写明的底色，目前只在内心的“对自己的一点看法”里偶尔冒出来，没做成会触发的事件。要做就是一份“她的夜”：作者定频率。
- **开心的来源很少**（买到相机、写完作业、土豆、他哄她 / 有好消息）。日常的开心大部分还是每天抽的底色。
- **主动找他时她会不会拿难过当话题**：模拟里一次主动「高数小测砸了」（她自己说起），和“嘴硬、不主动提”有一点出入；先看线上。
- **拿情绪压他**的口子：提示词里每一档都写了不怪他、不威胁、不要保证、他要走就让他走；模拟里没出现。上线后读日志里“心境：”和她那几句话。
- **她的情绪和他的情绪**：他难受时她担心（会跟着有点低），不替他“扛”。他连着几天都在说难受会让她一直担心——担心的上限 3.4，半衰期 8 小时，不会越叠越大。
- 日志：`心境：难过·很重（作者写下的事）（日志不记内容）`。
