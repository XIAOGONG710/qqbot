# ADR 0310：长期记忆的事实时间视图与民用日期

状态：接受，2026-11-05。接续 ADR 0303、0304、0307、0308。

## M35事实时间

实证：29条已发生行加一条未来行凑到30，提前双库retain；未来危机行在无新retain时提前删除公共旧片段。不能只阻止episode.end，因为条数阈值和敏感分支也消费消息。

每次sync固定采样now，在完整校验原始来源后只让已发生消息参与分片、条数、危机、修订及修复候选；await后检查实时钟回拨，未派发工作停止，已确认ACK仍记真实进度并建立时间屏障。时间推进不会把本次排队时尚未发生的行偷偷纳入旧快照，后续sync正常补入。

Contact/Pending增加可选sourceTimes前缀证据，不含正文，和进度同次保存。旧缺字段兼容；不可变pending的not_found仅在来源前缀仍可证明且均已发生时重交原请求。已派发任务completed保真，即使当前回拨也不丢count。过去正文真实修订/撤回不被隐藏未来行误吞。

未来行完全不参与过去45分钟分片边界；否则在已提交30条中插入48小时未来行，会把原片段重写为12条、后18条不足阈值暂失。既有docID利用已完成/不可变来源首成员锚点保留；时钟追上后如果实际重分片导致旧count归属不足或重复ID，则保留原文档与精确屏障、暂停，不能截短已确认事实或猜测迁移。普通首/中/尾小间隔到时可继续；病态retroinsert历史归属迁移仍需独立证据，本批不声称自动恢复所有重分片。

sourceTimes为必要持久来源证据，随已提交消息数增长；未任意截断。坏进度、初始高级状态、跨bank pending及旧弱来源限制沿原协议。公共派生/观察守卫不会因本批时间过滤自动解除。

## M29b民用日与供应商日历

Pacific/Apia的2011-12-30是合法民用日，却不能映射当地Date；旧lastTouched将它滚31，变淡与窗口均错一日。新civilDayNumber使用UTC中立日序表达民用日期，lastTouchedDay按文档日期/周末计算；clarity、summaryIn、diaryIn用日序比较，保留窗口end午夜exclusive和02:00规则。旧Date接口仅兼容，不再用于上述生产民用日判断。

共享providerTime保留合法Date.parse兼容格式，但先拒绝不实ISO日历前缀（包括空白、小写t、Z/UTC后缀绕过），不让Feb30滚入Mar2。变淡、实际召回窗口、mentioned窗口及最终日期标签统一使用它；坏发生时间可回退合法提及时间，无可用时间则不标日期。低年、闰日、DST23/25小时、跨年周末与epoch0保留。

验证仅合成聊天、假API、临时文件及固定时钟/TZ，不访问真实历史、角色或外部服务；原有危机、频率与披露政策保持。
