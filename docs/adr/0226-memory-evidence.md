# ADR 0226：长期记忆状态的证据摘要

## 状态

已实现，默认不改变记忆内容，只增强运行状态和审计可见性。

## 决策

长期记忆的最近一次写入 / 召回状态（`LongTermMemory.status()`）除了成功、失败和时间外，携带不含正文的证据摘要：

- `operation`：`write` 或 `recall`；
- `source`：来源类别，例如 `qq-episode`、`qq-common-episode`、`diary`、`hindsight-recall`；
- `items`：本次成功处理的片段消息数或召回条数；
- `fingerprint`：文档 id 或查询字符串的 SHA-256 前 12 位，只用于判断是否重复处理；
- `error`：失败时的错误摘要。

这些字段供控制台状态页、测试和运维诊断使用，不包含聊天正文、QQ 号、密钥或完整查询。旧状态对象仍可读取，缺少新增字段时按未知来源处理。

## 取舍

这是 bot 自己发起的操作证据，不是 Hindsight 数据库的完整审计；如果数据库被外部直接修改，仍需独立的 Hindsight 侧审计或对账。

## 验证

长期记忆测试覆盖成功写入、召回失败时的 `operation` / `source` / 时间和指纹长度，并确认正文不会进入证据字段。
