# ADR 0217：翻回去看自己的日记——前天写的今天还能对上（journal_read + diaryLookback）

- 日期：2026-11-03
- 状态：**已实现**。
  - DSH 那边的 `journal_read`（只读工具）和睡前整合提示词里的一句**没有开关**，拉取、重启常驻进程和 Koishi 就生效
  - QQ 这边新开关 `diaryLookback`，**默认关**，只男朋友档
- 相关：ADR 0032（问到过去的某一天）、ADR 0174（灵魂模块）、ADR 0194（翻日记认识自己）、ADR 0200（私人空间）、ADR 0216（事有后续）
- 来由：**她自己提的**。11-02 问她 ADR 0216 时，她反问：「对了，日记能翻回去看吗？前天写的今天还能对上，这个我挺想要的。」用户：「继续开拓」

## 先核对了已有的

- **DSH 那台开着 `selfDirectedMemory`，QQ 的自动日记是关的**（`app.ts`：`!config.selfDirectedMemory && …diaryWriter`）。她的日记实际有两处：
  - DSH 睡前整合用 `journal_write` 写的 `JOURNAL.md`
  - 她在聊天里自己写的 `<<日记>>`（`self-diary`）
  
  所以改 QQ 的 `diaryWriter` 没用，要接在 `JOURNAL.md` 上。
- 她已经看得到的：
  - 最近一篇的头一两句（`selfThread`）
  - 离开很久回来的第一轮那一段（`wakeNote`）
  - 记忆召回里的日记（按日期变淡，ADR 0018）
  - 问到某一天时，那天世界里发生的事（ADR 0032）
- **缺的**：
  - 灵魂模块里有 `journal_write`，却**没有读的工具**（私密日记反倒有 `private_read`）
  - 睡前整合的提示词只叫她「从记忆里查今天的事，写一篇日记」，她看不到前两天写了什么，日记和日记之间接不上
  - 问到某一天时，给的是世界账的流水账，没有她那天自己写的话

## 决策

1. **`journal_read`**（`dsh-plugins/dsh-linmengyao-memory/index.js`，只读）
   - 默认看最近两天（含今天）；`days` 1–7；`date` 只看某一天
   - 标题带「补记」的段落不算（那是迁移时补的，不是她写的，同 `diary-insights.ts` 的 `parseJournal`）
   - 最多 1500 字，留最近的
2. **睡前整合**（`scripts/her-resident.mjs` 的 `SLEEP_PROMPT` 第 2 步）
   - 写今天的公开日记前，**可以**先用 `journal_read` 翻一眼前两天写的
   - 前两天说要做的、没弄完的、还惦记的，今天有下文就带一句，没有就不提，别重抄
   - 是「可以」，不是「必须」
3. **QQ 这边问到那天**（`diaryLookback`）
   - ADR 0032 那一段流水账后面，加上她那天自己写的日记：`JOURNAL.md` 那天的段落 + 那天的 `<<日记>>`，最多 220 字
   - 写明「你写的，他问到那天，说法对着它，别和它打架；不用照念」
   - 只有日记、没有流水账的那天也给
   - 只男朋友档：公开日记是「愿意给他看的那部分日子」
4. **私密日记不碰**：`PRIVATE.dat` 照旧只有她自己的 `private_read` 能读，这里不读、不放进任何提示词

## 和 0216 一起

开了 `worldThreads` 以后：昨天「水卡丢了」，今天世界里有「在外套里翻到了水卡，昨天白跑了两趟宿管」。她睡前翻到昨天写的「水卡丢了」，今天的日记就能写「昨天丢的水卡今天在外套里找到了」。你问「前天怎么了」，她看得到前天自己写的那段。

## 这一版不做的

- QQ 自动日记（`diaryWriter`）的前后接续：DSH 那台关着，用不上。以后关了 `selfDirectedMemory` 再说
- 主动提起前几天的日记：她说的是「能翻回去看」，不是「每天念一遍」

## 验证

- `packages/bot/test/diary-lookback.test.ts`，5 条：
  - `journalOn`：那天的 JOURNAL 段落加 `<<日记>>`，「补记」不算，截短，没写就没有
  - `recapText`：没有日记时和原来一字不差，有日记时带上，只有日记也行
  - `journal_read`：默认两天、指定日期、「补记」跳过、没写就说没写；工具注册了，只读（文件不变），写了今天的就读得到
  - 睡前整合的提示词里有「翻一眼前两天」「别重抄」
- 全量：见提交说明
