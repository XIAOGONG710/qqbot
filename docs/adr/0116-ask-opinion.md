## 差距

她原来只会报告自己的事、接他的话、问他的事（待跟进）；很少拿自己的小事来问他、让他参与她的决定。有来有往的关系里，不总是他在问她。

## 做了什么

新的主动时机 `ask`（`withAsk` 运行时加，不改卡）：下午 14:30 起 0–150 分钟之内的一个时刻（21:00 以后不问），一天一次；某一天想不想问按“联系人 + 日子”取哈希（周末 32%、工作日 28%）。
- **只问小事**：提示词让她从“你那边”“你今天的打算”里挑一件**手上真有的**小事（吃什么、穿什么、作业先写哪个、周末干嘛、攒的钱先买什么），没有合适的就问晚上吃什么；选项最多两个，像随手问的，不考他的知识，别让他替她做大决定。
- **不勉强**：一周最多 2 次、两次之间至少隔 2 天；他没回**不催**（reach 不接这一条）；到点再查：他 3 小时内说过去忙 / 去睡、在忙 / 累了 / 没空，或下午晚上有待跟进的事，不问；她自己难过 / 很累 / 不舒服时提示词让她只输出「不发」（走 `canDecline`，记成没发）。
- 也带 ADR 0108 的“开头直接说事，别先叫名字”。

## 数据

- 模拟（真模型，`sim/ask.json`）：见提交说明里的数字；单元测试：120 天里 22–52 天有、时间落在 14:30–17:00、7 天 ≤ 2 次、隔 ≥ 2 天、各个“不问”的原因、没回不催（对照组照样催）。

## 没做 / 要注意

- 事由由模型从提示词里的事实里挑，不是从新数据里来；所以不会比“你那边”里已有的更具体。
- 排在睡前之后、随口说件事之前：名额不够时只挤掉“随口说件事”。
