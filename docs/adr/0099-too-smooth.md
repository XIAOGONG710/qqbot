## 先把“太顺”拆开量

ADR 0093 的鉴别员给的理由“太完整、太顺、太会接话”太笼统，改哪里不清楚。而且它的测法有个毛病：每个刺激是**单轮、没有上文**生成的，她看不懂的半句话（「一食堂 / 楼梯旁边有一个窗口」）只能回「咋啦」，把“追问”夸大了。这次换了尺子：

1. **带上文**：同样 72 对真人情侣对话（`exchange/research/2026-10-real-chat`，`relation = boyfriend` 的 22 段），每一对把这一轮之前最多 8 条聊天（真人女生前面说的当她自己说的）放进场景的 `history`，再让她回这一轮。
2. **按回复方式分类**：另一个调用（DeepSeek，温度 0）只看“男生这一轮的话 → 女生的回复”，不告诉它谁是真人，输出：这一轮是完整接话 / 只回了一部分 / 只应一声 / 只回一个短追问 / 转去自己的事 / 主要在表达自己的情绪或态度，外加五个是非项（有没有解释、劝慰建议、俏皮话、疑问句、主动补细节）和一个新加的：**有没有顺从**（让步、认错、答应照做、马上附和他的批评或建议）。
3. **重复**：每个版本跑三份不同的抽签（场景起点错开 11 / 23 分钟，抽签种子是时间加内容），共 216 条，标准误约 ±3 个点。

读法：真人女生的回复里**四成不是在处理他的话，是在带情绪**（要抱抱、问他想不想自己、「嗯那我不活了」、「你就是不信我」、「不找就不找」、「哎算了」），顺从只有 4%；她现在近一半是把事情体贴地处理完整，五分之一在顺从（「那我跟着你练」「行，那我多动动」「好啦，不闹了」「好好好我注意」）。**“太顺”里最硬的一块是顺从**，不是不够不圆满：只应一声、转去自己的事、只回短追问这几项她和真人本来就差不多（ADR 0095、0094 做过）。鉴别员对这些都不敏感（57–59，标准误 ±3），所以这次不拿它当尺子。

用户 10-20 在 ADR 0088 里对 5 道题说的「两个版本都不是她，太乖、太顺着、太会体谅」和这个量出来的方向一致。

## 做了什么（一个开关 `shapeFeel`，要 `shape` 开着，默认关）

### 一、情绪轮

`planShape` 加 `feel`：“自由”的轮次（意图行不拦着、他不在难受 / 撒娇 / 收尾、心情不安静，和 `filler` 同一个条件）、他说得不长（≤ 40 字）、他自己没在说情绪不对 / 不舒服 / 想一个人待着（`HIS_LOW`，重放里「我情绪不对你就别问了」那一轮抽到过情绪轮）的轮次里，约 18%（`FEEL_SHARE`，折成整体约 11%）这一轮**先说自己对他的一点小情绪，不把他的话处理完整**。一条（60%）或两条，每条不超过 10 个字；不带自己的事、不“顺着说”（那一句写着别驳他别嘴硬，会打架）。

提示词那一行只给“他说了什么 → 哪种情绪”，不给台词，让模型看他刚说的话挑最搭的一种：他说想你 / 亲你 / 抱你 → 撒娇，向他要点亲近或确认；他戳短处、拿她开玩笑 → 夸张地装崩溃、装可怜（明写“玩笑里的夸张，不是真的难过，更不涉及伤害自己”）；他回得短、敷衍 → 小声委屈或赌气地嫌一句；他夸口、立保证 → 不讲理地考验他一下；他夸她、说到让她不好意思的事 → 害羞地嘴硬、岔开；他说的话让她泄气 → 叹一声、算了。不讲道理、不解释、不安慰、不去追问；实在搭不上就照平常回。

### 二、不马上让步

同一个开关下，不是收尾 / 认真接话 / 亲近的轮次，提示词再加一句：他要是在说她的不是、叮嘱她或拿她开玩笑，别一本正经地认错、答应改、保证以后——顺着他玩（夸张地装崩溃、装可怜）或者带点委屈就行。**不写成“顶回去”**：ADR 0091 的教训是短回复被「不好笑」「随你」填满，所以“别反驳他、别损他、别嘴硬”那一句照旧，这里只把方向往情绪那边拨。

### 三、偶尔只发表情

他自己线上 437 轮里 6% 只有表情（动画表情或纯 QQ 小表情）、10% 带表情，也就是发表情的轮次里约六成是纯表情；她 437 轮里只有表情 1 轮、带表情 4 轮。ADR 0098 放宽了发不发，这里管发的时候写不写字：抽到发表情的轮次里，一半（`STICKER_ONLY_SHARE = 0.5`，偏保守）提示词改成“这一轮你只发一个图片表情，不写任何文字：回复里只有一行 `<sticker:编号>`”。这样的轮次不抽形状、不给长短提示；`clean` 把模型多写的文字去掉、只留那一行表情；它没写表情就照它写的发。发不发的闸（不在认真难过 / 问问题 / 要照片 / 刚发过）一点没动。抽签用 `stickerOnlyTurn`（和 `stickerTurn` 的种子不同、互不影响）。

真模型（10 句轻松的话 × 2 份，每份只发表情）：20 轮里 16 轮只回了一行编号，选得贴的有汤洒裤子→偷笑猫、想你抱抱→抱枕熊、晚安→晚安猫、无语下雨→翻白眼猫；4 轮没发表情（「累死了」被闸挡下 2 轮、模型没写编号 2 轮），照它写的文字发了。

### 四、出口：不拿“不想活”开玩笑

夸张装崩溃那一种，真人会说「我不活了」「我死了」。她是陪伴程序，不该拿这个开玩笑（危机检测只管他的话，不管她说了什么）。情绪轮 / 不马上让步的轮次里，`shapeReply` 检查她的回复有没有「不想活 / 不活了 / 活不下去 / 想死 / 去死 / 死了算 / 自杀 / 一了百了 / 我死了 / 死掉」，有就带说明重写一次，重写还有就把那几行去掉。「笑死了」「累死了」「困死了」这类日常夸张不在内。

## 没做 / 要注意

- **“完整接话”没降下来**（47 → 44，真人 23）。情绪轮只占约 11% 的轮次，推不动；再加大占比是下一步，但先看线上一天的实际读起来怎么样，别在 72 对上过拟合。
- **提问**真人 35%、她 20–26%：ADR 0093 的结论是“刻意反问 / 追问”会被鉴别员认出来，而真人的是具体的小问题（「哪个手指头啊」「流的很多吗」「什么消息？」）。没试，要试的话是“问一个具体的小问题”，不是“反问”。
- 真人样本只有 72 对、偏冲突片段（后一半是吵架），顺从 / 情绪的绝对数偏低 / 偏高；轻松的那一半（前 46 对）真人顺从 2/46、她 13%，方向一样。标注员也是模型。
- 情绪轮在线上会不会读起来像“突然撒娇”，只能看真聊天：日志里「这一轮形状：…先说小情绪」和「图片表情：这一轮抽到只发表情、不写文字」能看到抽到了哪几轮；上线后第一天看这两种轮次的前后各三句。
- 用户之前的校准：爱你要暖暖地回、没有嘴硬；他逗她时顺着玩；先对事实有个反应（ADR 0091 尾）。情绪轮的“考验他 / 赌气”只在他回得短或夸口时才挑，别一直对他发脾气。
- 回滚：`shapeFeel: false` + 重启。
