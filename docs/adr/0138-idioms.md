# ADR 0138：被他带出来的口头习惯（配置 `idioms`，默认关）

- 状态：**已实现，未上线**（2026-10-24）。上线 = 换代码重启 + `koishi.yml` 里加 `idioms: true`；回滚 = 去掉这一行（或改 `false`）重启，`idioms/` 目录可以删（派生数据，会重新学）
- 日期：2026-10-24
- 关联：[ADR 0114](0114-running-jokes.md)（小梗：本条沿用它的“后台抽取 + 代码硬校验 + 派生数据”的做法）、[ADR 0129](0129-memes.md)（网络热梗）、[ADR 0070](0070-hardening-program.md) 第 9 项（导出与遗忘）
- 来源：2026-10-24 对照麦麦（MaiBot）等相似项目后用户说「123都做」；这是第 3 条（从他的聊天里学说话习惯）。我在提这一条时就说了：涉及隐私和“变成他的镜子”的风险，所以做成最小的一种——**只学说话的习惯，不学内容**

## 问题

处久了的两个人会互相沾说话的习惯：他爱说「笑死」，她过阵子也会顺口来一句。她现在的口头禅全是卡上写死的，和他怎么说话没关系，所以过了一个月，她说话的方式一点没有被他带过。麦麦的“表达学习”是从群友聊天里学“场景→说法”并存下来，这里取其中最小、最安全的一块。

## 做了什么

- `idioms.ts`（沿用 `jokes.ts` 的结构）：隔一阵（`IDIOMS_CHECK_MS` 6 小时看一眼，`IDIOMS_REFRESH_MS` 20 小时最多学一次，他的话至少 60 条、比上次多 20 条新的）让模型从**他最近 30 天自己发的话**里挑最多 8 个口头习惯（口头禅、句首句尾的语气词 / 感叹词、爱用的网络说法）。只发他的话，每条截 60 字、最多 300 条；危机相关的消息不发；去掉“[引用你说的：「…」]”前缀（那是她的话）和占位符。
- **代码硬校验**（模型挑得再好也要过这一关，`parseIdioms`）：必须是他自己的话里**原样出现过至少 4 条不同的消息、分布在至少 3 个不同的日子**的 1–6 个字的短语；太泛的（嗯、好的、哈哈）、带数字 / 空白 / 符号的、脏话（含「卧槽」「我靠」）、危机相关的词（`detectCrisis`）、联系人和角色的名字、卡上的禁用词，一律丢掉。模型编出来的、聊天里找不到的，也丢掉。旧的习惯每次重新按同样的标准核一遍，他不说了就掉。
- 存在 `<数据目录>/idioms/<QQ>.json`（只有短语、类型、次数、天数，没有他的整句话）。**导出和遗忘跟着走**：`privacy-audit.ts` 的清单加上了 `idioms/`（同时补上了 ADR 0114 漏掉的 `jokes/`）。
- 用的时候（只对男朋友档）：约一半的轮次（`IDIOM_TURN_SHARE = 0.5`，按他最后一句取哈希，同一句每次一样）提示词里多一行 `[他平时爱说「X」「Y」（他的口头习惯，处久了你也有点被他带着）：这一轮你想说的话里正好用得上，就顺口用一个；用不上就别用，别原样学他刚说的那句，别提这件事，也别每句都带]`。一次最多给两个；他最近 14 天没再说的不给；她自己最近三次回复里用过的不给。他难过 / 危机 / 小别扭 / 主动找他 / 她在想事情的时候不给。她的语气、长短、条数都不变——只是偶尔多一个词。
- 开关 `idioms`（`config.ts` / `features.ts` / 插件 Schema）；模拟器场景加 `idioms: [{phrase}]`（预置，不去学）和 `idiomShare`。

## 为什么不是“变成他的镜子”

- 学的是 1–6 个字的说话习惯，不是内容；名词、人名、数字、倾诉里的话都被硬校验挡在外面。
- 提示词里是“用得上才用”，不是“要用”；每次最多两个，一半的轮次才给，最近用过就不给。
- 她的性格、长短、语气都由原来的那些管，这条不碰。
- 她不提这件事，也不会说“你爱说 X 所以我也说”。
- 默认关；数据是派生的，随时可删；跟着导出和遗忘走。

## 数据

- **学的质量**（拿线上他的聊天记录只读跑了真实的学习，三次，用线上同样的模型和温度；只记数量和类型，不记他的话）：他最近 30 天 648 条消息；模型每次提 7–8 个，硬校验后留下 **4–5 个**，每个都是在 6–33 条消息、5–10 个不同日子里原样出现过的语气词 / 口头禅 / 网络说法；没有名词、人名、事实、倾诉里的句子。另一次温度 0.3 的试跑模型什么都没提（[]）——所以更新时旧的习惯只要还核得过就留着，一次空的结果不会清掉已学的。
- **用的效果**（`sim/idioms.json`：他最近常说三个词，十句日常闲聊 × 3 次，`idiomShare: 1`，也就是每一句都给她看这一行；对照是同一批不给）：给的时候 41 个气泡里用到 **2 个**（「行吧，那你不就饿着了」「绝了，又被削」，都是话赶话正好用得上的）；不给的 38 个气泡里 **0 个**。没有原样学他刚说的那句，没有每句都带。按 6.7% 的使用率、一半的轮次给，大约是 3% 的回合会带一个——和他自己最爱说的那个词在他消息里的占比（5%）同一个量级，偏保守。

## 没做 / 要注意

- 隐私：学习时他的话（上面说的那些，≤300 条）会发给模型接口，和聊天本身、长期记忆、小梗是同一个接口、同一种发法；没有新增对外的去处。
- 只学一个人（男朋友档），不学别的联系人。
- 不学他叫她的称呼、不学他的表情习惯（质感 `texture` 管表情）、不学句式和长短（形状 `shape` 管）。
- 学出来的词她用在不合适的语境（例如拿“呜呜呜”回开心的话）是有可能的：提示词里写了“用得上才用”，但没有别的检查；线上要看几天。
- 单元测试：`idioms.test.ts`（硬校验、窗口、什么时候学、存储和隐私审计、什么时候给她看、模拟器里开 / 关 / 危机 / 他难过）。
