# ADR 0238：DSH 只自然表现内部状态，不复述数值仪表盘

- 状态：已实现
- 日期：2026-11-04
- 关联：[ADR 0225](0225-dsh-state-snapshot.md)、[ADR 0237](0237-human-value-trends.md)

## 背景

DSH 需要精确状态和趋势才能与 QQ 中的她连贯，但这些字段是内部决策依据。若直接在回复里说出 `hunger=70`、`energy=40` 或“亲密值 80”，会破坏她在两个渠道中的自然语气，也把实现细节暴露给日常对话。

## 决策

1. 保留 `STATE.json` 的精确白名单数值，供本地状态同步、审计和 DSH 判断使用。
2. 在线 DSH 的系统提示与状态块同时声明：不得复述字段名、等号数值或分数，只能把疲惫、饥饿、压力和关系余波自然表现出来。
3. DSH 桌面插件注入相同边界，避免桌面端与 QQ 工作模式使用不同说话规则。
4. 不用字符串删除器篡改生成结果；边界放在状态上下文和系统层，保留正常谈论用户主动提出的数字问题的能力。

## 验证

- 在线咨询测试确认系统消息和状态上下文都带有自然表达边界。
- 桌面插件测试确认同一边界随新鲜的 `STATE.json` 注入；过期和损坏状态仍然不注入。
