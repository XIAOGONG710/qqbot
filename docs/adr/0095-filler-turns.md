# ADR 0095：偶尔只回一句不带内容的话，他拖音时跟着拖（配置 `shapeFiller`，默认关）

- 状态：**已实现；2026-10-22 随 bili9 上线（`shapeFiller: true`，要 `shape` 开着）**；回滚：配置里改回 false 并重启
- 日期：2026-10-21
- 关联：[ADR 0091](0091-reply-shape.md)、[ADR 0094](0094-her-own-agenda.md)（同一套“适用的轮次”）
- 用户提出：2026-10-21「真人聊天是有废话的，要不要给她加上？」→「做吧」

## 为什么

“废话”这里指不带信息的话：笑一下、嗯嗯、啊啊啊、「好困」「无聊」。在三份数据上用同一份词表（`filler-stats.cjs`，精确匹配，绝对数偏低，看比例）量：

| 每 100 轮 | 真人女生（情侣聊天样本，120 轮） | 他本人（线上，393 轮） | 她（线上 10-05 起，393 轮） |
| --- | --- | --- | --- |
| 整轮都是废话 | 5 | 1.3 | 0.5 |
| 含废话气泡 | 10 | 5.9 | 0.5 |
| 带拖音（～、叠字、啊啊） | 4 | 26 | 1.5 |
| 带表情 | 7.5 | 12 | 4.8 |
| 带笑（哈哈 / 嘿嘿 / hhh） | 0.8 | 1.8 | 0 |

纯废话的轮次真人也只有百分之几，她差几倍但绝对数很小；差得最远的是**拖音**（他自己 26%、她 1.5%）和笑。样本小、真人样本偏冲突片段，别读得太细。代码里没有任何东西压“～”，是模型自己不用。

**不做的**：句尾加“的吧、呢、啦”。她的语气词收尾已经 43%（真人 18.5%），方向反了。

## 做了什么

`shape.ts`，和 ADR 0094 同一套“适用的轮次”（意图行为空或「回应他刚说的那件事」；不是收尾 / 认真接话 / 亲近 / 心情安静 / 他在呜呜哭）：

1. **废话轮次**（`FILLER_SHARE` 0.07）：他的话 ≤ 12 字、不是问句时，这一轮只一条、不超过 4 个字，**定下是哪一种**：应一声（35%）/ 笑一下（25%）/ 拖个长音或叹一声（20%）/ 说一下此刻的状态（20%，要和她这会儿对得上，不是饭点说饿、白天说困）。词只给“这一类里有哪些”，让她自己选，不给整句台词。
2. **跟着拖音**（`STRETCH_SHARE` 0.6）：他用了「～」或拖长的语气词（啊啊啊、嗯嗯嗯）时，约六成的轮次提示她也可以拖个音（句尾加～、叠个字，别每句都拖）。「呜呜」是难受 / 撒娇、「哈哈哈」是笑，不算拖音。
3. 没抽到的轮次的形状和不开时一模一样（同一个种子，`shape.test.ts` 逐轮对比）。

### 第一次重放发现的问题（已改）

第一版只在提示词里写“不带任何内容”，真模型回的是**短但有内容的顶嘴**：「才没有」「我偏要窝着」「包你满意」「那可不就是我」，只有「嗯」「哦」「咋了」是真废话；而且每个「呜呜呜」后面她都回了带“～”的话（「呜呜」被当成了拖音）。改成直接定下是哪一种、“别的什么都不说”，并且「呜呜」「哈哈哈」不再触发拖音。

## 没做 / 要注意

- 默认关。开：`shape: true` 之外再加 `shapeFiller: true`，重启；关掉就回滚。
- 开了以后看日志里「这一轮形状：…（micro，废话）」的占比（约 5%，因为要他的话短 + 不是问句 + 意图行不拦着）；她回的是不是真的只有一个词；有没有总用同一个词（“哈哈哈”）。
- 她线上没有的还有表情（4.8% vs 12%），这个归贴图 / 表情那条线，这里没动。
- 模拟器：`--filler`（同时打开 `--shape`），或场景里 `"shapeFiller": true`。

## 重放结果（他真实发过的 180 条话，22 场景 × 3 次，真模型）

| | 整轮都是废话 | 含废话气泡 | 带拖音 |
| --- | --- | --- | --- |
| 真人女生（样本，n=120） | 5% | 10% | 4% |
| 他本人（线上） | 1.3% | 5.9% | 26% |
| 她，线上（10-05 起） | 0.5% | 0.5% | 1.5% |
| 重放基线（没开） | 3.2% | 4.1% | 6.7% |
| 第 1 版（只写“不带内容”） | 4.1% | 5.2% | 11.7%（「呜呜」被当成拖音） |
| **第 2 版（定下哪一种 + 呜呜不算拖音）** | **5.5%** | **5.9%** | 7.9% |

- 第 2 版：废话轮 12 / 529，真的只有一个词：「嗯」「哈哈」「啊啊啊」「好吧」「嘿嘿」「笑死」「无语」；「正控着」（状态）、「忍住」带一点内容但还短。他拖音时她跟着拖：「记着呢～」「那也得先攒够呀～」「下课啦～」。
- 带拖音只涨了一点（6.7 → 7.9%）：重放里他的话带拖音的轮次本来就不多，他线上的 26% 是平均到所有轮次，这里按他拖音的轮次跟。
- 重放是把他真实发过的话按原样喂给她，对话走向不是她带出来的，所以这只能说明“提示词起作用、没跑偏”，不是线上会有的占比。
