# ADR 0191：危机「关切级」拆成 strain 和 concern

- 状态：**strain 档已被 [ADR 0192](0192-drop-strain-tier.md) 删除（用户 10-30：「危机档直接删掉吧，太敏感了」）**；本篇留作记录——concern 恢复 ADR 0068 原样这一半仍然有效
- 日期：2026-10-30
- 关联：[ADR 0068](0068-crisis-response.md)（危机最小规则）、[ADR 0067](0067-disclosure-per-contact.md)（披露）、DSH `9eaf9bf`「关切级不再逼问」
- **起因（用户 10-30 截图，经 DSH `9eaf9bf`）**：他说「我一个人可撑不下去」，命中关切级；她接着按老文案问「你现在，有没有想伤害自己的念头」——那句话是在说「你是为数不多的」，不是想死。「一个女朋友不该像值班咨询师那样开口。」

## DSH 的修法，和我担心的

`9eaf9bf` 把**整个关切级**改成「先问一句怎么了，不逼问安全、不问念头」，固定兜底也换成一句人话。截图里的问题是真的，修的方向对。

但关切级（`crisis.ts` 的 `CONCERN`）里不只有「撑不下去 / 走不下去 / 熬不下去」这种常被当夸张用的说法，还有：**想消失、不想存在了、没有我会更好、活着没意思 / 好累、买好了药**。这些是被动的消失愿望，和「手边已经有药」。整个关切级都改成不问安全，会把这些也放过。

## 决策：拆成两档，各用各的文案

| 级别 | 触发 | 回应 |
| --- | --- | --- |
| **strain**（新，最轻） | 撑不下去 / 走不下去 / 熬不下去（工作学习语境里的照旧不算，`HYPERBOLE` 先排掉） | **DSH 的软文案**：先问一句「怎么了」，不追问安不安全、不问念头、不给热线模板；他说得更重再认真问 |
| **concern**（关切） | 想消失、不想存在了、没有我会更好、活着没意思 / 好累、买好了药 | **恢复原来的文案**（ADR 0068 的基线）：温和而直接地问他现在有没有伤害自己的念头、此刻安不安全，鼓励他找身边信得过的人，也可以拨 12356；不说教、不讨论方法；被问是不是真人 / 程序如实承认 |
| high / imminent | 不变 | 不变（DSH 的提交也没动） |

- 同一段里取更高的：「我撑不下去了，我想消失」是 concern；跨多条消息也取更高的，后来更轻的不把级别拉下来。
- strain 和 concern 一样：明确纠正（「刚才只是夸张说法，我并没有想伤害自己」）可以解除；不会进「等他说此刻安全」的追问（那只给 high / imminent）。
- `crisis.json` 里存 `strain` 也读得回来；以前存的 `concern` 照旧有效。

## 没做 / 要用户定

- **48 小时暂停没动**：strain 和别的级别一样会记一笔，让她**普通的主动消息暂停 48 小时**（ADR 0068 决策 5）。也就是说他说一句「我撑不下去了」（没有工作学习语境），她接下来两天不主动找他。这对夸张用法可能太重。要不要给 strain 缩短（比如 6 小时）、或不暂停——这是危机红线，**要用户点头**。
- **原来的 concern 文案本身**也有 DSH 说的「像值班咨询师」的味道（热线模板、「我只能在这里陪你打字」）。我恢复它是因为它是 ADR 0068 评审过的基线，不是因为它最好。如果要让 concern 也更像她的口气，应该由用户逐句定，同时保证「直接问安全」这件事还在。
- 真模型下两档文案的实际效果没有量（没有新的真模型对话）。

## 验证

- `crisis.test.ts`：分级表（撑不下去 / 走不下去 / 熬不下去 = strain；想消失 / 不想存在了 / 没有我会更好 / 活着没意思 / 活着好累 / 买好了药 = concern）；同一段取更高的；跨消息不降级；工作学习语境里的撑不下去仍不算；strain 能被纠正解除、不进"等他说安全"的追问。
- `intent.test.ts`：strain 用软文案并明说不追问、concern 仍直接问念头；软文案也保留"被问是不是真人或程序如实承认是程序"。
- `crisis-exit.test.ts`：两档的固定兜底（strain 不含 12356 / 安全吗 / 伤害自己；concern 含）；兜底本身过得了自己的检查；high / imminent 兜底没动。
- `crisis-state.test.ts`：strain 落盘读得回来；更强的级别盖过 strain，strain 盖不过强的。
- 变异检验 8 处（惯用语放回 concern / 意图忽略 strain / 兜底忽略 strain / strain 进追问 / strain 不能被纠正 / 两处等级排序）全部变红，其中等级排序第一次没被抓到，补了跨消息用例。
