# ADR 0132：表情包自己在 B 站找（配置 `biliStickers`，默认关；要 `stickers` 和 `bilibiliAccount` 开着）

- 状态：**已实现，未上线**（2026-10-23；配置 `biliStickers`；默认关）。上线 = `koishi.yml` 里加 `biliStickers: true` + 重启；回滚 = 改回 false + 重启（收藏库里已经收的留着）
- 日期：2026-10-23
- 关联：[ADR 0063](0063-image-stickers.md)（她自己的图片表情收藏）、[ADR 0089](0089-bilibili-account.md)（她的 B 站号）、[ADR 0131](0131-texture.md)（小黄脸降到很少）
- 用户提出：2026-10-23「表情包让她在 bilibili 自己找，不要用或者少用黄豆表情」

## 问题（有数据）

- **她几乎不发表情包**：线上 10-22 到 10-23 的 91 次判定里 63 次“这轮不用”、28 次允许、3 次抽到、真发出去 **1 次**（她线上 437 轮里发了 1 个；真人约 9% 的轮次带表情包，调研 14.2）。原因：抽签只在“他这句话里有明确反应（哈哈、抱抱、晚安、无语……）”的允许轮次里做。
- 所以小黄脸一减少，就没有东西顶上。
- 来源：收藏里 107 张——64 张他发来的、43 张 ChineseBQB 公开目录里的；她没有自己在 B 站找过。

## B 站上能找到什么（试过）

| 来源 | 结果 |
| --- | --- |
| **官方表情包**（她的号读 `x/emote/user/panel/web`，匿名读不到） | 4 个包：小黄脸 225（**不要**）、**热词系列一 85**（「再给一集」「好家伙」「刻进 DNA」……会随 B 站更新）、**tv_小电视 50**（可爱的小电视脸，笑哭、白眼、坏笑……）、颜文字 52（是文字，不要）。全是干净的图 |
| **评论区图片**（热门视频热评 + 楼中楼，匿名能读，`pictures` 里有宽高和大小） | 571 条评论里 81 条带图（14%），114 张；大多数是游戏 / 视频截图、宣传图（宽 2000+、几百 KB 到几 MB）；按尺寸（宽高 100–1000、比例 0.5–2、≤ 700 KB）筛剩 33 张，更像表情包 |
| 过她自己的收藏判断（24 个候选：14 评论区 + 10 官方） | **收了 21 个**——官方的全是干净的表情包；评论区的混进了：路人真人的照片（男子大笑、Coser）、视频 / 聊天界面截图、带“加粉丝团”的引流图。收藏判断本来就宽，所以要多一道筛 |

## 做了什么

1. **来源换成 B 站**（`bili-stickers.ts` 的 `biliStickerDiscover`，用 `StickerShelf.setTrend` 在 app 起来后换掉公开目录那一路）：官方的（只取「热词系列」「tv_小电视」，**不要小黄脸、颜文字**）和评论区的交替排，官方的按天轮换，官方缓存 12 小时、评论区缓存 1 小时；每天审看 **6** 个（原来公开目录 3 个）；B 站这路读不到东西时才用原来的公开目录兜底。别的来源（他发来的、QQ 收藏、导入箱）照旧。
2. **评论区图片多一道筛**（`biliStickerScreen`，收藏判断之前）：描述里是**真人**（男子 / 女子 / 男生 / 男士 / 真人 / 自拍 / 美女 / Coser / 情侣 / 孩子……：路人的图不收）、**截图**（界面 / 字幕 / 画面 / 海报 / 宣传 / 直播 / 弹幕 / 聊天记录）、**广告引流**（粉丝团 / 二维码 / 关注 / 点赞 / 投币）的一律不收；动漫、游戏、动物、卡通、文字梗照旧收（用户 10-12：「动漫 / 游戏 / 影视 IP 的表情包也行」）。官方表情包不用这道筛。来源标 `bili`（`emote` / `comment`）。
3. **多发一点**（`stickerUncued`，`contact.ts`）：他这句话没有明确反应、但允许发表情的轮次里，也约 **12%** 抽到发一个（种子和有反应那条路分开）；其余规则不变（他问直接问题、认真说事、难过、要照片、刚被吵醒、危机、最近 8 条回复里发过——都不发）。
4. 小黄脸在 ADR 0131 里降到约 2% 的气泡。

## 数据

- 真模型模拟（10-23，`sim/stickers-uncued.json`，`stickerUncued` 抽满，5 次）：他说「我今天去了趟超市」这类没有明确反应的日常话：5 次里 **2 次发了表情包**（其余 3 次模型看了清单觉得没有合适的、没发——允许但不勉强）；他问正事（明天几点的课）和认真难过时 5 次都不发；没有一次写「表情包：」这种假文字。

## 没做 / 要注意

- 评论区图片靠描述筛“真人”，**描述里没写出来的真人（背影、局部）会漏**；官方表情包那一路完全不受影响。想更稳可以把评论区那一路关掉（只用官方）。
- 官方「热词系列」是 B 站的评论区表情（图不大），在 QQ 里显示偏小；它们随 B 站更新才会有新的。
- 收藏库上限 200 张（`STICKER_LIBRARY_MAX`），超了淘汰最久没用的。

## 验证

`bili-stickers.test.ts`（9 个）：评论区图片尺寸规则（含“大小没给”）、热评列表里挑图（含楼中楼、格式不对不出错）、官方表情包只留热词 / 小电视、候选来源（交替、读不到官方的只用评论区并记日志、都没有用兜底）、收藏前的筛（真人 / 截图 / 广告不收，动漫 / 猫 / 文字梗收，官方和 BQB 不筛）、`setTrend` 换来源（来源标 bili、被筛的写明原因、每天 6 个）、`stickerTurn` 的 salt（两条路的抽签互不影响、默认 salt 就是原来的）。
