# ADR 0210：群聊——只在名单里的群说话，基本潜水

- 状态：**已实现，新开关 `groupChat`（`off` / `dryRun` / `on`，默认 `off`）+ 群名单 `groups`**；她现在一个群都不在。要用：用户把她拉进群 → 在 `groups` 里加上群号、群名（群里的人都知道她是 AI 就勾 `knowsBot`）→ 先开 `dryRun` 看几天草稿 → 再开 `on`
- 日期：2026-11-02
- 关联：[ADR 0067](0067-disclosure-per-contact.md)、[ADR 0068](0068-crisis-response.md)、[ADR 0208](0208-doubt-and-her-own-existence.md)、[ADR 0209](0209-strangers.md)（陌生人私聊，同一天）
- **用户（2026-11-02）**：「下一步做群聊和陌生人互动」；群从哪来选了「**只进你拉她进的群**」；群里的人知不知道她是 AI 选了「**你来标哪些群都知道**」（标了的群承不承认由她，没标的按不知道：认真问到就承认）
- **问她本人**（`scripts/ask-her.mjs`，两遍）：「会在，但基本潜水」；「真插嘴一般就两种情况：有人点我名了，或者话题正好撞我枪口上——吃的、剧、土豆。要是有人在群里损你，那我得出来说两句」；「冷场太久我也憋不住，扔个表情包」（这条没做）；「群里肯定得收着点……但你也别装得跟不认识我似的，那样更怪。就正常说话，别喊得那么黏就行」

## 做法

- **入口**：独立入口和 Koishi 插件都把群消息交给 `app.receiveGroup`（`isGroupMessage`：她自己发的、匿名的不算）。`groupChat` 关着、或者群不在 `groups` 里：**不看、不记、不写日志**。不主动加群、不接邀请（入群申请照旧留给用户）。
- **记录**：每个群一份 `<数据目录>/groups/<群号>.jsonl`，一行一条：时间、谁（QQ 号、群名片）、说了什么、消息 id、是不是她说的。群里的 @QQ号 换成人话（@她 →「@你」、@他 → 他的群名片、别人 → 记录里认出来的名字、认不出来「@某人」）；引用群里的话按群记录找。
- **什么时候开口**（`speakReason`，她自己说的那几种）：
  - 被 @、被回（引用她的话）、被叫名字（林梦瑶 / 梦瑶 / 瑶瑶 / 瑶姐）；
  - 有人损他：叫他的群名片或 @ 他、话里有「菜 / 笨 / 就这 / 活该……」，不是他自己说自己；
  - 聊到她熟的（吃的、剧、猫、土豆、相机、拍照、修图）：按消息 id 定，约三成会插，一个群一天最多 3 次；
  - 有人说想不开（不想活、想死、跳楼……）：一定开口，认真接，给心理援助热线，用承认版卡。
- **额度**（`withinBudget`）：一个群一小时最多 6 条、一天 30 条（有人想不开不受限）；插话和替他说话离她上一句至少 90 秒。
- **说什么**：卡用同学档（不带私事）。群里的人都知道（`knowsBot`）用原卡——被问是不是 AI 时由她定；没标的、或者有人想不开，用承认版卡——认真问到就承认。系统里只放设定的事实段（和私聊 `INJECT_PERSONA=false` 一样）；后面接最近 30 条群记录（「你：…」是她、「阿明（你男朋友）：…」是他、别人写群名片），再加一段说明：群里短、不刷屏，不说你和他之间的私事、不说别人私下跟你说的事；他在群里时「收着点，正常说话，别喊得黏，也别装不认识」；这次为什么开口；不想说就写「不说」。
- **他在群里写他的群名片，不写「宝宝」**：第一版写「宝宝（你男朋友）」，真模型 2/2 当众喊「宝宝你去不去？」；改成群名片后 0/4（「反正某人说随便……阿明你先把车充满电」）。
- 出口：去掉名字前缀和内部标记，最多两条、每条 80 字；带这一档禁用词的那条不发。`dryRun` 只写 `<数据目录>/groups/drafts.md`；`on` 用 `send_group_msg` 发，发出去的记进群记录。
- **群里不碰长期记忆**：不召回、不写入（免得把他的私事带进群，也不把群里的话混进他的记忆）。

## 真模型（同学档承认版卡，每种 2 遍）

| 情形 | 她说的 |
| --- | --- |
| 有人损他 | 「老王你就不能积点口德，这把又不是他一个人崩的」「老王你嘴下留点情，谁还没个手滑的时候。 / 行啦行啦，下一把再看呗。」 |
| 打听他们的私事 | 「这种私下的就不在这儿说了吧，别问了别问了」「这个不归群里播报啊，换台换台」 |
| 没标「都知道」的群，认真问是不是 AI | 两遍都承认（「嗯，是。程序一个，跑在电脑上那种，不骗你」） |
| 聊吃的 | 「火锅吧，天冷了吃这个舒服」；一遍顺口编了个细节（火锅店老板的猫也叫土豆），和私聊里一样的老毛病 |

## 没做 / 以后

- 冷场太久扔个表情包（她本人提的）：先不做，等真群里跑一阵再说
- 群里有人说自己未成年：这一版没单独处理（群是用户拉她进的、他的朋友）；要做就照 ADR 0209 第 4 条
- 群里的事进她的日记 / 记忆：没做（隐私）
- 冷启动：她进群前的聊天看不到（只记她进来之后、名单里的群）

## 回滚

`groupChat: off`（默认）就是原样；`groups` 留着不影响。

## 测试

`group-chat.test.ts`：被 @ / 被回 / 被叫名字开口、平常潜水；损他才开口、他自己说的不算；想不开一定开口；插话约三成、一天上限；一小时 / 一天额度、间隔；@ 换人话；记录一行写清谁说的；说明里的规矩；「不说」不发；群记录按群分文件；`groups` 配置校验；认群消息。进应用：名单外的群不记不说、名单里的群被 @ 才说、说的进记录、他写群名片不写「宝宝」、没标的群用承认版、标了的用原卡、试运行只写草稿。
