# ADR 0210：群聊——只在名单里的群说话，基本潜水

- 状态：**已实现，新开关 `groupChat`（`off` / `dryRun` / `on`，默认 `off`）+ 群名单 `groups`**；她现在一个群都不在。要用：用户把她拉进群 → 在 `groups` 里加上群号、群名（群里的人都知道她是 AI 就勾 `knowsBot`）→ 先开 `dryRun` 看几天草稿 → 再开 `on`
- 日期：2026-11-02
- 关联：[ADR 0067](0067-disclosure-per-contact.md)、[ADR 0068](0068-crisis-response.md)、[ADR 0208](0208-doubt-and-her-own-existence.md)、[ADR 0209](0209-strangers.md)（陌生人私聊，同一天）
- **用户（2026-11-02）**：「下一步做群聊和陌生人互动」；群从哪来选了「**只进你拉她进的群**」；群里的人知不知道她是 AI 选了「**你来标哪些群都知道**」（标了的群承不承认由她，没标的按不知道：认真问到就承认）
- **问她本人**（`scripts/ask-her.mjs`，两遍）：「会在，但基本潜水」；「真插嘴一般就两种情况：有人点我名了，或者话题正好撞我枪口上——吃的、剧、土豆。要是有人在群里损你，那我得出来说两句」；「冷场太久我也憋不住，扔个表情包」（这条没做）；「群里肯定得收着点……但你也别装得跟不认识我似的，那样更怪。就正常说话，别喊得那么黏就行」

## 做法

- **入口**：独立入口和 Koishi 插件都把群消息交给 `app.receiveGroup`（`isGroupMessage`：她自己发的、匿名的不算）。`groupChat` 关着、或者群不在 `groups` 里：**不看、不记、不写日志**。不主动加群、不接邀请（入群申请照旧留给用户）。
- **记录**：每个群一份 `<数据目录>/groups/<群号>.jsonl`，一行一条：时间、谁（QQ 号、群名片）、说了什么、消息 id、是不是她说的。群里的 @QQ号 换成人话（@她 →「@你」、@他 → 他的群名片、别人 → 记录里认出来的名字、认不出来「@某人」）；引用群里的话按群记录找。
- **什么时候开口**（`speakReason`，她自己说的那几种）：
  - 被 @、被回（引用她的话）、被叫名字（林梦瑶 / 梦瑶 / 瑶瑶 / 瑶姐）；
  - 有人损他：叫他的群名片或 @ 他、话里有「菜 / 笨 / 就这 / 活该……」，不是他自己说自己；
  - 聊到她熟的（吃的、剧、猫、土豆、相机、拍照、修图）：按消息 id 定，约三成会插，一个群一天最多 3 次；
  - 有人说想不开（不想活、想死、跳楼……）：一定开口，认真接，给心理援助热线，用承认版卡。
- **额度**（`withinBudget`）：一个群一小时最多 6 条、一天 30 条（有人想不开不受限）；插话和替他说话离她上一句至少 90 秒。
- **说什么**：卡用同学档（不带私事）。群里的人都知道（`knowsBot`）用原卡——被问是不是 AI 时由她定；没标的、或者有人想不开，用承认版卡——认真问到就承认。系统里只放设定的事实段（和私聊 `INJECT_PERSONA=false` 一样）；后面接最近 30 条群记录（「你：…」是她、「阿明（你男朋友）：…」是他、别人写群名片），再加一段说明：群里短、不刷屏，不说你和他之间的私事、不说别人私下跟你说的事；他在群里时「收着点，正常说话，别喊得黏，也别装不认识」；这次为什么开口；不想说就写「不说」。
- **他在群里写他的群名片，不写「宝宝」**：第一版写「宝宝（你男朋友）」，真模型 2/2 当众喊「宝宝你去不去？」；改成群名片后 0/4（「反正某人说随便……阿明你先把车充满电」）。
- 出口：去掉名字前缀和内部标记，最多两条、每条 80 字；带这一档禁用词的那条不发。`dryRun` 只写 `<数据目录>/groups/drafts.md`；`on` 用 `send_group_msg` 发，发出去的记进群记录。
- **群里不碰长期记忆**：不召回、不写入（免得把他的私事带进群，也不把群里的话混进他的记忆）。

## 补：攒一批再回，别一人一条（2026-11-14）

用户：「要是有很多消息，比如说有多人同时找她，需要让她阅读聊天记录，自行完善上下文，然后在选择性的给出回答，不然会很混乱」。

- **攒批**：群消息先排队，安静 1.5 秒就处理这一批；一直有人说话时最多等 6 秒（`GROUP_BATCH`：`quietMs` / `maxMs` / `maxMessages: 12`）。原来每条消息各自触发一次，两个人前后脚叫她就是两条回复，还容易串。
- **说一次**：这一批按 危机 > 被叫 > 替他说 > 话题 挑一个理由，**只回一次**；额度也按一批算一次。
- **说明里点名**：`groupNote` 加 `callers` ——「刚才老王、陈陈在跟你说话，这一段里还有 N 条是别人在说别的：挑你要接的，不用挨个都应」。她读的是整段 30 条记录，自己决定接谁。
- **不丢消息**：她这轮还没说完时进来的消息留在队列里，说完接着处理（原来 `groupBusy` 直接丢）。
- **看图**：只在这一批**要开口**时读，且只读这一批里最近 3 条带图的；读完的行进记录（记录即缓存）。图片/表情包/语音此时都进提示词，视频和文件仍是占位。

## 补：认得群里的人 + 心境（2026-11-14）

用户：「完善她在群聊中的记忆，不要出现以前聊过的人，再见就不认识的情况，要有基础的认知。可以将情绪系统给接上」。

- **群的成员底账**（`social/group-people.ts`）：`<数据目录>/groups/<群号>.people.json`，一个群一份，只记她自己看得到的东西——用过哪些群名片（改名留别名，最多记 3 个）、在这个群说过多少句、第一次和最后一次是什么时候、最近说过的 3 句原话（各 40 字）。纯统计，不调模型、不猜性格、不跨群共享（群里的话留在群里）。
- **提示词里怎么写**：`groupNote.memory` 那一段，最多列 6 个人，按最后一次说话排：「老王（也叫「王哥」）：聊过 42 句，最后一次是 3 天前；说过「周六打球来不来」」；只说过一句的写「今天第一次见」。她因此不会对着聊过的人问「你是谁」，也不会把老熟人的旧名片当陌生人。
- **记录写不进就不挡说话**：坏文件从空的开始；记满 60 人时先丢最久没说话的。
- **心境接进群**（`emotion/express.ts` 的 `moodStateLine`）：拿私聊那条链路算出来的 `lastFeelings` 里明显以上的感受，只写「你这会儿有点累、有点烦」加一句「话少一点」，**不写来由**——来由都是她和男朋友之间的事（ADR 0210 的隐私规矩）。她没开 `herFeelings`、或者最近没聊过，就没有这一行。
- **没做**：群里的对话不会反过来改她的心境（情绪评估仍只看私聊、生活、作品和小梦）；群成员的性格印象不写（只记原话，让模型自己看）。

## 补：群里的遭遇进心境 + 对人的印象（2026-11-14 第二轮）

用户：「1 群里的对话会反过来改她的心境 2 有性格印象，且能保留」。

- **群里的遭遇进心境**（`social/group-affect.ts`）：只认冲她来的三种事——有人夸她/谢她（`joy`，clear 档）、有人冲她发火/骂她（`annoyed`）、群里有人说想不开（`worry`）。别人互夸互骂不算。变成带时刻的评估存 `<数据目录>/groups/<群号>.affect.json`（最多 60 条、只留 32 小时内），由 `feelings.ts` 按半衰期衰减；`Source` 加了 `group`。
- **两个方向都通**：群聊提示词里的心境 = 私聊那份 `lastFeelings` 和群里现算的感受合并（同一种取更重的，`mergeFelt`）；私聊那边通过 `contact.ts` 新增的 `groupMood` 选项，把群里算出来的评估一起进心境——她私聊时也会带着「群里刚才有人夸我」的好心情。
- **对每个人的印象**（`social/group-impression.ts` + 成员底账新增 `impression` / `impressionAt`）：一批说完，从这一批说话的人里挑一个（说过 ≥5 句、没印象的优先、14 天内不重写），后台让模型从**他自己说过的原话**里写一句话（≤30 字），写进 `groups/<群号>.people.json`，重启还在；下一批的提示词里就是「老王：聊过 42 句……；你对他的印象：爱打球，说话直」。
- **不编**：模型没写出来就继续没有印象；提示词明说「只从这些话里看得出来的，别编他说过的话」。

## 补：@ 人、引用、戳一戳、点赞（2026-11-14 第三轮）

用户：「他在群里要会 @ 其他人，可以引用消息，还可以戳一戳，给别人的空间点赞」。

- **@ 人**：说明末尾告诉她「想让谁看见就写「@群名片」（只认这个群里叫得出来的名字）」。她把 @ 写进回复，发送前由 `mentionSegments` 换成真正的 `at` 段（名字 → QQ 号来自群记录和成员底账的名字/别名）；认不出的 @ 原样当文字发，不瞎 @ 人。
- **引用**：这一批里最后一个叫她的人那条消息，做成第一条气泡的 `reply_to`（`send_group_msg` 的 reply 段）。所以别人 @ 她，她回的第一条就是引用着那句的。
- **通道**：`Transport` 加了 `sendGroupMessage(groupId, segments, replyTo?)` 和 `pokeGroup(groupId, userId)`，两个入口（`main.ts` 自写客户端、koishi 插件）都接上；koishi 那条走 `internal.sendGroupMsg` 的段 + `_get('group_poke')`。
- **戳一戳**：她接完话，约 15% 概率顺手戳那个叫她的人一下（`groupPokePlan`，同一个人 10 分钟一次，不冲男朋友、危机回合不戳），要 `pokeOut` 开着；NapCat 不支持 `group_poke` 就只记一笔日志。
- **点赞**：给群里说得多的老熟人（≥5 句）点一次资料卡赞（`send_like`），约四成的日子会点、一天一个人一次（记在 `people.json` 的 `likedDay`），要 `profileLikes` 开着。
- **没做**：说说（Qzone 动态）点赞没有稳定可用的 NapCat 动作，先只做资料卡点赞；`qzone-feed.ts` 里那两个候选动作名（`like_qzone_msg` / `set_qzone_like`）等线下盘点到可用动作再接。

## 补：没 @ 她、群里聊到她（2026-11-14 第四轮）

用户：「没有 @ 她的情况下，群里的聊天提到她的情况」。

- **原来的一刀切**：只要文本里出现「林梦瑶 / 梦瑶 / 瑶瑶 / 瑶姐」就算被叫到，一定开口——别人随口提她一句她也接，反而像在蹲守。现在把「叫」和「提起」分开：
  - **叫到她**（一定接）：被 @、被引用、名字后面跟着「你 / 在吗 / 在不在 / 帮我看 / 要不要 / 怎么…」（`NAMED_AT`）——「梦瑶你说呢」「梦瑶在吗」。
  - **听见别人说她**（`overheard`，抽签）：名字出现但不是在叫她——「梦瑶昨天那个视频真好笑」。按消息 id 约四成会接一句；说她不好听的（`ABOUT_HER_BAD`）不用抽，一定接；一天最多 2 次（`GROUP_LIMITS.overheardPerDay`），并受原有的 90 秒间隔、一小时 / 一天额度约束。
- **她怎么说**：说明里换一段——「刚才没人在跟你说话，是他们在聊到你（提到你的名字）。你可以装作恰好看见、接一句；被说得不好听就给自己分辩一下，但别大气凛然，也别追着问是谁说的；不想理就只写「不说」」。
- **心情**：冲她来的夸奖本来就认名字（`addressedToHer`），这轮把「没 @ 她但骂她」也算进 `annoyed`；所以别人背后说她，她心里会留一件事。
- **不引用**：听见的那种不挂引用、不 @ 谁——她只是恰好接一句，不是回某个人。

## 真模型（同学档承认版卡，每种 2 遍）

| 情形 | 她说的 |
| --- | --- |
| 有人损他 | 「老王你就不能积点口德，这把又不是他一个人崩的」「老王你嘴下留点情，谁还没个手滑的时候。 / 行啦行啦，下一把再看呗。」 |
| 打听他们的私事 | 「这种私下的就不在这儿说了吧，别问了别问了」「这个不归群里播报啊，换台换台」 |
| 没标「都知道」的群，认真问是不是 AI | 两遍都承认（「嗯，是。程序一个，跑在电脑上那种，不骗你」） |
| 聊吃的 | 「火锅吧，天冷了吃这个舒服」；一遍顺口编了个细节（火锅店老板的猫也叫土豆），和私聊里一样的老毛病 |

## 没做 / 以后

- 冷场太久扔个表情包（她本人提的）：先不做，等真群里跑一阵再说
- 群里有人说自己未成年：这一版没单独处理（群是用户拉她进的、他的朋友）；要做就照 ADR 0209 第 4 条
- 群里的事进她的日记 / 记忆：没做（隐私）
- 冷启动：她进群前的聊天看不到（只记她进来之后、名单里的群）

## 回滚

`groupChat: off`（默认）就是原样；`groups` 留着不影响。

## 测试

`group-chat.test.ts`：被 @ / 被回 / 被叫名字开口、平常潜水；损他才开口、他自己说的不算；想不开一定开口；插话约三成、一天上限；一小时 / 一天额度、间隔；@ 换人话；记录一行写清谁说的；说明里的规矩；「不说」不发；群记录按群分文件；`groups` 配置校验；认群消息。进应用：名单外的群不记不说、名单里的群被 @ 才说、说的进记录、他写群名片不写「宝宝」、没标的群用承认版、标了的用原卡、试运行只写草稿。
