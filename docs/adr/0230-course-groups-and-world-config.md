# 0230：匿名课程分组与世界配置边界

日期：2026-11-05

## 证据与约束

世界账 W10：同一课程分布在不同课表条目时，原有 nextLesson 只按条目 ID 查找，周四作业错误地截止到下周四，而不是周五。按可见课名比较会使低披露档的匿名课表产生不同事实。直接改写历史截止还会使原本成功的完成作业事件失效。

配置复现也确认零攒钱步长产生 NaN、非法日历日自动滚动、缺失月份温度及原型键事件窗口导致异常、启用的空物品池取到 undefined、负饭时长与无限相机行程破坏时间状态。不能等世界投影中途才发现。

## 决定

- 源课表 `course_group` 是一次分配并持久保存的 `cg-` 加 128 位随机令牌；转换成各档卡与运行时的 `groupId`。不使用课名或其可字典反查的哈希，也不在每次转换时按数组位置重编号。改名和重排保留令牌；同名异课可指定不同组。
- ClassToday 的组身份与原有条目 ID 一样不可枚举，不进入课表快照和提示词。它只表达同课程关系，不能据此恢复名称。原有作业 ID 和事件 target 不改变。
- 只有全部课程有组身份且显式配置 `homework.groupedFrom`，才对布置日期达到边界的新作业使用组规则。部分分组、旧无组与缺边界均保留整套旧规则，不按名字猜测。
- 源世界 `homework.grouped_from` 对应卡里的 `groupedFrom`。本次静态启用日为 2026-11-05；此前作业即使尚未完成，之后查询仍保留旧截止、默认完成时刻和事件关联。边界由布置日期决定，不取查询日、部署日或当前时钟。
- 仍在接下来 1–21 天的实际课表查找下次课，遵守假期、调休和转实训；本次不另改同日多节课的截止政策。
- 在 parseWorld 入口调用纯函数 validateWorldConfig，检查嵌套形状、真实日期、有限安全数值、区间、概率、有效时段及启用功能的非空候选。保留未知扩展字段、可选旧字段、禁用功能的空候选和已有负补货阈值语义，不修改输入。body/NPC 继续由各自既有校验器负责。
- 快递价格字典只读取自有项，合法的 constructor/toString 等物品名没有配置价格时仍使用默认价；不通过禁止合法名字规避原型链。
- 模拟雨天的最高温夹到既有最低温，修正窄温区产生的 high < low；原来有序的天气逐值保持不变。13 张当前卡所有月份温差均至少三度，因此不影响现有卡生成的历史天气，也不影响真实天气缓存。曾使用自定义窄温区的历史雨天高温会纠正，可能改变依赖 cold/hot 的小事和花销回放；不猜测迁移这类外部旧账。

## 迁移与验证

先证明旧无元数据源的 26 个转换产物逐字节不变。然后在内存分配并验证元数据：13 张卡剥离新字段后原有 JSON 完全相同，13 本世界书逐字节不变；13 档在四个历史时刻的 52 次世界投影全对象相同，13 档新作业身份和截止一致。验证后才写入源文件和生成卡，不运行服务或迁移私密事件账。

新增合成回归覆盖匿名身份持久性、解析和 JSON 往返、跨披露档同一事实、同名异组、部分分组回退、历史未完成作业与重启事件、布置日边界、假期调休实训及非法配置。配置校验不代替所有数值运算的溢出防护，也不能证明所有任意外部数据都安全；直接构造 TypeScript World 的内部调用方仍须遵守类型和业务约束。

本决策完成时交叉复核另确认 W22：0–99 年被多个本地数字日期构造器按 1900 年偏移；有限 Date 也可能越过四位持久格式。当时因此未将模块标记完成。后续已通过 [ADR0231](0231-local-calendar-boundaries.md) 统一修复并补齐调用方/持久边界；具体复现、最终验证和残余限制见世界账审查与持续进度。

## 后果

课程组是作者维护的机器元数据。未来修改课程关系须保留历史语义并选择新的生效方案；不能随意重生成已有令牌。令牌重排稳定不意味着原有按 course-index 生成的作业 ID 支持任意重排历史课表，本次迁移不改变条目顺序。旧数据继续可读，不借此次修复重算已经存在的事实。当前真实课表的 14 个确切课名互不相同，因此没有猜测合并别名；跨条目修复由合成同课程场景验证。
