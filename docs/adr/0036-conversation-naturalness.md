# ADR 0036：自然对话先接眼前这句话

- 状态：已上线（2026-10-08 20:59）
- 日期：2026-10-08
- 关联：[ADR 0014](0014-speech-habits.md)（说话的毛病）、[ADR 0019](0019-todays-layer.md)（这一轮意图）、[ADR 0028](0028-emotional-inertia.md)（情绪余温）

## 问题

世界和人生连续性已经明显变强，但“有生活”被错误地翻译成了“每轮都要汇报生活”。10 月 7–8 日线上原话暴露出四类结构性假感：

1. 对方说「我哭得很伤心」，回复前两句还在接话，第三句突然转去讲构图和土豆；
2. 对方说认识五千多天，回应完关系后固定补一条调色进度；
3. 对方说上午都要上课、只回「悲」，她先管一句早起，马上转去播报自己追剧；
4. 对方说「我去写代码了，你慢慢看」，她仍汇报小说还差多少章，再说「晚点你忙完找我就行」。

这不是某个词不口语，而是对话动作错了：程序把“她有自己的生活”当作每轮必说的 KPI。模型忠实执行后形成稳定三段式；同时，提示词放入最近 7 天全部原始聊天，线上已经达到 400 多条消息，程序自己的旧回复又成为下一轮最强的风格示例。

## 决策

### 1. 对方当前的话优先于她的后台进度

意图层的新顺序：收尾 → 直接问题 → 明确情绪 → 对方刚说的经历 → 无话题开场时才考虑待跟进 / 答应过的事。

- 明确难过、哭、累、难受时，只接住，不转去说猫、书、拍照或别的日常；
- 对方说自己的经历时，先回应；只有真想知道才问细节，不再规定每次必问；
- 想念、喜欢、纪念日、认识多久这类亲密话只围绕两个人回应一两句；普通玩笑和接话没有额外意图；
- 只有「在吗 / 在不在 / 人呢 / 滴滴滴」这种没有实质内容的开场，才捡起待跟进和承诺；
- 删除“空闲就必须说一件当前进度”和“在读书就必须报一次阅读进度”。状态、书和世界事实仍在提示词里，但明确写着用不用由她自己定。

### 2. 识别真实收尾

「我去写 / 改 / 学习 / 上课 / 开会 / 洗澡 / 吃饭」「你先忙」「你慢慢看 / 玩 / 吃」都算收尾。回复一两句就停，不另约“晚点找我”，除非关系和语境确实需要。

### 3. 原始聊天设上限

长期记忆开启时，仍先按 7 天过滤，但最终只把最近 80 条原始消息放进提示词。更早的事实走 Hindsight 召回；这不是遗忘事实，而是避免几百条旧模型回复不断自我强化措辞和三段式结构。

80 条通常覆盖数小时到一整段长聊；单条过长时，原有 token 预算仍会继续裁剪。未来若 80 条内仍有明显模仿污染，再改成“最近若干轮 + 当前片段摘要”，不直接盲目缩短。

## 不是只靠提示词的后续方案

自然度接下来按四层推进：

1. **对话动作层**：先判断接话、共情、回答、玩笑、追问、收尾或主动分享，内容事实不能越过动作层抢话；
2. **真实语料层**：从经同意的目标聊天语料抽取节奏、句长、转折、口头词和不完整表达，合成示例只补覆盖，不充当主要风格来源；
3. **候选选择层**：同一内容生成 2–3 个候选，用“不相关自我转场、过度完整、套话、重复结构”评分选一个，而不是让模型一次决定全部；
4. **盲评层**：把真人原句、旧版、新版混排，分别评“像真人、像林梦瑶、接得住、愿不愿继续聊”。规则检查继续负责硬错误，不再把规则全过等同于自然。

有足够干净目标语料后再考虑微调；没有目标语料时，微调只会更稳定地学会合成腔。
