# ADR 0072：谁来评判「她像不像」——怎么把用户之外的人拉进来、又不损害隐私（提议，只列选项）

- 状态：**提议**（只列选项，不写实现；需要用户裁决）
- 日期：2026-10-15
- 关联：[ADR 0073](0073-feedback-channel.md)（反馈通道：他回「假」/「像」，已实现、默认关）、[ADR 0020](0020-disclosure-and-social-life.md)（披露分级）、[ADR 0067](0067-disclosure-per-contact.md)（按联系人标记是否知情）、盲评包 `exchange/blind/`、DSH 的真人语料 `research/2026-10-real-chat/`；任务书 T4

## 背景

现在判断「她像不像真人」的人几乎只有两类：**模型**（合成题目、模拟、自动评判）和**用户一个人**（盲评、聊天里的感觉）。锐评（10-13）指出：评判者几乎全是模型，真人只有用户；这一个人既是对象又是评判者，还会因为知道哪个是她而有偏。反馈通道（0073）解决「用户当时的感觉怎么采」，**不解决「还有谁能看」**。

## 约束

- **隐私**：她和每个人的聊天是那个人的聊天。不能把真实聊天原文给第三方看（公共记忆已有披露上限，ADR 0020）。
- **知情**：名单里的人都知道她是程序（0003 / 0067）；让谁来标，要不要告诉她「你在被拿来评判」，是对她的告知问题。
- **不增加他们的负担**：不能变成每天催人打分。

## 选项

| 选项 | 做法 | 好处 | 代价 / 风险 |
| --- | --- | --- | --- |
| **A. 现状 + 反馈通道**（建议先做） | 只用户一个人；0073 把他的感觉每周汇总一次 | 零新增隐私风险；成本是用户 2 秒 | 仍是一个评判者；有偏 |
| **B. 只用虚构对话的盲评包给别人看** | 用 DSH 的虚构 / 公开语料和模拟对话做盲评包（不含任何真实聊天），请用户信得过的 2–3 个人（家人、朋友）各评一次，「像 / 假 / 哪句假」 | 不碰真实聊天原文，隐私风险≈0；能得到用户之外的真人判断 | 只能评「模拟里的她」，评不了真实聊天里的她；要用户去找人、告知这是一个陪伴机器人项目 |
| **C. 让鸽鸽（同学档、知情）偶尔标一句「像 / 假」** | 开 0073 的反馈指令给同学档；告知她「这个字是帮忙调她的说话」 | 第二个真人、真实对话里的信号 | 要先问鸽鸽本人同意；0073 现在只对男朋友档；她标的是**她自己和机器人的聊天**，没有第三方原文暴露，但要告知；容易变成负担 |
| **D. 用户自己拿某一句去问朋友** | 用户自己决定把某一句发给朋友问「像不像」 | 完全由用户自己控制 | 不是产品功能，不需要做；只是提醒这个选择在用户手里 |
| E. 外部评审 / 众包 | 把对话发给陌生人 | 样本多 | **不建议**：真实聊天含隐私，虚构对话又评不出真实场景；违反现有隐私底线 |

## 建议

1. 先 **A**：开 0073（A 看满 48 小时之后），每周看一次「最假的 10 句」。
2. 想要第二双眼睛，先 **B**（零隐私风险），而不是 C。
3. **C** 只在用户明确同意、并且先问过鸽鸽本人之后再做；做的时候只把 0073 的开关对那一个联系人打开，不做任何通知式的催促。
4. E 不做。
