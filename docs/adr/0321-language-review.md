# ADR 0321：语言模块审查后的回复与异常边界修复

- 日期：2026-11-05
- 状态：已实现并通过全仓验证（2,208 项测试、类型检查与差异格式检查）
- 范围：语言模块及其在 contact / responder 中的直接接线

## 问题

逐文件审查和合成输入复现发现 16 项问题：后续重写能绕过出口检查、废弃重写稿携带的设备动作仍可能提交、危机空正文没有兜底、摘要写盘失败逃逸、照片令牌错误豁免无关媒体承诺、排队任务绕过新熔断、正文读取断网分类错误、异常摘要被当成没有事实、滑动窗口刷新停滞、非游戏邀约进入陪玩、连发的详细请求被最后一句遮住、最新问题超预算被静默丢弃、质感补问号改变陈述语气、示例对话混入事实证据、跨行事实证据删不掉、深思输出额度未纳入提示词预算。

## 决策

1. 保留现有生成与审稿结构。所有可能重新生成的步骤结束后，执行只清理/删行、不再调用模型的 `finalizeReply`。事实检查开启且文本被后续修改时，再进行一次只审稿/删行的检查。
2. 重写清理返回独立草稿（文本及设备提议）。只有审稿步骤接受该重写时，才替换当前选中草稿的动作；空重写回退不会替换。危机回合不提交模型设备提议。
3. 危机空正文或普通审查删光时立即使用已有对应级别兜底，避免退化成分钟级重试。
4. 摘要完整 Promise 链捕获解析、生成和持久化异常。没有有效要点且不是明确的“- 无”算失败，继续保留原文并按现有间隔重试。有效要点仍容忍前后说明和附带的“- 无”。写盘成功后才更新内存缓存。
5. 模型调用拿到并发位置后重新核对熔断状态，不重复扣日额度；正文读取阶段的网络/超时错误同样转换成 `ModelUnreachable`。
6. 小梗与口头习惯保存上一轮末条材料的 SHA-256 游标，按游标之后真正新增的材料数刷新。旧文件没有游标时使用 `updatedAt` 作为兼容边界，下次正常刷新时补齐。保留旧 `messageCount` 字段；不保存额外聊天正文。
7. 游戏状态必须有明确游戏语境；详细解释请求按整串连发识别，支持后续明确撤销。质感补问号同时要求疑问结构并排除常见陈述/否定模式，拿不准就不补。
8. 事实证据排除带 `example_user` / `example_assistant` 名字的示例对话。跨行 quote 映射到原文的覆盖行后删除。
9. 提示词预留使用本轮实际模型的输出上限（包括合法的 `extraBody.max_tokens` 覆盖）。置顶示例必须为最新用户消息让出位置；当前消息或固定部分确实放不下时，返回明确的直接回复而非缺失问题的模型请求。主动消息超预算则跳过，危机超预算使用危机兜底。
10. 照片/表情包的媒体豁免按分句核对，不能豁免语音、电话、视频、红包、邮寄承诺。

## 兼容与回滚

没有新开关，不改变现有开关默认值。游标是派生状态的可选字段，旧版可忽略；回滚源码不需要迁移或删除运行数据。新增的预算兜底是有意行为变化：不再向模型发送缺少当前问题的提示词。最终事实复核只发生在已启用事实检查且后续阶段改动了文本的轮次，会增加一次审稿调用。
