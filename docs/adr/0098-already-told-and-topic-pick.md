# ADR 0098：继续去 AI 味——说过的事不再自己提、带事的轮次抽“说哪一件”、拖音/省略、图片表情放行

- 状态：**已实现，已上线**（2026-10-22；没有新开关：一行提示 / 挂在已经开着的 `shapeAgenda`、`shapeFiller` 上 / 放宽图片表情的判定）
- 日期：2026-10-22
- 关联：[ADR 0094](0094-her-own-agenda.md)（带自己的事）、[ADR 0097](0097-ai-smell-night-test.md)（深夜测试里量出来的 AI 味）
- 用户提出：2026-10-22「继续去除她消息的 AI 味」（接 ADR 0097 没做完的两项）

## 一、她主动说过的事，一天半内不再自己提

ADR 0097 里没做的一项：「肚子坠着」10-20 到 10-21 连着三个晚上，每晚都是她自己提的（他先说了别的话），他说「你会老是重复一件事」。`recentCrutches` 只看最近 8 条气泡，隔了一天的管不到。

`expression.ts` 的 `alreadyTold`：她最近 36 小时的气泡里，哪几类关于她自己的事是她**主动**提的——「主动」= 说那一轮之前，他的话里没提这件事（他问起来她答，不算）。五类：肚子不舒服 / 相机 / 猫 / 作业 / 快递。`contact.ts` 在提示词里多一行「这些事你已经主动跟他说过了：……。他不问，就别再自己提」；事实本身还在时间块 / 身体那一行里，他问起来照常答。危机回合不用。

## 二、带自己的事的轮次，说哪一件由我们抽

ADR 0094 里提示词只说“从「你那边」「你的身体」「你今天的心情」里挑一件他还不知道的”。真模型总是挑同两件。用 72 句真人情侣对话（单轮、没上文）测当前代码：

| | 提到相机 / 土豆 / 作业 / 快递的回复 |
| --- | --- |
| 没开带自己的事 | 5 / 72（7%） |
| 开了（提示词让她自己挑） | **15 / 72（21%）**，其中相机一件 10 条（14%） |
| 线上 10-05 到 10-18（没有这个开关） | 553 条气泡里 12% 提到这四类；10-19 到 10-21 是 5% |

所以：带自己的事的轮次，由 `planShape` 按轮从候选里抽一件（同一轮每次一样），提示词写成「就说「作业」这一件（看「你那边」「你的身体」「你今天的心情」里对应的那一行，没写的细节不编）……」。候选 = 「你那边」那一行里每一项的名字（天气 / 土豆 / 快递 / 作业 / 攒钱买相机 / 钱 / 朋友 / 约 / 今天的小事……）加上「身体」「心情」，**去掉她这一天半里已经主动说过的**（上一节）。没有候选就回到原来的“自己挑”。

## 三、拖音 / 省略（挂在 `shapeFiller` 上）

用户线上的话 505 条里 11% 带「～」或「…」，她形状控制后的 81 条气泡 0%。`planShape` 加 `drawl`：不管他有没有先拖音，约 12%（`DRAWL_SHARE`）的轮次（不是认真接话 / 收尾 / 他说倒霉事 / 呜呜）提示她「语气松一点：句尾可以带个「～」或者「……」，拖个音、留半句，别每句都这样」。他自己拖了音的那一路（`stretch`）不变，两者不同时出现。把他真实发过的 180 条话重放：她的气泡里带「～」或「…」的从 2% 到 7%（他 11%）。

## 四、图片表情：放行条件放宽

这是这一轮里差得最远的一项：用户线上 623 条气泡里，动画表情 73 条（12%）+ 纯 QQ 小表情 114 条（含小表情的气泡共 8%），两样加起来约五分之一的气泡是表情；她 668 条气泡里 1 条图片表情、3 条纯小表情，约 0.6%。图片表情货架有 104 张，只用过 1 张。

原因：线上从 10-20 02:43 开了 `stickers: send` 以后，图片表情的 52 次判定只有 2 次放行（4%，真人约 9% 的轮次带表情包）。挡的理由：31 次“他这一轮问了直接问题”（多数是用户测试里的真问题，但「在吗」「在干嘛」这类招呼式问句也被一起挡了）、11 次“要认真回应他说的事”（几乎全是最常见的意图行「回应他刚说的那件事」）、7 次最近 8 条回复里发过。

改了两处（`stickers.ts` `imageStickerAllowance`）：招呼式问句（在吗 / 在干嘛 / 睡了吗 / 吃了吗 / 想我没……）不算直接提问；意图行「回应他刚说的那件事」「他刚说了件好事」不再挡（一个表情就是一种反应）。挡住的只剩：想看照片、难过要接住、直接回答他问的、危机、被吵醒、刚发过。有没有合适的表情还要看他这句话有没有明确的反应（`stickerCued`），没有照旧不发，所以放宽不会让她乱发。上线后第一周看日志里「图片表情：这轮不用（……）」的构成和实际发出的比例（目标约 9% 的轮次）。

## 量出来的

| | 提到相机 / 土豆 / 作业 / 快递的气泡 | 带「～」或「…」的气泡 |
| --- | --- | --- |
| 上一版（带事由模型自己挑） | 18% | 2% |
| 这一版（抽一件 + 拖音） | 12% | 7% |

72 句真人对话（单轮、没上文）：提示词让她自己挑时 15 / 72 提到这四类（相机一件 10 条），改成按轮抽一件后 11 / 72；鉴别员挑中真人 52%（上一版 58%，标准误约 ±5，分不出）。鉴别员认她的理由 36 / 37 条是“太完整 / 太顺 / 太会接话”，13 条提反问；它认为真人的特征是“跳跃、答非所问、只应一声、只发表情、带情绪”——这和表情那一项是同一个方向。

## 没做 / 要注意

- 隔一天半以上的重复不管（那时再提也算自然）。
- 候选里“天气”“钱”“朋友”“约”是第一次被抽到，真模型怎么说要看线上；日志里「这一轮形状：…带自己的事：天气」能看到抽了哪一件。
- 五类话题的关键词是手写的（肚子 / 相机 / 土豆 / 作业 / 快递）；新增一类她爱重复的事要往 `TOLD_TOPICS` 里加一行。
