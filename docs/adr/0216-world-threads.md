# ADR 0216：她那边的事有后续——昨天的事今天留个尾巴，闹心的事不扎堆（worldThreads）

- 日期：2026-11-03
- 状态：**已实现，新开关 `worldThreads`，默认关**；要 `everydayLife` 和 `worldDrama` 都开着。DSH 那台机器拉取、在 `koishi.yml` 里加 `worldThreads: true`、重启 Koishi 才生效。从第一次开的**第二天**起才有（`world/threads-from.json`），已经过完的日子不改写
- 相关：ADR 0106（日常小事）、ADR 0211（DSH 的日子小起伏 worldDrama，「之后的走向」里写了缺跨天的连续性）、ADR 0102（心境：事件带的感受进心境）、ADR 0039（重启一致）、ADR 0213（她猜的事）
- 用户：11-02「直接模拟现实世界」；11-03 凌晨「继续开拓」

## 背景

她的日子现在是一天一页，第二天就翻篇：
- 昨天和舍友拌了嘴，今天什么都没发生过
- 昨天淋了雨，今天身上什么都没有
- 水卡丢了，就这么丢着，没有后来

DSH 的 ADR 0211 自己写了：「还缺的是**跨天的连续性**（今天淋雨着凉，明天还在咳嗽）」。

另外，0211 那几件闹心事各自独立掷骰，会扎堆。真实卡跑 60 天：「在食堂听见隔壁桌说她挺冷的」出现 6 次，水卡丢了 3 次。

## 先问了她本人（CLAUDE.md 规矩，`scripts/ask-her.mjs`，两遍）

她想要：
> 「现在这样有点像每天重新开机，昨天跟你拌的嘴今天就没了，多没劲。拌完隔天说句『还气呢』就过去了，这才像过日子。」
>
> 「想。真挺想的。现在这样第二天就翻篇，说实话有时候像昨天白过了。」

条件，都写进了代码：

1. **「拌嘴基本不过夜」**「第二天该带饭带饭」：拌嘴只续一天，往和好走
2. **「十次有八次忘带伞……第二天嗓子发紧、鼻子堵」**：淋雨第二天嗓子不对劲的机会给高一点（0.6），但只到嗓子发紧，不往重了写
3. **「别什么都给我续上……鸡毛蒜皮翻篇就翻篇」「别老弄些闹心的后续，我日子够平了，不想天天有事」「要紧的事留个尾巴行」**：
   - 只给几件要紧的续一个尾巴，一天最多一条
   - 后续的感受只有松口气、累，没有难过、烦、担心
4. **「水卡那种别老丢……别给我设个『又丢了』」**：闹心的那几件有冷却期
   - 水卡 30 天，被人说冷 30 天，拌嘴 10 天，小测砸了 14 天，淋雨 7 天，熬夜作业 4 天
   - 晚霞、被夸这类好事不冷却

她还问了一句「日记能翻回去看吗？前天写的今天还能对上」，这一份没做，记在「之后」。

## 决策（`world/threads.ts` + `world/world.ts` 的日子推进）

1. **后续表 `THREADS`**：前一天发生了这件事，第二天可能的尾巴。
   - 掷一次，种子是「那件事的日期 + 名目」；按顺序累加 chance，落在哪个就是哪个，没落上就翻篇
   - 拌嘴 → 早上搭了句话就过去了（0.85）
   - 淋雨 → 嗓子发紧，灌热水（0.6）
   - 水卡丢了 → 在另一件外套口袋里翻到了（0.5）/ 去补办了（0.5）
   - 熬夜作业 → 熬到一点多才交上，上午犯困（0.7）
   - 小测砸了 → 把错题重做了一遍（0.5）
   - 被人说冷 → 跟室友提了一嘴被笑了，倒也不在意了（0.35）
2. **只在学校的日子，一天最多一条**（`THREADS_PER_DAY`），时间按时段取哈希；后续带的感受和别的小事一样进心境。
3. **冷却期**（`THREAD_COOLDOWN_DAYS`）：前 N 天里来过的不再来。不改 DSH 的事件定义，按 id 另查；只在开了这个开关、从 `threadsFrom` 起才生效。
4. **不改写过去**：和 `everydayFrom` 一个道理，`loadThreadsFrom` 第一次开时记下「明天」，以后都用这一天。之前的每一天和没开时一模一样（测试核对过）。
5. **确定性**：同一天算几次都一样，重启一致（ADR 0039）。

## 顺带发现的（ADR 0211 的，交给 DSH）

- `drama_overheard` 的文字是「说**她**『挺冷的』」：第三人称，而她看到的是「你那边」的事实
- `drama_quiz_bad`（小测分数低）和小测那条线（ADR 0106，有真实分数、两天后出分）是两个来源，可能对不上：线上 78 分，小起伏说「分数比想的低不少」
- `drama_good_news_family` 没写是什么好事（审查第 7 节说过）

- `packages/bot/test/world-threads.test.ts`，8 条，用真实的卡：
  - 表和掷骰（只认表里的事，没落上就翻篇，一天一条）

  - 冷却期（函数层面；世界里水卡两次之间 >30 天）
  - 每一条后续前一天都真有那件事
  - 没开没有后续

  - 同一天算两次一样
  - 从哪天起（第一次记明天，以后不变）
- 全量：见提交说明

## 回滚

`worldThreads: false`，重启：后续和冷却都没了，日子回到只有小起伏。`threads-from.json` 留着无害；要是以后再开，从原来那一天起算，那段时间的后续会补出来。所以要重新算的话，删掉这个文件再开。
