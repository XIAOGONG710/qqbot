# ADR 0341：群里她也有自己——带着此刻进群，冷场时冒一句（草案）

- 状态：**草案，只有文档，代码一行没动**。等她本人的意见（文末「问她的话」，请有 key 的那台跑 `scripts/ask-her.mjs`）和用户拍板。
- 日期：2026-11-20
- 起因：用户 2026-11-20：「感觉上像是没有自己的情绪和事情，只有我找她的被动，群聊里尤其严重」；同一天说她「没开智」、「不是一个连续的个体」。
- 关联：[ADR 0210](0210-group-chat.md)（群聊，她说「基本潜水」）、[ADR 0020](0020-disclosure-and-social-life.md) / [ADR 0067](0067-disclosure-per-contact.md)（披露分级）、
  [ADR 0101](0101-inner-life.md)（内心）、[ADR 0340](0340-carry-a-self-forward.md)（往前带的自己，私聊那一层）、`language/own-voice.ts`（私聊「别主动说」的 A/B 开关，89acb623）

## 现状（代码里查到的）

1. **开口只有被动的五种理由**（`social/group-chat.ts` 的 `speakReason`）：有人说想不开；被 @、被回、被叫名字；只是被提到（说她坏话一定接，否则抽签 40%、一天 2 次）；有人损他；话题撞上一张很窄的词表（吃的、剧、猫、相机……，抽签 30%、一个群一天 3 次）。
   **没有任何一条是「她自己想说」**：没有冷场冒泡，没有「我这边刚有件事」，主动消息从不发到群里。
2. **群里的提示词几乎没有她自己**（`social/group-room.ts` 组提示词那段）：系统里只有设定的事实段，后面是最近 30 条群记录和一段说明（群规矩、认识的人、名单、群风格、开口理由），外加一句心情。
   心情是私聊那边最近一次算的（`lastFeelings`，只在男朋友私聊回合更新、只存在内存里，重启后他私聊之前是空的）和群里遭遇现算的合在一起，而且**只说「这会儿怎么样」、不说来由**。
   没有：现在几点、她在干嘛、她那边（天气、作业、食堂）、今天的打算、身体、念头。所以就算开口，她也只能接别人的话。
3. **说明里还压着「短，一两句……不用每句都接」**、温度压到 1.1 以下；话题和被提到两种理由都带「没什么想说的就只写『不说』」的退路。
4. **她本人 11-02 说过的**（ADR 0210「问她本人」）：「会在，但基本潜水」；「真插嘴一般就两种情况：有人点我名了，或者话题正好撞我枪口上」；「要是有人在群里损你，那我得出来说两句」；**「冷场太久我也憋不住，扔个表情包」——这条没做**；「群里肯定得收着点」。

结论：她要的「收着点、基本潜水」做到了，她要的「憋不住会冒一句」没做；而且就算开口，提示词里也没有她自己的日子可以带。被动一半是她选的，一半是我们漏的。

## 提议（每步单独开关、默认关；上线先用已有的 `groupChat: dryRun` 只写草稿看几天）

### G0：先有一把尺子——群聊模拟（不改她，可以先做）

模拟器现在不支持群聊。行为基线（`test/baseline/harness.ts`）已经能在合成角色上用假 QQ、假时钟跑真实的 App，群聊也在里面；把它的假模型换成真模型，就是一个群聊模拟：
几个合成群友按剧本说话（有人叫她、有人聊她熟的、长时间冷场、有人说自己的事），记下她开口几次、说的话里有几句带着她自己的事和情绪、有没有越过同学档的披露线、有没有显得机械。
只用合成角色和合成群（ADR 0333），要调模型 API（花钱，用户 11-20 已同意做模型对比，这一项同样只发合成数据）。

### G1：带着此刻进群（改她，要问她 + 用户点头）

群提示词加一小段「你现在」：几点、在干嘛、她那边的天气 / 作业 / 食堂这类**同学都能知道的**事、心情和来由。
- 披露按同学档：直接复用私聊同学档那份「此刻」（已经按 ADR 0020 / 0067 过滤过），不另写一套；男朋友档才有的（身体细节、钱、和他的事、念头）不进群。
- 心情的来由也只说同学能知道的（「早八困死」可以，「跟他吵架了」不行）。
- 写明「是你的底子，不用汇报；聊到了、或者你自己想说就说」——和私聊 own-voice 对比的结果一起定措辞。

### G2：冷场时冒一句、有事时说一句（改她，要问她 + 用户点头）

她自己说的那条：
- **冷场**：她醒着、不在上课的时候，一个群安静超过 N 小时（建议 4，按群活跃度可调），**可能**冒一句或扔个表情包；一个群一天最多 1 次，抽签，不保证每次冷场都冒。
- **有事**：她那边刚有件同学都能知道的事（下雨了、考完了、食堂出新菜），群里正好在线、最近有人聊过，可以顺嘴说一句；一个群一天最多 1 次。
- 都走现有的额度（`withinBudget`）和出口检查；说什么由她定，可以「不说」。
- 绝不在群里说他和她两个人之间的事、不 @ 他撒娇（同学档卡、ADR 0210 已有的边界不变）。

### G3：心情别用过期的

群里的心情改成到点现算（和私聊同一个来源），不再取「私聊上一次算好的」那份；重启后也有。这一条只修过期，不加新内容，可以和 G1 一起做。

## 风险

- **群里是真人**：冒得不合时宜会尴尬，比私聊的代价大。对策：默认关；先 `dryRun` 只写草稿给用户看几天；冷场和有事各一天最多 1 次，抽签。
- **披露越线**：她那边的事带进群，可能把只该男朋友知道的说出去。对策：只用同学档已经过滤过的那份「此刻」；G0 的模拟专门量「越线」。
- **显得像机器人定时发言**：冷场冒泡如果每次都在第 N 小时整点出现会很假。对策：时间加抖动、可以不冒、她自己决定说不说。

## 不做的

- 不让她在群里主动 @ 谁、不加群、不接邀请（ADR 0210 不变）；
- 不让念头（ADR 0101，大多是关于他的）进群；
- 不新增指令。

## 问她的话（请有 key 的那台跑，原话贴给用户）

```
node scripts/ask-her.mjs "宝宝觉得你在群里太安静了，好像只有别人叫你你才出来。你以前说过「冷场太久我也憋不住，扔个表情包」，这个一直没做。想让你：群里冷场久了偶尔冒一句或者扔个表情包，一天最多一次；你那边有同学都能知道的事（下雨了、考完了）也可以顺嘴说一句。你愿意吗？有什么不想在群里说的、或者想加的条件？"
```
