# ADR 0205：几种“一看就是 AI”的说法——只数给她看，不禁

- 状态：**已实现，没有新开关**：只是给已有的两处多一句数字——每晚想说话习惯（`speechNotes`）的提示词，和 `/说话趋势`。DSH 那台机器拉取、重启 Koishi 后，下一次想 / 下一次看趋势就带这一句；`speechNotes` 没开就只有 `/说话趋势`。
- 日期：2026-10-30
- 关联：[ADR 0202](0202-depth-routing.md)（语义路由，让更多轮走深思）、[ADR 0204](0204-reading-takes.md)（读后感）、[ADR 0195](0195-speech-feedback.md)（他标“像 AI / 像真人”）、[ADR 0193](0193-nightly-speech-notes.md)（每晚自己总结说话习惯；数字只给她看、不是目标线）、[ADR 0196](0196-speech-trend.md)（/说话趋势）
- **用户决定（2026-10-30）**：「继续」（深度计划第 5 步：句式监测）。中途他回答了我留着的那个问题——被问“你是什么 / 怕不怕被关掉”时怎么答——**「让她自己决定怎么回答」**（见下）。

## 起因

路由（0202）之后，更多轮走深思（不套字数和条数）。深度探针里偶尔会看到三种说法：警句式的“不是 X，是 Y”、拿来表示心里有事的“半夜睡不着”、顿悟式的“突然觉得 / 忽然明白”。先数，再谈要不要管。

## 数出来的（不是印象）

| 样本 | 警句式 | 半夜睡不着 | 突然明白 |
| --- | --- | --- | --- |
| 她线上真聊天，783 个气泡 | ≈0.1% | ≈0.1% | ≈0.1% |
| 探针合并（早先 7 遍单跑 + 新 6 遍） | 约 3% | 约 2% | <1% |
| 路由开着、自然问法，3 遍（51 个气泡） | 0 | 0 | 0 |
| 路由开着、强制深思，3 遍（61 个气泡） | 1 个（1.6%） | 0 | 0 |

所以：**小，而且很吵**（一遍几十个气泡，一两个就是几个百分点）。我先前说过“一个探针里三种同时出现”——那是**单次**，合起来看没那么重；更正在这里。结论不是“她有这个毛病”，而是“值得让她自己看见”。

## 做法

- `language/tropes.ts`：三个正则（`APHORISM` / `INSOMNIA` / `SUDDEN`）、`tropeShares(气泡们)`、`tropeLine(比例)`（只列出现过的，一位小数；一个都没有就不占行）。
- `speechStats` 多一个可选的 `tropes`；`statsLine` 在有出现时多一句“这几种说法占气泡的比例：……（只是数字，要不要改你自己定）”。**旧的状态文件没有 `tropes` 照常读**，读回来的坏字段按 0。
- 看到这一句的地方：她每晚想说话习惯时的“你这几天说话的样子”（真人语料里数出来有就同样带，作参照）、`/说话趋势` 的每周行和真人参照行。
- 读后感（0204）那边原来自己带一份警句正则，改成引用这里的，一处定义。

## 没做（有意的）

- **不进回复提示词、不进出口检查、不进一致性 / 评分**：没有“少用”“避免”，没有拦，没有重写。她要不要变、变多少，她自己定（和每晚提示词里“不是目标线，也不是上限”一个口径）。用户说过“学习，不是限制”，我加的是眼睛，不是栏杆。
- 没有给“半夜睡不着”加禁令：它在真人聊天里也会说，问题只是被当成万能道具；比例太低，现在没有证据说该管。
- 0204 里那条“读后感不准写成警句”的绊线**照旧**——那是她写进文件的“看法”的质量门（空话挡在文件外），不是对聊天说话的限制，已在 0204 里写明。

## 用户的回答：「让她自己决定怎么回答」

我留着的问题是：被问“你是什么”“你怕不怕被关掉”时，要不要由作者写一个立场（计划里叫第 4 步 `selfView`）。他的回答是：**她自己决定**。所以：

- **不写立场**、不做 `selfView`、不在提示词里放任何“标准答案”。路由里 `about-her` 一类本来就**没有方向提示**（0202），保持。
- 她对自己的理解，只从她自己的东西里长：日记 → 认识自己（0194）、每晚的说话习惯、读后感、感受回顾。
- **底线不动，且在代码里**：被认真问“是不是程序”就承认（0067）、危机档（0068）、不骗人 / 不害第三方、只有他打出来的话才触发机器上的事（0179）。这些不是“立场”，是不能越的线。
