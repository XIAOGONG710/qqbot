# ADR 0180：她自己上网

- 日期：2026-10-30
- 状态：已实施
- 相关：ADR 0101（内心）、ADR 0160（搜索 / 读网页）、ADR 0130（她自己在 B 站看东西）

## 背景

搜索 / 读网页（ADR 0160）原来只有两个触发：他贴链接、他明说「搜一下」。主动消息那条路还明确不查
（`app.ts` 的 `!initiating`）。也就是说**他不出声，她一个字都不查**——她想弄明白的事没法自己去找。

用户 10-30：「让她有自主性为什么不做，像这样类似的都做，让她完全的自主」。

## 决策

挂到内心（ADR 0101）上：她本来每 1.5–2.5 小时就会安静地想一次，这次让她想的时候可以顺手去查。

1. `thinkNote()` 多一个可选输出行：「想查：关键词」（2–15 个字）。不想查就不写。
2. `parseThought()` 解析出 `wants`，`inner.ts` 只做格式校验（带链接、太长的不收）。
3. `proactive-planner.ts` 的 `think()`：有 `wants` 且注入了 `look` 就调一次，查到的事实存进
   `InnerState.learned`（最多留 `LEARNED_KEPT = 20` 条）。
4. `WebLookup.look(query)`（`web.ts`）：**不走触发词判断**，直接搜 + 摘录；额度、缓存、防注入、时间线
   全用 `line()` 那一套。没额度 / 没查成返回 `undefined`，她照实说不知道。
5. `learnedLine()` 把 12 小时内的最近 2 条放进聊天提示词，写明「是你自己好奇才查的，不是他让你查的，
   也不是你亲身经历的」——防止她把 Wikipedia 的内容说成自己去过。
6. 聊天提示词里那一行（`innerLine`）在主动找他时也带上了，她能主动说「我查了一下……」。

## 边界

- 不查他的事（`thinkNote` 里写明：他的事问他本人）。
- 一天还是 20 次上限，和「他说一句我查一句」共用同一份额度。
- 查到的只进这一轮的提示词和 `learned`，不写长期记忆；记不记得住由聊天本身决定。

## 后果

- 他不说话的时候，她也会因为好奇去查一件事，下次聊天时自然带出来。
- 代价：她和「他说的」共用额度，最坏情况下他让她查时会撞上「今天查得太多了」。
- 验证：`npm test`；`inner.test.ts`（解析「想查」）、`web.test.ts`（`look()` 不看触发词、没开不查）。
