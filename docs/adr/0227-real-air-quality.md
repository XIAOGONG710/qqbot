# ADR 0227：现实世界空气质量接入

状态：已实现，默认关闭（`realAirQuality: false`）。

## 决定

在已有真实天气之外，增加一个只读的 Open-Meteo 空气质量适配器，读取济南（在学校）和青岛西海岸（放假在家）的逐小时 `PM2.5`、`PM10` 和 `US AQI`。数据按地点落在 `<dataDir>/air-quality/`，缓存超过两小时只标记过期，不覆盖旧值；请求失败、不完整或字段超限时保留旧缓存，但不把数据写进当前世界。

世界只接受当前时刻之前已经观测的小时。预报小时没有 `o` 标记，不会成为“她已经经历过的空气”；没有足够覆盖或没有已观测小时时，`WorldNow` 不带空气质量，原来的世界投影完全不变。

## 边界

- 通过 `realAirQuality` 独立开关控制，控制台提供中文说明；
- 不上传 QQ 号、聊天内容、角色资料或设备信息，只发送固定地点坐标；
- 响应体限制 2 MiB、逐小时最多 14 天、数值范围和数组长度都校验；
- 缓存过期、断网和供应商异常都降级为空气质量缺失，不改变天气、作息、猫、快递、作业等既有事实；
- 状态页只展示供应商、新鲜度、小时数和最近错误，不展示请求正文。

## 为什么先做空气质量

它和天气一样是低风险、只读、可缓存的环境事实，能直接影响“今天出门 / 在宿舍”的自然说法，但不会自动创造生活事件或改变数值状态。后续接入节假日、交通或新闻时，沿用同样的开关、缓存、过期和失败降级边界。
