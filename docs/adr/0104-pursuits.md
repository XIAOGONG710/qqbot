## 为什么

她现在有的是**事**（摄影成长、课程作业、读书，从生活账里投影出来的进度），没有**她想做成什么**：没有一件事是她“为了它”会说“我弄完这张”、会因为它推进了一步开心、几天没碰有点愧疚、隔几周回头看一眼的。ADR 0103 的真模型里，“别修片了，陪我聊天，现在就陪”她一口答“来了来了，修图哪有你重要”（6 次里 5 次），手头的事对她没有分量。

## 约束

- **不替她编未来**。内置的只有自传 / persona 里写明的话；毕业以后做什么（persona：「毕业打算还没想好，被问就避」）、家里的期待这类悬着的问题**不是追求**，作者没定之前不碰。
- 进度**只来自她做过的事**（生活账里的摄影 `work_on_project`、出分的小测），不存一个会漂的数字（和 ADR 0045 / 0102 同一个办法）。
- 作者随时能暂停 / 放下 / 加自己的（`pursuits.json`），代码和模型都不往里写。

## 做了什么

1. **内置两条**（`pursuits.ts`）：
   - **别挂科**：自传「这学期没什么大目标，就想别挂科」，persona「数学类最怕」。开了 `everydayLife` 时，提示词里带“这学期到现在出了分的小测 N 次，平均 Y，最低 X（哪门）”。
   - **用新相机拍出自己满意的东西**：自传「用手机拍了两年，总觉得差点意思」「在攒钱买相机」，世界里 10-11 已经买到。买了之后分五步：熟悉新相机的设置 → 拍一组土豆 → 拍一组校园的秋天 → 挑十来张修好 → 挑最满意的几张发到空间里；第 k 步在她买了相机之后认真弄过第 2 / 5 / 9 / 13 / 16 回（生活账里的摄影 work_on_project，失败的、买之前的不算）时做完。相机没买就没有这条。
2. **进提示词的一小段**（时间块，男朋友档）：「你自己想做成的事（是你的追求，不是任务；不用主动提，话题碰到或他问起才带一句，带点真的感觉；事实以这里写的为准，没写的进展别编）：①别挂科——……；②用新相机拍出自己满意的东西——……现在在第 3 步（拍一组校园的秋天），做完的有：……；买了相机以后认真弄过 6 回，上一回是昨天」。内心（ADR 0101）想一想时也看得到，所以她的念头会想到它。
3. **进心境**（ADR 0102）：做完一步是开心（做完第五步更开心）；买了相机、有 7 天没碰，有一点愧疚（担心·小）。作者自己加的追求，作者标完成一步也是开心。
4. **先弄完这一小段**（`herNo` 开着，ADR 0103 的另一半）：她正在修片 / 拍照 / 研究相机设置时，他说“别修片了，陪我聊天，现在就陪”，她可以说先把手上这一小段弄完、给个大概的时间，不立刻放下也不冷；他认真说需要她、或她自己也想聊了就放下。
5. **作者的文件** `<数据目录>/pursuits.json` + 工具 `node packages/bot/src/ops/pursuit-cli.ts list | add | step | status`：内置两条可以暂停 / 放下 / 做完（按 id），作者另加的（标题、她为什么想要、最多 12 步，作者标步骤完成）。写坏了不挪走、不覆盖，记一行日志、沿用上一次。

## 没做 / 要注意

- **没有第三到第五条草稿**：毕业去向（3）和被期待替她定（4）是悬着的立场，现在只在内心的念头里偶尔冒出来；“做点专业里有意思的小东西”（5，自传里没有）我不加，作者要，用 `pursuit-cli.ts add`。
- 摄影的五步是我按“每步 1–3 周、总共五周左右”定的节奏（第 2 / 5 / 9 / 13 / 16 回），不是作者定的；要换改 `CAMERA_THRESHOLDS`。
- 买了相机的世界快照要有（`cameraFund.camera.state === 'bought'`）、生活账要有（`autonomousLife`），线上两样都有；模拟器里没有他转钱的动作就看不到这条。
- 她不会因此变得老提摄影：这一小段写明“不用主动提”，议程（ADR 0094）里的“相机”已经有“说过了就不再自己提”（ADR 0098）。
- 她不会 **改主意**：放下、改方向只能作者做（`status … dropped`）。要不要让她自己改主意、改了要不要过作者，还没定。
