## 为什么还差这一块

她现在有的是**事**（摄影成长、课程作业、读书，都是从生活账里投影出来的进度），没有**她想成为什么样 / 想做成什么**：没有一件事是她“为了它”会拒绝别的、会因为它开心或泄气、会隔几周回头看一眼的。ADR 0103 里“别修片了，陪我聊天，现在就陪”她会答“来了来了”，就是因为她手头那件事对她没有分量。

## 约束（先说在前面）

- **不替她编未来**。下面每一条都从自传 / persona 已经写明的话里提，标出处；没有出处的（第 5 条）单独标“最像我编的，需要批准”。
- 她“毕业打算还没想好，被问就避”是作者的话，**不被我替换成一个方向**。
- 追求不新增“发生过的事”（谁说了什么、考了多少分）；进展只来自她自己做过的事（生活账里的 `work_on_project` 事件）和作者写下的 `moments.json`。

## 如果你选了，机制大概是这样（也是草稿）

- 追求放在一个作者自己管的文件里（和 `moments.json` 一样，`runtime/bot/pursuits.json`，工具 `pursuit-cli.ts list | add | done | drop`），每条：名字、为什么（她的话）、阶段、状态。进展**从生活账里的事件投影**（`work_on_project` 的 `target`），不另存一个会漂的数字。
- 阶段做成了 → 心境里一条“开心 / 得意”的评估（ADR 0102）；一周多没碰 → 一条小的“有点愧疚 / 担心”；考砸 / 考好 → 你写的事。
- 她的空闲时段选择在原有的效用里给手上正在做的追求加一点权重（摄影已经有，推广到别的）；内心的念头可以想到“最近想做成的事”（一行）；ADR 0103 的“拒绝”多一个来由：**手头在弄她在意的事**（“等我弄完这张”），同样只在确实在弄的时候。
- 她可以**改主意、放下**（`drop`）——放下也是你批。

## 要你定的

1. 1–5 里选哪些？（我的建议：1、2 做，3、4 当立场，5 不做。）
2. 第 2 条：成品发去哪里？要不要给他看？
3. 第 3、4 条：有没有你想让她经历的大事（写进 `moments.json`），还是先空着？
4. 她能不能**改主意**（比如拍着拍着不想拍了）——要不要，改了要不要经过你。
