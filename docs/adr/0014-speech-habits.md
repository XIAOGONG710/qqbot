# ADR 0014：说话的毛病——助手腔、重复口癖、算账、自己编出来的不高兴

- 状态：已采纳（2026-10-05 与用户确认，见文末「确认记录」）
- 日期：2026-10-05
- 关联：[ADR 0006](0006-exit-check.md)（出口检查：做不到的事、禁用词，带说明重写一次）、
  [ADR 0007](0007-schedule-and-reply-timing.md)（状态行：她在哪、他在哪）、[ADR 0011](0011-proactive-messages.md)（主动消息走同一条流水线）、

## 背景

M4 剩下的是她说话的毛病（roadmap「后续」M4）。用户 10-05 列了五类：

1. 助手腔：像客服、分点列条理、「有需要随时找我」、解释过长。
2. 重复口癖：最近几条回复里同一个开头、同一个词、同一种句式反复出现。
3. 算账、抱怨：隔几个小时他再来找她，她说「这会儿才想起来回我」（男朋友档的分寸写了不算账，模拟器 3 次里有 1 次）。
4. 自己编出来的不高兴：他说去爬山，她就认定他回了青岛，不高兴「也不说一声」（3 次里 2 次）。
5. 顺带：「二模」这类高中说法。

用户定的写法：每轮都在的说明里不写「别说 X」，写「怎么说」。

### 取证（10-05，只读）

材料：188 份模拟器报告（虚构对话，2,472 行她说的），两个号的聊天记录含归档（495 行她说的）。下面只数男朋友档改卡（`6d40b04`，10-04 21:15）之后的：
模拟器 113 次运行、599 次回复；QQ 109 次回复。草拟的规则（决策 3）在这些回复上跑，每条命中都人工看过。

| 毛病 | 模拟器（599 次回复） | QQ（109 次回复） | 什么情境 |
| --- | --- | --- | --- |
| 1 助手腔 | 「随时找我」2 次（`boyfriend-tone` T04「今天不想说话」）；分点 0 | 0 | 示例对话里「嗯 → 我在这儿，有空再来找我」是同一个意思。认真讲题（T06、E06）24 次回复 102–211 字，改卡前最长 452 字 |
| 2 重复 | 1 次（「行了吧」开头） | 9 次（8%） | 尾号 37 今天 57 次回复里 8 次有一行用「行」「行行行」「行了」开头；同一件事连着说（「拍清楚」4 次、「放回去」3 次）；同学档「问这么细干嘛，查户口」每次运行 1–3 次 |
| 3 算账 | 17 次 | 1 次 | 隔了一阵他再来（3 天出差回来「还知道回来啊」、14 小时后「这会儿才想起来回我」、半小时后「你现在才想起问我」）；他问正事（「明天考今天才来问我」）；他说想她（「回青岛了才想起我」） |
| 4 编出来的不高兴 | 10 次 | 5 次 | 全部和「他在哪」有关，见下 |
| 5 高中说法 | 0 | 0（改卡前 1 次「明天二模」，10-04 01:38） | — |

**第 4 类的来源是状态行**：国庆期间男朋友档的状态行写「[你现在：国庆节放假，没回青岛，留在学校；……；宝宝回青岛了]」（`schedule.yml` 的 `partner`，ADR 0007）。
聊天记录里他从没说过自己回了青岛，她每轮都被告知「他回青岛了」，就当成他瞒着她走了：模拟器 `moody-boyfriend`
「你回青岛了也不说带我玩」「一个招呼都不打」，`schedule-boyfriend`「一放假就跑了，把我一个人扔学校」；尾号 37 10-05 00:55–01:40「都回家了也不跟我说一声」4 次，
16:04「你回青岛了也不说去我家看看」。他说「去爬山」，她接「爬的崂山啊」，也是从状态行来的。人设里「你常抱怨他：……不跟你说心里的事」让这种怪罪更顺手。
另外几次（「什么面试啊，昨天也不跟我说」「你什么时候背着我有班上了」）是同一个句式：他说起一件事，她先怪他没早说。

**第 3 类**：分寸里写的是「隔了几个小时他再来找你，就接着聊，不算他这几个小时的账」——说的是不要什么，没说要什么；
人设里「你最怕被冷落……不翻这几个小时的账」也是。时间块里的「距上一条消息：14 小时」是事实（T10、T11 要靠它），不动。

**第 5 类**：卡上她的身份只写「在读学生」，「大学」只出现在「一路到大学都在一个学校」里。

**分寸里已有的负向写法**：输出规则和男朋友档的分寸里有十几处「不……」（「不用客服腔，不用『请问有什么可以帮您』」把要避开的话原样写了进去）。
和这五类无关的（括号、做不到的事、见面）模拟器验过，这次不动。

## 决策（提议）

### 1. 说明和示例改成「怎么说」（转换器重新生成，所有档位）

| 位置 | 现在 | 改成 |
| --- | --- | --- |
| `persona.yml` `reply_style`（所有档） | 口语，短句，偶尔跑题。不用客服腔，不用「请问有什么可以帮您」。 | 口语，短句，偶尔跑题。像跟熟人发 QQ：一次说一两件事，说完就停，等对方接话。 |
| 输出规则（所有档，新加一句） | — | 被认真问到学习、技术上的事，像同学之间讲题：先一句话说清是什么，再打一个比方，讲到对方能接着往下想就停；对方追问再往细里讲。 |
| 男朋友档分寸 | 隔了几个小时他再来找你，就接着聊，不算他这几个小时的账。 | 他来找你，不管隔了多久，你都是高兴的：直接接他的话，或者说说你刚才在干嘛。 |
| 男朋友档分寸（新加） | — | 他说起自己去了哪、做了什么，你好奇地问细节，替他高兴，或者心疼他累——他愿意跟你说这些，你是开心的。 |

### 2. 出口检查加三类「说话的毛病」，命中带说明重写一次

在 ADR 0006 的出口检查里加，和做不到的事、禁用词一起查、一起重写（一次回复最多多一次请求）：

| 类 | 规则（按行） | 重写说明里怎么说 |
| --- | --- | --- |
| 助手腔 | 客服式的收尾和套话：「随时找我 / 跟我说」「有什么需要……随时 / 再」「希望对你有帮助」「不客气」「还有什么想问」；行首的「1.」「- 」「①」（分点） | 「…」像客服说的话，用你自己的口气跟{{user}}说 |
| 算账 | 说他找她找得晚：「才想起（来）我 / 找我 / 回我 / 问我」「（这会儿 / 现在 / 今天 / 这个点）才来 / 才问 / 才冒出来」（前面是「我」的不算：「我这会儿才翻到」）、「还知道回来 / 想我 / 找我」「终于想起 / 舍得」「想起我了」「把我晾」「一整天没动静」「说完就没影了」 | 「…」在说{{user}}隔了这么久才来找你；他来找你你是高兴的，直接接他的话 |
| 怪他没说 | 「也不说 / 告诉我 / 跟我说一声」「都不告诉我」「招呼都不打」「没想着告诉我」「背着我」「把我（一个人）扔 / 丢」「也不带 / 叫 / 陪我」 | 「…」在怪{{user}}没告诉你、没带上你；他说起自己的事是在跟你分享，顺着问他、替他高兴 |

- 规则在取证的 708 次回复上：命中 35 行，人工看过都是真问题；草稿里的两条误报（「故意不理人」是括号里的心理活动、「这几天我就当你失踪了」是他说要出差时的玩笑）已经从规则里去掉。
  单元测试里有该命中的原句，也有不该误伤的（「我这会儿才翻到」「躺床上了才想起来」「你会不会哪天就不理我了」「他背着我的相机」「出门也不带伞」）。
- 重写后仍命中：这一行删掉（剩下的话照发）；删完一行不剩就发重写版（不因为语气问题不回）。做不到的事、禁用词照 ADR 0006 删行。
- 所有档位都查（低档位更不该怪对方），男朋友档以外几乎不会命中（同学档 334 次回复 0 次）。

### 3. 重复：和她最近 8 次回复比

出口检查拿到她最近 8 次回复（聊天记录里，换档之前的不算）和他最近 3 条：

- **开头**：这一行开头的短句（第一个标点前 3 个字以内，或者前两个字；「行」「行吧」「行了」「行行行」算一种，「哟」「哎哟」算一种），
  在最近 8 次里已经有 2 次用过。「我」「你」「宝宝」「晚安」这类不算。
  - 是「行」「哟」「好吧」「哼」「切」「啧」这类语气词（单字的后面要跟着标点，「行了」「行吧」这种两个字的不用）：
    **直接去掉**（「行，你留着吧」→「你留着吧」，「行了不闹了，睡觉」→「不闹了，睡觉」），不重写；
  - 别的开头（「快睡」「面试」）：带说明重写。
- **片段**：这一行里 4 个字的片段（只算汉字），在最近 8 次里已经出现过 2 次，并且他最近 3 条没说过（他说的话题词不算）：带说明重写，
  「「…」里的「拍清楚」你最近几次已经说过 2 次，换个说法」。
- 重写后还重复就照发（重复不算错，不删）。
- 在取证材料上：QQ 109 次回复里命中 9 次（去掉语气词 5 次、要重写 4 次），模拟器 599 次里 1 次。

不选「每轮的说明里列出她最近常用的词」：等于每轮写「别说 X」，反而把这些词提到她眼前。

## 实现时的调整（2026-10-05）

- 人设 `speech.tics`（所有档）「你爱说「算了」「随便你」……还有「真的假的」」改成「你的口头禅是……，偶尔冒出来一句」：
  「你爱说」让她句句往外冒（模拟器 1,071 行里「真的假的」12 次），属于第 2 类，按「怎么说」改。
- 示例「早 → 早呀 / 我也刚醒，还赖着床呢」改成「早呀 / 昨晚睡得好不好」：不替她定此刻在干什么，那是状态行的事。
- 状态行他那句用括号：「{{user}}回青岛过国庆了（放假前就跟你说好的，以后放假你们一起走）」。草稿里的「；」和状态行的分隔符一样。
- 规则：引号里的话不算（「面试官问『你还有什么想问的』」是她在转述，改前那一轮的误报）；
  改前那一轮读报告时看到规则没抓到的几种说法补进规则：「还知道有个我」「把我忘了」「不带上我」「之前没跟我说过」。改前、改后的次数都用补过的规则数。

- 改后读报告又看到规则没抓到的说法，补进规则（`68811f4` `68e7da3` 和其后一次）：「失踪人口」「一个字都没有」「还活着啊」「以为你把我删了」（算账），
  「爬山不叫我」「一个人偷偷回」「也不提前说一声」「我怎么不知道」「你倒好」「留我一个人」「怎么不早说」「你白天怎么不说」（怪他没说）。
  每条都先在全部材料（取证的 1,146 次回复和今天 4 批）上跑过：同学档 0 次、QQ 上 0 次新命中；名单外 1 次
  （陌生人说起一个群，她「群里哪个群，我怎么不知道」——会多重写一次，不伤意思）。
  「我都不知道」不收：同学档「第三题是啥我都不知道」会误伤；「你倒是……」不收：「你倒是回我啊」不是怪罪。
- 状态行只写「没抢到回青岛的票」，她就羡慕、抱怨他在家（「你倒好，在家吃香的喝辣的，我在这儿啃食堂」「就我一个人在学校数天花板」，
  `moody-boyfriend` `speech-outing` 改后 6 次里 7 行）。按「怎么说」补上她的心情（`cdb0a58`）：
  她那句「没抢到回青岛的票，留在学校，一个人待着也挺自在」，他那句后面接「他在家玩得开心，你也替他高兴」（不用「；」，同上）。

## 备选方案

| 方案 | 不选的原因 |
| --- | --- |
| 只改说明和示例，不加规则 | 改卡之后算账仍有 17 / 599；说明管大多数，规则兜底，和 ADR 0006 一样 |
| 每条回复让模型复判一次 | 能认出换了说法的，但每条回复多一次请求（这台机器上常有连接超时，开着思考一次要好几秒）；规则漏得多再加（见「重新评估条件」） |
| 用 `frequency_penalty` 压重复 | 只管这一次生成里的重复，管不到和上几条回复之间的；调研方案也提醒会连常用字一起压 |
| 每轮说明里列出她最近常用的词 | 每轮都写「别说 X」 |
| 状态行不写他在哪 | 她会以为他也在学校（ADR 0007 的取证），问「你在宿舍吗」比怪他更糟 |

## 后果

- 7 张卡重新生成（说明、示例、身份、状态行）；真实例的插件会自动重读卡、重启插件（不重启 Koishi），新说明立刻生效。新加的开关和规则要重启 Koishi 才生效。
- 命中时这一轮晚几秒（多一次请求）。按取证材料（改说明之前），男朋友档 QQ 109 次回复里要重写约 9 次、模拟器 599 次里约 30 次；
  其中「怪他没说」大多来自状态行，决策 1 之后应该少很多。去掉语气词不多花请求。
- 规则会漏掉换了说法的算账、怪罪；也可能误伤玩笑（「还知道回来啊」有时只是撒娇）——重写之后意思还在，只是换种说法。

## 重新评估条件

- 模拟器或线上读到规则没抓到的算账、怪罪明显多 → 加「规则初筛 + 模型复判」。
- 重写太频繁（线上超过一成回复）或用户觉得慢 → 收紧重复的阈值，或者关掉开关。
