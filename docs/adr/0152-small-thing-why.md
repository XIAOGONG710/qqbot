# ADR 0152：小事主动讲的时候，先定下「为什么说」，不许编反转、不许说给他看没有的东西

- 状态：**已实现，未上线**（分支 `claude/human-videos`；改的是 `smallNews`（ADR 0127，线上已开）那一条主动消息的提示词，没有新开关）
- 日期：2026-10-25
- 关联：[ADR 0127](0127-small-news.md)（今天碰到的一件小事）、[ADR 0110](0110-cat-photo.md)（`LEAD_NOTE` 的由来）
- 用户提出：2026-10-25 19:55 她发了「陈佳宁发了张图来损我，我笑完才反应过来她骂的是我」，用户：「太假了，我不知道她为什么给我发这个，是想分享还是求我的安慰，看不懂她的意思」

## 证据

- 账上只有一句：`ed_jn_meme`「陈佳宁发来一张搞笑图，互损了几句」，事件自带的感觉是开心（`joy`）。提示词只说「你今天碰到一件小事：……想跟他说一句」，没说**为什么要说**。
- 模型自己编了一个反转（「被骂了才反应过来」）：账上写的是互相损，不是被骂；那句话是什么、图上是什么都没有。读起来像吐槽 / 求安慰，而设计上它是随口分享。没有图、没有那句话，他也接不上。
- 线上到现在只有两条这样的主动消息（10-23「室友分了点零食，还挺好吃」、10-25 这条），他都没回。
- 探针（同一件事、旧提示词 vs 新提示词，各抽 12 次，真模型，只放角色卡）：说「给你看看 / 转给你 / 发你」（她手上没有图）3/12 → 0/12（笑图）、2/12 → 0/12（笔记）；编反转 / 编细节 1/12 → 0/12。样本小，旧提示词也只在少数抽签里出反转，所以这条线上的消息只是分布里的一个点。

## 决策

1. `WorldNews` 带上事件自己的感觉（`feel`，来自 `EVERYDAY_EVENT_DEFS`），一路带到主动消息的候选里。
2. `small_thing` 的说明按感觉加一句「为什么说」（`SMALL_PURPOSE`）：开心 → 想把这份开心分给他、让他也乐一下，是分享，不是吐槽、更不是求安慰；烦 → 随口吐槽两句、想让他附和一句，不是真的难过；松了口气 / 累 / 担心 / 难过各有一句。账上没写感觉的不硬加。
3. 加一句不许编（`SMALL_NO_TWIST`）：事实只用账上那一句，对方具体说了什么、图上是什么、后来怎么样没写就不编，不编「原来 / 没想到 / 才反应过来」这类反转或笑点；她手上没有那张图、那句话，不说「给你看看 / 转给你 / 发你 / 你也看看」。

## 没做

- 「搞笑图」这类事件真正的解法是让她发出一张真的图（表情包库里选一张），分享才完整。这一步会动发图的链路，没做。
- 一件小事 + 一句感觉能撑起多少话是有限的：账上只有一句时她只能说「发生了 + 我的感觉」。要更像真人得有更具体的事（账里写细一点），那是内容问题。
