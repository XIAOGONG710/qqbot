## 差距

约他一起玩（ADR 0107）被答应之后，她回一句“来了来了”，下一条起又是平时的她：回话照常长、照常聊自己的事，玩到一半还可能冒出“你人呢”。真人在一起打游戏时回得短、聊的是局里的事，两个人都在游戏里的沉默不是冷场。

## 做了什么

1. **`together.ts` 的 `togetherNow(history, now)`**（纯函数，每一轮从聊天记录往回推，不落盘）：
   - 她邀、他应了：她的邀约（`HER_INVITE`：开黑 / 双排 / 王者 / 我的世界 + 问句，或“来不来 / 上不上”）→ 他 30 分钟内的第一句是答应（开头来 / 好 / 行 / 可以 / 走 / 上 / 没问题，前面没有“不行 / 没空 / 改天……”）；
   - 他邀、她应了：他的邀约 → 她 10 分钟内的第一句开头是来 / 好 / 行 / 可以 / 走 / 上 / 没问题 / 等我 / 马上，且前 14 个字里没有推掉的话；
   - 窗口：从答应的那一刻起 `TOGETHER_MAX_MS`（2.5 小时）；答应之后任何一方说了“下了 / 下线 / 不玩了 / 不打了 / 睡了 / 晚安 / 散了 / 先下 / 打完了 / 我去忙 / 去睡”就结束；
   - 玩的是什么：邀约里的字眼（我的世界 / 王者 / 别的游戏）。
2. **时间块多一行**（`contact.ts`，`describeTogether`）：「你这会儿正和他一起打王者（已经玩了约 N 分钟）：手上在玩，回话短一点、慢一点，聊的是眼前这局 / 你在存档里弄的东西，别说你在忙别的、别另起话题、别写长段；游戏里的具体情形随口说，但别编你们以前没一起经历过的事」。只对男朋友档；危机回合、主动找他的那条不加。
3. **这段时间不插别的主动消息**（`blockReason`，`together`）：窗口里“你人呢”之类的冷场 / 随口说件事 / 下课等一律不发（原因写明“正和他一起玩”）。**不拦**重要的日子（生日祝福）和睡前（玩到很晚她也会说“我要睡了”；聊着的时候有 20 分钟的老规矩挡着）。

## 没做 / 要注意

- 不改她的“生活账”：她在行动账里不会变成“在打游戏”；这是聊天层的状态。
- 游戏里的“局势、队友”是随口编的聊天内容，不是事实，也不进长期记忆的“事实”（和平时聊天一样）。
- 判断全靠关键词，漏判时退回平时的她（不坏）。

## 验证

- `together.test.ts`（7 个）：她邀他应 / 他邀她应 / 没应 / 拒绝 / 隔太久才回 / 她没约；结束词；活动；时间块一行；窗口里不插别的主动，重要的日子和睡前不受限。
- 模拟（真模型，`sim/together.json`，4 次）：全部通过——他说“这把队友太菜了 / 我又被抓了你在哪 / 赢了赢了”，她回「你也没好到哪去好吧」「我在下路清线呢，你别一个人乱冲」「赢了赢了，这把稳」，每条 ≤ 40 字，不提作业 / 相机 / 土豆；他说“我下了，晚安”她回晚安。
