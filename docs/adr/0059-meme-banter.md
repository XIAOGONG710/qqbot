# ADR 0059：先认出“他在玩”，再顺着接梗

- 状态：已实现；真模型回归通过
- 日期：2026-10-11
- 关联：[ADR 0019](0019-turn-intent.md)、[ADR 0036](0036-conversation-naturalness.md)、[ADR 0058](0058-intimate-reciprocity.md)

## 问题

10-10 真人聊天里出现了三类断点：`zdjd` 被理解成别的意思；“老师真是死冯了”里用姓氏替换“疯”的谐音被略过；“我先睡为敬”“并非早”只按字面处理。她的卡只写“离谱的话可以回问号”，没有告诉模型先判断对方是不是故意说得怪，也没有给缩写理解线索。普通问句意图还可能把带问号的梗压成认真回答。

单纯塞一张很长的热词表会快速过时，也会让她每句话堆梗，像运营号而不是真人。

## 决策

1. 只在男朋友档启用 `playful`：识别一小组稳定的首字母缩写、明显的网络说法、短句式怪话和带“老师”的人名谐音。人名谐音除“死冯了”外，也识别“史老师……气史了”这种前后复用同一个姓的结构；普通英文、真实事故和正式长句不触发。
2. 玩梗意图排在普通问句和收尾之前：先按最近上下文理解笑点，顺着同一种逻辑接一句，再接他真正说的事；不纠正字面，不解释百科，不报出处。对替换固定说法中一个词的怪话，回复保留被拧过的关键词或句式，不能退回只按字面劝吃、睡或做事。真要睡时接完梗照常收尾。
3. 对五个常见且稳定的缩写给当轮理解线索（`zdjd / xswl / nsdd / u1s1 / srds`），只供理解，不让模型复述对照表。其他梗接不准就自然问，不编意思和出处。
4. 男朋友卡补风格边界：可以偶尔用夸张、反差、故意一本正经或谐音回敬，但一次一个点，不堆热词；补 `zdjd`、人名谐音和“为敬”三个一行示例。
5. 不做自动联网搜梗：每条消息外发检索会增加延迟和隐私面，也可能把普通私聊原文交给搜索服务。后续若要扩词，更新本地小表并用真实聊天回归。

## 验证

- 单元测试覆盖稳定缩写、`u1s1` 问句、短句“并非”、为敬、“老师 + 死冯了”和“史老师 + 气史了”；它们优先进入接梗意图，普通的“史老师气坏了”不误触。
- 非男朋友档不加强；`cos`、`mua`、猫死掉、正式的“这并非事实”不误触。
- 新增 `boyfriend-banter.json`：用卡里没有出现过的 `xswl`、另一组人名谐音和“我先吃为敬”检查泛化；未知梗允许短问，不允许编百科解释。
- 2026-10-11 真模型批次 `generalization-v4` 中，所有非空回复的接梗检查都通过，但 11 次生成里有 4 次空正文，其中一次连续两次为空；回复器因此把空正文的当场重试从 1 次提高到 2 次，三次都空才进入原有的分钟级延迟重试。
- 修正后批次 `generalization-v5` 以 `--no-memory --parallel 1` 跑两次：两次均为 16/16，合计 8 个轮次全部产生正文，0 次出口重写、0 次清理后为空。`xswl`、换姓谐音和“我先吃为敬”都能沿原逻辑接话；未知“山楂树”只短问或原样回敬，没有编百科出处。
