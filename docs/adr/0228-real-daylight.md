# ADR 0228：现实世界日照接入

状态：已实现，默认关闭（`realDaylight: false`）。

## 决定

在天气和空气质量之外，增加一个只读的 Open-Meteo 日照适配器，读取济南（在学校）和青岛西海岸（放假在家）的逐日 `sunrise`、`sunset`。世界按当前时刻投影成「夜间 / 清晨 / 白天 / 傍晚」，让环境描述能和真实光线对上。

数据按地点落在 `<dataDir>/daylight/`，缓存超过 24 小时只标记过期；请求失败、不完整或字段超限时保留旧缓存，但不把过期数据写进当前世界。

## 边界

- 通过 `realDaylight` 独立开关控制，控制台提供中文说明；
- 不上传 QQ 号、聊天内容、角色资料或设备信息，只发送固定地点坐标；
- 响应体限制 1 MiB、逐日最多 31 天，并校验日期、时间和日出早于日落；
- 缓存过期、断网和供应商异常都降级为缺少日照事实，不改变天气、空气质量、作息、猫、快递、作业等既有事实；
- 状态页只展示供应商、新鲜度、日期覆盖和最近错误，不展示请求正文。

## 为什么先做日照

它是低风险、只读、稳定的环境事实，可以让她在清晨、傍晚和夜间的说法更连贯；同时不自动改变生活事件，后续接入交通、新闻等波动数据时仍沿用同一套开关、缓存、过期和失败降级边界。
