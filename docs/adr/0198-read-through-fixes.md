# ADR 0198：通读一个晚上的聊天，修两个"一眼像 AI"的毛病（质感的"先嗯一声"、他低落的延续）

- 状态：**已实现，不是新开关**——都是对已上线功能的修正：质感（ADR 0131，`texture`）、意图（ADR 0019 的 `needsCare`），随各自的开关生效；DSH 机器要拉取后重启 Koishi
- 日期：2026-10-30
- 关联：[ADR 0131](0131-texture.md)（说话的质感）、[ADR 0019](0019-today-layer.md)（这一轮你想）、[ADR 0099](0099-too-smooth.md)（情绪轮、不马上让步）、[ADR 0095](0095-filler-turns.md)（废话轮次）、[ADR 0091](0091-reply-shape.md)
- **用户决定（2026-10-30）**：「继续做吧，尽量让她更像人」。

## 做法：先看，再改

度量说她已经很接近了：线上近 4 天每条中位 8 字（真人 7）、语气词 23%（真人 18.5%）、没有重复套话、同一个开头的气泡只占 2%。度量看不出的毛病要靠读。所以我写了一个 41 句、自然起伏的晚上（日常、逗、约周末、撒娇、他心情不好、半夜哄睡；`research/2026-10-30-readthrough/read-through.json`），按线上当时开着的开关（`shape`、`shapeAgenda`、`shapeFiller`、`shapeFeel`、`shapeSplit`、`herFeelings`、`herNo`、`everydayLife`、`pursuits`、`texture`、`curious`、`rhythm`、`shortReplies`、`grievance`……加 `--ask --long --deliberate`）用真模型跑一遍完整管线，**自己把整段读一遍**。第一遍读到五处：

1. **开头冒一个没来由的"好""嗯嗯"**（41 轮里 5 次）：他问"吃的啥啊"，她先回一个"好"，再答"食堂炒饭"；"谢谢你听我说"→"好"。
2. 答非所问："你怎么不理我了"→"刚才回宿舍了，桌上放了碗炒饭，不好吃"（还和前一句矛盾）。
3. 原样重复：他先后两句话她都回"行，几点？"。
4. **他低落的时候她在质疑他**：他说"我今天心情不好，被领导骂了"，接着"他当着全组的面说我方案是垃圾""我真的有点想辞职""你说我是不是太没用了"，她回"诶，被骂几句就想到辞职了？""不是，被骂一顿就给自己下这种结论啊"。
5. 角色弄反：他让她明早叫他起床，她最后说"明天记得叫我"（两次）。

## 修了两个（有根因、可复现）

**1. 质感层的"先回一个反应"**（`texture.ts`）。日志里这四次"好 / 嗯嗯"都是 `质感：先回一个反应：…`——不是模型写的，是代码在她的第一条前面加的。规则是"他陈述了件事（不是问句）、她第一条比较长，10% 的概率先嗯一声"，而"是不是问句"的判法只认 `？ 吗 呢 吧 么 什么 怎么 为什么`。在 72 句真人对话里，旧判法当成"陈述"的 47 句里有 **9 句其实是在问**（"我在我在老婆干嘛呀""哪个男的教你的""是不是打算再买几个"……），还有"爱你""我也想你呀"这类示爱。现在：
- 他是在问的（问号、语气词、`啥 / 哪 / 谁 / 几 / 多少 / 是不是 / 有没有 / 嘛……`、句尾的 `没 / 不`）不先应一声；
- 道谢、道歉、示爱、问候、道别（`谢 / 对不起 / 爱你 / 想你 / 晚安 / 辛苦……`）不先应一声；
- 陈述只接"嗯嗯 / 嗯"（原来还有"好 / 对"，"我今天累死了"→"对"是错的）；他提了件要一起做的事（`我们 / 一起 / 周末 / 明天 / 约……`）才接"好 / 行"。

**2. 他的低落往后接着算**（`intent.ts` 的 `distressCarried` + 多认几类难受）。原来"他在难受"是**逐句判断**的（`needsCareText(这一串)`），没有延续：他说"被领导骂了"那一句认得出（`被骂`），后面的"想辞职""是不是太没用了"每句单看都不在识别词里，系统就把这几轮当成"轻松的轮次"，还抽到了"只回一个短句"的废话轮次（日志里那一轮的提示词有"只回很短的一句，一两个字也行"）。现在：
- `distressCarried`：往回看他最近 8 条（30 分钟内），有一条在难受、之后他没说缓过来 / 笑了（`好点了 / 没事了 / 想开了 / 哈哈……`），这一轮就还算在难受里——意图行还是"先接住他此刻的情绪"，其它依赖 `needsCare` 的意图（吃醋、她那边的新鲜事、讲她今天一天）也跟着让路；"先接住"又会让形状控制把这一轮当"认真接话"，废话轮次、情绪轮、不马上让步、带自己的事都不抽。
- `needsCareText` 多认几类：`心情不好 / 不开心 / 低落 / 失眠 / 睡不着 / 想哭`、被人说得很难听（`说我方案是垃圾`）、`想辞职 / 不想干了 / 被炒`、觉得自己没用（`我是不是太没用了`；`没用过 / 没用到` 是在说东西不算）、`考砸 / 挂科 / 压力大 / 扛不住`。

**修之后同一段再跑一遍**：他低落那一段变成"被骂了啊，怎么了说说""这人也太过分了，当着全组的面说这种话""怎么会啊，一个方案被说成这样，谁被当面那么骂都会难受，跟你有用没用没关系""怎么了嘛，受委屈了就别自己憋着"；"谢谢你听我说"→"跟我客气啥"；开头的"好"没有了，质感日志里只剩他在笑时的"笑死"。两份对话都在 `research/2026-10-30-readthrough/`。

## 看到但没修（要说清楚）

- 第 2、3、5 条（答非所问、"行，几点？"重复、叫起床的角色弄反）**第二遍没有再出现**——是随机的模型失误，不是系统性的；没有根因就不乱改。第 3 条原样重复一个 5 字的短句：现有的原样重复检查（`verbatim`）只管 ≥6 字，没有为这一次改。
- 只跑了两遍同一个场景（每遍 41 轮），第二遍读起来好得多，一部分是随机；**确定的是两处机制修了**（单元测试 + 日志里的 `质感` / 意图行），不是"整体变好了多少"的数字。要量化得用 72 句真人对话 + 标注员那一套（ADR 0099），这次没做。
- 场景是我写的（他在讲老板和方案，而卡里他是学生），他的话是脚本；不是真聊天。
