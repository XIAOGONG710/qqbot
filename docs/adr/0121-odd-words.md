# ADR 0121：医书词和小说腔——「肚子坠着」这类真人不这么说的词

- 状态：**已实现，未上线**（2026-10-23；没有配置开关，纯措辞）。上线 = 落地代码 + 重启；回滚 = `git reset --hard` 回上一版
- 日期：2026-10-23
- 关联：[ADR 0097](0097-ai-smell-night-test.md)（说话的毛病）、[ADR 0098](0098-already-told-and-topic-pick.md)、[ADR 0118](0118-weekly-report.md)
- 用户提出：2026-10-23「她最近老是说肚子坠着，这不是正常人的语言说话方式」「为什么会出现这个情况？」「其他回复好像也有这种情况，检查一下」

## 为什么会这样（原因）

线上 10-20 到 10-22 三天里她说了 4 次「肚子有点坠 / 肚子还坠着 / 肚子坠得难受」。**这个字不在任何地方**：角色卡、事实行、提示词里都没有“坠”。事实行写的是「生理期第 1 天，肚子疼得厉害」「肚子隐隐地疼」，卡里只有「你有痛经」。是模型自己从“痛经”联想到网上医书和健康论坛里最常见的写法“下坠感 / 小腹坠胀”，当成口语说了出来；这两天的提示词每次都一样，所以每次联想到同一个词。

**我当时看错了**：10-22 深夜测试里看到她三个晚上都在说，把它当成“同一件事反复提”，做了 ADR 0098（一天半里不再自己重提）；没人检查这个词本身像不像人话。原有的检查也管不到：“最近反复说的字词”只看最近 8 条，禁用词表里没有这类词。

## 检查了什么（「其他回复好像也有」）

对线上她的全部 677 条（637 条够长的）：
1. **词表**：书面 / 医书 / 文艺 / 助手腔的词在她的话里占 0–0.7%，和他自己差不多；只有“坠”（4 条）和“发紧”（1 条）。
2. **只有她说、他一次没说过的 3–4 字组合**（≥3 条）：几乎全是话题词（作业写完、半包饼干），也有“大半夜 ×7、想得美 ×6”这样偏口头禅的，没有书面词。
3. **身体 / 感觉的说法**（肚子、脑子、眼睛、心里……开头的片段，共 55 种）：“坠”是唯一反复出现的怪说法；“心口发紧”1 次偏书面。
4. **让模型逐批读 637 条标“真人不这么说”的**：只标出 4 个、各 1 次——「json」（她把消息叫 json）、「笔都没落下去」、「听得我嘴角上扬」、「白送你还万岁」。**它没把“肚子坠着”标出来**，所以这个审计是弱裁判，不能拿来证明“没有别的问题”。
5. **通读最近两天 46 条较长的话**：除了“坠”，另有 10-22 凌晨被他追问时的“是真心话，不是设定”“我要是没这功能”这类自称设定 / 功能的话——那是 ADR 0097 的 CHALLENGE 意图上线（02:13）之前的。

结论：线上规模上**“坠”几乎是孤例**，其余是偶发的小说腔（嘴角上扬、笔都没落下去、心口发紧）。你觉得还有的话，请指给我几句原话，我加进来。

## 做了什么

1. **身体那一行教大白话**（`body.ts`）：疼的那两天多一句「（说的时候用大白话：肚子疼、小腹酸、一抽一抽地疼、疼得没劲；别用“坠着”“下坠”“坠胀”这种医书里的词）」。
2. **出口检查把这些词当禁用词**（`expression.ts` 的 `ODD_BODY_WORDS`，`contact.ts` 并进 `banned`）：出了就让她重写一遍。两类——
   - 医书词：坠着、坠得、坠胀、坠痛、下坠、肚子坠、小腹坠、腹坠、点坠（有点坠）、些坠；
   - 小说腔的动作神态：嘴角上扬 / 微扬 / 扬起、眼眶发热 / 一热 / 泛红、心口发紧、心头一暖 / 一软 / 一紧、心里一暖、笔都没落。
   组合词才算，不碰“坠入爱河”“摇摇欲坠”“笑得嘴角都压不住”。
3. **周报多一节“她的口头禅”**（ADR 0118）：她说了 ≥3 次、他一次没说过的 3–4 字组合（前 15）；只有她的话。每周扫一眼有没有新的怪说法冒头。

## 数据

- 模拟（真模型，`sim/odd-words.json`：12-21 生理期第 1 天，他连问肚子还疼吗 / 今天怎么样 / 吃药没 / 早点睡，8 次）：**41 条回复里“坠”0 次**；她说「还疼……一抽一抽的」「疼得没劲」「懒得动」「躺着呢」。

## 没做 / 要注意

- 禁用词表是治标的：新的怪词（模型下次联想出别的）要靠周报的口头禅一节和你指给我才能发现。
- 没有改角色卡（卡里“你有痛经”不动）。

## 验证

`odd-words.test.ts`（4 个）：线上 4 种说法 + 其他“坠”的说法都抓得住、大白话和别的“坠”不误伤、教大白话那句写明哪几个词；小说腔的几句抓得住、平常说法不误伤。`body.test.ts` 多一条：疼的那两天有这句、不疼的日子没有。
