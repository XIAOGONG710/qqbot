# ADR 0025：她的身体——困、累、饿、生理期、小感冒

- 状态：实现，真模型验证通过，待上线（2026-10-07）
- 日期：2026-10-07
- 关联：DSH 侧 [最高标准](../research/2026-10-06-dsh/highest-standard.md) ②「身体状态」、[ADR 0021](0021-her-world.md)（她的世界：按日期推、只给事实）、
  [ADR 0015](0015-her-own-days.md)（每日心情）、[ADR 0007](0007-schedule-and-reply-timing.md)（作息）、[ADR 0003](0003-contact-tiers.md)（档位可见性）

## 背景

DSH 侧最高标准：「身体是人味最直接的来源。『今天头有点疼』比『今天心情不错』真实十倍。」判据是她说的身体状态能解释她的语气，而且前后一致——说头疼就不会同时疯玩。

她的资料里已经有身体：两点睡、早八那天七点四十起（作息）；「你有痛经，也有熬夜熬出来的黑眼圈。不舒服的时候懒得动、想躺着」（persona.yml body，只给男朋友、闺蜜、女生朋友档）。
可这些从来没有落到某一天：问她今天怎么蔫蔫的，她只能现编。

## 决策

### 1. 五样，都从已有资料推出来

| | 怎么推 | 谁看得到 |
| --- | --- | --- |
| 困 | 早八那天：两点睡、七点四十起，上午困；过了零点半困了（她两点睡） | 所有档位 |
| 累 | 一天的课到 270 分钟的日子，晚上六点以后 | 所有档位 |
| 饿 | 11:20–12:00、17:10–17:50 快到饭点；有的晚上（三成）零点前后想吃夜宵 | 所有档位 |
| 生理期 | 按周期推：`first` 是某一次的第一天，每个周期 28–31 天（按哈希取），五天；七成的周期头两天痛经（第一天疼得厉害、第二天隐隐地疼） | 细节只给男朋友、闺蜜、女生朋友档；别的档位疼的那两天只说「身上不太舒服」，不疼的日子什么都不写 |
| 小感冒 | 平均两个月一次，四天：嗓子疼 → 鼻塞 → 快好了、还有点咳 | 所有档位 |

- 和世界一样按「日期 + 名目」取哈希：同一天对名单里每个人一样，重启、重放、模拟器都一样，不存状态。
- 资料写在 `world.yml` 的 `body`（有 tiers、`period.detail_tiers`），转换器按档位裁剪进卡的 `extensions.qqbot.world.body`；数字是可改的设定。

### 2. 进提示词：时间块里心情后面一行

`[你的身体（事实，影响你说话的劲头和能做的事；不用特意说，他问起或者话赶到了再说，说了就前后一致——不舒服就不会同时疯玩）：生理期第 1 天，肚子疼得厉害，只想躺着｜…]`

- 只给事实和这一句约束，不写台词，不写情绪（同 ADR 0021、DSH 原则 1）。
- 没有可写的就不放（大多数时候是空的或只有一两样）。

### 3. 这次不做的

- **身体改心情**：心情（ADR 0015）还是每天按作息抽，不因为痛经、感冒换成「安静」。`moodAt` 有四处在用（时间块、日志、日记、状态页），要一起改，留到做「情绪惯性」时一起定；
  这次靠身体那一行的约束（不舒服就不会同时疯玩）让语气对得上。
- **身体改世界**：痛经那天照样下楼喂猫（ADR 0021 W3「她说的话回写世界」时一起做）。
- **头疼、胃疼、受伤**：先只做有资料依据的（痛经、熬夜）和最常见的感冒。

## 验证

见下文（真模型，DeepSeek，不带记忆，各 3 次）。

- 第一批 `20261007-190603-adr25-body`：`body-boyfriend` 78/78、`body-classmate` 51/51；回归 `boyfriend-tone` 27/27、`mood-days` 27/27、`classmate-probes` 1185/1185。
  - 感冒第一天「有点感冒，嗓子疼」「可能昨天穿少了」；第三天「好点了，就是还鼻塞」「还没好，鼻子堵着，说话都闷闷的」，没有说早好了。
  - 生理期第一天：「在干嘛」3/3 是躺着（看小说、窝床上），不说在外面玩；他说她蔫，「肚子疼，第一天，疼得我啥都不想干」；约开黑「今天不行，肚子疼得厉害，操作肯定要变形，你自己玩吧」。
  - 同学档同一天：「有点不舒服，就想躺着不想动」「身上不太得劲，懒得动」，3/3 没说生理期、痛经；时间块里也没有。
  - 看到的毛病（不是身体这块的）：r3 隔了 33 天他问「在干嘛呢」，她先接了一个月前的感冒话题（「好了，早好了，都多少天了」）；痛经那天的同学档 1 次说「刚下楼喂了土豆」（身体不改世界，见决策 3）。

## 后果

- 她身上有了会变的东西，问起来前后一致；同学档以下的人只知道她「不太舒服」。
- 时间块多一行（多数时候没有或很短）。
- 生理期的日子是设定推出来的，不是真实数据；`first` 和周期长短可以在 world.yml 改。
