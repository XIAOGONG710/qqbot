# ADR 0235：控制台用六个能力包解释底层功能

- 状态：已实现，纯展示层；不增加总开关
- 日期：2026-11-04
- 关联：[ADR 0120](0120-status-dashboard.md)、[ADR 0234](0234-life-pulse-card.md)

## 背景

控制台能够逐项展示全部功能开关，但一百余项技术能力不适合作为首屏导航。类似陪伴产品常用“插件”描述功能，容易理解；本项目不能因此把不同风险等级的开关真的绑在一起，否则开启一个体验包可能同时放开外部发布或设备权限。

## 决策

1. 首屏增加六个只读能力包：对话与关系、自主生活、图片与语音、社交空间、记忆与边界、外部能力。
2. 能力包从现有功能总表按模块实时投影，展示正在使用的功能数量和最多四项自然语言摘要。
3. 能力包没有开关、配置键或写入接口；完整技术开关继续在折叠区逐项展示和控制。
4. 顶部总览从“已开多少技术开关”改成“六个能力包中有几个正在使用”，减少工程数字对普通用户的干扰。
5. 设备控制、QQ账号控制、外部发布等高风险能力仍使用自己的白名单、确认、审计和熔断，不能被能力包绕过。

## 验证

- 纯函数测试保证六个能力包顺序稳定、关闭项不进入摘要、每包最多展示四项。
- 总览统计和完整功能开关测试继续运行；新增配置开关漏登记时仍会失败。
- 控制台脚本通过语法检查，并保留窄屏两列、手机单列布局。
