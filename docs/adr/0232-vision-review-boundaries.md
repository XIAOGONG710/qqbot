# 0232：视觉输入、截止与照片事实边界

日期：2026-11-05

## 证据与范围

视觉模块五文件及直接调用链采用四路并行审查，只使用合成图片、语音、响应和供应商。确认下载/DNS/正文不合作时超时只发取消但调用不结束、照片索引坏读/写失败造成事实丢失、已知照片编号可绕当前类别/菜名权限，以及多个服务返回和取消边界缺陷。

本决策记录首批修复，不将视觉模块标为审完。两个独立进程在版本比较之后、原子 rename 之前同时停住再释放，两次 add 均返回成功，磁盘只剩一条记录。乐观版本检查只能阻止已经完成的陈旧写，不能代替跨进程原子读改写协议；后续须单独处理锁、崩溃恢复和活实例/CLI 协调，不盲用有残锁或清理竞态的方案。

后续 V06 协调协议见 [ADR0233](0233-photo-index-process-coordination.md)：SQLite 仅持操作系统锁，JSON 保持事实源；本段保留首批未完成时的证据，不再代表最新状态。

## 决定

- 下载使用覆盖排队、DNS、fetch、重定向与正文的单一截止；每个异步阶段独立响应取消，失控取消承诺也不能占住下载门。所有出口释放 reader，晚响应取消正文。默认 DNS 建连仍再次校验，不将未知/私有地址交给网络层。
- 对下载限额和超时严格校验；base64 在分配 Buffer 前检查解码大小，保持声明类型与签名一致。补齐 IANA 非全球 IPv6 区段；2001::/23 按更具体分配保留明确的全球可达例外，不能整段误封。
- 照片索引整体严格验证，坏文件保留原字节并明确失败，缺 seen 的有效 v1 索引兼容。只引用安全的内容哈希文件名，发送时要求真实普通文件且大小受限。磁盘成功后才发布内存，入库和 seen 同次提交，公开条目使用副本；落盘失败可留下未入索引的图片孤儿，下次按 hash 恢复，不发孤儿文件。
- 类别目标在 await 后提交前重查；配额按实际时间而非数组末项，排除未来记录。联系人清理照片指令时传当前 kind/dish；食物只准当前菜，保留旧 bool 调用接口兼容。照片元数据可用于已发送历史，不依赖缓存仍存在；猫的系列身份也来自已登记元数据，缓存丢失不能换成另一只猫。
- 照片关闭也剥内部控制语法，未知/畸形/未闭合指令不作为普通文字发出。清理后缓存失效必须明确失败，不能以 raw token 发文字再伪记照片历史。图片传输返回成功 ID 后，使用次数副索引失败只安全计日志，仍由聊天历史记录真实发送；不因副索引失败重复发图。
- 远程来源只接受有效结构、有限正整数尺寸和字符串元数据；精确白名单词表读取，非法 offset/timeout 失败。Commons 请求有独立截止和 2 MiB 原生流上限；错误不回显响应正文，已知暂时错误保留可重试类别。来源页与完整作者可追溯，保持 ADR0109/0128 已定的许可筛选政策。
- 媒体截止在调用工作前监听取消，提前/同步取消都能结束，完成时移除监听；语音/OCR 排队同样计时。不将未知类型转成转写/描述事实，也不将服务原文放入日志。本地语音仅为元数据读取，限定普通文件与 2 MiB、分块有界读并关闭句柄；超额只省略秒数，不影响转写。AMR-NB 保留帧不计入时长，合法 NO_DATA 保持。
- 看图单次 describe 的总截止覆盖下载、两个门、重试及正文；guard 的实际 work 也结束，才能释放模型槽并正确熔断。调用者取消保留原 reason。HTTP 失败直接按状态处理，不先读可能挂起的正文；原生响应流限 1 MiB，旧 text-only 测试接口仅能在返回后验大小。模型始终只接收经本地检查的 data URL，没有原 URL 回退。
- 在字节限额内也要避免解析放大：Commons HTML 清理改前进扫描，媒体截断仅迭代所需代码点。分别用超时子进程与 64 MiB 受限堆复现了旧版 CPU/内存问题，正常文字及旧 HTML 处理语义保持。

## 验证与边界

每组使用合成反例、故障注入与正确行为回归；修复后复核直接联系人、名单内外分流、app 停止、照片历史与配额链。真实 QQ、供应商和私密图未调用；默认构建只做字节/签名处理，没有本地像素解码器，不宣称校验了像素内容、动画帧或完整图像有效性。供应商/OS 不合作的底层工作无法硬停，但调用、并发槽及迟到资源有明确清理。

出处分类依据 [IANA IPv6 特殊用途表](https://www.iana.org/assignments/iana-ipv6-special-registry)、[RFC8215](https://www.rfc-editor.org/rfc/rfc8215.html) 与 [RFC3879](https://www.rfc-editor.org/rfc/rfc3879.html)；AMR 帧依据 [RFC4867](https://www.rfc-editor.org/rfc/rfc4867.html)。完整发现、验证结果、提交与未完成工作见持续进度及视觉审查报告。
