# ADR 0236：私有生活片段在 Koishi 与 DSH 之间共用

- 状态：已实现；只读、不发布
- 日期：2026-11-04
- 关联：[ADR 0177](0177-same-her-recent-turns.md)、[ADR 0225](0225-dsh-state-snapshot.md)、[ADR 0234](0234-life-pulse-card.md)

## 背景

类似陪伴项目常用朋友圈或动态强化角色存在感。真实平台发布会引入账号、隐私和风控风险，而项目已经有可回放的世界账；更合适的第一步是把已经发生的事实做成私有生活片段，并让QQ侧控制台和DSH桌面读取同一来源。

## 决策

1. 继续使用 `worldHighlights()`，只投影喂猫、用餐、取快递、完成作业和已经发生的世界事件；未来计划和没有时间依据的状态不进入。
2. Koishi“她此刻的生活”卡片显示最新一条，存在多条时可展开“今天的生活片段”，带本地时间。
3. QQ写入 `NOW.md` 时同步写入相同的近期片段；DSH沿用现有新鲜度检查读取，不新建第二套动态数据库。
4. 片段不含聊天原文、QQ号、账号凭据、精确位置或模型生成文案，也不会发布到QQ空间、B站或其他外部平台。
5. `NOW.md` 仍每十分钟原子重写并在三十分钟后失效；QQ没有运行时，DSH不能把旧片段冒充今天。

## 验证

- 编排测试比较 Koishi状态接口与 `NOW.md`，确认两端包含同一组已发生事实。
- 控制台纯函数过滤非法时间、空文字并限制最多六条。
- 既有世界摘要测试继续保证未来事实不会进入片段。
