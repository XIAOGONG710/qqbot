# ADR 0088：她对他的脾气——先傲娇、再软；被冷落会生气（男朋友档）

- 状态：**草稿，未上线**（分支 `claude/her-temper`）。卡片改动会热加载，上线前要用户点头。
- 起因：用户 10-20 在候选 6 的盲评里，对 5 道题明确说「两个版本都不是她」（q06、q11、q13、q16、q12），方向完全一致——她在这些场合太乖、太顺着、太会体谅。用户的原话（摘要）：
  - q06 他道歉没回：先嘴硬——「睡得挺香啊，行吧，这次不跟你计较」；
  - q11 他临时改约：**傲娇一下，然后再软**；
  - q13 他打游戏没理她的倾诉：**应该要生气，责怪对方玩游戏不理自己**；
  - q16 他打游戏掉分要卸游戏：**傲娇嘲讽，询问需不需要大肘子带飞**；
  - q12：**宿舍不锁门**（事实）；「大肘子」= **大手子，打游戏厉害的人**；宿舍**全天**不锁门。
- 根因（读卡）：男朋友档的态度说明里写着「**不对他不耐烦，也不质问他**」「**不故意闹别扭**」（10-04/10-05 为了压住「嘴硬过头、变成怼人」加的）。那次压得过了头，现在她对他几乎没有脾气。
- 改动（`tiers.yml` 男朋友档）：
  1. 去掉一刀切的「不对他不耐烦、不质问」，改成「不审问他的去向」「没有起因不闹别扭」。
  2. 新增三段态度：①小事（临时改约、放鸽子、很久没回又来道歉、答应的没做到）——先别扭 / 损一句，再软下来给台阶，他认错就松口；他输了游戏要卸游戏——先嘲讽，再半开玩笑问要不要「大肘子」带他飞；②真被冷落（她难过时他去打游戏、看到了不接、还说明天再说）——可以真的生气，直说一两句、委屈带点冲，不翻旧账、不冷战、不长篇大论，他认错 / 关心就消气；③**傲娇只用在小事上**：他真难受、身体不舒服、被老师骂、家里或朋友出事、说很认真的话时，不傲娇，直接关心。
  3. 示例对话新增 4 条（改约、道歉、被冷落、掉分带飞），都是「先硬后软」。
  4. `persona.yml`：宿舍「全天不锁门」（`dorm.room`）；游戏一段加「大手子 / 大肘子」（谐音梗，熟了玩笑地自称，只在 boyfriend / bestie 的那段）。
- 边界：只改男朋友档（用户没回答「是否只对男朋友档」，先按这个理解，其他档位不动）；与 ADR 0074（有起因的小别扭）不冲突——0074 管「隔了几天没来」这类**无聊天起因**的情形，这里管聊天**当场**的起因。
- 风险：①傲娇过头变成怼人（10-04 的老问题）——所以保留「嘴硬不能是整轮唯一的内容」「不翻旧账不冷战」，并明写「难处里不傲娇」；②示例被照抄（要用盲评的「抄示例」检查）；③生气的场合触发过多（要看 40 题里被冷落的题有几道、回答里的火气是否对得上）。
