## 问题（有数据）

刚才（23:51）她发的是两条：「想啊，都想得有点睡不着了」，隔 2 秒「不过你别得意」，然后没有下文。转折词起了头，后面只剩一句态度，读起来像被打断。

线上聊天记录（10-04 起 503 个“一轮”）用同一把规则查：抓到 **3 处，都是 `shape` 上线（10-21）之后**：

| 时间 | 她发的 |
|---|---|
| 10-22 01:19 | 「这话说得」/「也太突然了」/「我要想想」（一句话被硬拆成两截；10-23 的 ADR 0134 改过分条说明，之后没再出现） |
| 10-22 01:27 | 「会伤心」/「不过你别瞎想这些」 |
| 10-24 23:51 | 「想啊，都想得有点睡不着了」/「不过你别得意」 |

10-21 起线上多条回复的轮次是 26 个，3 处里 2 处是转折收尾，约 8%。来源有三个：

1. **提示词在要它这样。** `shape.ts` 里写着「像手机上随手打的，半句也行，不用凑成完整的句子」「想到哪说到哪，不用把话说圆」，语气松一点那句还写着「拖个音、留半句」。模型照做了。
2. **分条 + 亲近意图。** 亲近的意图行是「先给一个明确的亲密回应，再自然地保留一点嘴硬」；分成 2 条时，第 1 条是亲密回应，第 2 条就成了一句只有态度的「不过你别……」。
3. **质感把「……」去掉了。** `texture.ts` 会把 3 个字以上的句尾「……」去掉（70%）。「要是你不来……」本来是故意拖着，去掉后就只剩「要是你不来」。（这次那条日志里没有质感记录，不是这次的原因，但是同一个毛病的另一条路。）

## 做了什么

1. **`unfinished.ts`：出口检查，写死的，不靠模型听话。** 随 `speechCheck`（线上已开，没有新开关），放在形状检查之后、危机回合不走。两种：
   - `tail`：多条回复的**最后一条**以转折词开头（不过 / 但是 / 可是 / 只是 / 不然 / 虽然……），后面只剩一小句（≤ 8 个字、没有逗号），不是问句、不是「……」结尾；
   - `cut`：某一条停在不能结句的词上（要是 / 如果 / 万一……、因为、所以、然后、觉得、说得、跟你……，以及只剩假设半句的「要是你不来」；「……的话」只有前面有假设词才算）；「……」「？」结尾的不算（是故意拖着、是在问）。
   处理：先带说明重写一次（说明里**不引用原句**——10-10 的教训：模型会抄被点名的那句）；重写后还是这样，`tail` 并回前一条（「想啊，都想得有点睡不着了，不过你别得意」；前一条是问句就去掉最后一条），`cut` 退到上一个逗号（退不回去就去掉那一条，只有一条就原样留着，不发空消息）。日志只记条数和种类（`话没说完：最后一条停在转折上，带说明重写一次`），不记原话。
2. **`shape.ts` 的提示词改了三处**：「半句也行，不用凑成完整的句子」→「一个词、一小句都行，但话要说完，别停在转折或铺垫上」；「不用把话说圆」→「随口一点没关系，但每条要把意思说完：起了转折或铺垫，这一条里就带上后半句，没有下文就别起头」；「拖个音、留半句」→「拖个音」；分条说明末尾加「最后一条要有自己的内容，别只丢一句转折的态度就停」。说明里没有引用任何具体句子。一个词的反应（`micro` 档：「嗯」「哈哈」）不受影响，那本来就是一句完整的话。
3. **`texture.ts`**：句尾「……」前面是连词 / 假设词时不去掉（`endsHanging`）。

## 没做 / 要注意

- 这是规则，抓的是“转折词起头只剩一句态度”和“停在连词 / 假设 / 觉得 / 说得上”两类；别的没说完的（如 10-24 模拟里的「嘴上不承认那种想」）抓不到。
- 并回前一条后，读起来仍是转折收尾（「……，不过你别得意」）但是一句完整的话；如果用户还是觉得像没说完，下一步是直接去掉最后一条，不并。
- `cut` 的“退到上一个逗号”会少说半句话，是兜底；正常走的是重写。
- 单元测试：`unfinished.test.ts`（11 个：检测的正反例、处理、出口、提示词、质感）、`app.test.ts`（端到端：重写 / 并回 / 关着不管 / 危机不管）。
