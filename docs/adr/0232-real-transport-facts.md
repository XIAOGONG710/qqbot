# ADR 0232：现实交通 / 公共服务事实适配器

状态：已实现为可选适配器和宿主显式配置，默认不启用。

## 决定

提供一个不绑定供应商账号的交通 / 公共服务事实层。调用方显式给出地点、端点和解析器输入，适配器只接受“正常、延误、关闭、未知”以及观测时间，落本地缓存并暴露状态；没有可信观测时不返回事实。

## 边界

- 适配器不自带城市密钥、账号或默认外部端点，避免启动时偷偷请求第三方服务；
- 宿主只接受不含账号、密码、片段和密钥参数的公网 HTTPS 端点；地点固定为学校那边 / 老家，关闭时不发请求；
- 每次响应最多 50 个地点、512 KiB，描述最多 160 字，时间必须是带时区的 ISO 时间；
- 单个地点失败不覆盖其它地点的旧缓存，也不阻塞聊天；缓存过期后调用方必须忽略；
- 原始响应、链接和供应商正文不进入角色提示词，只有结构化状态可供上层世界模块选择性使用；
- 交通事实不能自动改学校课表、约定或世界事件，后续若要影响行动必须另写明确的策略和测试。

## 为什么这样接

“实时交通”在不同城市和平台的接口差异很大，先把安全边界和缓存/失败语义固定下来，才能在 DSH 或 Koishi 侧按用户明确配置接入具体供应商，而不会把一份不可验证的网络正文当成她已经经历的事实。
