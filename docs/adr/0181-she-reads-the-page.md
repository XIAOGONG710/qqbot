# ADR 0181：她查东西的时候，读完再摘

- 日期：2026-10-30
- 状态：已实施
- 相关：ADR 0180（她自己上网）、ADR 0160（搜索 / 读网页）

## 背景

ADR 0180 的 `look()` 只拿搜索结果（标题 + 摘要）去摘录。摘出来的常常只是「有个条目叫这个」，
不是她想知道的那件事。用户 10-30：「上网也让她看」——她要的是看进去，不是一串链接。

## 决策

`look()` 搜到结果后，取第一条的 URL 读全文（沿用 `readPage()`：只读公开 http/https、
防 SSRF、1.5 MB / 10 秒封顶），正文比搜索结果长就替换掉材料，再交给摘录。
读不成、或读完比搜索结果还短，就用搜索结果；两种情况都算同一件事，**不额外占额度**。

## 实测（2026-10-30 这台机器）

- `api.tavily.com` 通，搜索能用。
- `zh.wikipedia.org`、`baike.baidu.com`、`www.zhihu.com`、`www.baidu.com` 全部超时
  （`readPage` 返回「打不开（超时或连不上）」）——这台机器的出网只放行少数域名，
  本机代理 127.0.0.1:7897 没在跑（`ProxyEnable = 0`）。
- 所以现在实际效果是：搜到摘要，读全文那一步大多跳过。网络放行多了以后不用改代码，
  它自己就会读。

## 后果

- 读得通的时候她拿到的是正文，不是标题；读不通的时候退化成和以前一样。
- 日志里多一个「（读了 xxx）」能看出来这次有没有真的读到。
