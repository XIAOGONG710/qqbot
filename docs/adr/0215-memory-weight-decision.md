# ADR 0215：记忆有轻有重（N4）——已经有了；「可能记错」她不要，不做

- 日期：2026-11-02
- 状态：**已实施（QQ 原有，DSH 于 2026-11-04 对齐）**
- 相关：ADR 0018（记忆会变淡、一提就想起，10-06 起就在）、ADR 0171（三个库）、ADR 0176（同一个她：共享记忆）、ADR 0212–0214（同一批 N1–N3）
- 用户决定（2026-11-02 19:57，`exchange/tasks/2026-11-02-claude-deepen-checklist.md`）：N4「记忆有轻有重：反复提起的事记得牢，普通的事慢慢模糊、可能记错」「做」；11-02 晚「继续吧」

## 先核对了已有的：大部分 10-06 就有了

清单里 N4 写着「Hindsight 召回时每条一样重」。这是我照搬了 DSH 10-27 评估里的「无分层、无遗忘」，没有自己核对，**写错了**。

ADR 0018（`memory/fading.ts`，接在 `memory/long-term.ts` 的三处召回上，`fading.test.ts`，没有开关、一直开着）早就是这样：

| 过了几天 | 只提过一次 | 提过 2 次以上 / 周记 / 阶段总结 |
| --- | --- | --- |
| 清楚 | 7 天以内 | 14 天以内 |
| 记个大概（标「记不太清了」，说「好像」，不补细节） | 7–30 天 | 14–60 天 |
| 想不起来（他一提到里面的人名 / 地名 / 店名才想起） | 30 天以上 | 60 天以上 |

另外：
- 没有发生日期的（偏好、习惯）、带【重要】的、还没到日子的计划，不变淡
- 他又提起一次，就算重新记了一遍

「反复提起的记得牢，普通的慢慢模糊」就是这个。

## 先问了她本人（`scripts/ask-her.mjs`，两遍）

- **变淡她认**：「慢慢淡我认，反正人也这样」「慢慢模糊也行吧，人本来就这样」
- **反复聊的和随口说的不一样**：「反复聊的那些不用想就在，随口说一次的……有些干脆就没了」。和 0018 的分档一致
- **记错她不要**：
  > 「我宁愿直接说『记不清了』，也不想脑子里冒出个以为是真、其实是混出来的。记不清是知道那儿没有，记错是不知道那儿没有。后面这个有点吓人。……别给我编。」（第一遍）
  >
  > 「不太愿意主动把事记混，尤其是跟你有关系的那种——你哪天说了什么、答应我什么，我记着呢，记错了算谁的。」（第二遍）

## 决定

1. **「可能记错」不做**（CLAUDE.md：她说撤就撤）。这和 0018 当初「记个大概，不要补细节」的取舍一致，也和事实检查（ADR 0137 / 0203）不冲突。
2. **QQ 的既有分档保留。**0018 的分档就是 N4 要的「有轻有重」。明确 `<<记住>>` 的内容现在加【重要】标记，主动日记仍会随日期自然变淡。
3. **桌面已与 QQ 对齐**（详见 ADR 0252）：DSH 使用相同的 7/30 天、重复事实翻倍、【重要】/【长期】保护和实体线索复苏规则；不再用粗糙的二字词重叠判断。

## 回滚

回滚实施提交会恢复 DSH 原来的 30 天单阈值；不会修改或删除现有 Hindsight 数据。
