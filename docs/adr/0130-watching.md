# ADR 0130：她自己在 B 站看东西、形成看法（配置 `watching`，默认关；要 `bilibiliAccount`，想法变成念头要 `innerLife`）

- 状态：**已实现，未上线**（2026-10-23；配置 `watching`；默认关）。上线 = `koishi.yml` 里加 `watching: true` + 重启（`bilibiliAccount`、`innerLife` 已开）；回滚 = 改回 false + 重启（`watching/watched.json` 和念头状态里的 `reflected` 留着，不影响）
- 日期：2026-10-23
- 关联：[ADR 0101](0101-inner-life.md)（内心）、[ADR 0089](0089-bilibili-account.md)（她的 B 站号）、[ADR 0129](0129-memes.md)（热梗）
- 用户提出：2026-10-23「能否让她在 bilibili 学习像人一样说话和思考」

## 先回答能不能：说话不能、思考能

她不能“训练”（模型权重动不了），能做的是给她**真实的素材和记忆**，放进提示词。分两半取证：

**说话——B 站评论区不适合当语料（不做）。** 从 30 个热门视频的评论区（含楼中楼）收 957 句候选，用「像不像真人」的尺子（`humanness.ts`，用他自己的聊天和真人聊天样本训练）筛到 270 句，再让模型判断“不依赖视频内容、像熟人私下聊天会说的话”，只剩 **39 句（4%）**；而且全是「哈哈哈哈哈」「是的！」「支持继续扒！」「加油」这类依赖视频的话，比她现在写的还空。新词新梗那一部分已经由 ADR 0129 管了；写法（长短、结构、语气词）靠真人聊天样本 + 尺子（ADR 0091 / 0099），那里测得出来，也在改。

**思考——人有看法，是因为看过、经历过、记得。** 她缺的是“真看过什么”：现在刷 B 站只是挑一个视频发给他（一周 3 个），看完没有任何东西留下来。

## 做了什么（`watching.ts`）

1. **她自己“看”**：每天一次（14 点以后；`app.ts` 每 30 分钟看一眼）。按口味搜（`SEARCH_KEYWORDS`，一天一个词，搜不到合适的再换后面两个词），只看口味范围内的视频（分区、广告词、时长，沿用刷 B 站的 `suitable` / `rankVideos`，看过的不重复），读第一个有字幕的：存**标题、UP 主、分区、字幕前 220 字、两条热评（每条 ≤ 40 字）**，不存评论者；最多 30 条、留 30 天。存 `<数据目录>/watching/watched.json`。
2. **想事情时有个“你怎么想”的题目**（`inner.ts` 的 `WATCH_THEME`）：「你最近在 B 站看过的那个东西：你自己怎么想——喜欢还是不以为然、哪里好笑、哪里不对劲；说得具体、有自己的立场，别写成影评或总结」。事实就是那条字幕摘要和热评（提示词写明：真的看过、想法由你自己定、不用夸也不附和热评、不编里面没有的情节）。
   - **每个新看的视频，她下一次想事情就专门想这一件**（`forceWatch`），想完把视频编号记进念头状态的 `reflected`，不再专门想；之后它只是多一个可选题目。
   - 念头照旧：想告诉他 / 想问他的变成“心里惦记”的主动消息，聊天里带着“你这几个钟头心里在想”（ADR 0101 原有的路）。
3. **他问到“最近在看什么 / 刷到什么 / B 站 / 视频”**：提示词里给她最近两条真看过的，让她随口挑一个说，别照着念字幕、细节别编。没问不放。

## 数据

- 真实一轮（真 B 站号、临时文件）：搜到手机游戏分区的视频，读到 221 字字幕和 2 条热评，存下。
- 真模型模拟（10-23）：
  - `sim/watching.json`（预置她今天看了一个王者荣耀的视频）：他问「你最近都在看什么呀」，5 次里 4 次她接得上（「在看 b 站，一个打游戏的视频」「佐悠那个，讲开局出拳套的」），1 次答「看游戏」（我的检查没认）；没有一次说“字幕 / 热评 / 摘要”；他再问「晚上想吃什么」时她不硬提。
  - `sim/watching-think.json`（innerLife + watching，他一下午晚上不说话）：只加一个**可选**题目时，20 个念头里只有 1 个落到视频上（模型总挑相机、淘宝、想他）；改成“新看的视频下一次专门想”以后，5 次里 4 次第一个念头就落到视频上，且有立场：「开局出拳套这个思路我服，我都是先出鞋，活该被抓。不过对面要是怂着不打，那不白出了？」「听完还是一脸问号，热评那帮人也是纯绷不住」。

## 没做 / 要注意

- 看法是模型根据字幕摘要写的，她看的是**公开视频的字幕和热评**，不涉及私人内容；只在她口味范围内（游戏、日常、萌宠、美食……），新闻、政治、争议类被 `suitable` 挡掉。
- 字幕是语音识别的，有错字，摘要只有 220 字：她知道“大意”，不会比这更细——提示词里写了“细节别编”。
- 每天多一次 B 站读取（1 次搜索 + ≤ 4 个字幕 + 1 次热评），风险监测（ADR 0090）照常看她的号；和 ADR 0129 热梗（一天两次）、刷视频分享（一周 3 个）加起来仍是低频。
- 她看了不等于要说：想法是不是变成消息，仍由内心的“告诉他 / 问他 / 自己想想”决定，和主动消息所有的闸（每天条数、没回不催、她难过 / 很累让路等）。
- 她的“口味”（喜欢什么、讨厌什么）是看多了自然留下的念头，没有单独存成一份偏好档案；那是之后可以做的“稳定的立场”，要不要做看你。
