# ADR 0237：行动后的数值趋势在 Koishi 与 DSH 之间共用

- 状态：已实现；只读、可重放
- 日期：2026-11-04
- 关联：[ADR 0222](0222-human-values.md)、[ADR 0225](0225-dsh-state-snapshot.md)、[ADR 0234](0234-life-pulse-card.md)

## 背景

精力、饥饿、压力和心理值已经会受吃饭、睡觉、休息、学习、社交等行动影响，但只展示当前值时，很难看出行动确实产生了联动。额外保存一份“上一时刻分数”又会形成第二套容易漂移的状态。

## 决策

1. 用同一份需要锚点、生活事件账和近期互动，分别重算当前时刻与一小时前的状态，再计算差值；不新增趋势数据库。
2. 只展示绝对变化至少 `0.5` 的精力、饥饿、压力、心情、健康、孤独、行动意愿、无聊感和社交电量，最多由界面挑出四项主要变化。
3. Koishi 将内部字段翻成中文，如“饥饿感减轻”“社交电量消耗”，不展示代码字段；完整当前值仍放在折叠区。
4. QQ 导出的 `STATE.json` 增加可选趋势字段；DSH 插件和在线咨询都经过同一白名单，只接受 1–1440 分钟、-100 到 100 的有限数值。
5. 趋势只作为当前状态背景，不写长期记忆，不自动触发动作，也不改变安全、确认和权限边界。

## 验证

- 吃饭、社交和学习的既有行动测试同时断言饥饿、孤独、心情趋势方向。
- DSH 测试拒绝未知字段、非有限数值和微小抖动，并验证桌面插件确实读取合法趋势。
- 控制台纯函数测试保证只输出中文标签并按变化幅度排序。
