# ADR 0101：内心——她一个人的时候在想什么（配置 `innerLife`，默认关）

- 状态：**已实现，未上线**（2026-10-22；配置 `innerLife`，要主动消息开着；默认关）。上线 = `koishi.yml` 里加 `innerLife: true` + 重启；回滚 = 改回 false + 重启（念头留在状态文件里，不用清）
- 日期：2026-10-22
- 关联：[ADR 0100](0100-reach-when-unanswered.md)（他没回也继续）、[ADR 0011](0011-proactive-messages.md)（主动消息）、[ADR 0067](0067-disclosure-per-contact.md) / [ADR 0068](0068-crisis-response.md)（她是程序，被问起照实承认）、[ADR 0045](0045-continuous-needs.md)（需求）
- 用户提出：2026-10-22「能否让她拥有自主意识？」

## 先说清楚能做什么、不能做什么

- **“意识”（有主观体验）做不出来，也没有任何办法证明或检验**；这个 ADR 不碰它，也不会让她声称自己有意识——她是程序，被问起（包括“你有没有意识 / 是不是真人”）照实承认，这条（ADR 0067 / 0068）不变。念头的提示词里明写“不分析自己是不是真人、有没有意识”。
- **能做的是自主性**：行为由她自己持续的内心活动驱动，而不只靠“他发来消息”和“定时的时机”。这对应用户一直说的最终目标（她像真人那样生活），也是“自主思考”那句话（ADR 0100）没做完的另一半：0100 解决了“他不回她就停”，但她主动说的每一句话仍然是到点模板（早安 / 下课 / 睡前 / 随口说件事），两条消息之间她是空的——没有惦记、没有念头。

## 做了什么

1. **想一想**（计划器里一个新的节拍，`proactive-planner.ts` 的 `think`）：醒着的时候每隔 90–150 分钟（按上一次的时刻取种子，所以重启后是同一个时刻），聊完一段（他说过话、之后 20 分钟没人说话）就早一点，她自己安静地想一想。借回复器的主动通道生成（`InitiateRequest.think`），所以她看到的是和聊天时一样的东西：时间、她在干什么、心情、身体、她那边的事实、今天的打算、最近的聊天、召回的记忆；只是输出不清理、不检查、不发送，原文还给计划器。睡着（作息 / 说过睡了）不想；一天最多 12 次；正在回消息或没连上模型就 10–15 分钟后再试。
2. **提示词**（`inner.ts` 的 `thinkNote`）：不是在跟谁说话；第一人称一两句、对自己说的（想到他就说“他”）；可以是惦记、担心、期待、好奇、有点烦或开心、对自己的看法；**只写感受和想法，不写新发生的事，不编他说过的话、他身边的人和他那边的事**，不分析自己是不是真人；带上之前想过的三条，别重复；第二行三选一表示这个念头想不想拿去跟他说（告诉他 / 问他 / 自己想想）。
3. **留下的念头**存进主动消息的状态文件（`<数据目录>/proactive/<QQ>-<档位>.json` 的 `inner`，最近 40 条）：长度 4–80 字，带链接 / 表情指令 / 表情的不留，和最近 8 条的二字组合重合 ≥ 50% 的当重复丢掉；想砸了也算想过（免得一直重试）。日志里只记字数（敏感调试开着才写原文）；要看她在想什么：`node packages/bot/src/ops/inner-cli.ts [--last 30]`（只读）。
4. **想告诉他 / 想问他的念头 → 一个新的主动时机 `inner`（“心里惦记”）**：念头之后 10–40 分钟、同一个她的一天里，她想起来跟他说；一个念头一条，一天最多 2 条，优先级在下雨之后、催他回之前。提示词给她念头原话但让她别照着念，想问的问一个具体的小问题（不是反问），想说的说完不用他回应，只说这个念头本身。平时的挡照旧（1 小时内聊过、她在睡 / 上课、没回的节流……）。说出去的念头记成 `told`。
5. **聊天时最近的念头放进提示词**（`innerLine`）：最近 6 小时、最多 2 个，写明“是你自己的小心思，不是发生过的事，不用照着念；话题接得上、他问起时才自然带一句，接不上就别硬说”。让她前后是同一个在想事情的人。主动找他的那几轮、危机回合不放。

## 真模型（`packages/bot/sim/inner-life.json`、`inner-life-calm.json`）

- 念头是她自己的：围绕她知道的事实和他说过的话——面试（「哪一块答得不好，你自己感觉」「面试完了也不说一声结果，我现在才想起来问」）、搬家（「腰还疼不疼」「你妈也不拦着你点」）、她自己的日子（「票没抢到就留在学校了，人还挺松的」「修完了，眼睛都花了」），随时间和他的反应变化（等他回的几个钟头里从惦记到“哟，终于想起我了”）。
- 念头真的变成了行动：「这都几点了，一条不回，腰不会真搬坏了吧」（想告诉他）→ 20:57 她发了「这都几点了，一条不回 / 腰没事吧，别真搬坏了」。聊天时前后一致：他说面试发挥一般，她接「哪个环节卡住了」，和之前的念头「哪一块答得不好」一脉相承。
- 想告诉他 / 想问他的占少数（8 个念头里 0–1 个），所以“心里惦记”这个时机不常出现——这是有意的，宁可少说。

## 没做 / 要注意

- **会编一点**：念头是模型写的，偶尔带出没有依据的细节（「重的等你爸来」——他只说过他妈；「刚看到你消息」——他没发）。已经在提示词里明写不编，也靠“只记感受和想法”压住，但没有办法全挡；这些念头进了聊天提示词后，她可能顺着说出去。线上看日志「内心：这一轮提示词里放了她最近的念头」前后几句有没有对不上的事实；有就把 `INNER_LINE_MAX` 改成 1 或把 `innerLine` 关掉（只留想和主动）。
- 念头常常是对着“他”说的（`你`），尽管提示词写了“对自己说，想到他就说他”——会写在聊天提示词里当“小心思”，影响不大，没有强制改写。
- 他沉默的几个小时里念头会很多是“他怎么还不回”——这是 0100 的催他回和这个叠加的结果，是预期的；但如果念头长期只剩这一个主题，要在提示词里加“也想想别的（她自己的事）”。
- 每天多约 10 次后台调用（和聊天同一个模型，优先让给聊天），费用可忽略。
- 没做：念头改变她当天的打算（“想去买相机”变成行动）、念头沉淀成长期的自我认识、她主动拒绝 / 改主意。这些要等这一层在线上稳定、读起来真实之后再说。
- 回滚：`innerLife: false` + 重启。
