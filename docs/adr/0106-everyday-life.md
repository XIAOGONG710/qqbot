- 日期：2026-10-22
- 关联：[ADR 0021](0021-her-world.md)（她的世界）、[ADR 0033](0033-npc-days.md) 的小事、[ADR 0102](0102-feelings.md)（心境）、[ADR 0057](0057-her-news.md) / [0064](0064-her-own-events-as-reasons.md)（她那边的事成为开口理由）、[ADR 0094](0094-her-own-agenda.md)
- 用户提出：2026-10-22「把你提出的这些差距都进行补平，真人怎么样就让她怎么样」（差距：她的日子像课表、社交世界只有一个人）

## 差距（有数据）

- 线上事件账 15 天 150 件：休闲 36、学习 31、吃饭 23、上课 20、项目 19、睡觉 13，**与朋友来往 1 次**，被打断 9 次；全是例行。17 天里只有 5 件事值得主动说。
- 卡上的“小事”只有 12 条（食堂排队、图书馆没座、宿舍查卫生……），按日期哈希平均一天 **1.48 件**，23 天有 0 件的一天（占 21%）。
- 结果：她被问“今天干嘛了 / 有什么好玩的事”只有“赶作业呢”“没呢”可回；也没有什么可以让她高兴或烦。

## 做了什么

1. **日常尺度的小事 98 条**（`everyday.ts`，代码里补充，**不改角色卡**——改卡 = 上线）：吃（食堂新窗口、阿姨多给半勺菜、外卖晚了）、上课与学习（老师拖堂、点名、机房卡、实验里少个括号、作业延期、图书馆）、宿舍（洗衣机排队、热水器、舍友的闹钟 / 零食 / 聊天）、手机与玩（掉电、追的剧更新、王者连赢连输、一首歌循环）、天气与季节（下雨没带伞、降温、晚霞、银杏黄了）、土豆（蹭手、翻肚皮、没出来）、朋友（高中闺蜜在微信上互损、吐槽她们学校；大学闺蜜把笔记拍给她、一起自习、分零食、研究作业题）、妈妈发微信、身体与睡眠（没睡好、睡过头、眼睛干、午觉）、买东西（满减券、退款、快递柜满）。
   - **只加日常尺度**：不加新的有名字的人、社团、恋爱、家里变故、考砸之外的大事——那些走作者写的 `moments.json`（ADR 0102）。
   - 条件：月份、星期、天气（下雨 / 没下雨 / 最高气温 ≤ 12 / ≥ 30）、她那一天的状态（大学闺蜜感冒 / 在家的日子就没有一起自习）、土豆那天见到 / 没见到（猫的事发生在她喂完之后）、买了相机以后（拍照）。
   - 频率：各条概率整体 ×0.55，一天补充的最多 3 件、同一类一天一件；加上原来的，平均一天约 3.5–4 件（原来 1.48）。花钱的小事（奶茶、文具、打印、水果）记进她的账。
   - 档位：亲近的四档看全；同学档只有吃 / 上课 / 天气 / 追剧这类（没有宿舍、闺蜜、家里）；陌生人 / 名单外只有最普通的几条。
2. **“小测”一条线**：高等数学、概率论（数学类，75% 的候选周真考，大约每四周一次）和专业课（35%，大约每八周一次）；前一次课老师说“下次课小测”、当天写（写得顺 / 一般 / 有两道卡住——不说分数，她写的时候不知道）、**两天后晚上出分**。分数：数学类均值 72、专业课 83（自传：怕数学），38–99；< 60 是难过（< 50 很重），≥ 90 开心，数学类 70–79 松一口气。水课（形势与政策、创业基础、思想概论、Python 数据分析、体育）没有。**这是她难过 / 开心的真正来由**：不靠作者、不靠模型随口说，一个学期数学类大概有一次没考好。
3. **带感受的小事进心境**（ADR 0102）：小事上写了“开心 / 烦 / 担心 / 难过 / 松口气”的（晚霞、外卖晚了、小测出分……）成为一条评估；出分的难过留得久（半衰期 14 小时），所以第二天她还记着——心境多看一眼“前一天的世界”（`previousWorld`）。
4. **被问起她的一天时有东西可讲**：他问“今天干嘛了 / 有什么好玩的事 / 有没有什么烦的事 / 最近怎么样”，意图行让她从“今天的小事”和今天的事实里挑一两件具体的说（带感觉，像随口讲），不回“没什么 / 就赶作业”，真没有才说没有，没写的别编；他难过时让路；长度不压成几个字（至少 medium）。

## 数据

- 日历：2026-09-01 到 12-20（112 天）模拟：每天平均 4.4 件（缩放前）→ 缩放到约 3.5–4；小测相关 41 件 / 约 14 场，数学类一个学期 4 次（91、58、79、70 这样的分数），没考好的大概一个月一次。
- 真模型（虚构对话，`--shape --agenda`，4 次）：被问“今天干嘛了 / 有什么好玩的事 / 有什么烦的事”，原来是“赶作业呢”“没呢”，现在是「下午那节课老师拖堂十分钟，坐得我腿都麻了」「早上没吃早饭，第二节课饿死我了」「今天下雨，土豆都没见着，白惦记了一天」「有道题卡了半天，最后放弃去睡了」。
- 小测的线（10-16 晚上高数 58 分，开 `herFeelings`）：他问“今天怎么样”→「不怎么样」「还行吧」；问“高数小测考得咋样”→「58，别问了」「别问了，没考好」。嘴硬在前、被问才说，没有倾诉成篇。

## 没做 / 要注意

- **不改写已经过完的日子**：第一次开 `everydayLife` 时定下“从哪天起”（第二天）并存进 `<数据目录>/world/everyday-from.json`（和 `needs-anchor.json` 一个办法），以后重启读同一个；那天之前的日子小事和小测一件都不多（世界里 `everydayFrom`），“别挂科”的数也只数从那天起的小测。文件读不了就用今天之后的一天，不往前改。
- **更大的事仍然是作者的**：一次真正伤心的事、跟谁闹僵了、家里的事——还是 `moments.json`；这里不碰。
- **“值得讲”和“发生过”不同**：一天 3.5–4 件里她只会讲被问到或被议程抽到的一两件（ADR 0094 的带事轮次），不会每件都汇报（ADR 0064 的教训）。
- 重复：同一件小事每个月会出现几次（食堂排队 23 次 / 112 天）；日记里写下的会让她前后一致，线上看 `crutch` 一行（“最近反复说的字词”）。
- 小测的课名取自课表（亲近档位看得到）；同学档以下没有。
