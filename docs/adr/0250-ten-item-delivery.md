# ADR 0250：十项交付的验收闭环

日期：2026-11-04

## 决策

1. 用 `verify:cross-end` 离线真实走一次配对、QQ/DSH/手机共享上下文、幂等重试和进程重载，不用拼装假的“已连接”状态。
2. Android 0.2.0 正式构建必须使用非占位 HTTPS 域名；预检与 Gradle 双重阻止误打包，真机安装仍是现场验收。
3. 实时语音原始分片只在内存保留到 stop/cancel/reset；stop 后通过宿主 STT 转成文字，再走同一 DSH 对话入口。没有 STT 或空转写时失败关闭。
4. 真实生图和 Hindsight 隔离恢复可写一次性验收回执；回执不包含提示词、供应商配置或数据库连接串，已有文件不覆盖。
5. 世界事实按键、来源、有效期、优先级汇总；同级近时冲突明确标为 conflict，不能猜值。
6. 贴吧、抖音、小红书真实发布只由注入的官方适配器承担。草稿批准、本次确认、账号授权、幂等预占缺一不可；网络结果不确定时停在 publishing 等人工核对。
7. Koishi 状态页增加只读“一键体检”，只给中文结论，不访问外网、不重启、不发送消息，不回显地址、密钥和上游错误。
8. 拟人回归支持基线/当前双窗口比较，并可在 CI 中因比例恶化失败；样本不足也不冒充通过。
9. `release/manifest.json` 是发布版本、手机协议和状态格式的统一清单；`release:check` 校验 Android 版本、文档和 diff 格式。

## 环境边界

仓库自动测试只能证明实现和安全门槛。真实图片供应商、Android 真机、隔离 PostgreSQL、正式域名及三个平台官方账号必须在对应环境中单独验收，结果不能由模拟测试替代。
