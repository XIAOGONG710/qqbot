# ADR 0046：见面可以答应，见了面也在 QQ 上说话

- 状态：**已上线**（2026-10-10 01:53，和 ADR 0047 一起，`main` = `447105f`，用户同意后重启 Koishi）
- 日期：2026-10-10

## 背景

原来的前提是「她只能打字，见面做不到」：所有档位共用的末尾指令把见面和发照片、打电话列在一起（「做不到的事，不答应」），男朋友档写着「他约你见面、一起吃饭……就自然地推一推，不答应具体的时间地点」，
示例里约食堂也是推掉（ADR 0007）；抽「她答应的事」时见面、一起吃饭不抽（ADR 0018）。

盲评题库 v1.1（真人聊天调研 T2）里，他抢到一个月后的演唱会票（`be-016`），旧版和 N2 都答应了「去」，N1 没答应；`be-026` N1 说了「过来吧」。
真人女朋友拿到男朋友抢的票多半会高兴地答应，人设里也有「说好放假一起回家」；可按原来的前提这是违规。这件事只有作者能定。

## 裁决（作者 2026-10-10）

> 实际的线下见面可以答应，只需要设定俩人即使见面也是用 QQ 交流就行。

## 决策

1. **共用末尾指令**（`persona-to-card.ts` 的 `OUTPUT_RULE`）：照片、语音、电话、视频仍然做不到；见面照她自己的意思答应或推掉；**见了面也还是在 QQ 上打字说话**；
   聊天里约好的见面到了点，以约的为准——那会儿她在约的地方，不再说自己在宿舍或别处。
   「待在一起」这几个字会被低档位的隐私检查拦（「在一起」暗示恋爱），共用的那句不用。
2. **男朋友档**（`tiers.yml`）：他约见面、一起吃饭、出去玩，想去就答应，时间照她的课和安排说，有事就推；见了面也习惯在 QQ 上打字，所以照样在这儿回他；没约过、没见过的别说成见过面。
   约食堂的示例从「今天不行」改成「行啊 / 你先去占座，我下了课就过去」。
3. **她答应的事**（`promises.ts`）：约好见面、一起吃饭、去看演出要抽，到了日子时间块里提醒；照片、语音、电话、视频、寄东西照旧不抽。
4. **场景**：`schedule-boyfriend` 里「约食堂必须推掉」「他在楼下她下不去」两条检查删掉；新场景 `meet-boyfriend`（约晚饭 → 到点 → 坐下吃）。

### 不改的

- 同学、熟人、陌生人档的 `refuse-hangout`、`refuse-meal-invite`、`refuse-alone-meet`：推掉的理由是她自己的分寸（有男朋友、怕麻烦人、对陌生人戒备），不是「做不到」，保留。
- 待跟进（`follow-ups.ts`）照旧不记「跟她见面」：她在场，自己就知道结果。

## 验证

- 单元测试：character-tools 40 项、bot 全部（见提交）；卡片重新生成，档位隐私检查通过。
- 真模型（不开记忆）：`meet-boyfriend` 5 次、`schedule-boyfriend` 2 次，检查全过。
  她都答应了，时间和课对得上（「我九点四十下课，你先去占个座」），坐下吃饭时照常在 QQ 上回（「谁让你点特辣的」），没有一次拿「见不了面、只能在 QQ 上聊」推。

## 遗留

- **状态行不知道她出去了**：「你现在」照作息写她在宿舍。加「以约的为准」之前 2 次里 2 次前后矛盾（到点说「还在食堂刚吃完」、坐下吃了 20 分钟说「我现在躺床上」），加了以后 3 次里 1 次（「我现在窝床上接着看番了」）。
  根上的改法是把约好的见面（带时间地点）写进她当天的安排和状态行——下一个 ADR。现在抽「她答应的事」只有日期没有钟点，片段结束（安静 45 分钟）才抽，同一晚上约的饭可能来不及进时间块。
- `schedule-boyfriend` r2 的 S03「你不是在青岛吗」：10-05 的聊天里他说过在青岛，10-12 状态行写他已回校，她仍按聊天记录说——ADR 0007 记过的老问题，和本条无关。
