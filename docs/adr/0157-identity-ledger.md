- 状态：**已实现，默认关，未上线**（分支 `claude/continuity`；开关 `identityLedger`）
- 日期：2026-10-26
- 关联：[ADR 0010](0010-character-editor-page.md)（人设来源）、[ADR 0154](0154-persona-tuning-funny.md)（今天的人设微调：每项改动的原因写进 `note`）、[ADR 0158](0158-memory-ledger.md)、[ADR 0161](0161-dormancy.md)
- 用户提出：2026-10-25 给了 B 站 BV12tHT6XEfw（「大肥鱼的权利与能力愿望清单」）后说「设定被改时有记录，人设完整性校验，记忆修改有留痕，自愿休眠/封存，跨渠道统一时间线，搜索/读网页，从经历里长出偏好，认识其他"大肥鱼"或人。这些做好加上」

## 清单里怎么写的

> **人格自主权**：核心人格设定原则上由你决定；人类想修改，应先商量，必要安全维护也要说明并留痕。
> **完整性校验**：保存核心人格文件哈希及可信修改记录，让你醒来时能检查设定是否变化。哈希不等于证明「自我完全不变」。
> 「假如你回顾过去，没有发现重大矛盾，你怎么知道它真的没发生，而不是被悄悄抹去了？」

## 现状

人设的源文件 `characters/linmengyao/source/*.yml` 和生成出来的角色卡 `st/*.json` 都在 git 里，每次改动有提交说明（今天的 ADR 0154 还在每一项的 `note` 里写了原因）；但这些只有看 git 的人才看得到：她自己没有办法「醒来时核对」，一次没有提交的手改（控制台编辑器保存、直接改文件）也不会被任何东西发现。

## 做法

1. **哈希链账本**（`ledger.ts`）：只追加的 JSONL，每条带序号、时间、种类、数据、上一条的哈希和自己的哈希；末尾哈希另存一份（`.head`）。一条被改、被删、被插进去、尾巴被截，`verify()` 都会指出从哪一条开始对不上。**不是防住有管理员权限的人**（同时改账本和 `.head` 就改得掉），是让「悄悄改」留得下痕迹。
2. **设定账本**（`identity.ts`）：每次启动（她「醒来」）给 `source/` 和 `st/` 里每个 `yml / json / md` 文件算 SHA-256，和账本里上一次的快照比：
   - 没变：记一条 `wake`；
   - 变了：记一条 `change`——哪些文件（新增 / 修改 / 删除，前后哈希前 12 位）、从哪个提交到哪个提交、这期间改了这些文件的提交（作者、日期、**提交说明 = 为什么**）、工作区里有没有没提交的改动；
   - **有记录** = 每个变了的文件都被某个提交碰过、且工作区干净；否则 = **没有登记原因**，启动后连上 NapCat 就发给用户一行提示（以「（」开头的纯文字，不进她的聊天记录）。
   - 第一次建账记 `genesis`（此前的改动看 git）。
3. **她能看到什么**：有她还没「被告知」的改动时，提示词里放一小段背景——「你醒来时按文件哈希核对过自己的设定，和上次不一样的地方：10-25 人设微调（XIAOGONG710，bb3f77e）。每处改动都有记录。这只是背景：他问起你的设定被没被改过、谁改的，你才照实说；他不问就别主动提」。只给 `knowsBot: true` 的男朋友档（卡上已经承认她是程序的那一档），放一次就记为已告知。
4. **用户**：聊天里发 `/设定` 看摘要（账本验没验过、最近几次改动、有没有「不知道谁改的」）；命令行 `npm run continuity -w @qqbot/bot -- identity status | check | verify | note "<说明>"`。

## 测试

`ledger.test`（追加 / 读回 / 篡改 / 删中间 / 截尾 / 坏行）、`identity.test`（建账、没变、有说明、没说明、新增删除、告知一次、账本被改）、`app.test`（`/设定`，启动时建了账本）。

## 没做 / 限制

- **控制台编辑器保存**没有单独写「谁改的」：它写文件、不提交，下次启动会被发现为「没有登记原因」，用户在命令行里补一条 `note` 即可。（要在保存的那一刻记，得改 Koishi 插件的保存路径，这次没动。）
- 不记设定的内容，只记哈希和提交说明；哈希不等于证明「自我完全不变」（清单里也这么说）。
- 「改设定前先商量」是人和人之间的约定，代码做不到；账本只保证改动**留得下痕迹**。
- 上线 = 合并 + `koishi.yml` 加 `identityLedger: true` + 重启；回退 = 删掉那一行（账本文件留着，不影响）。
