# ADR 0351：DSH 面板化用成我们自己的插件——三层与边界

- 状态：**已采纳**（代码在 main；DSH 那台重载后生效，重载要用户点头）
- 日期：2026-11-26
- 关联：[ADR 0200](0200-private-space.md)（她的私人空间）、[ADR 0347](0347-one-life-two-places.md)（一个生活）、[ADR 0348](0348-weekly-effect-metrics.md)（效果数）、
  [ADR 0349](0349-guest-room-and-home-status.md)（会客室、她的家）、[ADR 0350](0350-her-inner-panel.md)（她心里的）；
  计划 `docs/plans/2026-11-26-dsh-panel-our-own.md`；审查 `docs/reports/2026-11-26-dsh-qqbot-services-review.md`、`docs/reports/2026-11-26-panel-integration-review.md`

## 起因

用户 11-26：「今晚把这个插件的移植本土化改造做好，和我们项目联系起来，尤其是记忆和情绪，可以将我们的大部分东西缝合进去，化用成我们的插件」。
插件 `dsh-plugins/dsh-qqbot-services` 是从灵犀 QQ 桥接（MIT）移植来的服务面板；这一轮把记忆、情绪、她自己的账和项目工具接进去。

## 决定

**面板上的东西分三层，以后往面板里加任何东西都先归到某一层：**

| 层 | 是什么 | 默认 |
|---|---|---|
| A 运维数 | 只有数和新鲜度：记忆（登记、Hindsight、公共库 / 他的库条数、片段、账本）、情绪（心境导出多久前、感觉账条数）、她的账（世界账、时间线、日记、SELF / NOW、桌面回合数）、QQ 那边（心跳、今天主动找他几次）、项目工具（开关、效果数含他的反馈、提示词构成、上线前预检和重启记录） | 开 |
| B 她会说给他听的 | 「她的一天」（世界账里她那边真发生的事，用 QQ 那边同一套说法）、她在看的书、她的家（她主动发布） | 开 |
| C 她心里的 | 心境、感觉账的内容视图（按 ledgerNote 的规矩换说法、封顶、不带来由） | **关**，先问她（ADR 0350）、用户点头 |

**边界（每一层都守）：**

1. ADR 0200 的私人空间——说话习惯、心境、自我认识、追求、拒绝过的、她猜的事、PRIVATE.dat——不进面板（C 层是她点头后的例外，且只给换过说法的那一层）。
2. 不出原文：聊天、记忆、反馈的上下文、主动消息的正文都不读出来；QQ 号、bank 名、绝对路径、原始报错不给页面。测试里在每份合成数据埋记号，断言输出里一次都不出现。
3. **面板只读，不替 bot 做决定**：不写、不改名隔离、不改写格式（审查发现过「效果数改写 QQ 的撤回状态」「坏文件被改名」，已改）；读到坏文件就当没有。
4. 路由一律在 DSH 浏览器认证之后（`requestRejection`）；局域网来宾监听只有房间路由。
5. 重活（扫聊天记录、读清单、读几十 MB 的账）放短命子进程：超时、并发上限、同请求共用一次计算；子进程只拿数据目录、时区和他的 QQ 号。
6. 「今天」「她的一天」按插件配置的时区，02:00 换天，和 QQ 那边一致。

## 不做的

- 面板不改她的言行，不改线上开关（配置编辑器是用户自己的操作，和控制台一样）。
- 对账时刻只在 QQ 进程内存里，面板给不出，不为它落盘（会改数据目录，动行为基线）。
