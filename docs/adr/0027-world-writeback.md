# ADR 0027：说出口的行为回写她的世界（W3）

- 状态：已实现、真模型验证并上线（2026-10-07 21:31）
- 日期：2026-10-07
- 关联：[ADR 0018](0018-memory-fades-and-promises.md)（片段抽取）、[ADR 0021](0021-her-world.md)（她的世界 W0–W2）、
  [ADR 0026](0026-diary-of-her-day.md)（日记写当天发生的事）、DSH 侧 [世界子系统](../research/2026-10-06-dsh/world-subsystem.md) W3

## 背景

W0–W2 让她身边有了会自行推进的天气、猫、快递、作业和家事，但世界仍是单向的：确定性推演说下雨没喂猫，她在聊天里顺嘴说「我刚还是下楼喂了」，下一轮又会看到“今天没喂”。真人说自己做完了一件事，之后面对任何人、写日记、主动发消息时，都生活在已经发生过这件事的世界里。

## 决策

1. 首批只回写四种已有实体的完成动作：`feed_cat`（喂猫）、`pick_parcel`（取快递）、`finish_homework`（写完作业）、`family_call`（和家里视频）。不做相机存款：它已有每周自动入账，口头再记一次容易重复记账。
2. 复用“她答应的事 / 挂着的事”在每段聊天安静 45 分钟后的那一次模型抽取，JSON 多一个 `world` 数组，**不增加模型调用**。只抽她自己的已完成事实；计划、将来时、猜测、玩笑、否定句和对方做的事都不算。
3. 每个动作必须带那句原话的本地分钟 `YYYY-MM-DDTHH:mm`，运行时还要和该片段里一条 assistant 消息精确对上；缺失、格式错、对不上、来自未来的都丢掉。模型只能做语义判断，不能凭空指定动作时间。
4. 动作全局写入 `<数据目录>/world/actions.json`，原子落盘。按“她的一天 + 动作种类 + 物品 / 课程”跨联系人去重：她把同一件事告诉两个人，只改变一次世界。重启后从文件恢复。
5. 推演仍以规则世界为底，动作只覆盖确实存在的对象：取快递不能凭空造包裹，写作业只能完成已有作业；喂猫和家庭视频用当天最后一次有效动作。动作在说出时刻之后才生效，并继续影响以后几天（如猫粮减少）。
6. 一个 `WorldState` 给所有入口共用：每个联系人的时间块、主动消息、同学档日记都读取相同动作，再由各自角色卡裁掉不可见部分。`state.json` 在新动作落地后立即刷新。

## 安全边界

- 回写的是她已经发出去的陈述，不是让模型替她决定接下来做什么。
- 不把任意聊天文本直接当命令；抽取结果必须通过动作白名单、时间锚点和实体存在性三层约束。
- 日记仍按同学档可见范围写；全局动作不会绕过 ADR 0003 的披露分级。
- 世界动作和情绪分开。动作是事实；是否因此高兴、担心或累，留给“情绪惯性”单独定。

## 后果

- 她说过的完成事实不再只是一句台词，会成为之后所有视角共享的生活状态。
- 回写要等片段结束（最多到安静 45 分钟后的同步），同一片段内原聊天仍在上下文里，不需要提前抽。
- W3 没有放开“凭说法创造新实体”：她说取了一个根本不存在的快递时，动作会留作审计，但世界不会生成那件快递。
