# ADR 0107：约他一起玩（主动时机 `invite`，配置 `proactiveInvite`，默认关）

- 状态：**已实现，未上线**（2026-10-22；配置 `proactiveInvite`；默认关）。上线 = `koishi.yml` 里加 `proactiveInvite: true` + 重启；回滚 = 改回 false + 重启（不存新状态，只多几条 `invite` 主动记录）
- 日期：2026-10-22
- 关联：[ADR 0011](0011-proactive-messages.md)（主动消息）、[ADR 0096](0096-share-and-filler.md)（随口说件事）、[ADR 0100](0100-reach-when-unanswered.md)（没回也继续）、[ADR 0101](0101-inner-life.md)（心里惦记）
- 用户提出：2026-10-22「继续开发新功能让她作为人」

## 差距

- 她主动找他的方式只有：问候（早安 / 下课 / 睡前）、报告自己的事（她那边的事、随口说件事）、问他的事（待跟进）、想他（心里惦记、催他）。**没有一条是“提议一起做点什么”**。
- 真人情侣的日常里，提议的一方不总是他：“今晚打不打游戏”“我的世界你上不上”。只有他提议时，她永远是接话的一方；这是少有的、卡上本来就写着的双向事实：
  - character 卡：「你和他有一个我的世界存档，这是你俩的固定节目。你爱在里面盖东西，会拉他去看自己盖的」；
  - 对话示例：「今晚王者双排吗 → 来，你跟紧我，别又一个人冲上去送」。

## 做了什么

1. **新的主动时机 `invite`**（`proactive.ts`；`withInvite` 在运行时加，**不改角色卡**，和 `withReach` / `withInner` 一样）：晚上 19:30 起 0–100 分钟之内的一个时刻（22:00 以后不约），一天一次；某一天想不想约按“联系人 + 日子”取哈希，周五到周日 60%、工作日 35%（平均一周两三次），重启不变。
2. **约什么只限卡上写着的固定节目**（`INVITE_ACTIVITIES`）：我的世界存档（权重 3）、开黑打王者（权重 2）。不编新活动、不编游戏里发生的事。
3. **不勉强**（全是代码规则，不靠模型自觉）：
   - 一周（任意连续 7 天）最多 3 次，两次之间至少隔 2 天；
   - 上一次约，他回的第一句（4 小时内）像拒绝（不了 / 不行 / 没空 / 改天 / 累了 / 在忙 / 有事……）隔 4 天；
   - 到点再查：他 3 小时内说过去忙 / 去睡了、在忙 / 累了 / 没空、或者已经在聊游戏，不约（第一轮模拟里他刚说“今天不行，在赶东西”，一个多小时后她又约了一遍）；他有“今晚”的待跟进事不约；一小时内聊过不约（和别的主动一样）；
   - 约出去他没回：**不催**（reach 不接这一条；这一条仍算“主动了一条他没回”，受 unanswered 节流）；
   - 提示词：随口约一句、他来不来都行、别勉强他、别撒娇逼他、别说“你不陪我”这类话；她自己很累 / 不舒服 / 心情不好就只输出「不发」（走 ADR 0100 的 `canDecline`，记成没发，不占名额）。
4. **优先级**：在睡前之后、随口说件事之前——名额不够时只挤掉“随口说件事”。
5. **他拒绝时她接得轻松**（`intent.ts` 的 `declinedHerInvite` → `DECLINED_INVITE_INTENT`，跟 `herNo` 同一个开关、男朋友档；他难过 / 很累时让给“先接住他”）：她上一串话是个邀约（开黑 / 双排 / 我的世界 + 问句）、他这一串是拒绝（不行 / 没空 / 在忙 / 改天 / 下次……，开头是“来 / 好 / 行”的算应了）时，意图是“说行 / 那你忙 / 下次，或顺着说自己去干点别的；别说‘我还等着你’‘你不陪我’，别追问为什么、别劝、别赌气、别再约第二遍”。第一轮模拟 3 次里有 1 次回了“哦，我还等着你呢”，带着让他有负担的施压。

## 没做 / 要注意

- 没有“约了之后真去玩”的状态：他回“来”之后聊天里她接着说，但她的生活账（world / schedule）不会因此变成在玩游戏。后续如果要做，是“他应了 → 她那一晚的几个钟头变成 `leisure`”，另起一条。
- 约的时间是“晚上”，不指定几点；是现在上还是等会儿，由聊天自然带出。

## 验证

- `test/proactive-invite.test.ts`（12 个）：`withInvite` 不动原卡、优先级；没开就没有；60 天里 16–36 天、时间在 19:30–21:10、两样节目都抽到、同一天每次一样；固定节目在卡上都有；周末比工作日多；任意 7 天 ≤ 3 次、间隔 ≥ 2 天；被拒后间隔 ≥ 4 天；`inviteDeclined` 只看约完之后他的第一句；到点再查的各个原因；没回不催（对照：别的主动没回照样催）；提示词；计划器带 `canDecline` 且“不发”记成 skipped。
- `intent.test.ts`：拒绝 5 种说法触发、应了 4 种不触发、她没约 / 没开 / 不是男朋友档 / 他难过 / 她只是说自己在玩，都不触发。
- 模拟（真模型，live 的形状开关和 herNo 全开，各 3 次）：`sim/invite-accepted.json`、`invite-declined.json`、`invite-ignored.json`。应了：「来了来了」「你选的谁」，自然；没回：之后只有睡前，没有催；被拒：加意图前 3 次里 1 次「哦，我还等着你呢」；加意图后 5/5 都是「行，那你忙」，再自己去干别的（「研究相机去」），没有施压。
