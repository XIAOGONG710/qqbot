# ADR 0028：情绪有来处，也有余温

- 状态：已实现并通过真模型验证，待上线（2026-10-07 21:48）

- 关联：[ADR 0015](0015-her-own-days.md)（每日心情）、[ADR 0018](0018-memory-fades-and-promises.md)（不保存情绪记忆）、
  [ADR 0021](0021-her-world.md)（她的世界）、[ADR 0023](0023-open-loops.md)（挂着的事实）、[ADR 0025](0025-her-body.md)（身体）

## 问题

原来的每日心情只按日期和课表抽一次。她即使痛经、感冒、昨晚没睡够，提示词里也可能同时是「爱笑」「话痨」；对方刚刚抱抱、道歉，下一轮又会像什么都没发生。身体和经历虽然都在提示词里，却没有真正成为心境的原因。

作者裁决的边界也必须守住：跨天可以存「发生了什么」，不能存「她很委屈」这种情绪标签。真人的情绪会延续，但不是再建一本永久的情绪账。

## 决策

### 1. 当下底色由事实落地

仍先按日期和课表抽每日心情；正常运行时，再用当前事实把高能量底色压到「安静」，并换成真实原因。优先级如下：

1. 身体：痛经、感冒、早八缺觉、深夜困、课多后的疲惫；
2. 明确的现实压力：猫粮用完导致没喂成土豆、24 小时内到期但未完成的作业；
3. 原来的课表 / 放假加权和日期抽样。

只采用不需要猜测正负的事件。普通下雨、宿舍小事、NPC 互动不擅自判成开心或难过。饥饿仍只影响身体和说话劲头，不把整天改成坏心情。模拟器显式指定的心情不被覆盖，便于 A/B。

这不是新的持久状态：每轮都从日期、时间、身体和世界事实重算。同一天对所有人是同一个生活底色；生理期细节仍按角色卡档位裁剪。

### 2. 未了事实产生余波，但不保存情绪

`unsettled` 仍只落盘客观事实，例如「说好一起看电影，最后没看成」。放进当前提示词时，告诉她这件事会让语气留一点余波，不必假装完全没发生，也不准主动翻旧账。

如果对方此刻已经明确道歉或安慰，修补动作优先：事实尚未被后台抽取判定为 resolved 也不能让她机械地继续绷着。跨天文件里从始至终没有「委屈」「生气」等字段。

### 3. 对话里的温度保留三轮

从眼前原话识别三类明确的正向信号：

- 修补：对不起、抱歉、我错了等；
- 安慰 / 关心：抱抱、我在、早点睡、好好休息等；
- 亲近：我想你、爱你、亲亲等。

触发后，这股余温影响接下来的三次完整回复；连续气泡算一轮，第四轮自动消退。它只从最近聊天重算，不另建文件，重启也不恢复一个脱离原话的情绪数值。普通的「嗯」「哦」「行」不做负面推断，避免模型凭空认定对方冷淡。陌生人和名单外档不启用这层亲近惯性。

提示词只说「自然软一点、接住好意」，同时禁止解释机制、郑重道谢和突然煽情。

## 没做的事

- 不保存跨天情绪值，不给关系做隐藏加减分，不从一句「哦」推断冷淡。
- 不让普通天气和任意小事自动决定喜怒；以后若世界事件需要情绪方向，应在资料层显式标注，而不是靠关键词猜。
- 负面冲突的 2–3 轮惯性暂不从原始聊天做规则识别；已有的客观 `unsettled` 足以提供安全余波，贸然识别讽刺和敷衍更容易冤枉人。
