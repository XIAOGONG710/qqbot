# ADR 0245：手机伴侣审核 AI 生活照草稿

## 决定

手机伴侣协议增加四类消息：读取草稿列表、返回列表、提交审核决定、返回审核结果。它们全部经过原有 `CompanionGateway` 的一次性配对、会话绑定、时钟窗口和 nonce 防重放检查，并进入 `CompanionRuntime` 的同设备串行队列。

列表只允许返回草稿编号、类型、状态、中文说明、时间以及短期缩略图 `mediaId`。协议验证器严格拒绝额外字段，因此宿主不能误把含有原图路径、提示词、事件键、模型名或密钥的完整索引直接返回手机。缩略图不接受 URL 或路径，必须复用已有的设备归属媒体仓库。

通过和拒绝都要求请求携带字面量 `confirmation: "confirmed"`。Android / PWA 应只在用户看过确认界面后生成该请求。宿主的 `onPhotoReviewDecision` 回调负责状态修改和写入现有审计记录；回调成功前不缓存结果，临时审计故障可用相同 `requestId` 和新 nonce 重试。回调结果必须与草稿编号和预期状态一致。

bot 宿主已经接入这两个回调：列表从同一份草稿仓库生成安全摘要，并在每次预览时重新核验普通文件、内容哈希和真实格式；不超过 1 MB 的预览放入当前设备专属的短期内存媒体仓库，过大的图片只返回摘要。审核决定复用草稿仓库与照片货架，并记录设备、请求编号和结果；成功后仍不会触发发送。

## 边界

- 本协议不生成图片、不自动通过草稿，也不发送 QQ。
- 配对只证明是已登记设备；产品界面仍必须显示明确确认，不得暗中填入确认字段。
- 宿主未注入列表或审核回调时失败关闭。
- 审核成功后的照片仍只进入既有照片货架；何时发送由 QQ 侧原有策略决定。
