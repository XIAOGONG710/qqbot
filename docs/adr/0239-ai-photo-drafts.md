# 0239：AI 生活照先生成草稿，审核后才进入照片货架

日期：2026-11-04

## 背景

现有照片货架能发送真实图片文件，但网络随机图经常与她当天吃的饭、天气和环境不一致；直接把 AI 图说成“刚拍的”也会放大穿帮和误导风险。自拍还涉及固定长相，当前没有作者确认的角色视觉设定。

## 决定

第一阶段只生成不露脸的日常照片：土豆、食物、书桌、窗外。提示词由已经存在的世界事实组成（时间、天气、普通地点、活动、菜名），禁止添加人物、脸、手、倒影、可读文字、精确地址和额外故事。

生成结果只进入 `<dataDir>/ai-photo-drafts/` 的待审核区，不自动进入回复，不自动发送 QQ。作者运行审核命令通过后，图片才复制到既有照片货架；既有发送频率、联系人边界和照片开关继续生效。拒绝的草稿不能再直接通过。

生图使用单独的 `QQBOT_IMAGE_API_KEY`，不复用聊天模型密钥。服务地址和模型分别由 `QQBOT_IMAGE_BASE_URL`、`QQBOT_IMAGE_MODEL` 指定；默认使用 OpenAI 图片生成端点。状态文件不保存完整提示词，只保存提示词哈希、模型、来源事件键和审核结果。稳定事件键负责防止重试导致重复付费生成。

## 操作

```powershell
$env:QQBOT_IMAGE_API_KEY = "..."
npm --workspace @qqbot/bot run ai-photo -- generate --kind cat --event "cat:2026-11-04:evening" --subject "土豆蹲在自行车棚旁边" --caption "土豆蹲在自行车棚旁边看落叶" --at "2026-11-04T18:20:00+08:00" --weather "阴，12°C" --place "宿舍楼下的普通自行车棚"
npm --workspace @qqbot/bot run ai-photo -- list --status pending_review
npm --workspace @qqbot/bot run ai-photo -- approve <编号>
```

## 暂不做

- 不生成她本人或他人的脸、身体和自拍。
- 不让定时任务自动生成或发送，避免费用失控和无人审核时误发。
- 不把生图供应商返回的错误正文写入日志。
- 不用 AI 图冒充新闻、证件、聊天截图或现实证据。
