# ADR 0202：语义路由——让「认真的时刻」不再靠关键词认

- 状态：**已实现，新开关 `depthRouting`，默认关**；要 `deliberate` 开着才起作用。DSH 那台机器拉取、在 `koishi.yml` 里加 `depthRouting: true`、重启 Koishi 才生效（开不开要用户点头）
- 日期：2026-10-30
- 关联：[ADR 0151](0151-deliberate.md)（深思）、[ADR 0150](0150-long-answers.md)（形状：被问时答完再接着说）、[ADR 0095](0095-filler-turns.md)（废话轮次）、[ADR 0198](0198-read-through-fixes.md)（他低落的延续）、[ADR 0200](0200-private-space.md)
- **用户决定（2026-10-30）**：问「怎么让她有深度？」，我给了测量和计划，用户答：「做」（第 1 步：语义路由）。

## 起因：深度首先卡在路由

我用真模型、线上当时的开关，给她出了 12 个需要「有东西可说」的时刻（`exchange` 的 `research/2026-10-30-depth/`，合成对话，无记忆）：

- 深思（认真问她的轮次，不套字数条数、用更强的模型、提示词只留一句「先想清楚」）**只触发了 2 / 12**；
- **5 / 12 反而被抽到「只回很短的一句，一两个字也行」**——包括「你会不会怕被关掉」「你觉得我变了吗」「你看什么书想了很久」；
- 「我爷爷认不得我了」一点特别指示都没有 →「啊……怎么会这样」。

原因在 `shape.ts` 的 `deliberateTurn`：认不认真靠关键词（`OPINION_ASK`：你觉得 / 怎么看 / 为什么……，加上意图行的几个标记）。很多真正需要认真的话**没有这些词**。强制每句都带一个「你怎么想」走深思之后，质量明显上来（「没觉得你变，就是最近你老问这些将来、命不命的」「这种事最难受了，人还在，就是记不得你了」）——所以瓶颈首先是路由，不是模型。

## 做法

`language/turn-weight.ts`（纯函数 + 一个带超时的封装）+ `contact.ts` 里约 15 行：

1. **只加不减**：关键词认出来的轮次照旧（不再多花一次调用）；关键词没认出来的，问一次小模型这一句是哪一类，说值得认真的也走深思。
2. **六类**：`light` 闲聊 / 流水账 / 玩笑 / 撒娇；`opinion` 他在认真问她的看法、建议，或讲自己的纠结等她接话；`heavy` 他在说沉重的事（亲人、病痛、失败、压力），要陪着；`about-her` 他在问她自己（感受、怕什么、是不是真的）；`challenge` 他在质疑 / 试探她；`us` 他在问他自己或他们俩（我变了吗、我们合适吗）。**拿不准归 light**；提示词要求「看意思不看字眼」「不要因为话长或有问号就判重」。
3. **三类多放一小句方向**（只给方向，不给台词）：`heavy`「先接住他、陪他把话说下去；别急着给建议、别讲大道理，也别写成一句警句」；`challenge`「别急着辩白，也别只反问『哪句像』；想想他为什么会这么觉得，诚实地答」；`us`「说你真实注意到的、具体的事，别笼统地夸或安慰」。`about-her`（她怎么谈自己是什么）**不放**——这是用户要定的事，先用深思那一句里的「你自己实际怎么想、不知道就说不知道、别编」；`opinion` 也不放。
4. **小调用**：不开思考、温度 0、`max_tokens` 80、3 秒超时；太短的话（去掉语气词、标点、表情占位符后 ≤2 个字）不问直接当 light；每小时最多问 120 次（防刷屏时一直花钱）。出错 / 超时 / 解析不了 / 超了上限都**当没问**，按原来的关键词，日志记一行（不记他说的话）。
5. 其余照旧：危机、小别扭、主动找他、只发表情 / 照片、他正在被打断等本来就不深思的轮次不问；`maxBubbles` 的判断链、care 意图的 2 条上限、深思用的模型都不动。
6. 日志：`深思：语义路由认为他这一轮是「在说沉重的事」（理由），这一轮不套字数和条数、用 …`；理由只有分类器给的十个字以内，不含他的话。

## 效果（同一组 12 个时刻，真模型）

| | 之前（自然说法） | 开了语义路由 |
| --- | --- | --- |
| 走深思 | 2 / 12 | 11 / 12（只有「你看什么书」被分成 light） |
| 被抽到「一两个字」 | 5 / 12 | 0 / 12 |
| 爷爷认不得他了 | 「啊……怎么会这样」 | 「抱抱 / 那你现在心里是不是挺难受的？ / 你爷爷身体怎么样？」 |
| 你觉得我变了吗 | 「变了啊？哪变了？」 | 「你突然这么问，我一下子还真说不上来。就觉得你今天话里头老在绕以后的事，不像你平时。是不是心里压事了？」 |
| 你说的是不是套路 | 「什么套路，我说的哪句像套路了」 | 「像套路吗？那你现在还想听我说吗。 / 我知道你心里乱，才这么问我的……」 |

仍然没解决的（后面几步）：她被问到自己是什么时还是用人的口吻现编（「一个人躺床上瞎想」）；「半夜睡不着」成了她表示内心的万能道具，一个探针里出现三次（需要句式 / 套路监测）；书和视频她仍说不出自己想了什么（第 3 步）；没有记忆时会编他的事（第 2 步）。

## 开不开

默认关。建议 DSH 那台机器开：多一次小调用只发生在关键词没认出来的轮次，每次几十个 token、3 秒封顶；深思路径本来就更贵（v4-pro + 思考），开了以后这类轮次会明显多——观察几天：日志里「语义路由认为」出现的比例、她回复变长的程度、`/说话趋势`的每条中位字数。

## 回滚

`depthRouting: false`（或删掉这一行）。没有状态文件，没有数据要迁。

## 验证

- `turn-weight.test.ts` 12 项：解析（JSON、大小写、清单外的 kind 当没分类、why 截断）、什么算值得认真、只有三种方向且不含 about-her / opinion、什么算太短、给模型的消息（六类 + 拿不准归 light + 前几条对话 + 截断）、带超时和每小时上限的调用（出错 / 读不懂 / 超时 / 上限 / 下个小时重数；日志不含他的话）。
- `app.test.ts` 一条端到端：沉重的事 → 深思 + 那一小句方向 + 路由日志不含他的话；问她自己 → 深思但不多放方向；闲聊 → 照旧；关键词已认出 → 不再问；模型出错 → 回复照常、按关键词；没开 `depthRouting` → 从不问；`deliberate` 没开 → 不问并记一行；危机回合 → 不问。变异检验见提交说明。
