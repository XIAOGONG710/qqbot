# ADR 0251：人格与生活深化共用事实层

日期：2026-11-04

## 决策

长期人生线、自主决策、关系阶段、主动分享、连续情绪、审美观点、生活创作、共同经历、成长反思和人格一致性评测，不各自保存一套“当前人格”。它们统一从生活事件账、聊天记录与 `human-values` 的同一时刻投影重算。

1. 人生线只统计九十天内有证据的学业、摄影、人际、自我照顾和创作事件；没有事件就没有进展。
2. 自主选择只改变柔性安排，身体恢复、硬日程和安全规则仍优先。
3. 关系阶段同时看亲密、信任、熟悉、依恋、摩擦与真实修复信号，不用一句道歉把余波清零。
4. 主动分享只从尚未标记已见的成功生活事件中挑；私密事件、低电量和不合时机时按住。
5. 审美只从她自己明确说过的话形成，不能拿用户偏好冒充她的观点。
6. 日记、照片、语音和动态只生成绑定真实事件编号的待审核意图，不自动发送或发布。
7. 共同经历只投影类型、计数与时间，不复制私聊正文；反思只来自失败、打断、后来成功、身体负荷或关系修复。
8. QQ 提示词只收到自然语言行为底色；状态页与 DSH 只收到枚举和计数摘要，不含原文、事件正文或内部评分。
9. `eval:personhood` 检查重复、助手腔、稳定立场突变和无世界账依据的经历声明；输出只含计数和比例。

## 边界

这一层不能创造生活事实、替她写观点、自动发布内容或绕过既有确认门。模型临时说过但没有进入受控证据源的内容，不能反向改写世界账。
