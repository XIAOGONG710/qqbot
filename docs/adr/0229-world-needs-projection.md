# ADR 0229：需要状态进入世界快照

状态：已实现。

## 决定

把现有 `needs.ts` 的版本化锚点投影接到 `WorldNow`。世界不再另存精力、饥饿和压力，而是和生活执行器一样，根据同一锚点、同一份生活事件账和当前时刻重算。写入 `state.json` 和世界摘要时可以看到这三个值，便于审计“行动为什么这样选”。

## 边界

- 没有 `autonomousLife` / needs 锚点时，`WorldNow` 保持旧形状；
- 投影失败只记录日志并省略 `needs`，不阻塞聊天或改写事件；
- 事件结算、规则版本和数值范围仍由 `life/needs.ts` 唯一负责；
- 原始分数不直接写进角色提示词，聊天侧继续由 `human-values.ts` 转成自然语言状态；
- 这是只读视图，不会反过来修改锚点或生活账。

## 目的

此前生活执行器已经用需要值决定“先休息 / 先吃饭 / 暂缓项目”，但世界快照没有同一份事实。接入后，行动选择、`state.json` 和摘要都能对上同一时刻的身体状态，重启和回放仍保持一致。
