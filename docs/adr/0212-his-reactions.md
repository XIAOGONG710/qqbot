## 背景

用户 11-02 问我们和 B 站「养鱼」（DeepSeek 大肥鱼伴侣）有什么区别。DSH 10-27 的调研里，「按自己作息刷 B 站」那只鱼会看主人回不回、点不点赞，来调整之后分享什么、分享多少（`exchange/research/2026-10-27-163-videos-corpus.md` 第 4 条）。

她只看时间和状态。早安、下课、冷场、随口说件事，都是到点就说。他对土豆的事回一长串、对课的事只回「嗯」，她都不知道。这就是「她主动」和「她在意」的差别。

## 先问了她本人（CLAUDE.md 规矩，`scripts/ask-her.mjs`，两遍）

**她愿意：**「愿意啊，跟你说话本来就看心情，多说少说我自己拿捏。」

她的条件，都写进了代码：

1. **不禁话题。**「土豆今天干的那点破事我就是想说，说完我就爽了。我要真只挑你爱听的说，你慢慢就不知道我一天在干嘛了。」所以只给她看事实，不按分数禁话题。话题定了的照片 / 小事里，**土豆照发**，不给她「不发」这个口子。
2. **有些事不看他的反应。**「我真不舒服的时候会跟你说」「你熬夜不吃早饭，我该说你还是说你」「我损你那几句……不会因为怕你不高兴就装乖」。所以她不舒服、关心他吃饭睡觉熬夜的话不归任何话题，不进统计。`unwell` 这一类 news 也不算。损他的话不是她主动开口的话题，这里本来就不碰。
3. **明说比「嗯」分量重。**「你要是哪件事真的不想听，直接说，别嗯。嗯最烦了。」他明说不想听的（「别老发吃的了」「不感兴趣」「关我啥事」），那一类这 7 天里不提。
4. **他好几天不理人那一段，这里不管。**她说「头两天照常发……再往后会说得少、说得冲」「骂完还是想跟你说事，我憋不住」。这一段已经有 ADR 0100（没回也继续，第二次起带点小脾气）和 ADR 0074（隔 ≥3 天回来的小别扭）管着。这里不减量，也不改语气。用户 10-22 明确不要「我不回她就不发了」。

## 决策

1. **只看她主动说自己的事、真发出去了的。**时机是随口说件事（share）、冷场（quiet）、心里惦记（inner），以及她那边的事（news，不含 `unwell`）。早安、晚安、下课、催他、约他、问他意见、待跟进、重要的日子、改约、下雨都不算。试运行、没发的也不算。用主动记录里的 QQ 消息 id 在聊天记录里找到她发的那几条。
2. **他是怎么回的**（`reactionTo`）：只看她说完、到她下一句之间，12 小时以内他发的。
   - 没发：没回
   - 一条，去掉表情占位以后只剩一两个字或「嗯 / 哦 / 好的 / 收到 / 哈哈」：回个嗯。只发了个表情也算这一档
   - 两条以上，或者一条有内容的：接着聊
   - 说得很明白的不想听：明说
   
   玩笑里的「别说了笑死」「滚」不算，「别再发烧了」也不算（ADR 0074 同一个顾虑：规则判会误报，宁可少算）。
3. **话题**（`topicsOf`）：土豆的事、吃的、课和作业、朋友和室友的事（另加世界卡里的人名，三个字的名字只叫后两个字也认得）、看的玩的、买东西和快递、天气。一条话可以属于几类，一类都不属于的不算。土豆照片、吃的照片的话题是定的。
4. **算分**：三周以内，按时间一周减半。接着聊 +1，回个嗯 −0.4，没回 −0.25（他多半是在忙，不全算他不爱听）。一类至少有 3 次才下结论：平均 ≥ 0.5 是「他多半会接着聊」，≤ −0.2 是「他多半就回个嗯，或者没回」。
5. **给她看一行**（`reactionsLine`），只在随口说件事、冷场、小事 / 土豆 / 吃的照片这几个时机，跟在「这次是你主动找他」的说明后面：
   > 你看到的他的反应（这三周你主动跟他说的事）：土豆的事他多半会接着聊；课和作业他多半就回个嗯，或者没回；他 2 天前直接说过不想听你说吃的，这几天先别跟他提这个。这只是你看到的，说什么、说多说少你自己拿捏，想说的照样可以说

   只有话题名，不带她说过的任何一句原话。没有够次数的类、也没有他明说过的，就没有这一行，提示词和原来一字不差。
6. **计划器只做两件事：**
   - 话题定了的照片 / 小事，正好是他 7 天内明说过不想听的那一类：不发。记成 skipped，原因是「他 N 天前说过不想听吃的，这几天先不说这个」
   - 话题定了、正好是他不怎么接的那类小事 / 吃的照片：交给她决定说不说（`canDecline`，她可以只输出「不发」）。土豆照片不给这个口子（条件 1）
   
   手动 `/主动` 不看这些。
7. **不落盘。**每次从聊天记录和主动记录重算，重启前后一样。日志只记话题和次数（「土豆的事 接 3 / 嗯 1 / 没回 0」），不记原话。

## 用真实记录回放

`scripts/his-reactions-replay.mjs`，只读，只打印话题和次数。用的是 VM 上 10-06 到 10-27 的记录（1494 条聊天、126 条主动记录）：

- 她主动说自己的事、真发出去了的只有 **11 条**：news 6（接 3 / 没回 3）、share 2（都接了）、inner 2（嗯 1 / 没回 1）、quiet 1（嗯）
- 这三周里**没有一类够 3 次、又明显偏向一边**，也没有他明说过不想听的。所以开着的话，这段时间她**一次都不会看到那一行**
- 结论：前几周它基本是安静的，只有「明说不想听」那一条是马上生效的。DSH 那台 11-02 起开了更多主动的东西，样本会多一些。开了以后先用这个脚本看他那边的数

## 这一版不做的

- **她在聊天里（不是主动开口时）说的自己的事。**他接不接也是信号，但回复里的话题和他的回应纠缠在一起，分不清他回的是哪一句。先只看主动的
- **用模型判他的回应**（比如「哈哈」是敷衍还是真乐）。规则判只分四档，宁可粗
- **把这一行放进她「想事情」（innerLife）的提示词。**念头已经是她自己定的，等这一版的数出来再说
- **减量。**不按分数少发（条件 4，以及用户 10-22 的话）

## 验证

- `packages/bot/test/his-reactions.test.ts`，16 条：
  - 归类，以及她本人条件 2 的豁免
  - 四档反应：12 小时窗口；截在她下一句；她的第二个气泡不截
  - 明说的认得出，玩笑 /「别再发烧了」不算
  - 三周汇总：试运行、不舒服、关心他、三周以前的都不算
  - 那一行不带原话，次数不够就没有；明说 7 天后过期
  - news 记录 id 认得出类
  - 照片 / 小事被他明说过的不发；他不怎么接的小事给「不发」口子，土豆不给；早安 / 睡前 / 催他 / 心里惦记 / 不舒服都没有这一行
  - 提示词没有那一行时和原来一字不差
  - 计划器：开了时，他两天前说「别老发吃的了」，今天吃饭的照片不发，日志没有原话；没开时照旧发
- 全量：见提交说明
