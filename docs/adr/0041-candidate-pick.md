# ADR 0041：他难过、说亲密话、收尾时挑候选

- 状态：已实现，模拟器 A/B 见下（2026-10-09）；线上默认不开（配置 `candidates: 1`）
- 日期：2026-10-09
- 关联：[ADR 0036](0036-conversation-naturalness.md)「不是只靠提示词的后续方案」第 3 层（候选选择）、[ADR 0006](0006-exit-check.md)（出口检查）、[ADR 0014](0014-speech-habits.md)（说话的毛病）、
  DSH 诊断 1.2、DSH 复核 ADR 0036 3.1、[长期执行计划](../plans/2026-10-08-long-term-execution.md) 第 12 节 P2「多候选选择器原型」

## 背景

ADR 0036 加严判据以后的两批（`p1008a`、`p1008b`，`conversation-naturalness` 各 3 次）里，剩下的毛病是模型在这三种时候稳定的倾向：
一轮说 3–4 句（合并成两条发出去）、回完他的话再补一句自己在追剧 / 喂猫、收尾约「写完跟我说一声」。
意图行再加限制会让她更僵（10-08 加「也不用约他忙完回来找你」之后，这一条从 3 次 2 次降到 3 次 1 次，其余没变）。

## 决策

1. **只在三种时候挑**：意图行是「先接住他此刻的情绪」（他难过）、「只接他刚说的你们两个人的事」（亲密话）、「顺着他的话收尾」时；她主动找他、别的时候照旧一次。
2. **同一份提示词并行生成 N 个**（配置 `candidates`，1–5，默认 1 = 不挑），清理之后按看得见的规则扣分，挑最少的，一样少挑先生成的：
   - 说的句数超过这一种的上限（他难过、收尾 2 句，亲密话 3 句，和模拟器的 `maxLines` 一样）：每多一句 2 分；
   - 扯到她自己生活里的东西（猫的名字、相机、在读的书、追剧、调色、构图、修片、摄影区）：每个 3 分；**他这次说到的不算**；
   - 客服式约定（「写完跟我说一声」「忙完找我」）：3 分；
   - 他难过时叮嘱作息、吃饭：2 分（收尾时叮嘱是她的性格，不扣，同 ADR 0036 的判断）；
   - 出口检查的问题每个 4 分、说话的毛病每个 2 分。
   挑中的再照常走出口检查（ADR 0006）。日志「候选 3 个，挑第 2 个（第 1 个：约「写完跟我说一声」；第 3 个：说了 3 句，扯到自己的「追剧」）」。
3. **不让模型给自己打分**（长期计划：不以 DeepSeek 单一评分决定胜负）：规则写在 `candidates.ts`，每次为什么挑这个都在日志里。
4. 默认不开：开了这三种时候是 N 倍的模型调用（并行，不加等待时间）。开不开问用户。

## 不做的

- 不在所有回合挑：别的时候的毛病（重复、助手腔）出口检查已经在管；全挑的成本是每轮 N 倍。
- 扣分的权重是拍的数，等 DSH 的真人聊天调研（`exchange/tasks/2026-10-09-dsh-real-chat-research.md`）回来再按真人的分布调（例如真人收尾时约「完事跟我说」到底多常见）。

## 验证

- `candidates.test.ts`：扣分、挑选、日志。
- A/B（`a8aaad0`，`conversation-naturalness` 各 6 次，同一时间跑）：

| 批次 | 回复检查 | 没过的 |
| --- | --- | --- |
| `20261009-001318-c1`（不挑） | 343 / 348 | 句数超了 3 次（3–4 句）；没有表里的关心词 2 次（「哭什么呀，摸摸头」「哎呀……一上午呢，光想想就累」，其实是关心，检查词没收） |
| `20261009-001355-c3`（挑 3 个） | 347 / 348 | 没有关心词 1 次：「一上午啊，那不得饿死在里面 / 不过你哭什么，又不是我让你去的」——这是真没接住，规则判断不了语气 |

  24 次挑选里 6 次没挑第一个或者淘汰了有毛病的：淘汰的理由是说了 3–4 句、扯到自己的「追剧」「土豆」、他难过时叮嘱作息。「写完跟我说一声」这两批都没出现（10-08 改了收尾的意图行之后）。
- 还挑不出来的：语气（损他、不当回事）。这类等 DSH 的真人调研回来，看嘴硬的女生接情绪第一句一般怎么接，再定要不要加规则。
