# ADR 0145：她刷自己的好友动态，看到宝宝发的说说

- 状态：**已实现，未上线**（分支 `claude/qzone-cookie-shape`，在 `dsh/qq-control` 之上；开关沿用 `qzonePeek`，默认 `off`）
- 日期：2026-10-25
- 关联：[ADR 0143](0143-qzone-peek.md)（原来的读法，已被本条取代）、[ADR 0142](0142-qq-account-control.md)、[ADR 0144](0144-qzone-strangers.md)、[ADR 0083](0083-presence.md)、[ADR 0085](0085-napcat-probe.md)（先探针再上线）
- 用户授权：2026-10-25「先做 2（好友动态流），名单只放宝宝，然后尝试做 1（H5 版）」；「空友爱看在 QQ 客户端上」

## 背景：10-25 在这台虚拟机上跑了只读探针

DSH 的三版（0142–0144）按 NapCat 源码和文档写，全部没在真 QQ 上试过。探针（read-only，对腾讯共 5 个 GET，用她自己的登录态）的结果：

| 假设 | 实测 |
| --- | --- |
| `get_cookies` 返回数组 | 返回 `{cookies: 'k=v; k=v', bkn}`，cookies 是整串。原解析器取不到登录态（已修，见下） |
| NapCat 有 `get_qzone_msg_list` 等读空间动作 | 线上 NapCat 4.18.28 只注册了 `send_qzone_msg` / `delete_qzone_msg`；`get_qzone_msg_list` 只出现在删除动作的说明文字里。`qzoneBrowse` 的四个候选名全部落空 |
| 陌生人推荐流 `qzone_recommend` | HTTP 404，接口不存在 |
| 陌生人推荐流 `emotion_cgi_re_feeds` | HTTP 200，`ret:1034 非法请求`（接口在，缺参数） |
| `feeds3_html_more` 是好友动态 | HTTP 200、`code:0`、69 KB，**不是 JSON 而是 JS 对象字面量**；内容：她自己的 6 条说说 + 1 条广告（appid 6600，带 adinfo）。没有陌生人，也没有好友的 |

结论：网页版动态页读得到，也能解析，但里面没有「空友爱看」（它在 QQ 客户端里，是内测功能，把算法推荐的陌生人插进好友动态流）。

## 决策

1. **登录态**（`qzone-remote.ts`）：`cookieHeader` 认 NapCat 的真实形状 `{cookies: 'k=v; k=v', bkn}`，也认裸字符串和旧的数组形状；实测本地算的 `g_tk` 与 NapCat 给的 `bkn` 一致。
2. **读法**（`qzone-feeds3.ts`）：读她自己的好友动态流 `feeds3_html_more`，再挑出名单里这个人发的。**不进对方的空间，不留访客记录**——这比原来 0143 的 `emotion_cgi_msglist_v6` 逐人读法更轻，也不需要对方的空间权限。
3. **解析**：JS 字面量只用自写的小解析器（`parseJsLiteral`）：对象 / 数组 / 字符串（`\x` `\u` 转义）/ 数字 / true false null undefined，认不出的一律抛；**不 `eval` 一段来自网络的东西**。嵌套深度上限 40。正文在每条 `html` 的 `f-info` div 里，去标签、表情留 alt、实体还原。
4. **收谁**：只收 appid 311（说说）、有正文、`opuin` 在名单里。广告（appid 非 311 / opuin 0 / 带 adinfo）、没有正文的、她自己发的一律不收。
5. **名单**：`qzonePeek` 的目标 = `qqAllowFriends` ∩ 联系人。**上线时只放宝宝（2260168937）**；鸽鸽没被问过，不放。
6. **节奏**：沿用 10:00–22:00、醒着、两次至少隔 4 小时。新增：
   - 只当新鲜事看 **3 天内**、**没看过**的（`peekSeen`，最近 30 条 id），同一条不会每 4 小时被她「发现」一次；
   - 读不到（登录态 / 网络 / 风控 / 结构变了）**6 小时后再试**，不再「读不到就永久停用」——这台虚拟机断过 17 小时的网，一次断网不该让功能直到重启都是哑的；
   - 读到了但宝宝没有新说说（`[]`）不算失败，也不进提示词。
7. **提示词**：新鲜的最多 2 条、每条 ≤40 字，带时间：「你刷了会儿 QQ 空间的好友动态，看到宝宝昨天晚上发了「…」」。`describeSelf` 现在分两行：「[你在 QQ 上的样子（他点开资料卡、空间能看到的…）]」是她自己的；「[你刚才刷空间看到的（是别人发的，不是你发的；用不上就不提，没写的别编）]」是她刷到的别人的——原来混在一行里，措辞是「他能看到的你」，会让她把别人的话当成自己发的。6 小时窗口不变。
8. **隐私**：正文只进提示词，不进日志（日志只记条数）；`dryRun` 只写 `presence/drafts.md`（同一条不重复写）。

## 验证

- `qzone-feeds3.test.ts` 9 项：解析器（unquoted 键、单引号、`\x` `\u`、尾逗号、undefined；函数调用 / 标识符 / 多余尾巴 / 没结束的字符串 / 嵌套过深 / 坏转义一律抛）、正文提取（嵌套 div、表情 alt、实体）、收谁（宝宝收，广告 / 没正文 / 她自己的不收）、`[]` 与 `undefined` 的区别、请求地址、`readFriendsFeed` 的成功 / 非 200 / 网络错误 / 结构坏。
- `qzone-remote.test.ts` +1 项：NapCat 真实 `get_cookies` 形状。
- `qzone-browse.test.ts`：带时间的说法、3 天内 / 看过的不再提、6 小时重试、`[]` 不进提示词、`describeSelf` 两行分开。
- 在真数据上：用保存下来的真实响应（她自己的 6 条说说 + 1 条广告）跑 `parseFriendsFeed`：不过滤自己时解出 6 条、过滤自己后 `[]`，广告一条没混进来。
- 类型检查（bot + 插件）干净；`modules.test.ts` 登记了新文件。

## 没做 / 要注意

- **没有看到过一条真的「好友发的」说说**：10-25 的响应里只有她自己的和广告，所以好友那一路（`opuin` ≠ 自己）用合成数据测，配图块（`img-box`）和转发说说的结构没有真样本——数不准配图不影响正文；转发说说若 `f-info` 里只有转发语，也只收转发语。宝宝是否常发说说也不知道，开了之后可能长期是空的。
- 没有读「空友爱看」：它在 QQ 客户端里，这条网页流里没有。H5 版（`h5.qzone.qq.com` 的 `getActiveFeeds`）另做一轮探测，结果写在 [ADR 0144](0144-qzone-strangers.md) 的 10-25 补记里。
- 好友动态的广告：本条直接丢掉；0144 的通用解析器会把广告当「陌生人说的话」收进去，所以 0144 不能直接用 `feeds3` 的返回。
