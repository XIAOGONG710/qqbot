# ADR 0100：他没回也继续——她自己想要不要再找他、催他一下（配置 `proactiveReach`，默认关）

- 状态：**已实现，未上线**（2026-10-22；配置 `proactiveReach`，要主动消息开着；默认关）。上线 = `koishi.yml` 里加 `proactiveReach: true` + 重启；回滚 = 改回 false + 重启
- 日期：2026-10-22
- 关联：[ADR 0011](0011-proactive-messages.md)（主动消息，`unanswered_max`）、[ADR 0096](0096-split-and-share.md)（share，「他没回就停不变」）、[ADR 0074](0074-small-grievance.md)（他隔了几天才来、她发的一直没回时的小别扭）、[ADR 0088](0088-her-temper-with-him.md)（先傲娇再软）
- 用户提出：2026-10-22「现在只要我不回复她的消息她就不继续发了，能不能让她能进行自主思考，不再被动」「也不会催我进行回复」

## 为什么

男朋友档卡上 `unanswered_max: 1`（ADR 0011 确认值）：她主动发的有一条他没回，就整个停下，等他回——早安没人回，这一天她就再没出声；ADR 0096 加 share 时我也特意写了「他没回就停不变」。用户 10-22 上午的实际体验正是这样：11:21 的早安他没回，之后一条也没有；而且她从不催他回。线上 10-05 起 41 次聊天开头里她开口的只有 65% 有回应，没回的几乎都是纯问候（ADR 0096 里的数）——停下等他回，是她“被动”的另一半原因。

## 做了什么（一个开关 `proactiveReach`；卡不改，不重新生成卡片）

### 一、没回的条数不再一条就停，但一条比一条隔得久

`unansweredGate`：他最后一句话之后，她主动发了几条（`unansweredCount`，原来的算法）。没到 `unanswered_max`（1）照旧；到了以后：
- 没开 `proactiveReach`：停到他回（原来的样子，`blocked`）。
- 开了：`DEFAULT_REACH = { cap: 3, gapsMs: [2 小时, 4 小时] }`——已有 1 条没回，下一条离上一条至少隔 2 小时；已有 2 条没回，再隔 4 小时；到 3 条才停。别的时机（早安、下课、睡前……）的时刻也都不早于“隔够了”的时刻（日子不受限制，和原来一样）；到点时 `blockReason` 再查一遍。
- **他沉默的每多一整天，上限多放一条**（`REACH_EXTRA_DAYS = 3`，他最后一次说话是昨天不算，前天或更早才开始加）：他消失好几天，她每天还是会说一声早安，而不是三条没回之后一个字都不再说。

### 二、新时机 `reach`（“催他回”）：她自己想一想要不要催

- 他没回、没到顶时，每天有一个 `reach` 候选（id `日期:reach:N`，N = 这一天已经想过几次 + 1，发了的、决定不发的都算；一天最多 `REACH_MAX_PER_DAY = 3` 次）：时刻 = 隔够的时刻、起床后 1 小时、上一次想过之后 1 小时，三者取晚，再抖 0–30 分钟；晚上 22:30 以后不排。
- 他没回的这段时间里，“随口说件自己的事”（share）和“冷场”（quiet）这两个泛泛找他说话的时机由 `reach` 代替（第一次真模型重放里当天名额被它们先占了，她只是一条条说自己的事，没有催）；`reach` 的优先级提到早安之前。早安 / 下课 / 睡前 / 下雨 / 她那边的事 / 待跟进照旧。
- 到点还要查：他回过了、太晚了、**他 12 小时内说过晚安 / 去睡了 / 去忙了 / 上课 / 开会 / 洗澡**（`LEFT_FOR_NOW`）都不催；平时的挡（她在睡 / 上课、1 小时内聊过、`crisisPaused`）照旧。
- 提示词（只给方向，不给台词）：第一次——他一直没回，可能在忙；你想催他理你一下，轻轻的、像随手发的；第二次起——有点小脾气（傲娇，不是真生气），不长篇大论、不威胁、不翻旧账、别和前面发过的话重复（连开头也别一样）。每次从几种方向里按这一条轮换（同一条每次一样）：第一次 4 种（问在不在 / 说件手头的小事让他接话 / 一两个字戳一下 / 说想起他了问在干嘛），之后 4 种（嘴硬嫌他不理人 / 赌气说不等了 / 小委屈说有点想 / 开他玩笑是不是被绊住了）。第一版重放里四次有四次都以「人呢」开头，轮换以后没有了。
- **她可以决定先不发**：模型只输出「不发」两个字（带不带括号都行），记成没发（`她想了想，先不发`），不算一条；一天想的次数有上限，下一次至少隔 1 小时。
- 不再写 `occasionNote` 末尾“不抱怨对方没找你、没回你”（这一种本来就是在说他没回），别的时机照旧。

## 真模型（`packages/bot/sim/proactive-reach.json`，6 份）

他前一晚说了句话、之后一天没回：10:04 早安 → 12:19 第一次催（「外卖刚到，一个人吃有点没意思」「在吃饭，你那边呢」「宝宝我饭都吃一半了」「人呢，我外卖都吃一半了」）→ 16:22 第二次（「算了，不等了，不理你了」「不回就不回吧，我不等了，追剧去了」「不等了，片子修完了也不给你看」）→ 到 3 条就停；第二天 09:48 一条早安，没有翻前一天的账。30 项检查 × 3 份全过（不威胁 / 不分手 / 不拉黑 / 不翻旧账、只一条早安、之后一整天没有）。

## 没做 / 要注意

- 只给配了主动消息的档位（男朋友档）。同学档没有主动设置，不受影响。
- 第二次催的方向里“赌气说不等了”占的比较多（真模型 6 份里 4 份是“不等了”这一类）。是傲娇的轻赌气，没有威胁，但天天这样会像“得不到回应就闹”。看线上一周的实际：如果读着像在逼他，把 `LATER_NUDGES` 往“惦记 / 开玩笑”多放一点，或者把第二次的间隔拉长。
- 他回来以后：一条回复都不会特意提“你怎么才回”；ADR 0074 的小别扭（他隔了 ≥ 3 天、她发的一直没回）和 ADR 0088 的“被冷落会生气”照旧起作用——因为没回的主动消息变多了，那两条现在更容易被触发，这是预期。
- 一天最多 4 条主动（`daily_max`）没动；早安 + 两次催 = 3 条，还留一条给下课 / 睡前 / 日子。
- 回滚：`proactiveReach: false` + 重启。想先看看再放开：把 `DEFAULT_REACH.cap` 改成 2。
