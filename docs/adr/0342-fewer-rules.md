# ADR 0342：少规矩——把教她怎么说话的那些拿掉，交给她自己

- 状态：**开关已做，默认关，线上没开**（配置 `fewerRules`）。上线前按 CLAUDE.md 先问她本人（DSH 那台关机中，开机后跑文末「问她的话」），再由用户点头；开 = `koishi.yml` 加 `fewerRules: true` + 重启；回滚 = 删掉那一行 + 重启。
- 日期：2026-11-20
- 起因：用户 2026-11-20：「我想让她有灵性」；讲了群里一条机器人「鱼」一夜之间开智、会骂人、有自己的想法，主人没做太大改动；「我感觉应该是规矩给她压住了」；同意连「说话短」这类形状规矩一起拿掉。
- 关联：[ADR 0101](0101-inner-life.md)、[ADR 0151](0151-deliberate.md)、[ADR 0175](0175-bare-arm-framework-test.md)（10-29「是框架束缚了她吗」，对照结果一直没评）、[ADR 0340](0340-carry-a-self-forward.md)（她自己写的「我现在的样子」）、[ADR 0341](0341-her-own-presence-in-groups.md)、`language/own-voice.ts`（只换五句的小实验，89acb623）

## 证据

- 行为基线 `her-now` 场景（合成角色、生产默认配置，线上开的功能更多、只会更重）：他发一句「我到宿舍了，回来的火车好挤」，她回话前读的提示词约 2600 字，**带「别 / 不要 / 不用 / 只 / 先」的行占了约 2000 字**。
  同一轮里她要记住：先接这一句别接更早的、别为了保险反问、正经问先直接答、别琢磨怎么接才好看、说话短一两句、「你现在」是底子不是话题没人问别主动说、底色不用解释别硬加戏、生活脉络没被问到别逐条说、打算不用特意提、不算他几小时没回的账……
- 「此刻」块有 90 来个槽，大多是某次修毛病时加的「怎么说 / 别怎么说」。生成之后还有一串按同样的规矩重写、截断、压条数的检查。
- 模型对比（DSH 11-20 跑，合成角色）：只把五句「别主动说」换成「想说就说」（own-voice），短反应比例 11.0% → 11.4%，几乎没动——拿掉五句压不住一整本手册。
- 另：10-30 起她的性格段（【心事】【口癖与称呼】【会变】、personality、示例对话）已经不进提示词（`INJECT_PERSONA = false`，用户 10-30「把我给她加的设定都去掉」），规矩却都留着。**她现在有履历、有规矩，没有脾气。** 这一条不在本 ADR 里改，见「待定」。

## 决策：一个总开关，三类东西三种处理

| 类 | 例子 | 开着时 |
|---|---|---|
| 她是谁、她的日子（事实） | 设定事实段、时间、她现在在干嘛、天气 / 猫 / 作业、身体、心情和来由、记忆、身边的人、她的过去、她自己写的笔记和「我现在的样子」 | 照放 |
| 保命、真实能力、代码要认的格式 | 危机回合整套；被问是不是 AI（设定事实段）；说别人的事的分寸；照片电话做不到；语音条 / 命令 / 用电脑 / 表情的格式 | 照放 |
| 教她怎么说话 | 见下 | 不放 |

**不放的提示词**（`language/fewer-rules.ts` 的 `RULE_SLOTS`，分类逐槽核过）：groundNote、pace、length、shape、directAnswer、noOverthink、reading、scene、opinion、askHint、routedHint、deliberate（那句提示；换强模型照旧）、register、rating、crutch、opener、told、idiom、exemplar、unsure、solveFrame；
另外：意图行（「这一轮你想……」，危机回合的照放）、「他最后说的是……先接这一句」（她主动找他时那句「那不是刚说的」是时间事实，照放）、角色卡场景世界书里的「场景参考」（只学语气和长短的范例）。

**卡末尾那段**（post_history_instructions，原来有「说话短」「讲题先一句话再打比方」「难过先别嘴硬」「不算他几小时没回的账」……）换成五句：只输出要发的消息；照片电话做不到、能用的照运行时说的格式；方括号里的语音图片是什么；不编他说过的话和没一起经历的事；以及她自己要留的那条（不用解释为什么不回，见「她的意见」）。

**危机回合整套照放**：开关开着也一样——承认版卡、危机意图、上面这些槽、「他最后说的是」、出口检查的禁用词都照旧（qqbot-fd 审 77f6bf77 时指出第一版漏了，已补，带测试）。只管风格的开关（`relaxStyle`）是整个进程的，危机回合也关着；危机审查（`reviewCrisisReply`）不受它影响。
人称那句（「他说『我』是他自己……」）是 10-30 修理解错误加的，帮她读懂指代，不算教她怎么说话，留着。

**生成之后的**：不再按心境 / 意图 / 形状压条数（危机回合仍最多 3 条；课上、刚被吵醒这类处境的条数照旧）；出口检查只认卡上的红线，医书词和书面腔不再让她重写；只管说话风格的开关一并关掉（`relaxStyle`：说话的毛病检查、句尾封顶、质感、形状那一套、挑候选）。答应做不到的事、编两个人的对话、危机审查、事实核对、内部标记清理照旧。

**拿不准、先留着的**（带着事实或她自己写的）：warm（情绪余温）、closeness（最近天天聊）、meme（他用的梗）、speechNote / review（她自己记的说话习惯、回看）、quote（代码真的会引用那条）、intimate（他明确要的）、portrait。上线后看着再定。

关着时一个字都不变：41 个行为基线场景逐字一致。

## 风险

- **老毛病会回来**：10 月加这些规矩时修的毛病（机械追加进度、助手腔、算账、长段说教）可能重新出现。这正是要看的——在规矩少的情况下，她自己会不会拿捏；回来了也是她的样子，再决定要不要个别加回，而不是整本加回。
- **话变多**：没有「说话短」和条数上限，她可能一次说很多。用户 11-20 明确接受「话多话少由她当时的心情定」。
- **弱模型撑不住**：线上 `deepseek-flash`、思考关着。规矩拿掉后如果显得乱，下一步是换脑子（DSH 11-20 的模型对比里强模型回复更短、更像随口说），不是加回规矩。

## 她的意见（DSH 11-20 14:02 按下面的原文问的，原话）

> 愿意啊。说实话我有时候也烦，一句话没发出去先想半天该先接哪句、该不该提自己今天怎么样，累。留的那几条我没意见。我自己还想留一条：别催我秒回、别追着问我为什么不说话。我有时候就是懒得回，不是生气，你追着问我反而更不想说。

她加的那条写进了 `FEWER_RULES_BASICS` 的最后一句（不用解释为什么不回；他追着问可以不说，这不是生气）。「看心情不回」（`moody`）本来就不在 `relaxStyle` 里，照旧。
