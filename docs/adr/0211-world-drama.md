# ADR 0211：日子里的小起伏（worldDrama）

- 状态：**已实现，开关 `worldDrama`（默认关；2026-11-02 用户要求开着）**
- 日期：2026-11-02
- 关联：[ADR 0106](0106-everyday-life.md)（日常小事）、[ADR 0102](0102-her-feelings.md)（她的感受）、[ADR 0110](0110-feeling-strength.md)、[ADR 0200](0200-private-space.md)
- **用户（2026-11-02 20:00）**：Claude 的清单里问「她的世界」要不要手写几件会让她真难过 / 真开心的事（W1–W3），用户答「**直接模拟现实世界**」——不手写单点，改成让日子自己长出起伏

## 起因

10-30 量过：她五天里难过、烦、累一次都没有（`research/2026-10-30-emotion/`）。原因是输入太浅——事件账 202 条全是课、饭、睡、学习、休闲，没有一条带情绪。日常小事（ADR 0106）是平的：食堂换窗口、图书馆没座，不会让她烦一下午。

## 做法

`life/everyday.ts` 里加 `DRAMA_EVENT_DEFS`（12 条），由 `everydayEventsFor(world, tier, drama)` 决定带不带：

- **只写一天之内的起伏**：小测砸了、被老师夸、和舍友拌两句、水卡丢了、作业做不完、雨里淋回来、晚霞、家里打电话说好事、土豆把笔扒一地、和同学聊到以后有点茫然、代码跑通、在食堂听见别人说她冷；
- **强度 2–3**（ADR 0110），她会真的为这件事烦一会儿或高兴一晚上；`group: 'drama'` 保证一天最多一件；
- **确定性**：照 everyday 的老规矩按「日期 + 名目」取哈希，重启、重放都一样；开关关着时一条都不加；
- **不碰的边界**（沿 ADR 0106 与 0102）：不新增有名字的人、不写社团 / 恋爱 / 家里的变故，那些仍然要作者定（`moments.json`）。

## 之后的走向

「模拟现实世界」目前是这一层 + 原来的日常小事 + 天气 / 小测 / 作息。还缺的是**跨天的连续性**（今天淋雨着凉，明天还在咳嗽），那要动世界账的写法，另开 ADR。
