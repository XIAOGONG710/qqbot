# ADR 0054：生活账接进提示词（第一步）——她这几天练拍照修图

- 状态：已实现，开关默认关（配置 `lifeInPrompt`）；等影子账满两整天再审一次（10-11 15:00 以后），干净再开
- 日期：2026-10-10

## 背景

ADR 0040 起，没人聊天时她按作息一件件过日子，过完记进事件账；到现在是影子模式：账只记，不进提示词。10-09 的计划（`docs/reports/2026-10-09-current-status.md` 建议的下一步第 4 条）：
影子行动账稳定观察两个完整生活日后，**先把「最近项目进展」以只读事实接入提示词**，再逐步接日记和状态行。这一块原来是 GPT / Codex 的，GPT 这周额度用完，Claude 做。

10-10 傍晚只读审计线上那本账（10-09 15:07 起）：12 件行动，0 重叠，和同一时刻的状态行 0 分叉，1 处空当（10-09 晚饭，原因和修正见 ADR 0040 调整：落在饭点中间也吃这顿）。

## 决策

1. 新配置 `lifeInPrompt`（默认关，控制台可开），要开着 `autonomousLife`（账是它记的）。
2. 开着时，看得到她爱好的档位（卡上有相机基金的：男朋友、闺蜜、女生朋友、普通朋友）时间块在「你那边」后面多一行：
   `[你这几天拍照修图（你自己过的日子，账上记着的；用不用、怎么说你自己定，没写的别编）：3 天里练了 2 回，加起来 2 个小时（拿新相机去校园里拍、研究新相机的设置）；上一回是昨天晚上]`
   只数已经落账的 `work_on_project`（摄影项目）；三天里一回都没练就不写这一行（不写「没怎么碰」，免得账刚开始几天把她说成荒废了）。
3. 只写事实和来源，不写台词（ADR 0021 决策 3）；时长说成人话（45 分钟、一个多小时、1 个半小时、3 个小时），「上一回」按今天 / 昨天 / 前天 + 上午下午晚上。

## 为什么先接这一项

账上别的东西（吃饭、睡觉、上课）状态行和「你那边」早就有了；这几天练了几回拍照是账上独有、聊天里用得上的（他问「最近还拍照吗」「新相机用得怎么样」），
而且 10-11 买了相机以后这一块会天天有东西。需要值（累不累、饿不饿）和日记接进来放在后面，一次只开一个变量。

## 验证

- 单元：三天以外、还没到的不算；几种时长和「昨天晚上」的说法。
- 应用级（`app.test.ts`）：事件账里预先放一段两小时前的修片，开着开关时最后一次提示词里有这一行，默认关时没有。
- 开之前：10-11 15:00 以后用 `live-ledger-audit` 再审一次线上的账。
