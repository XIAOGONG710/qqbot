# ADR 0182：她自己决定今天干什么

- 日期：2026-10-30
- 状态：已实施
- 相关：ADR 0101（内心）、ADR 0034（一天的打算会改）、ADR 0180（她自己上网）

## 背景

她一天做什么是排好的：作息里按「日期 + 时段」挑卡上的 plans（出门 / 学习 / 躺着），
再加上在读的书。用户 10-30：「决定今天干什么让她自己决定」。

## 决策

复用内心的念头（ADR 0101）：她每 1.5–2.5 小时想一次，这次多一个可选输出
「想做：一句话」（2–60 字，说具体的事）。写了就写进 `her-plan.json`：

```json
{ "date": "2026-10-30", "window": "afternoon", "text": "去操场走两圈", "at": "..." }
```

这一天里它作为**额外的空闲活动**（`ExtraFreeActivity`）和「在读的书」并排进作息：

- 状态行变成「你在去操场走两圈」——她聊天时说的就是这件事
- 「你今天的打算」里多这一条
- 日记、在线状态、B 站动态用的都是同一个状态，所以处处一致

一天一条（后写的覆盖先写的），第二天自然不算。文件坏了就当没有。

## 边界

- 只写"今天想干什么"，不排课、不改作息里的硬事件（上课、考试、睡觉）。
- 不写他安排的事，也不替他安排（提示词里写明）。
- 现在只是状态和话，**没有真的进行动队列**（`action-queue.json` 仍由世界裁判排）。
  她说了「去操场走两圈」，说话时她确实在走；要不要真排进队列、让对方也看得到，留给下一步。

## 验证

`npm test`；`her-plans.test.ts` 覆盖：今天算、第二天不算、窗口按时段、坏数据不收。
