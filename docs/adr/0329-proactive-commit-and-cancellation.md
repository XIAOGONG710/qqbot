# ADR0329：主动消息的持久提交、取消与时间事实

日期：2026-11-05

## 取证与约定

本轮审查六个登记源文件和配置转换、app/contact/responder、媒体分享入口及重启链。既有 ADR0011 要求先记后发、宁少不重；ADR0112 的回来消息不受未回复节流；ADR0116 下午有事不问意见；ADR0156 的手动主动只守危机和待回复两道闸。按这些约定修实现，不提高配额、不改变重试次数/间隔、危机窗口或联系人权限。发现与复现见本日 proactive-review。

## 决定

发送预留必须真正落盘。原临时写失败宽限仍适用于维护状态，但不能作为发送提交成功：提交未持久则本次跳过且不发，恢复后保存跳过事实，跟进/念头消费回滚。JSON rename 后报错，在app数据目录单写约束下读回确认已应用，不把成功误判失败。原文件及条目未知扩展保留，更新时清掉旧失败的已知retry字段。

跟进消费与发送预留同次保存：根据已生成parts判断提到、未问出口一次或第二次放弃，保持原策略。此前record已提交、followUps尚未消费时崩溃，次日会对同一事件再问；现在重启无此入口。部分发送失败也不补问，符合宁少不重；意图已提交但传输未知的极端情形可能少问一次，不假称获得远端ACK。念头told同步保存作为同一意图事务，但未把它另凑成已证明跨日重发缺陷。commit后不因错误被误标unreachable而重试；真正生成前不可达仍按原上限重试。

手动请求使用独立UUID，不因同一毫秒/虚拟时钟覆盖另一条记录。手动候选无法由普通定时规则重建，旧代码虽写retryAt并声称稍后重试却不会执行；现在失败记录终结且返回安全原因，让已有命令UI说明本次失败，不新增延迟手动发送策略。自动候选的既定网络重试不变。

启动读状态的暂时IO失败保持待恢复，不用空记录做计划或抽取；宽限内重读真实状态，持续超过既有5分钟则失败关闭，坏schema立即保留原文件并暂停。停止后不再恢复。状态单写仍依app数据目录单实例锁，不宣称支持外部多写者。

单次主动请求加可选AbortSignal，取消只结束该请求，不停止共享的普通回复器。Planner的搜索/抽取、内心、主动与等待continuation均竞速生命周期；晚结果不更新状态/日志/计数。Responder在构建/生成/审稿/commit/打字及每个实际发送边界检查取消；自定义模型不合作时不强杀底层，实际已经派发的传输保留等待ACK和真实历史，不丢确认，也不再发余下气泡。取消生成可让普通回复继续工作。

未来聊天/念头不影响当前计划、行程消费、模型提示、去重或今日次数；Responder主动入口也使用当前可见视图，新增消息检测仍以原始history长度为基准，普通回复策略不改。同秒OneBot回复借真实messageIds和追加顺序确认，仅校正commit同源秒桶的歧义，身份不唯一、旧无ID及dryRun保守走原时间回退，不擅加一秒宽限。

日历间隔双方统一民用日号，时区移动保本地分钟；年度公历拒不存在月日但保留02-29，农历最多30日，不猜某年大小月，源转换与运行解析同规则。世界今天/明天按本地日历推进，不按24小时跨DST跳日。纯窗口可数学越界，真正候选与world投影守四位本地/UTC边界，跳过不可执行项而不拖停其它合法时机。

模型输出要求完整协议数组和自有时段枚举，错误顶层走既定失败重试，不当合法空结果已抽过；畸形条目/无有效日期的事丢弃而保留合法项。错误不回显服务/JSON正文；敏感调试既有开关只作用于已批准的内容日志。内心只取约定去向，否定/冲突拒绝；多行异常流只取所需行数，不全展开。shares虽登记在本模块，实际为ADR0080入站卡片摘要：可见HTTP(S) URL不进聊天，分享及跟进短事实按代码点截断不切半emoji。

## 验证和边界

纯合成数据、假模型/传输、VirtualClock、磁盘故障和独立时区/受限堆进程验证。200万行文本旧代码在64MiB堆OOM，新代码安全拒绝；无任意新增内容quota。纽约DST、Kathmandu、Kiritimati与0000/0099/9999覆盖直接反例。真实Planner磁盘提交后停机、次日重启，以及真实Responder部分发送失败均验证跟进不再重复。

不使用真实QQ/模型/运行时，不部署或推送。无法硬停的底层请求/已派发传输可能晚结束；这不授权晚发后续内容或丢弃已确认事实。没有新增fsync断电或跨进程exactly-once保证，JSON提交和QQ发送仍不可能单事务；宁少不重保留。中文语义、混淆链接和无限入站JSON大小不声称完全识别/有界；没有凭空提高主动频率、保留期或扩大权限。
