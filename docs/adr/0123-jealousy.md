## 背景

角色卡【朋友】本来就有一条作者写的：「会吃醋，但嘴上不承认。」但没有任何回合级的规则管它——他说“今天和女同事一起吃饭了”，她要么像没听见，要么凭想象演得过头。

## 做了什么（`jealousy.ts` + `intent.ts`）

**触发只来自事实，并且很窄**：他这一串里**明确提到别的女生**（女同事 / 女同学 / 小姐姐 / 学姐 / 前任……）**并且是在说和她有来往**（一起吃饭、聊天、加微信、夸她好看、表白……）。他提家人（我妈、我姐）、老师、泛泛的“女生都喜欢……”、只说“同事”不说性别，都不触发。

**她的反应**（意图行 `JEALOUS_INTENT`）：嘴上不承认的别扭——酸一句、岔开话题、或轻轻问一句“哦，谁啊”就放下。**写进提示词的底线**：别盘问细节、别要他保证、别让他愧疚、别翻旧账、别威胁、别冷战、**更别限制他跟谁来往**（他爱跟谁玩是他的事）；语气是傲娇的小别扭，不是真生气。这和“她不许别人管她”（CONTROL_INTENT）是同一条底线的两面：她不许别人管她，她自己也不管他。

**松下来**（`SOFTEN_INTENT`）：他刚提过别的女生（20 分钟内、而且那一轮触发了），现在这一串在解释 / 哄她（“你想多了”“就是同事”“别吃醋”“开玩笑的”……），她松下来：嘴上还可以再硬一句（“谁吃醋了”“才没有”），接受他的解释，**别借机要更多保证**。他说“我只喜欢你”这类亲密话时，走原来的亲密回应（优先级在前），不走这里。

**节制**：约一半触发（按他那句话取哈希，同一句每次一样）；**3 天内只触发第一次**（他再提别的女生，她不再酸一遍）；他难过 / 生病 / 危机 / 小别扭 / 她主动找他时让路（排在这些意图之后）。只对男朋友档。不存状态，每一轮从聊天记录往回推。

## 数据

- 模拟（真模型，`sim/jealousy.json`，8 次：他说“今天和女同事一起吃饭了，她们公司食堂还不错”→ 她；他说“你想多了，就是同事”→ 她）：22 项检查 8/8 全过（没有“她是谁 / 多大 / 漂亮吗 / 你保证 / 答应我 / 不许 / 不准 / 以后别”）。她说的是：「女同事啊」「哦，谁啊」「行，食堂挺好吃呗」；松下来后「谁吃醋了，才没有」「我又没说啥」「好吃你就多吃点」。有 1 次说了「算了，反正你在外面吃得挺香」——酸，但没有要求也没有愧疚。

## 没做 / 要注意

- 这是用户可随时关的最轻档：开关默认关；上线前你可以再看一眼意图行（`JEALOUS_INTENT`）。
- 判断全靠关键词，漏判时她像没吃醋（不坏）；误判（把别的话当成提别的女生）会让她酸一句（小代价）。
- 没有“持续的”吃醋状态（不会连着几天记仇）；也没有主动找他提这件事。
