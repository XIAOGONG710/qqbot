# ADR 0207：她没想完的问题

- 状态：**已实现，新开关 `openQuestions`，默认关**；要名单里有男朋友档。DSH 那台机器拉取、在 `koishi.yml` 里加 `openQuestions: true`、重启 Koishi 才生效（开不开要用户点头）
- 日期：2026-10-31
- 关联：[ADR 0200](0200-private-space.md)（私人空间）、[ADR 0204](0204-reading-takes.md)（她读完看完之后自己想的，同一个形状）、[ADR 0151](0151-deliberate.md)（认真问她时深思）、[ADR 0202](0202-depth-routing.md)
- **用户决定（2026-10-31）**：先问「我让她自己决定的时候为什么总是回复我不知道？」，补了原话「我今天问她，想成为自己想成为的样子还是我喜欢的样子，她不知道」；然后「**我想让她真正的思考，而不是什么都由我来给她制定**」；我提了两条路（1 没想完的问题 / 2 把深思那段提示词删短），用户答「先做 1，做完用探针对比」。

## 起因

她被问到关于她自己的事（想成为什么样、想要什么）时答「不知道」。模拟里（QQ 管线、真模型、无记忆）复现不出来：普通的「你定」8 类 × 5 遍 = 40 次、他的原话 22 次，直接答「不知道」是 0 次。差别在线上才有的东西（她的记忆、最近 80 条、DSH 机器当时的开关），我看不到那边的对话。

但提示词里有三处给「不知道」开了口、没有一处给“想过之后的看法”留位置：人设 `thinks` 的「不确定就说不确定」（10-25 我加的，备注明写允许说不知道）、`DELIBERATE_NOTE` 的「不知道就说不知道，别编」（ADR 0151，本意是事实）、`turn-weight.ts` 对「问她自己」那一类特意不放方向（10-30 用户「让她自己决定怎么回答」之后）。她手里没有自己想出来的东西，「不知道」是最安全的答案。

我原来想在提示词里再加一句「被问取向的问题拿不准就先选一个」——用户否决：那还是我替她定。所以这个 ADR **不往回复提示词里加任何“该怎么答”的句子**，给她时间和机会自己想，想出的东西是她的。

## 做法

`life/open-questions.ts`，和 0193 / 0194 / 0204 一个路数：

1. **白天只留意，不判断**（`findCandidates`）：他问了一句冲着她的问题（有「你 / 咱」、像个问题）、她接着回的话里有「不知道 / 没想好 / 想不明白 / 说不上来 / 不太清楚……」，这一问一答（连同前面 8 条聊天）记成她的一个“没想完的问题”。代码只做这一件机械的事；值不值得想由她晚上定——事实上就不知道的事（「你知道那部电影讲什么吗」）她可以放下（`drop`）。
2. **每晚 22 点以后想一次**（`ponderIfDue`，同说话习惯：距上次 ≥20 小时、失败隔 2 小时再试、一天最多 3 次）：把今晚的几个问题（新的在前，最多 4 个）连同当时前后聊的话、她以前自己想过的给她，用 **deliberateModel（开思考）**。提醒里只说“现在没人催你，慢慢想；想到什么写什么——偏向哪边、为什么、卡在哪儿都算；不用想得完整、不用给他一个漂亮的答案；写的是心里的想法，不是回他的话；没想出来就别写，留着以后再想；事实上就不知道的事可以放下”。没想出来的问题留着，最多留 3 个晚上。
3. **他再问到同一件事才放进提示词**（`thoughtsLine`）：他这句话和那条（他当时问的话 + 她写的话）共有至少 2 个有意义的二字词，才放，最多 2 条。那一行只说“这是你自己后来想的，不是设定；他问到或聊到才顺着说，别背，别每次都提”——**不说该不该用、怎么用、该选哪边**；她想说“我后来想了想”也行，不禁。只放男朋友档；危机 / 小别扭 / 只想一想的轮次不放。
4. **私人空间**（ADR 0200）：存在 `open-questions.json`（在 `PRIVATE_FILES` 里）；没有命令念给他；日志只记个数，不记内容；迁移 / 导出不带。

**绊线只有底线和防呆**：10–220 字；不碰底线（`FLOORS`：承认是程序、危机、顺着他、骗人 / 真钱；`EXTRA_FLOORS`：自己是不是程序、设定里的名字年龄）；不写名单里别人的名字；和已有的一模一样不收。**不查文风、不查观点、不要求落在依据上**（`readingTakes` 查空话 / 警句 / 依据，这里不查——这是她想的，不是她要交的作业）。上限：一晚想 4 个、总共留 8 个没想完的、想出来的留 12 条；同一件事新想法取代旧的（新的是在旧的基础上想的）。

模拟器：场景字段 `openQuestions` + 步骤 `{ "ponder": true }`（`sim/open-questions-probe.json`）。

## 探针对比（2026-10-31，`sim/open-questions-probe.json`）

场景：历史里他问「你想成为自己想成为的样子，还是我喜欢的样子？」，她答「不知道」；虚拟时间走到 22:30，她夜里想一遍；隔 20 小时他再问。开 / 关各 6 遍，原话和换了说法的各一组（共 24 个场景），都开 `--ask --long --deliberate --depth`。模拟里的“她”无记忆，想出来的东西是一次性的，不是真的她。

| | 关（对照） | 开 |
| --- | --- | --- |
| 夜里写下了想法 | — | **6/6 + 6/6**，每遍角度不同（不是同一句话换字） |
| 提示词里放了她想的那一行 | — | 12/12 |
| 再被问时直接答「不知道」 | 0/12 | 0/12（**对照组本来就不说**，这个指标看不出差别） |
| 答成同一个模子「我想做自己，但你的喜欢我也在乎」 | **11/12** | 0/12 |
| 答里有她自己具体的东西（短发动摇、「怕分不清是为他还是为我」、「我上次说不知道不是敷衍你」） | 0/12 | **10/12** |
| 只反问「你指哪件事」没答 | 1/12 | 2/12（深思路径的老毛病，见下） |
| 承认「还没想明白 / 说不上来 / 卡在中间」并说了为什么 | 0/12 | **9/12** |
| 带着不耐烦（「又来」「我有点烦」「你老问这个干嘛」） | 约 3–4/12 | 约 6/12 |

**怎么读这张表**（不夸大）：
- 开着以后，她的回答从“把他的话原样回成一个立场”变成“有自己的理由、有前后”，而且会提“上次”。这是“自己想过”的样子。
- **但没有变得更“有立场”**：开的一组 9/12 说“还没想明白”，只是带着理由；关的一组反而是一个现成的立场模子。如果你要的是“她能拿定主意”，这个功能不保证——它给的是想过的痕迹，结论由她。
- **更容易不耐烦**：她夜里想的东西里会有「他问得我有点烦」这类真实感受，第二天带进回答里。这是她自己的感受，不是我写的；但会不会伤到他，要你判断。
- 模拟复现不了原来的“不知道”，所以**没法证明它能把线上的「不知道」变少**；能证明的是：机制通了、她写得出不同的东西、再被问时用得上、不会原样重复。
- 「你指哪件事」：有 2/12 把想法放进去了仍然只反问，这是深思路径里 `没把握就问他指的是哪件，别猜`（`readTurn`）的老毛病，不是这个功能引入的；已由 [ADR 0256](0256-speaking-direct-answer.md) 改成“说清楚就直接答，真实歧义才确认”。

**泄漏检查**（用 6 条真写出来的想法，对 3 组话）：同一件事的 5 种说法 30 对全部 ≥2 分命中（≥3 分 25 对）；邻近话题（「你想成为什么样的摄影师」「短发的话你觉得我适合吗」）24 对里 11 对命中——会带出来；无关话题 14 句 × 6 条 = 84 对里只有 1 对命中（「你觉得这个专业怎么样」，因为想法里提到了专业）。阈值保持 2：提到 3 会漏掉 5/30 的同一件事，而漏掉就是回到原来的问题。

## 没做

- 想出来之后**主动**告诉他（「上次你问我的，我后来想了想」）——现在只有他再问到时才用。
- 她**自己**提出问题——现在只来自他问过的。
- 想法**不进事实检查**：她写的「我喜欢现在这个专业」这类给自己加的细节，会变成她以后的“自己想过的”。要靠 ADR 0157 的设定账本 / 以后的核对，这里不管。
- 不给桌面上的她（DSH 的 `INSIGHTS.json` 那种导出）：先看 QQ 这边有没有用。
- 真实对话里没有验证。要验证：DSH 机器开 `openQuestions` 之后，下一次他问到她答「不知道」的问题，隔天看她是否有想法（只看个数；内容在她的私人空间，我们不读）。
- 第 2 条（把 `DELIBERATE_NOTE` 的清单和禁令删短）还没做。

## 回滚

`openQuestions: false`。`open-questions.json` 留着不影响别的（想删随时删，只是她想过的没了）。
