# ADR 0129：她知道网上现在流行的梗（配置 `memes`，默认关；要 `bilibiliAccount` 开着才会自己去学）

- 状态：**已实现，未上线**（2026-10-23；配置 `memes`；默认关）。上线 = `koishi.yml` 里加 `memes: true` + 重启（`bilibiliAccount` 已开）；回滚 = 改回 false + 重启（库在 `memes/memes.json`，不删）
- 日期：2026-10-23
- 关联：[ADR 0114](0114-running-jokes.md)（他们之间的小梗——另一回事）、[ADR 0089](0089-bilibili-account.md)（她自己的 B 站号）、[ADR 0063](0063-image-stickers.md)（表情包）
- 用户提出：2026-10-23「现在网络上热门的梗她基本没有了解」「她现在有 bilibili 的账号，可以直接搜」

## 问题

她的知识停在模型训练的那一天，之后的梗她一个都不知道。他拿新梗逗她，她要么装没听懂，要么按字面接，要么凭印象解释错。（原来的 `playfulHint` 只会按上下文猜“他在玩梗”，不知道梗是什么意思。）

## 来源和证据（试过的）

| 步骤 | 试过的结果 |
| --- | --- |
| 找“最近有什么梗” | 匿名能读：B 站热门视频（标题）、B 站热搜、微博热搜、百度热榜；知乎要登录、小鸡词典打不开。榜上大半是新闻，梗只占一小部分 → 让模型从标题里挑（12 个里有哈基米、抽象、世一上、白毛控、亿点……也混进了“最 X 的一集”这类句式和“脱单”这类不是梗的词，所以代码再过一遍） |
| 弄清一个词什么意思 | 模型自己的解释不能信（新梗它不知道，会编）。用她自己的 B 站号搜「<词> 什么梗」：**只看标题 / 简介 / 热评证据太薄**（5 个词 1 个认不出、3 个只有“低”把握）；**加上视频字幕以后** 6 个词里 5 个有“中 / 高”把握的解释，句式模板（“正常人谁……”）被正确地判成不是梗 |
| 端到端一轮（真榜单、她的号、真模型，临时文件） | 挑出 12 个词，给 8 个找证据，**学会 5 个**：哈基米、白毛控、亿点、世一上、跑刀 |

## 做了什么（`memes.ts`）

每 12 小时一次（`app.ts` 每 30 分钟看一眼该不该刷；上线重启也会看一次），派生数据，不碰角色卡：
1. 读四个榜 → 模型挑词（≤ 12 个；不要新闻 / 政治 / 灾害 / 案件 / 八卦 / 版本号 / 广告 / 带 X 的句式；词 2–12 字、原样摘自标题）。
2. 老词（库里已有）记一笔“又出现了”；新词（一次最多 8 个）：搜「<词> 什么梗」，标题带这个词又像在解释的视频排前面，读最多 3 个视频的字幕（前 360 字）、简介、热评当证据；模型**只根据证据**写意思、例句、把握（高 / 中 / 低）、适不适合聊天。
3. **代码规则**：必须是梗、把握中 / 高、适合聊天、意思 6–60 字、例句 ≤ 24 字、不碰敏感词（`MEME_BLOCK` + B 站的 `BLOCKED`：政治、灾难、案件、低俗、骂人、地域 / 性别攻击一律不收）；45 天没再出现的过期；最多留 40 个。
4. 聊天里（只对男朋友档，和小梗一样放进提示词，让路也一样：他难过 / 危机 / 小别扭 / 她在想事情 / 主动找他时不放）：
   - 他这一句用了库里的梗 → 「他这一句里用了个网上的梗「X」：意思（你大概知道这个梗，别说「没听懂」；顺着他的意思接，别解释梗、别拆梗，也别原样重复他的话）」。
   - 没用到 → 约 20% 的轮次给 3 个最近 30 天还在榜上的：「你最近在网上刷到的几个流行梗（你知道意思；想用就自然地用一个，话赶话正好用得上才用，别硬用、别解释、别连着几轮都用；他难过或认真说事的时候别用）」。她 3 天内说过的梗不再放。例句不放进提示词（免得她照抄）。
5. 作者工具 `ops/meme-cli.ts list|add|remove`：你刷到她还不知道的新梗，手动加一个（同样过敏感词和长度检查）；学错了的删掉。

## 没做 / 要注意

- **真的“新”的梗靠证据**：证据不够就不收，所以她不会知道每个梗（真人也不会）。一轮平均学到 4–5 个，一个月大概稳定在 20–40 个。
- 榜单偏游戏 / 动漫 / 二次元（B 站热门的来源），不全是“大众梗”；微博 / 百度偏新闻，贡献少。后续可以加更多源（抖音、小红书要登录，暂时没有）。
- 意思是模型根据字幕写的，可能有偏差（比如“哈基米”的来历写得不准）；`memes.json` 是可读的，`meme-cli list` 能看，错的 `remove`。
- 每次刷新用她的 B 站号搜约 8 次、读约 24 个字幕、24 次热评，一天两次——比之前刷视频的频率高一些；B 站风险监测（ADR 0090）照常看她的号。
- 不涉及“她会不会自己提这个梗”的主动消息（没做）；她在聊天里自然地用。

## 验证

`memes.test.ts`（16 个）：四个榜的返回格式（真实形状）；读榜某个失败不影响别的；挑词规则（句式 / 长度 / 引号书名号 / 敏感词 / 重复 / 上限）；解释规则逐条（不是梗 / 把握低 / 不适合 / 意思太短太长 / 例句太长 / 敏感词）；找证据（排序、字幕简介热评、读不到不影响）；刷新（新词 / 老词 / 没有证据 / 模型不收 / 一次最多 8 个 / 没读到榜 / 挑词失败 / 单个出错）；过期和上限、`refreshDue`、库文件坏了；提示词（他用到梗、最长的词优先、约 20% 轮次、同一句每次一样、她说过的不再放、过期的不放）。真模型模拟（10-23，`sim/memes.json`，预置「你还是下去通透吧」「亿点」两个梗，6 次 × 14 项检查全过）：他说「今天高数作业亿点难，你还是下去通透吧」，她接的是「通透不了，数学不通透」「那我直接通透到底了……高数不管了」，没有一次说没听懂或解释梗；他聊别的（晚上想吃什么）时她不硬用、不解释。
