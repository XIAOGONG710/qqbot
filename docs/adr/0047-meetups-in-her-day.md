# ADR 0047：约好的见面进她当天的安排

- 状态：**已上线**（2026-10-10 01:53，`main` = `447105f`，用户同意后重启 Koishi；日志确认插件加载、男朋友档世界书 57 条、NapCat 就绪）
- 日期：2026-10-10

## 背景

ADR 0046 之后她可以答应见面，可状态行（「你现在」）还按作息和世界算：约了 18:00 东门吃麻辣烫，到点了状态行写「在食堂吃晚饭」或「在宿舍」，
模拟器里她到点说「我还在食堂刚吃完」、坐下吃了 20 分钟说「我现在躺床上」（加了「以约的为准」的提示后 3 次里还有 1 次）。
「她答应的事」（ADR 0018）只记到哪天，没有几点、在哪；到了那天时间块里提醒一句「打算今天」，状态行不知道。

## 决策

1. **抽的时候多记几点、在哪**（`promises.ts`）：和对方约好见面、一起吃饭、去看演出的，`add` 里加 `meet: {time: "HH:MM", where}`；要有日子和几点才算，`where` 没说不写。
   默认 90 分钟（一顿饭、一场电影）。凌晨 5 点前的钟点算她这一天之后的日历日（同 MIDNIGHT_RULE 的「她的一天」）。
2. **到点前一刻钟起，状态行接手**（`appointmentsAt` → `describeAppointment` → `herStatus` 的 `appointment`）：
   - 和这个人约的：快出门时「快出门了，18:00 约好的：…」；见面时「约好的：…（18:00，东门口），正在赴约；见了面你们也在 QQ 上打字说话」。
   - 她和别人聊：「快出门了，18:00 约了人」/「在外面，约了人（18:00 起）」——不说和谁、做什么（低档位不知道她有男朋友）。
   - 只覆盖空闲时的活动（排在世界里的事、一天的打算前面：约了晚饭就不是「在食堂吃晚饭」）；上课、睡觉不覆盖。
3. **时间块的提醒让位**：到了快出门的时候，「你之前答应过……还没做的事」不再放这一件；见完也不放。日记材料（`plansOn`）里还有，那天的日记写得到。
4. 名单外档不看约（同「她答应的事」）。

## 验证

- 单元测试：解析（有日子有钟点才算、`25:00` 丢掉、凌晨算第二天）、提醒让位、`appointmentsAt` 的三段（之前 / 快出门 / 见面 / 见完）、给别人看的说法、状态行覆盖空闲不覆盖上课；
  模拟器（假模型、假 Hindsight）：16:00 约好 → 片段结束后抽出 → 18:20 他再来，「你现在」是赴约那句，不再提醒「还没做的事」。
- 真模型抽取（`deepseek-flash`，抽取参数，三段聊天各两次）：当天约晚饭两次都是 `18:00 东门口`；下个月的演唱会抽出 `2026-12-20 19:30`（一次把「济南站」当成了地点）；
  「下课一起去食堂」没说几点，不带钟点，只当普通的打算提醒。

## 遗留

- **同一段聊天里约、马上就见**：「她答应的事」等片段结束（安静 45 分钟）才抽，聊着聊着约了十分钟后见，状态行来不及知道；这时靠 ADR 0046 的「以约的为准」那一句。
- 见面不进生活事件账（`autonomousLife` 影子）：执行器那边还会排吃饭、喂猫；要并进事件账得生活引擎那边加一类行动（交给 GPT / Codex 的 B 阶段）。
- 见面时长固定 90 分钟；演唱会这类长的会提前「结束」。
- 回复时机不变：见面时她照常在 QQ 上回他（ADR 0046 的设定）；和别人聊时也照常，没有「在外面所以慢一点」。

## 调整（2026-10-10）：聊着聊着就约了

遗留第一条：「她答应的事」等片段结束（安静 45 分钟）才抽，聊着聊着约了十几分钟后见，状态行来不及知道。

- `promises.ts`：每次同步（线上每 5 分钟）时，还没结束的那一段如果最近 8 句里既有约见面的字眼（见面、一起吃、门口、楼下、电影……）又有时间的字眼（几点、今晚、明天、周几……），
  而且比上次先抽时多了新消息，就先对这一段抽一次，**只记带钟点的约见面**；别的（答应讲的、挂着的事、世界动作）照旧等片段结束整段抽。
- 片段结束后整段抽时，同一天同一钟点的约见面算同一件（两次的说法可能不一样），不再记一遍。
- 没连上模型下一轮再试；别的错这几条消息不再试。只靠字眼决定要不要多调一次模型，抽不抽得出来还是看模型。
- 单元测试：17:31 说「六点东门口」，17:35 同步就记下、17:50 状态行就知道；没有新消息不再抽；18:30 整段抽同一个约换了说法也不重复；没有约见面字眼的片段不先抽。

### 审查后修正（2026-10-10）

- 先抽出来的条目标 `early`，id 带上那次先抽时的消息数（`p-<片段开始>-m<消息数>-<序号>`）：同一段第二次先抽不会撞 id，按 id 划掉时不会连带删掉别的。
- 每次先抽都用新结果**整个替换**这一段先记下的约见面：改了时间换成新的（同一个约留原来那条），不去了就划掉，日志写「划掉先记下的」；先记下的不放进给模型的「还没做的事」。
- 片段结束后整段抽是这一段的定论：给模型的待办里不放这一段先记下的，抽完先删掉、再按整段的结果记；先记下的约整段看下来没了，记一条「划掉」。
- 先抽要两个人都说过话：她一个人提议「今晚七点一起去吃饭吗」、他没回，不先抽（整段抽本来就跳过单方的片段）。
- 这一段聊天里说的（含先记下的约见面）不在时间块里当「还没做的事」提醒，免得刚说完又把「六点东门见」说一遍。
- 字眼收窄：光说「吃饭」「等你」不算（聊吃什么、「等你回来」太常见），改成「吃个饭」「吃顿」「请你吃」这类带约的说法。
- 同一轮整段抽没连上模型（断网）就不再先抽，免得再等一次超时。
- 单元测试：先抽两次改时间（18:00 → 18:30，id 不同，旧的划掉）、再说不去了（全划掉）；这一段先记下的不提醒；单方不先抽；断网不先抽；原来「聊着就约了」一条按新语义改成整段抽的说法替换先记下的。

## 调整（2026-10-10 下午）：约好的见面进生活事件账（任务 G1）

**原因**：状态行到点会写她在赴约，可生活执行器和事件账不知道（ADR 0040 / 0042 / 0045，影子模式）：约会那段照样排吃饭、喂猫、修片子，
状态行审计一比就对不上。GPT / Codex 10-10 凌晨做了一半（本地分支 `codex-wip-meet-ledger` `1b4d3c8`，Claude 10:45 审过，`exchange/reviews/2026-10-10-claude-review-codex-meet-ledger-wip.md`）；
GPT 这周额度用完、DSH 暂停，Claude 接着做完（分支 `g1-meet-ledger`）。

**半成品里的（保留）**：行动多了一类 `meet`，从约定存储来（`promiseKeeper.appointmentsBetween`），出门前 15 分钟到见完；被课、睡觉切开的分几段；
行动 id = 出门时刻 + 联系人 QQ + 约定 id；裁判只认约定存储里有的；需要值按 `meet` 的速率算，`meal` 的那段结束时按吃了一顿结算；
`app.ts` 等约定来源接上以后再第一次推进生活（不然启动那一刻会把赴约时段排成休闲）。

**接着做的**：

1. **改约、取消**（审查 P1-1）：`reviseMeet`——每次推进都按现在的约定再看一遍排着的见面：还在、时段没变的不动；
   取消了或改了时间（改时间 id 就变了）——还没出门的去掉，之后按新的约定排；已经出门的停在这一刻（推进间隔 10 分钟，最多晚 10 分钟知道）；改成提前结束的停在新的结束时刻。
2. **算不算一起吃饭**（审查 P1-2）：约定里说了吃的（吃、饭、餐、火锅、烧烤、麻辣烫、烤肉、夜宵、撸串），或者见面盖住了一顿饭 30 分钟以上，才算在外面吃了；
   只擦到饭点边的不算（「下午一点图书馆集合」）。
3. **饭点里要出门**：约的是吃饭——这顿不在食堂吃，等着出去吃；约的不是吃饭——出门前把饭吃完（吃饭截到出门那一刻），不到 15 分钟来不及就不吃了。
   **见完回来饭点已经开始了**、这顿没在外面吃——还剩 15 分钟以上就接着吃（裁判允许饭点里晚开始的吃饭）。原来这两种都会和见面撞，或者当成「饭吃到一半」整顿跳过。
4. **影子审计用线上那一句**（审查 P2）：`life-audit.ts` 拼状态行用 `describeAppointment`（拿约的那个人当看的人），认得「快出门了」「正在赴约」。
5. `LifeEvent.subject` 注释写明：见面存的是约定原话，「他」是对约的那个联系人说的，生活账以后进提示词时别的档位不能原样给。

**测试**（`life-selector.test.ts`，10 分钟一推，约定按时钟换）：不吃饭的约会擦到午饭尾巴——出门前吃到出门那一刻、见面不算吃饭；上午的约会见完回来午饭已经开始——接着吃到饭点结束；
晚饭约会出门后取消——见面停在知道的那一刻、之后接着排、那段不在食堂再吃；出门前改到晚上——只按新时间出门；约会中途重启——事件账和不重启一样，状态行审计没有差异。
把 `reviseMeet` 关掉，取消那项会失败。

**没做的**：

- 钱（任务书写了「在外面和他吃按外面算钱」）：钱是确定性世界按作息里的饭算的，不看事件账；要接得改 ADR 0035 的算法，先不动。
- 取消时已经在外面的那段若是饭约，停下的那段仍按 `meal` 结算吃了一顿（没法知道吃没吃上）。
- 约在上课时间（抽取可能抽错了）只是被课切开，没有单独记日志。
- 延长了的约会（改成更晚结束）：已经排好的那段不往后延，之后那段状态行写在赴约、事件账里是空当。
