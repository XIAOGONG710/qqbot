## 问题

用户 10-18 定了优先级：「先让她更像人，这是我们的最终目标」。取证（`exchange/handoff/2026-10-18-claude-realness-evidence-and-order.md`）：她的日子有骨架（课、饭、自习、休闲、猫、作业、相机、钱）和一批当天小事（排队、停水、室友外放，`world.yml` 的 `events`），
但**别人对她主动做的事几乎没有**。陈佳宁、苏雨桐有自己的日子（感冒、忙、回家，ADR 0033），也进了她的账（一起吃饭、拍板书、微信互损，ADR 0044），可全是**定好就照做、一天就完**：
没有谁约谁，没有人迟到、改时间、临时不去，她也从来不用说「今天不行」。真人的日子里，这些比「一起吃了饭」本身更常被拿出来说：
「雨桐又放我鸽子」「佳宁叫我去，我作业没写完没去」。长期计划 C 阶段的门槛也正是这个：两周里至少一次合理的拒绝或改约。

ADR 0064 否掉过「把所有小事都当新闻」（会变成今日汇报、占满每天 2 条）。所以这里不是让她多讲，而是**让日子里有「别人对她做的、有结果的事」**，讲不讲、讲哪件，另一步再定，仍受 0064 的准入和每天上限管。

## 边界（不变的）

- **作者裁决一·1、1b 不变**：两位只是 NPC，不做 QQ 联系人、不在 QQ 上出现、不进长期记忆的 bank。这里的「约她」「变卦」全是她那边世界里的事（微信上、当面），他只能从她嘴里知道
- 室友仍不命名；不新增 NPC
- 不让模型决定发生了什么：事实按日期和她的状态推，可重放；模型只负责她怎么说（接线以后）
- 危机最小规则（ADR 0068）不受影响；这里不碰任何和他的情绪、关系有关的判断

## 决策

1. **新的一类世界事件：「约」**（`packages/bot/src/npc-asks.ts`，纯函数，不存状态）
   - 谁发起（目前陈佳宁、苏雨桐；她自己约人以后另说）、约什么、哪天几点、什么时候说的
   - 同 ADR 0033：按「月 + 人 + 序号」取哈希，每月 `perMonth` 次（整数部分一定有，小数部分按哈希），约的那天按哈希落在那个月里，顺着往后找第一个合适的日子（一个人一天最多一个约）；重启、重放一样
   - 哪些日子会约：学期内、不放假；「上课的日子」类的名目要那天有课，「周末」类的名目要是周六日；开始时刻落在那一段里（午饭 11:30–13:00、晚饭 17:00–18:30、晚上 19:00–20:30、周末下午 13:30–16:00，十分钟一档），和课前后各留十分钟（苏雨桐同专业，不会约在有课的时候）
   - **对方自己正病着、忙着、在家时不发起约**（ADR 0033 的状态）；**约了之后新发的病 / 忙 / 回家 → 取消，理由就是那个状态**（`fromState` 标出来，审计时能看出理由不是随机挑的）
   - 说的时间：一半前一晚（20:00–22:00）、一半当天上午（09:00 起，至少提前一个半小时）；陈佳宁（外地、微信）多在前一晚
2. **结果在约之前就按哈希定好**（可重放）：按时 / 迟到（5–20 分钟）/ 改到晚一点（1–2.5 小时，同一天，结束不晚于 22:30；原定就很晚的没得挪，按原定来）/ 临时取消。理由从配置的几句里挑，每句带 `private` 标记
3. **默认数字（待用户确认，可改）**

   | | 苏雨桐（同专业、济南） | 陈佳宁（外地、微信） |
   | --- | --- | --- |
   | 每月约几次 | 4 | 3 |
   | 名目 | 下课一起吃饭、一起吃晚饭、晚上一起去图书馆、周末下午出去转转 | 晚上微信视频 |
   | 迟到 | 15%（下课被老师拖堂、出门晚了、路上碰到人） | 15% |
   | 改到晚一点 | 10%（临时要先去办件事、作业还差一点、睡过头） | 15% |
   | 取消 | 5%（被老师叫去帮忙；肚子疼 / 家里有事：私事） | 5% |

   学期里平均每周约 1.5 次，不是按时的约每周约 0.5–0.7 次（一个月两三件）。**不做「没有硬理由的懒得去」**：她的拒绝都带硬理由（见 4）
4. **她答不答应按她那一刻的状态定，规则判，不问模型**（`judgeAsk`，输入是她那一刻知道的：课、和他约好的见面、最近一份没写完作业的截止、身上不舒服）
   - 优先级：**撞他的约（ADR 0047，「跟他约好了」）> 撞课 > 身上不舒服 > 作业 48 小时内要交**（吃饭类不因作业推：人总要吃饭）；没撞上就答应
   - 判的时刻是「对方说的那一刻」；迟到、改约之后传新的那一段再判一次（改到的时候撞了课，就又变成她推掉）
   - 闺蜜的约和他的约撞了：**先约先得**（他的见面已在账上就推掉闺蜜；闺蜜的约先到、之后他才约，则答应他时才撞，那时的规则是 ADR 0066：推掉要有来源，闺蜜的约算一个）。她推掉他去陪闺蜜这种大事，这一版不做
5. **谁能知道**（ADR 0020）
   - 约了谁、去没去、对方迟到 / 放鸽子：当面也能说的事，看得到这个人的档位都可以（同 ADR 0033 第 4 条：同学档以下卡上没有这两个人，也就没有他们的约）
   - 取消 / 改约的理由是对方的私事（`private`：身体、家里的事）：只在最亲的档位、被问到才说
6. **接线顺序（每步一个开关、看 48 小时）**
   0. **事实层**（`npc-asks.ts`）：纯函数 + 测试 + 月历预览。不改行为
   1. **进她的一天和「你那边」（配置 `npcAsks`，默认关）**：开关设在世界对象上（`World.asks`，`app.ts` 读卡时、模拟器场景的 `npcAsks` 设上），其余代码照旧读世界。
      - `WorldNow.dates`：今天、明天里已经说到她这里的约（`FriendDate`：谁、约的事、原定时刻、结果、实际时刻、她什么时候知道变了、理由、她推掉的理由、会不会真的发生 `held`）
      - 「你那边」多一段「约：…」，只写事实（「约好今天 20:20 和苏雨桐一起去图书馆」「…她还没到」「…她迟到了 12 分钟（下课被老师拖堂了）」「…她说改到 20:30」「…她说去不了了」「你推掉了（作业还没写完）」）；变卦要到她知道的那一刻才写；说不出口的档位不写私事理由
      - 状态行：在一起的那一段（迟到、改约的按实际时刻）`occupationAt` 写「在图书馆和苏雨桐一起自习」；约的是食堂 / 晚饭的，开始时刻就是世界里排好的那顿饭（`AskKind.anchor`），状态行写「在食堂和苏雨桐吃饭」盖住「在食堂吃午饭」
      - 选择器：非吃饭的约进 `busySpans`（占着时间，别的活动让出）；约的午饭给那顿 `eat` 带上 `target`
      - 复盘那天（`recapDay`）和他说起她（`recentWith`：每种约只留最近一次）都带上
      - 开着时，世界里随机的「下课和苏雨桐一起去食堂」（`lunch_with_friend`）让位给「约」，免得一天两顿
      - 她答不答应：课、身上不舒服、快交的作业；**他的约（`meetups`）在约定那一边，世界层看不到，这一步传空**——和他的见面撞车的处理放到下一步
   2. **说出口（10-18 做完，分支 `claude/friend-news`）**：ADR 0064 的新事件类 `friend_changed`（走同一套准入：了结、有结果、事实来自账、这一档看得到；受每天≤2、没回就停约束）。只有两种算：**对方临时去不了了**、**改到至少晚一小时**；她自己推掉的、迟到几分钟的不算（太小）。了结的时刻 = 她得知的时刻（`knownAt`），5–20 分钟后找他说一声；说明只给事实和方向（谁、约的什么、变成了什么、她说的原因），不要他回应或安慰、不编没写的原因。单独一个开关 = 卡上的 `newsKinds` 里加 `friend_changed`（和 0064 的逐类开关一样，是卡改动，要和 `npcAsks` 分开两次上）；同时要接上和他的约的冲突（先约先得）留到下一步
      - 真模型（`proactive-news-friend`，两个真实日子 × 8 次）**8/8、31/31**：「宝宝，陈佳宁刚说视频改到八点半了」「宝宝，苏雨桐被老师叫去帮忙了，中午饭我自己吃」；16 条里有 2 条用了「放我鸽子」，对一次改约来说略重，先留意不处理
   3. 她自己约人（反过来）：另开
7. **日志可审计**：约、结果、她的答复都写一行（`describeAsk`），沿用 0011 §7

## 不做的

- 不让模型决定约不约、变不变卦；不做「懒得去」
- 不新增 NPC，不让 NPC 出现在 QQ
- 不进长期记忆（NPC 的约不是他说过的话）；一次放鸽子不改写她对朋友的长期印象
- 这一版不接线（上面第 6 条的 0 步以外都不做）
- 放假、学期外不约（她那时不在学校；陈佳宁的视频放假时也先不约，下一刀）

## 验证

- 单元：`npc-asks` 14、`world-asks` 15；类型检查干净；**全量：bot 977/977、插件 29/29、工具 43/43**（10-18 02:0x，接线最终版；内存守护最低可用约 1.6 GB）
- 统计（三年多、课表延长、去掉假期，276 次约）：每周 1.6 次；按时约 66%、迟到约 13%、改约约 13%、取消约 8%（含新发的病 / 忙 / 回家几个）
- 真学期（09-14 起 105 天）：24 次约（含吃饭的约跟着饭点后重排），预览表在 `exchange/handoff/2026-10-18-claude-asks-preview-for-user.md`
- **真模型（`npc-asks-days`，纯虚构对话，`--no-memory`）**：
  - 第一轮（3 次）：90/92，管线 18/18；唯一的失败是 11-20 那步（视频改到 20:30）她 2 次说「没安排」——「你今天的打算」那一行还写着「晚上研究新相机」，没有这次约
  - 加「打算行带约」之后（3 次）：92/93，该步 2/3 提到视频和 20:30
  - 说起她时发现 3/3 夸大成「老放我鸽子」（只留每种约最近一次变卦，按时的被丢了）→ 改成先给一句数（「最近 14 天约过 3 次（按时 1、改时间 1、她临时去不了 1）」）再写最近两件变卦；之后（4 次）**144/144，管线 24/24**，说起雨桐时「约她三次有两次都黄了」「两周约了三回」，没有夸大
  - 已知的小毛病：问「昨天中午」时 1 次编了「今天中午也没一块儿」（提示词里没有这件事，「没写的别编」管不住所有次数）；和 0064 的「顺带说」同一类风险，不在这里根治
- 线上：**没动**。`npcAsks` 默认关；要开：`koishi.yml` 加 `npcAsks: true` 重启（一次一个变量，看 48 小时）；回滚 = 改回 false 重启
