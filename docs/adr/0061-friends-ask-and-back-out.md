## 问题

陈佳宁、苏雨桐现在有自己的日子（感冒、忙、回家，ADR 0033），也进了她的账（一起吃饭、拍板书、微信互损，ADR 0044），但全是**定好就照做**的：
没有谁约谁，没有人迟到、改时间、临时不去，她也从来不用说「今天不行」。真人的日子里，这些比「一起吃了饭」本身更常被拿出来说：
「雨桐又放我鸽子」「佳宁叫我去，我作业没写完没去」。长期计划 C 阶段的门槛也正是这个：两周里至少一次合理的拒绝或改约。

## 边界（不变的）

- **作者裁决一·1、1b 不变**：两位只是 NPC，不做 QQ 联系人、不在 QQ 上出现、不进长期记忆的 bank。这里的「约她」「变卦」全是她那边世界里的事（微信上、当面），他只能从她嘴里知道
- 室友仍不命名；不新增 NPC
- 不让模型决定发生了什么：事实按日期和她的状态推，可重放；模型只负责她怎么说

## 决策（草稿）

1. **新的一类世界事件：「约」**（`world.yml` 每人的 `life` 下加 `asks`，`npc.ts` 推）
   - 谁发起（陈佳宁 / 苏雨桐；她自己约人的以后另说）、约什么（吃饭、去图书馆、逛街、借东西 / 还东西）、约在哪天几点、提前多久说的
   - 同 ADR 0033：按「日期 + 人 + 名目」取哈希，按月排，不存状态，重启重放一样；她们自己的日子挡着就不约（病了、回家了、忙）
   - 结果在约之前就按哈希定好：按时、迟到几分钟、改到另一个时候、临时取消（带一个理由，理由从她们自己的日子里来：「感冒了」「临时要交作业」）
   - **频率、提前多久、迟到 / 改约 / 取消各占多少、理由的样子：待 DSH 填**
2. **她答不答应按她那一刻的状态定，规则判，不问模型**
   - 撞上课、撞已经和他约好的见面（ADR 0047）、三天内要交的作业（ADR 0056 的截止时间）、身上不舒服（ADR 0025）→ 不去，理由就是撞上的那件
   - 都没撞上 → 答应；要不要偶尔「懒得去」（没有硬理由的拒绝）：**待 DSH 的数据和作者定**
   - 判的时刻是「对方说的那一刻」：提前一天约的，按那一刻已经知道的安排判，后来才有的事不回头改答复（改约走第 3 条）
3. **进账**（ADR 0044 的路子）
   - 答应了的 → 当天安排里一件硬事件（同 ADR 0047：到点前一刻钟状态行写快出门了 / 在赴约），账上 `eat` / `interact_npc` 带 `target` = 那人的 `id`
   - 对方迟到 → 账上开始时刻往后挪；改约 → 原来那件不发生，挪到新时刻；临时取消 → 空出来的时间回到空闲活动
   - 她拒绝的 → 账上一段短的 `interact_npc`（在微信上回了她），不占后面的时间
   - 被聊天改写（ADR 0042）：她在聊天里跟他说「今天不去了」，同 0047 的取消
4. **谁能知道**（ADR 0020）
   - 约了谁、去没去、对方迟到 / 放鸽子：当面也能说的事，看得到这个人的档位都可以（同 ADR 0033 第 4 条：同学档以下卡上没有这两个人）
   - 取消的理由是对方的私事（家里的事、身体）时，按第三方的事处理：只在最亲的档位、被问到才说
5. **先影子**：进账、进审计，不进「你那边」、不进提示词；14 天模拟过了门槛、线上影子看几天，再另开一项决定怎么说出口（同 ADR 0054 一次一项）

## 门槛（C 阶段，实现时）

- 14 天模拟：每位至少 1 件和她无关的事（已有，ADR 0033）、至少 1 次合理的拒绝或改约；同一种结果不连着出现
- 状态行 ↔ 事件账两个方向 0 分叉（`auditLifeStatus`、`auditLedgerCoverage`）；同一种子重放逐事件一致；中途重启一致
- 秘密泄漏 0：低档位的提示词里没有第 4 条的私事理由
- 一次放鸽子不改写长期印象（她对苏雨桐的看法不因为一次取消就变）

## 待定（要用户 / 作者定的）

- 闺蜜的约和他的约撞了：现在写的是「先约先得」。会不会有她推掉他、去陪闺蜜的时候（比如佳宁出了事）——这会碰到他的感受，要作者定
- 她自己主动约闺蜜：这一版不做，下一刀
- ADR 0033 已有的「和苏雨桐一起吃饭」「辣米线」要不要并进「约」（由谁发起、会不会变卦），还是留着当日常

## 待审的问题

- 结果在约之前就定好（第 1 条），还是到点再判（更像真人，但重放要多存一笔）
- `meet`（和他见面）和 `interact_npc` / `eat`（和闺蜜）要不要统一成一种「赴约」行动
