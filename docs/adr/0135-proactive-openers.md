# ADR 0135：主动消息的开头别老是同一种、不照搬套话、不编事实里没有的小动作（没有开关，同 ADR 0108 / 0133）

- 状态：**已实现，未上线**（2026-10-24）。上线 = 只是换代码重启，没有配置变化；回滚 = `git reset --hard da8721d`
- 日期：2026-10-24
- 关联：[ADR 0108](0108-proactive-opener.md)（开头别叫名字）、[ADR 0133](0133-proactive-lead.md)（主动发的话要有由头；`LEAD_NOTE` 是这一条要改的）、[ADR 0100](0100-reach-when-unanswered.md)（催他）
- 来源：2026-10-24「继续」——接着找“还有哪里不像人”，这次读的是 ADR 0133 上线后的主动消息

## 问题（有数据）

ADR 0133 的 `LEAD_NOTE` 里为了讲“开头要有由头”，写了「刚…」「你猜怎么着」「跟你说个事」当例子。用 6 个主动场景 × 2 次真模型模拟读出来（67 次生成，约 0.34 百万输入 token）：

1. **例子被当成套话**：非催他的 11 条主动消息里 **6 条以「刚」开头**；「你猜怎么着」被原样塞进句子里，变成「那张雨里的你猜怎么着，居然拍出点感觉来了」（读不通）。每一条单看都自然，连起来像一个模子。
2. **改写 `LEAD_NOTE` 的第一版里，模型在“带感觉”的要求下给事实添小动作**（基线的 ADR 0133 措辞里没出现，是我只去掉例子、没有限定“事实只能用写了的”之后冒出来的）：土豆那几条写成「蹲在楼道口等我，一见我撒腿就跑，跑两步又回头看我」「喂完它扭头就跑了，一点不领情」。事实里只有“土豆今天没下楼 / 昨天喂过”，动作是编的——和 10-23 用户说“在逛淘宝，加了又删”不像人（尤其后半句）是同一类毛病。
3. **改写第二版里，“接上面聊过的话头”被用在隔了几个小时的话头上**（同样不是基线的毛病，是把“要有由头”写成“接话头”之后冒出来的）：一条主动消息的第一句只有「行」，一条是「累就先歇会儿，别硬撑」，都是在回几个小时前他说过的事，没头没尾。

催他的几种说法（ADR 0133 改过的“说你这会儿有点无聊、在等他”）里，这批模拟的“人呢，我这儿有点无聊”占多：但这批模拟同一个场景里每次抽到的说法是同一个（说法按候选 id 定），所以不能当作“线上也这样”的证据，没动。

## 做了什么

1. **`LEAD_NOTE` 改写**（`proactive.ts`）：去掉所有现成的例子（不再列「刚…」「你猜怎么着」「跟你说个事」）；改成「开头给个由头让他看懂你为什么这会儿说——接上面**刚聊过**的话头（一小时内的；隔了几个小时的别翻出来，会变成没头没尾的一句），或者先说你此刻的感觉再说事，或者直接说事本身；开头别老是同一种，也别照搬现成的套话」；末尾加「感觉是你自己的，事实只能用上面写了的，别添上面没写的小动作、小场景（猫怎么看你、怎么跑，手上又干了什么）」。
2. **最近几次开头都一样就提醒换一种**（`expression.ts` `repeatedOpener`，`contact.ts`）：她主动找他时，看她最近 5 次话头（连着发的一串算一次，看第一句）的起头词（刚 / 对了 / 哎 / 诶 / 喂 / 人呢 / 跟你说 / 你猜 / 话说 / 今天），同一个出现 2 次以上，提示词里多一行「你最近几次开头都是「X」：这次换一种开头，别用「X」起头」。只在她主动找他的时候加，回他的话不加；危机回合不加。

## 数据

同样的主动场景再跑三批（每批 `--runs` 2–3，共约 132 次生成、0.7 百万输入 token；说明是边读边改的，所以三批用的措辞不完全一样：第一批只改了例子和开头，第二批加了“不添小动作”，第三批加了“只接一小时内的话头”）：

| | 非催他的主动消息里以「刚」开头 | 「你猜怎么着」 | 事实里没有的小动作 | 没头没尾的一句 |
|---|---|---|---|---|
| ADR 0133 的说明（基线） | 6 / 11 | 1 条塞进句子里 | 0 | 0 |
| 改后第一批 | 2 / 20 | 0 | 2 条（土豆） | 0 |
| 改后第二批 | 3 / 16 | 0 | 0 | 2 条（只有「行」；「累就先歇会儿，别硬撑」） |
| 改后第三批（最终措辞） | 1 / 15 | 0 | 1 条轻微（「蹲了半天没见着它」） | 0 |

样本小，同一场景每次的世界一样，所以只能说“这几类毛病没再出现或变少”，不能说没有了。线上要看几天：她主动发的话里以「刚」开头的占比、有没有套话、有没有添小动作。

## 没做 / 要注意

- 催他（reach）的说法没动。
- `repeatedOpener` 只认上面那些常见起头词，不认任意两个字。
- 单元测试：`realness-intent.test.ts`（`repeatedOpener`）、`proactive-lead.test.ts` / `small-news.test.ts`（新措辞）。
