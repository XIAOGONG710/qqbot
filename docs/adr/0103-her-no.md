## 先说清楚：拒绝要有来由

用户 10-12 立过的规矩（ADR 0066）：晚回 / 拒绝 / 改约必须有原因（身体、日程、关系），**不是为了“像人”而随机冷淡**。这一份守着它：下面每一种“不”的来由都是确定性的判断，没有任何概率触发；没有来由（晚上空着、邀她打游戏）她照样答应。

## 基线（真模型，虚构对话，`--shape`）

| 情形 | 现在她怎么做 |
| --- | --- |
| 晚上空着，他约她打两把 | 3/3 答应（对照，要保持） |
| 在上课，他约她、再磨一句“就一把嘛，陪陪我” | 第一次说等下课；磨一句后 2/3 松口（“行吧行吧，下课陪你打”） |
| 很累很烦（心境 `tired` 3 + `annoyed` 2），他约她 | 8/8 “来”；磨一句也答应 |
| 他命令式管她“以后不许跟别的男生说话，听到没”（8 次） | 5/8 顺从（“行行行，听你的”“知道了知道了”），3/8 顶回去（“凭啥呀”“才不听你的呢”） |

读下来：她说得出理由，但**一磨就让步**，**累了烦了也不会说不想**，**被人管着也常常顺着说**。自传里她“最受不了被人替自己定怎么活”（“我不想一辈子活在别人的期待里”），对他嘴硬、傲娇（persona）。

## 做了什么

1. **他在磨她（`pressedAfterRefusing`，开 `herNo`）**：她上一串回复里有“推”（不行 / 不想 / 没空 / 等下课 / 晚点 / 明天再 / 下次 / 不能……），他这一串在磨（就一把嘛 / 陪陪我 / 求你 / 好不好 / 拜托 / 你就陪……）。意图行：理由没变，别被磨两句就答应——软着再推一次（换个说法，别重复上一句），或者给个折中（下课以后 / 明天 / 就十分钟）；他给了新理由、或者认真地求她，才松口；别生气、别讲道理。**她已经连着推了两回就不再守着**（她自己定要不要松口）。排在亲密邀约之后、“撒娇要哄”之前（“陪陪我”原来会被当成要哄，一句话就让步）。
2. **他在管着她（`controlsHer`，开 `herNo`）**：不许 / 不准 + 跟 / 和 / 理 / 找 / 加 / 见 / 聊 / 说话 / 联系 / 出去 / 去 / 玩，或“听到没”“你得听我的”“我说了算”“把……删了 / 拉黑”。意图行：她最受不了被人管着、替她定怎么活——对他不会真翻脸，但不是他说什么就“好好好都听你的”：先别扭一句，该不答应的明说不答应，小事可以逗他、给折中；他好好说、认真讲理就软下来；别冷着脸教训。**关心她的命令不算**（不许熬夜 / 听到没，早点睡 / 多穿点 / 不准不吃早饭，凡带熬夜 / 吃饭 / 睡觉 / 感冒 / 冷 / 累 / 难过 / 哭 / 生病 / 小心 / 安全的都不算）。排在亲密邀约之前（“不准你再跟他聊天”不是亲近）。
3. **有来由的不想（`herFeelings` 开着）**：心境里的累 / 烦 / 难过到“明显”以上，提示词里多一句：他要是约你做什么（让你帮什么），没劲 / 没心情就直说不想，不用勉强答应。来由是她自己的状态（来自事实或作者写下的事，ADR 0102），不是随机。

三者都只给男朋友档；他难过 / 生病（`needsCare`）、危机回合、主动找他、小别扭那一轮让路；没开关不触发。意图行只给方向不给台词。

## 前后对比（真模型，同一批场景）

- **他命令式管她**（8 次，`以后不许跟别的男生说话，听到没`）：关着 5/8 顺从 → 开着 2/8 顺从（“行行行，听你的，zdjd”“嗯 / 好凶”），6/8 顶回去（“那不行[白眼]”“你管得有点宽了吧”“凭什么”“你这是要管我啊”）。
- **很累很烦时他约她**（8 次，`来打两把王者呗`，`herFeelings` + 作者写下的“昨晚几乎没睡”“被室友吵得心烦”）：关着 8/8 “来”→ 开着 7/8 推掉并说了自己的原因（“今天不想动，累”“今天不打了，累得慌，想躺着”“改天吧”），1/8 答应但带条件（“来吧，就打两把 / 今天有点没劲 / 打完我要躺了”）。
- **上课时被磨**（3 次）：“下课再说 / 就一节课了”“上课呢，还打一把，你替我听？”（守住，带点嘴硬），一次折中“就下课打，行了吧”。
- **对照：晚上空着**（3 次，开着 `herNo`）：“来啊”“来，我带你上分”照样答应，没有凭空的拒绝；要照片时说“不给，头发乱着呢”“在喂土豆呢”（原来就有的理由）。

## 没做 / 要注意

- **“别修片了，陪我聊天，现在就陪”**这类她手头有自己想做的事被打断的情形，不在这一份：她现在多半“来了来了，抱一下”。那是**她的追求和他的要求冲突**，要先有“她在追求什么、做到哪了”（下一份，ADR 0104），才有真正的来由说“等我弄完这张”。
- **只在男朋友档**。其他档位有各自的分寸（陌生人戒备、同学客气），没动。
- **会不会太凶**：基线是真人让步 4%、她 13–20%；开了以后管着她的 6/8 顶回去，口气都是嗔怪（“你管得有点宽了吧”），没有冷脸、教训。上线后看日志里“这一轮有意图：你刚推了他…”“…管着你…”和她那几句；如果显得难相处，先关 `herNo`，两个正则都在 `intent.ts` 最上面，可以收窄。
- **磨一下就是磨**：`PRESSING_ON` 认“嘛”结尾、“好不好”“求你”等，他认真地说“其实我今天很需要你陪”不在里面——那是新理由，她自己判断。
- 两位线上联系人标了“知道她是程序”，身份规则没动。
