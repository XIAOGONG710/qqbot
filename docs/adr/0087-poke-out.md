# ADR 0087：她主动戳他一下

- 状态：**已实现，未上线、未开启**（分支 `claude/poke-out`；配置 `pokeOut`，默认关）
- 日期：2026-10-19
- 关联：[ADR 0079](0079-pokes.md)（他戳她、她戳回去）、[ADR 0083](0083-presence.md)（存在感的每分钟小循环）、[ADR 0085](0085-napcat-probe.md)（`friend_poke` 和 packet 服务在线上验过）
- 用户提出：2026-10-19「继续之后让其更像人」。

## 背景

现在她会被戳（ADR 0079），也会戳回去，但**从不主动戳他**。真的女朋友会在他很久没动静的时候戳他一下，什么都不说，就是「我在」。这是一个很轻、没有文字、对方一眼就看得到的动作。

## 决定

1. **配置 `pokeOut`，默认关**，放在存在感的每分钟小循环里（ADR 0083），和点赞、说说同一类；要传输层有 `friend_poke`。
2. **频率**：约三成的日子（`POKE_OUT_CHANCE`）；工作日 19:00 起、周末 14:00 起（按日期哈希定，最晚 21:30 起）；一周最多 3 次、两次之间至少 36 小时；到点之后每分钟看一眼「合不合适」，22:30 还没等到合适的就今天不戳。她睡着、上课时不戳。
3. **合适**（`quietEnoughToPoke`）：聊天记录里**最后一条是她说的**（他没回，没有他的话在等她回）、**已经安静了 90 分钟以上**、最近四条里没有「晚安 / 睡了 / 去睡 / 睡觉」；没聊过的不戳；这个联系人在危机暂停里（ADR 0068）不戳。只戳男朋友档的联系人。
4. **戳了就记**：聊天记录里追加一条她说的「[你戳了戳他]」（id 用 2^41 + 毫秒，不和真 id、他的戳撞），所以他回「戳我干嘛」时她知道是自己戳的，不会装傻。
5. **失败**：`friend_poke` 失败（packet 服务不可用）今天的机会用掉、只记一次日志，成功了记一次。
6. 别的不变：他戳她、她戳回去（ADR 0079）照旧；她戳他的通知回声（`user_id` 对方、`sender_id` 她自己）不满足 `isPokeAtMe`（`target_id` 不是她），不会被当成他戳她。

## 验证

- `pokes.test.ts` 2 项：什么时候合适（最后一条是他说的、才安静不到 90 分钟、刚道过晚安、他说去睡、没聊过都不戳；更早的晚安不算）；记下来的那条的 id 是非负安全整数、不撞。
- `presence.test.ts` 2 项：计划（约三成、钟点范围、同一天每次一样）；循环（到点前不戳、到点了聊天没安静就等、安静了戳一下并记下来、一天一次、22:30 之后不戳、关着不戳）。
- `presence-soak.test.ts`：60 天每分钟一次、每隔几天重启，任何 7 天最多 3 下、间隔 ≥ 36 小时、钟点在范围里、她醒着、总数 6–25；`friend_poke` 一直失败时 60 天里最多试一天一次。
- `app.test.ts` 1 项：整条线接通——聊天安静了、最后一条是她说的 → 戳了并记下「[你戳了戳他]」；最后一条是他说的、或关着，不戳。
- 线上的 `friend_poke` 本身 10-19 16:52 探针验过（她戳了你一下）。**第一次真开要你在场看**：等到某个晚上聊天安静了，看有没有「林梦瑶戳了戳你」，你回「戳我干嘛」她接不接得住。

## 没做

- 不戳「还没睡的陌生联系人」，只戳男朋友档的。
- 没有按他的作息推断他睡没睡（不知道他的作息）：晚上 21:30 前后是时间窗，戳在 QQ 里是静音的小动作，最多他醒来时看到。
