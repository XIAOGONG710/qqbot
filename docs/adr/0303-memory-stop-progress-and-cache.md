# ADR 0303：记忆停止收尾、进度校验与实体缓存世代

状态：接受

## 证据

记忆审查 M25–M27：建库请求挂起时停止 App，旧实例仍继续发起模型和记忆写入；进度字典为数组时字符串键在 JSON 中丢失；并发实体查询的旧失败覆盖新成功缓存。调用链复核还发现日记、承诺和回复发送有各自的异步所有者，不能只停 LongTermMemory 就释放目录锁。

## 决定

1. LongTermMemory 停止后拒绝排队工作和后续请求，取消纯读取的等待，晚读取不提交缓存。不强杀已经派发的远端修改：确认成功后保存实际进度再完成 drain。模型更新成功但尚未派发 refresh 时，不把整项更新标为完成；创建确认可以记录创建版本。稳定 document ID 的既有重试语义保持。
2. 日记和承诺有独立停止入口。日记已派发 retain 的确认和本地 written/texts/weeks/phases 记录归日记所有者；停止后不开始下一篇、总结或模型请求。承诺纯抽取可以结束等待，晚结果不发布到状态或世界。
3. Responder 在调用发送函数之前登记发送所有权，覆盖真实 ACK、历史表示转换和追加。停止取消剩余气泡、打字和错字改口，保留已经发出的事实；已派发的撤回等待其确认。历史 IO 失败与 QQ 发送失败分开，安全诊断后返回真实发送结果，避免重复发送。发布后异常只在确切新增 ACK 历史可读回时确认；持续未落盘没有持久 outbox，不声称 ACK 历史必然耐久。

2026-11-05 的记忆收口复核补上纯等待的资源边界：Responder 默认的安静窗口、重试、打字和气泡间隔定时器归属该实例，生命周期停止必须实际清除定时器；`waitForQuiet` 在停止后直接结束，不能在已中止信号与冻结测试时钟之间形成立即 resolve 的忙循环。注入的自定义 `sleep` 仍只保证本地放弃结果，无法强杀不合作实现。该修复不把纯等待变成 mutation drain，已经派发的发送仍按上一段等待 ACK 和本地事实收尾。
4. App.stop 闲置同步返回 undefined，有收尾时返回可等待 Promise；聚合各所有者后才释放 bot.lock。Koishi dispose 返回此 Promise；独立进程正常信号退出先等待 App，再断开 OneBot，保证在途 ACK 可返回。强杀、显式同步 process exit 和外层独立发送者不在这一保证内。
5. 构造入口先拿目录锁再读写状态。同一 JS isolate 使用模块热重载也共享的租约令牌，避免同 PID 的新实例抢占旧实例收尾期，以及旧释放回调删除新锁。PID 文件原有跨进程陈旧锁算法不升级为事务锁，不宣称解决所有 TOCTOU、worker isolate 或网络文件系统互斥；CLI 全过程停机协调仍待处理。
6. Contact/Common 进度完整校验：普通对象、bank 身份、片段计数和版本字段；保留合法旧 boolean/string 版本及未知扩展。坏 JSON/schema 沿 ADR0013 隔离并按稳定文档重写，只有真正缺失才无旧文件；瞬时 IO 不隔离、不覆盖。换 bank 从头建立进度，不猜测旧身份。
7. 公共实体查询同世代 singleflight；公共内容写入成功使缓存世代失效，旧请求无论成功或失败都不能提交新世代缓存；返回数组克隆。

## 验证与边界

合成 API 覆盖读挂起、建库/模型/retain 确认、排队停止、缓存旧失败和跨世代失效；实际 App 加独立子进程验证收尾期间目录仍被锁定。没有访问真实 QQ、记忆服务或运行时。

远端 retain 的接受确认不证明异步抽取完成、事务性删除旧衍生事实或 exactly-once。计数相同的撤回片段仍未触发长期文档覆盖，另列待修；本 ADR 不把停止修复称为撤回彻底遗忘。日期补查保留追加顺序与低年份，修真实日期、民用日差、持久时间和 Unicode 有界检查；合法但所在时区不存在的民用日仍需接口层补查。
