# ADR 0039：重启前后她是同一个人

- 状态：已实现，单元测试通过，真模型回归见下（2026-10-08）
- 日期：2026-10-08
- 关联：[ADR 0017](0017-long-term-memory-like-a-person.md)（公共记忆的线索）、[ADR 0022](0022-her-past.md)（她的过去）、[ADR 0033](0033-npc-days.md)（她身边的人）、
  [ADR 0038](0038-replayable-action-queue.md)（行动队列的重启恢复）、[实施方案](../research/2026-10-07-life-engine/implementation-plan.md) 第 6 节 72 小时验收「重启对照」

## 背景

线上每次上线都要重启 Koishi（10-07 三次、10-08 两次），以后还会有崩溃重启。真人不会因为「重启」忘掉刚才在聊什么、刚想起什么。

取证（`qqbot-life` 分支，模拟器加了 `restart` 步骤之后）：她刚想起的三样东西只在回复器的内存里——
公共记忆（`lastCommon`，ADR 0017：接下来两轮没有新线索也沿用）、从前（`lastPast`，ADR 0022）、刚说起的她身边的人（`lastNpcs`，ADR 0033）。
重启以后他追问「她好了没」「那后来呢」，提示词里就没有了——同一场景带重启和不带重启跑两遍，第 3 次生成的提示词就不一样。

ADR 0038 的行动队列说「重启后从 `action-queue.json` 恢复」，但只有单元测试，没有端到端验证过。

## 决策

1. **「刚想起的」不记在内存里，每轮从聊天记录往回推**（`people.ts` `lingering()`）：从最近一轮往回找，第一个「他那一轮说的话里有线索、她之后回了不超过 2 次、10 分钟以内」（和原来 `stillInMind` 同一个标准）的那一轮。
   - 公共记忆：用那一轮的话、那一轮的时刻重新召回一次（召回是 Hindsight 现查的，和当时想起的基本一样；日志照旧「公共记忆沿用刚才想起的 N 条」）；
   - 从前、身边的人：用那一轮的话重新认线索，卡上的东西是固定的，和当时一样。
   这样重启前后、同一份聊天记录推出来的提示词一样——事实只在磁盘上（聊天记录、记忆库、事件账、行动队列），回复器里不留只有它知道的状态。
2. **模拟器 `{ "restart": true }` 步骤**：照 `app.ts` 启动时的做法，丢掉聊天记录、记忆、世界（含行动队列，ADR 0038）、答应的事、日记、回复器、主动消息，从数据目录重新读起，
   然后和连上 NapCat 时一样补写日记、回没回的消息（`catchUp`）。
3. **重启对照测试**（`test/restart.test.ts`）：同一场景带 4 次重启和不带重启各跑一遍（假模型），逐次比较完整提示词，再比较事件账；
   中间排了一个小时的学习、没结束就重启，确认队列读回来、到点照常落账、队列清空。
4. **对照测试把真实时间冻住**（`runScenario` 的 `realNow`）：两遍的消息时刻才一样（ADR 0024 的长短提示按他那条消息的毫秒掷骰子）。
   冻住以后回复器等连发停下来（`waitForQuiet`：真实的 `sleep` 等、虚拟的 `now()` 判断）永远等不到，测试里不开连发合并（`settle: { quietMs: 0, maxMs: 0 }`，每步一句话用不着）。
   试过把 `waitForQuiet` 改成和「到点才看到」一样用 `waitUntil` 等，`runtime.test.ts` 里连发合并的测试是靠假 `sleep` 控制时间的，会卡住，撤回了：线上行为没问题，不为测试改回复器。

## 不做的

- 不把「刚想起的」存盘：能从聊天记录推出来的就不另立一份状态（和 ADR 0030、0034、0035 同一条纪律）。
- 公共记忆重新召回比沿用文字多一次 Hindsight 请求（只在「没有新线索、上一轮有」时）；量很小，不缓存。

## 验证

- `restart.test.ts`：4 次重启前后每一次生成的提示词逐字一样，事件账一样，学习跨重启照常落账（约 50 秒）。原来没有 `lingering()` 时第 3 次生成就不一样。
- 真模型回归 `20261008-232636-p1008c`（`964ee15`，追问类场景各 3 次）：
  - `npc-days` 回复 74 / 75、管线 18 / 18：ND02「她严重不」没带名字，3 次都接上了苏雨桐感冒（日志「从前沿用刚才想起的：苏雨桐」）；不过的一项是检查词误判（「她说周末就好了」含「好了」）。
  - `past-boyfriend` 回复 74 / 75、管线 21 / 21：「那后来呢」3 次都沿用了「小时候走丢那天、那块牌子」；不过的一项是「什么叫天天，也就一半吧」，接得很好，检查词没收。
  - `memory-diary` 回复 35 / 36、管线 17 / 18：DY03 追问 2 次「公共记忆沿用刚才想起的 6 条」；r2 那次「你不是不能吃辣吗」里的「吃辣」被抽成了公共库的实体，自己就是线索，重新召回了，不需要沿用（行为对，检查假定了没线索）。
    DY02 r2 问昨天没说麻辣烫：召回里有，是她自己挑了别的说。
  - `memory-cues` 回复 24 / 24、管线 15 / 15。
