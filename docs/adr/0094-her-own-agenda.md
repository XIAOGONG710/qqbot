# ADR 0094：答完他的话之后，偶尔带一件自己的事（配置 `shapeAgenda`，默认关）

- 状态：**已实现，默认关**（要 `shape` 开着；上不上线等用户点头）
- 日期：2026-10-21
- 关联：[ADR 0091](0091-reply-shape.md)（形状控制）、DSH `exchange/research/2026-10-21-aliveness`（活人感研究，第 2 步）、`exchange/research/2026-10-real-chat`（真人聊天样本）
- 用户提出：「现在长短什么的已经和真人相似了，但内容还是差距有点大」；10-21 晚「看 ds 的推送」「继续吧」

## 为什么

DSH 的研究说她缺“自己的议程”：真人女生答完他的话，常会顺带说一件自己的事，她只会应他。用它的定义（这一轮带「我」、且和他上一轮没有共同的两字词）在同一批真人情侣聊天（女方一侧、男朋友关系，n=79）上重算：

| | 自带议程 |
| --- | --- |
| 真人 | 30.4% |
| 她，旧代码 | 19.3% |
| 她，形状控制（ADR 0091） | 13.1% |
| 她，形状控制 + 新意图行 | 15.3% |

所以 DSH 说的“≈ 0”不对（旧代码就有 19%），但方向对：形状控制把长回复压短时，顺带把“补一句自己的事”也压掉了，从 19% 掉到 12–15%，真人是 30%。

另一个事实：真人的自带议程大多不是“汇报今天干了什么”，而是**关于她自己的感觉和状态**（「我好像长肥胖纹了」「我不活了」「好想你」「感觉我瘦了」）；他问了问题时只有 17%、没问时 34%；他的话长短对它影响不大。

## 做了什么

`shape.ts` 的 `planShape` 加了 `agenda`：开了 `shapeAgenda`，在**适用的轮次**里 25%（`AGENDA_SHARE`）让这一轮带一件自己的事：

- 适用 = 意图行是空的，或者是「回应他刚说的那件事」。其余意图行明着不让另起话题 / 转去讲自己（回答问题、他的好事、答应的事、忙着、两个人的事），或者本来就让她接着说她那边的事，加上去会和意图行打架——第一次重放里他问了问题时后面挂一句「刚喂了土豆」就很生硬。收尾、认真接话（难受 / 好事 / 问起她认识的人）、亲近 / 撒娇、心情安静、他在呜呜 / 哭 / 嘤嘤（连玩笑式的「呜呜呜」也算）也不加。
- 这样的轮次至少 medium（每条 14 字）、至少 2 条，不再“顺着说”。
- 提示词多一句（`AGENDA_NOTE`）：先回他刚说的，回完顺带说一句自己的事；从「你那边」「你的身体」「你今天的心情」里挑一件他还不知道的（不是正在做的那件事，前面说过的也别再说），事或者此刻的感受（累、困、饿、烦、开心）都行；没有合适的就别说，更别编；说完不用问他，也别用反问句。不给台词。
- 其余抽签不动（同一个种子）：没带事的轮次的形状和不开时一模一样（`shape.test.ts` 逐轮对比）。

## 量出来的（他真实发过的 180 条话，22 个场景 × 3 次，真模型）

| | 自带议程（DSH 定义） | 无关的结尾条* |
| --- | --- | --- |
| 真人 | 30.4% | 27.8% |
| 基线（形状控制 + 新意图行，没开） | 15.2% | 11.5% |
| 第 1 版（所有意图行、从「你那边」挑） | 18.9% | 24.5% |
| 第 2 版（限意图行） | 16.6% | 19.6% |
| 第 3 版（+ 呜呜不加、不说正在做的事） | 15.4% | 20.7% |

*无关的结尾条 = 一轮 ≥2 条、最后一条不是问句、和他上一轮没有共同的两字词。DSH 的“带我”定义量不出她的新内容：她补的事多半不说「我」（「明天笔记本到」「土豆今天蹭我腿了」），所以另加这一把更宽的尺子（`tail-topic.cjs`）。真人 n=79，标准误约 ±5，重放的几次之间也差 ±2，别读得太细。

- 带事的轮次约占全部轮次的 12%（66–72 / 530）；其中 82–89% 真的说了一件她那边的事，只有 5–12 条带问号。
- 第 1 版的问题：她补的几乎都是“正在研究相机设置，头都大了”（那是时间块里的当前活动，一晚上不变），连着几轮复读；他问问题或“呜呜呜”时挂一句也生硬。第 3 版补的事开始分散（笔记本明天到、土豆、今天没课心情好、攒到 2950、生理期第 5 天「别惹我」），生硬的情形也少了。
- 没量到的：这些场景的世界是固定的（同一份事实），真实的一周里每天事实不同；一天里她把“你那边”的事说完以后会不会硬凑，要在线上看。盲评鉴别员（ADR 0093）的样本里没有她那边的事实，量不了这一项。

## 没做 / 要注意

- 默认关。开的方式：`shape: true` 之外再加 `shapeAgenda: true`，重启。回滚：关掉就行。
- 开了以后看的东西：日志里「这一轮形状：…（medium，带自己的事）」的占比（应约十分之一）；她补的事是不是都在“你那边”里（不编）；有没有连着复读同一件；他那边有没有觉得突兀。
- 她“关于自己的感觉”只靠心情和身体两行；真人更多的“我不活了 / 我瘦了”这类是情绪化的自我表达，这里没做，也不该靠一条提示词硬做。
- 模拟器：`--agenda`（同时打开 `--shape`），或场景里 `"shapeAgenda": true`。
