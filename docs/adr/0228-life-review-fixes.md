# ADR 0228：生活模块审查修复边界

- 日期：2026-11-05
- 状态：采用
- 背景：[生活模块审查](../reviews/2026-11-05-life-review.md) 的 16 项缺陷已由合成数据复现；修复需保持单一事实源、历史数据可读和确定性投影。

## 决定

1. 约定抽取结果至少包含一个已知结果数组，已提供的结果字段必须为数组。兼容只返回部分数组的旧结果，但错误对象不能冒充成功的空结果。按原有失败重试策略处理；失败不清除提前约定。错误日志不包含模型原文。
2. 已写日记但原文暂不可用时，周记和阶段总结均等待重试；未写过的日子仍可跳过，不编造缺失内容。
3. 熟人观察按平台事件 ID 或完整观察指纹去重，每人保留最近 256 条 SHA-256 指纹，独立于八条展示摘录。去重范围有界；不声称无限重放幂等，旧记录不根据缺失证据猜测迁移身份。
4. 当前状态和项目组合只消费截止时刻已发生的事实。摄影统计作为通用全账聚合器仍允许不传截止时刻，但当前项目组合必须传入 now。成绩记录和事件共享公布时刻；自定义追求的完成状态与评价同时按 now 过滤。
5. 已知可靠阅读总量时封顶；max 仍可以让阅读在全书结束前暂停，max 高于全书总量时以全书总量为界。起点超过全书总量视为配置错误。
6. 保持接单接口单日最多一单；perMonth 必须为 0–28 内的有限数，保证每个月都排得下，非法值明确报错。先保留旧规则每个日期的第一单及其工资，再把碰撞丢失的单确定性安置到空日，不对全部日期重新洗牌。历史曾漏计的收入可能影响回放的后续余额；验证现有财务事实锚点，不以修改锚点断言掩盖回归。
7. 指定日期活动配置在解析时保留并校验日期、时段、正文和可选 home；不允许以静默丢字段代替校验。

## 验证与后续

正确行为回归位于 `packages/bot/test/life-review.test.ts` 和 `life-review-time.test.ts`，覆盖解析、持久化、重放、重启、缺失恢复、时间边界和确定性排程。逐批验证和提交记录见 [持续优化进度](../reviews/optimization-progress.md)。完成已知问题不等于模块不存在其他缺陷，后续仍需按完整模块清单深入复查。
