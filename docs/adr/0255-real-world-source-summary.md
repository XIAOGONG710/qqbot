# ADR 0255：现实世界数据展示来源与更新时间

- 日期：2026-11-04
- 状态：已实施
- 相关：ADR 0048、0227、0228、0231、0254

## 问题

Koishi 状态页已经能汇总天气、空气质量、日照、法定日历和交通是否正常，但只显示覆盖数量和错误状态。数据看起来正常时，用户仍不知道来自哪里、最后何时更新；排查陈旧缓存时需要翻日志。直接展示底层供应商字段又可能泄露自定义来源名、接口细节或错误正文。

## 决策

1. 只复用世界模块已有的只读状态，不新增网络请求或缓存文件。
2. 已知供应商按固定白名单翻译为 `Open-Meteo`、`法定日历服务` 和 `自定义交通数据`；未知供应商不展示。
3. 地点只展示现有公共地点“学校那边、老家”，未知键不进入页面。
4. 更新时间统一转换成本地的“月日 时分”，不展示 ISO 字符串；非法时间直接省略。
5. 每项摘要按“状态、覆盖、来源、更新时间”排列。错误正文、交通详情、自定义来源字段和接口地址仍不进入控制台。

## 验收

- 覆盖五类现实数据的正常、陈旧、失败和等待取数状态。
- 验证已知来源、地点、覆盖量和本地时间能显示。
- 注入未知供应商、未知地点、非法时间和敏感错误，确认页面摘要不包含这些原文。
- 运行 Koishi 状态页测试、插件全量测试、类型检查和 `git diff --check`。

## 回滚

回滚本次提交即可恢复原有简短状态；没有修改世界数据格式或刷新逻辑。
