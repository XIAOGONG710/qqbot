# ADR 0131：说话的质感（配置 `texture`，默认关）

- 状态：**已实现，未上线**（2026-10-23；配置 `texture`；默认关）。上线 = `koishi.yml` 里加 `texture: true` + 重启；回滚 = 改回 false + 重启（不存任何状态）
- 日期：2026-10-23
- 关联：[ADR 0024](0024-expression-layer.md)（打错字——同一个位置）、[ADR 0051](0051-qq-faces.md)（QQ 小黄脸）、[ADR 0091](0091-reply-shape.md)（形状 + 「像不像真人」的尺子）、[ADR 0132](0132-bili-stickers.md)（表情包自己在 B 站找）
- 用户提出：2026-10-23「质感那几项也往真人靠，如果可以的话尽量超过我」；同日追加「表情包让她在 bilibili 自己找，不要用或者少用黄豆表情」

## 问题（有数据）

用「像不像真人」的尺子（`humanness.ts`，用他自己的聊天训练，只看写法）量 10-21 以后线上她的话：被判成真人的 **21%**，他自己的 **64%**。最拖后腿的是写法，不是用词（每百条里有多少条带）：

| 写法 | 她 | 他 |
| --- | --- | --- |
| 句末没有任何标点 | 95 | 79 |
| 「～」 | 0 | 10 |
| 句末「？」 | 3 | 10 |
| 整条只有一个小句 | 95 | 83 |
| QQ 小黄脸 | 0 | 18 |
| 叠字（哈哈哈 / 啊啊啊） | 2 | 6 |
| 两个字以内的反应 | 5 | 14–24 |
| 夹英文字母（ok / hhh） | 0 | 2 |
| 结尾「……」 | 2 | 0 |

这些模型自己不会写（ADR 0051 实测 9,039 条气泡里只有 1 处方括号；卡里写“偶尔带小黄脸”也没用；问句她多半不带问号）。

## 做了什么（`texture.ts`，`contact.ts` 的 `decorate`——和打错字同一个位置：气泡拆好、出口检查过之后，发出去之前）

按概率、按语气，纯函数，同一句话结果固定。**只对男朋友档**；危机、他难过 / 生病 / 小别扭 / 她在认真安慰他的回合（`serious`）一律不加；表情包、照片、链接、已经带了小黄脸的气泡不动。
1. **问号 / 感叹号**：一条看得出是在问的（吗 / 什么 / 几点 / 有没有……）没带标点，约 60% 补「？」；「太……了」「好……啊」约 30% 补「！」；结尾的「……」去掉（问句换成「？」），整条只有“……”的无语反应不动。
2. **「～」**：轻松的短句（句尾是啦 / 呀 / 哦 / 嘛 / 哈……，很短时也包括呢 / 吧 / 啊 / 好 / 行）约 50% 把句号换成「～」，一次回复最多一条；不加在问句、长句、陈述句上（「宿舍有人睡了」不会变成「宿舍有人睡了～」）。
3. **叠字 / 英文字母**：整条只是一个语气词（哈哈、嗯、啊、呜……）时拉长；整条是「好的」「哈哈哈」时偶尔写成 ok / hhh。
4. **并条**：连着两条都很短的（各 2–9 字、没有问号 / 小黄脸），约 50% 并成一条（「你说，我听着」）；不增加条数。
5. **先回一个字的反应**：他在笑（哈哈、笑死）→「哈哈 / 哈哈哈 / 笑死」，他觉得离谱（真的假的、居然、！！）→「啊？ / ？ / 真的假的」，约 30%；他陈述了件事、她的第一条比较长时约 10% 先「嗯嗯 / 嗯 / 好 / 对」；要有空位（不超过这一轮的条数上限）。
6. **小黄脸**：**用户 10-23「不要用或者少用黄豆表情」**——只在语气很对得上时偶尔带一个（笑 → 笑哭、晚安 → 睡、想你 → 爱心、无语 → 白眼……，只用她能发的 16 个），**约 2% 的气泡**；没有线索的回合不带中性的；她最近 6 次回复里已经带了 2 次就不带。表情的位置由表情包顶上（ADR 0132）。要完全关掉：`TEXTURE_SHARES.faceCue` 改成 0。

## 数据

- **离线重放**（她线上 88 个回合、121 条气泡，不调模型）：尺子给的平均分 0.438 → **0.506**，判成真人的 30% → **41%**（小黄脸 0%）；开着 80% 的小黄脸时是 0.526 / 43%——小黄脸不是主要的，句末标点、「～」、并条、问号才是。句末无标点 95% → 80%，问号结尾 3% → 15%，「～」0 → 5%。
- **真模型 A/B**（同样的 6 个多轮场景各跑 2 次，约 230 条气泡，有 / 没有 `texture`，用同一把尺子；有质感那批跑的时候小黄脸还是早先的 80%，所以小黄脸占 13%）：平均分 0.467 → **0.531**，判成真人的 34% → **45%**；可见的写法：「～」3.4% → 10.4%，问号结尾 1.3% → 7.2%，句末无标点 94% → 80%。
- **没有做到“超过他”**（他自己 64%）：加上质感能到 41–45%，再往上要靠**内容层面**——她还差的主要是：非汉字的比例（她 0.91、他 0.83）、句末「吗 / 嘛」（1% 对 7%，她问得少，ADR 0126 追问开了会好一些）、整条多个小句（7% 对 17%）、两个字以内的反应（7% 对 14%）、很长的气泡（她 1%、他 6%）。靠代码把这些硬加上去会越来越像刻意（小黄脸一多就是），所以这版停在不刻意的范围。**这个差距是尺子量出来的，不等于“人一眼看出来”**——用户读她的话的感觉还是准的，要继续用你的眼睛。

## 没做 / 要注意

- 只改“写法”，不改内容；加的东西都会进聊天记录（她下一轮知道自己发过）。
- 尺子是用他自己的话训练的，它会偏向他的习惯；调参别只盯着它（`TEXTURE_SHARES` 里每一项都可以单独调成 0）。
- 一次回复最多一个小黄脸或「～」；并条 + 先回反应不会超过这一轮的条数上限。

## 验证

`texture.test.ts`（15 个）：serious / 空 / 表情包照片链接不动、同一句每次一样；问号和感叹号（比例、本来带标点的不动、不是问句不补、「真的」不当感叹）；省略号；「～」（比例、一次一条、不加在问句 / 长句 / 陈述句）；小黄脸（线索对应的表情都在她能发的 16 个里、一次最多一个、最近带得多就不带、整条是英文字母的不带、他在笑时短句也可能带、**一般回合里带小黄脸的不到 5%、中性的 doge 不带**）；叠字 / 英文字母 / 并条 / 先回一个字的反应（有空位才加、已经是反应开头的不加、他在问就不“嗯嗯”）。
