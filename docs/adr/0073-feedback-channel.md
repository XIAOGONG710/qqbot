# ADR 0073：反馈通道——他在 QQ 里对她的话回「假」或「像」

- 状态：**已实现，未上线**（分支 `claude/feedback-channel`，开关默认关；上线要等观察窗口结束、用户当次点头、重启一次）
- 日期：2026-10-15
- 关联：任务书 `exchange/tasks/2026-10-13-gpt-measure-realness-and-reliability.md` 的 T1；[ADR 0068](0068-crisis-response.md)（底线：危机最小规则不能被绕过）；ADR 0069（稳定与隐私基线，在加固分支里）
- 编号说明：`0071`、`0072` 留给任务书 T4 的两份只写设计的 ADR，所以这份用 `0073`。

## 背景

终极目标的几条验收，现在每天量的只有表层（一轮几条、1–3 字占比、问句率）。**「哪句话像机器人」最直接的信号是他当时的感觉**，之前没有采集通道：评判者几乎全是模型，真人只有用户一个人，盲评一轮要花很多时间。

## 决策

1. **新开关 `feedbackCommands`，默认 `false`**，只对**男朋友档**联系人有效（名单外和别的档位一律当普通消息）。
   - **10-15 补充（用户批准「鸽鸽那边直接改」）**：联系人名单里可以给某一个人单独写 `feedback: true`，他/她也可以用；同一档位没写的人仍然不行，名单外永远不行。记录里的 `tier` 记这个人的真实档位。这个人要先知道有这个功能再写（鸽鸽：用户从自己的 QQ 告诉她，她知道林梦瑶是程序）。
2. **指令**：收到的消息里**只有**「假」或「像」一个字——前面可以有一个 `/`，后面可以有标点、至多一个小黄脸，带不带 QQ 的「回复」引用都行。「假的」「太假了」「真假」「你真假」「好像」「假装」都**不算**，当普通消息处理。图片、语音、@、第二个小黄脸一出现就不算。
3. **找被评价的那一轮**：
   - 带引用：被引用的那条她的消息所在的、连续的一串她的消息（按 OneBot `reply` 段的 id 对聊天记录里的 `messageId`）；
   - 不带引用：她最近的一串消息，最后一条要在 30 分钟之内；
   - **找不到**（引用的不是她发的、不在记录里；她还没说过话；超过 30 分钟）：这条当普通消息处理，什么都不记。
4. **命中就消耗掉**：不进聊天记录、不交给回复器、不进长期记忆、不触发主动计划器的 `poke`、**她不回应**。实时收到和停机后补回两条路都一样处理；同一条消息 id 只记一次（入口重投、重启后补回都可能再来一遍）。
5. **记录**：`<数据目录>/feedback/YYYY-MM.jsonl`，一行一条 `{ at, label: 'fake' | 'real', messageId, herMessageId, her: [那一轮的气泡], context: [之前最多 6 条], tier }`。数据目录在 `runtime/`（被忽略），**不进仓库、不进日志正文、不进交接**；日志只写一行「`[QQ] 反馈：假（本月第 N 条）`」。
6. **摘要工具** `npm run feedback-digest -w packages/bot -- [--days 7] [--dir <数据目录>]`：按天数「假」「像」各几条，再列出被说「假」的那几轮（带前面两条上下文）；只在终端打印，不写文件。

## 这是工具，不是行为

- 开关关着时，代码路径等于没有：不读不写 `feedback/`，「假」「像」按普通消息走。
- 开着时，**她说什么、什么时候说都不变**：不碰提示词、意图、出口检查、时机、角色卡。唯一的变化是用户的这一类消息不再作为聊天内容被她看到。
- 与危机规则（ADR 0068）无冲突：命中的只可能是单字「假」「像」，不含任何危机词；危机检测在聊天路径里，反馈消息本来就不走那条路。

## 代价和已知限制

- 他回「假」之后，她不回应——对他来说是「说了没反应」。用 NapCat 的消息表情回应（`set_msg_emoji_like`）可以让他知道「记下了」，但当前版本的 NapCat 源码里没有找到这个接口，先不做。
- 他只回「假」而没有别的话时，主动计划器仍认为「上一条主动消息他还没回」——这是对的：这不算回复她。
- 引用只能指到她发出去并记了 `messageId` 的消息；她的表情包记录里的 id 同样可用。
- 记录里有聊天原文（和 `chats/<QQ>.jsonl` 里本来就有的一样）；没有保留期。保留期工具见 ADR 0070 的数据治理部分，接上之前这份文件按 `chats/` 同等对待。

## 待用户确认

1. 字：「假」/「像」可以吗？还是别的（比如 👎 / 👍）？这一版把两个字写死在 `feedback.ts` 里，换字只改一个常量表。
2. 开在哪一档：现在只男朋友档。
3. 什么时候开：建议窗口结束（10-15 13:17）之后，A 组加固上线并看满 48 小时之后；一次一个开关。
