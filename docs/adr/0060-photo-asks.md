# ADR 0060：他要看照片——她先不发，用她自己的理由，再说给他听

- 状态：已上线（10-11 11:00，`57526b5`，和 GPT 的 `codex/intimacy-followup` 一起；用户当场同意）
- 日期：2026-10-11
- 关联：[ADR 0006](0006-exit-check.md)（做不到的事）、[ADR 0019](0019-today-layer.md)、[ADR 0053](0053-buying-the-camera.md)、[ADR 0057](0057-her-news.md)、[ADR 0058](0058-intimate-reciprocity.md)

## 问题

她只能打字（ADR 0002 决策 3）。出口检查拦的是答应发、假装发了（ADR 0006），但没人告诉她不发的时候该怎么说。

10-11 上午预演买到相机那一幕（`proactive-news` ×3，live `9d3b0f0`）：她 16:39 主动说买到了，他回「可以啊，发我看看」，三次她都直说自己发不了，其中一次说的是 QQ 这边拍不下来。真人手里有手机，不会说自己发不了图；这句话一出来就不像人了。今天 16:35 线上就会走到这一步。

卡里男朋友档只有一条「发张自拍看看 → 不要，头发乱得像鸡窝」的示例；同学、陌生人有世界书「要照片」（`privacy-photo`），男朋友档没有。

## 决策

1. 男朋友档（和亲密意图同一个开关 `intimate`）认出他要她发照片、给他看看：「发我看看」「来张自拍」「拍给我看看」「照片呢」「有图吗」「晒一下」「想看你」这类。他自己要发、要拍的（「我发你看看」「我拍张给你」「我给你发个照片」）和「把地址发我」「发个定位」不算。
2. 意图行：他想看照片。你手机能拍也能发，这次只是先不发：用此刻真实的理由轻轻推一下（看她正在干嘛，或者嫌拍得不好看），再用一两句话把他想看的样子说给他听；他要的是已经拍好的照片，就说拍了什么、拍得怎么样；不答应回头再发（答应了出口检查会拦，ADR 0006）。第一版举了三个现成理由（忙、懒得起来拍、拍得不好看），模型照抄「懒得起来拍」去回「你昨天拍的照片呢」，答非所问，改成只给方向。
3. 意图行只写想要的做法，不写出不想要的那句话（10-10 夜「行，睡吧」被照抄的教训；ADR 0058 第 3 条）。
4. 排在亲密意图、撒娇要哄、接梗之后，收尾、提问之前：「发张自拍，想你了」先按想他接。
5. 理由怎么选是她的事，不在代码里轮换；同一个理由天天说，由出口检查的原样重复（`verbatim`，ADR 0014）兜底。

## 没做的

- 真发图。她发得出真照片才是最像人的；要么作者提供一组照片（相机、土豆、食堂）按世界里的事挑着发，要么接图片生成。两条都要用户定，记在进度报告里等回话。
