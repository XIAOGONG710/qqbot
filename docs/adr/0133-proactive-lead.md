- 状态：**已实现，未上线**（2026-10-23）。上线 = 只是换代码重启，没有配置变化；回滚 = `git reset --hard ae7747e`
- 日期：2026-10-23
- 关联：[ADR 0100](0100-reach-when-unanswered.md)（没回也继续 / 催他）、[ADR 0101](0101-inner-life.md)（心里惦记）、[ADR 0108](0108-proactive-opener.md)（开头别叫名字）、[ADR 0110](0110-photo-shares.md)、[ADR 0127](0127-small-news.md)、[ADR 0128](0128-food-photos.md)
- 用户提出：2026-10-23「现在她主动发的信息很莫名其妙，没来由的突然发一个，感觉十分突兀」

## 问题（有数据）

线上 10-22 到 10-23 她主动发的 8 条里，说自己的事的几条是：「刚在超市逛了一圈，买了个笔记本」（催他的时机里发的）、「洗完澡了，肚子坠得难受」、「刚跟苏雨桐吃完晚饭回来，正研究相机设置呢」（心里惦记）、「室友分了点零食，还挺好吃」（她那边的小事，ADR 0127 刚上线的那条）。共同点：
1. **一句平平的汇报**：没有由头（他为什么要看这个）、没有自己的感觉、没有话头可接。
2. **都是他没回的时候**：每一条之前她的话都还没人回（距上一条 2–8 小时），她一条接一条地报自己的事——发给一个不在的人，更像播报。
3. **一半在提示词**：这几个时机的说明里写的就是「像突然想起来随口说的」「说完不用他回应」「不要他回应」（那是为了治“每句话都把球踢给他”的旧毛病，ADR 0013 / 0057 时写的），模型照字面写成了没头没尾的一句。催他那一条的备选说法里还有“顺手说一句你这会儿在做什么”，所以催他变成了汇报。

## 做了什么

1. **共用的一段 `LEAD_NOTE`**（`proactive.ts`）：「别写成一句平平的汇报：带上你自己的感觉（馋、烦、好笑、开心、想他），像在跟他聊天，不是发通知；开头给个由头让他看懂你为什么这会儿说——要么接上面聊过的话头（没聊完的话题、他说过去忙的事），要么用「刚…」「你猜怎么着」「跟你说个事」这类自然的起头；说完留个能接的口子（一句和这件事有关的话，或者让人想接的语气），但别问「在干嘛」「吃了吗」这类客套」。用在：随口说件事、冷场、她那边的小事（ADR 0127）、喂完土豆 / 吃饭拍的照片的那句带话、心里惦记想告诉他的；去掉了「像突然想起来随口说的」「说完不用他回应」「不要他回应」。想问他的念头改成「问得要让他看得懂你为什么问」。ADR 0108 的“开头别叫名字”照旧。
2. **他没回的时候，不再排说自己小事的几类**（`planFrom`）：她主动发的有一条他还没回，就不排 **小事（small_thing）、喂完土豆 / 吃饭拍的照片、心里惦记想告诉他的**（想问他的、催他、早安、睡前这些有理由的照旧）；他回了、或者聊着聊着没人理的（replied）不受这条管。这些本来就是“当天的事”，错过了就算了，不留到后面。
3. **催他不借机汇报**：`FIRST_NUDGES` / `REPLIED_NUDGES` 里“顺手说一句你这会儿在做什么”换成“说你这会儿有点无聊、在等他（别报自己去了哪儿、买了什么、吃了什么：那是汇报，不是戳他）”，“问他在干嘛”换成“问他忙完没有”。

## 数据

- 真模型模拟（10-23，同样的场景、有 / 没有这一段）：「土豆吃得特别快」那条，以前是「土豆今天吃得特别快，碗都舔干净了」（一句报道），现在是「刚下楼喂土豆，你猜怎么着，碗舔得跟新的一样」「平时还挑两下呢，今天跟饿了三天似的」；吃饭的照片以前是「午饭吃的青椒肉丝盖饭」，现在是「刚坐下吃午饭，青椒肉丝盖饭，闻着还挺香 / 你忙完记得也吃啊」「刚打完饭，青椒肉丝盖饭，看着比食堂平均水平高」。有了由头和自己的感觉，仍然是她自己的事。
- 单元测试：`proactive-lead.test.ts`（6 个）+ 4 个旧测试的断言改成新说法。

## 没做 / 要注意

- 这一版是“把话写得像聊天、不在他不在的时候一条条报”。**“她为什么这会儿找我”这件事本身**还有别的办法（比如只在他最近聊过的当天找他说小事、其余的留到他下次来了顺着说），要不要做看你；上面第 2 条已经去掉了最扎眼的那种。
- 催他（reach）本身没变：他一直没回，她还是会隔一阵戳一下（用户 10-22 的要求）。

## 附：用量（用户 10-23「昨天的花费好像有点高」）

模拟器每次跑完会打印「用量小计」（`sim/run.ts`）：共多少次模型生成、输入约多少百万 token。按各天模拟报告统计（只数聊天 / 主动 / 内心的生成，不含看图、抽取、记忆）：10-21 约 7,100 次、约 3,750 万输入 token；**10-22 约 4,800 次、约 2,550 万**；10-23 约 560 次、约 300 万。同一天线上自己的日志里模型相关的只有几十次（回复 22 + 主动 9 + 内心 23 + 看图十几次）。也就是说昨天的花费绝大部分是我的测试（全量回归 127 个场景跑了两遍、各个开关的真模型模拟），不是线上的她。
