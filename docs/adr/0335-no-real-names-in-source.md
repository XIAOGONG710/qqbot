# ADR 0335：源码和测试里不写真实的猫名、人名、城市名

状态：接受，2026-11-06。

## 问题与证据

ADR 0334 把按真实角色写死的逻辑改成了读卡上的字段，但源码的文案、正则和注释里还留着真实资料：

- 猫的真名约 60 处：日常小事的文案、照片货架的提示词和日志、主动发照片的提示词、「认出他想看猫」「她说过这件事了」的正则、相机追求的第二步、QQ 个性签名、心里念头的主题、控制台的标签和说明。
- 两个真实 NPC 的全名和名约 30 处，几乎都在注释里（线上取证的原话、举例），控制台说明里有一处。
- 她学校和家所在城市约 25 处：照片说明的地名过滤、「你倒是回 X 了」这种怪他的话的正则、照片筛选的日志理由、承诺提取提示词里的举例，其余在注释和控制台说明里。
- 测试里约 150 处用这些真名当测试输入（梗、笑话、照片说明、搜索词……）。

源码比角色资料更容易被拿出去（贴代码求助、交给代理或审查工具），这些名字不该在那里。

## 决定

1. **运行时要用的名字从卡上读**：新增 `src/character-terms.ts`，记着猫的名字（`world.cat.name`）、学校和家所在的城市（`world.weather.places` 的 name）。
   - 读卡时记下（`contact.ts` 的 `loadTierCard`）：同一个角色各档的卡名字一样，看得到的那一档记上，看不到的档位不清空。城市只写在前四档的卡上，所以 `app.ts` 启动时另从男朋友档的卡上记一次，名单里只有低档位时也有。
   - 用到的地方：认出猫（`photos.ts` 的 `photoWanted`、`expression.ts` 的「已经说过」、`contact.ts` 的话题标签）、照片在提示词里的叫法（`photoKindName`）、主动发猫照片的提示词、相机追求的五步（`cameraSteps()`）、照片说明里不许带的地名、「你倒是回 X 了」里的 X（家所在的城市）。
   - 日常小事的猫文案写成 `{cat}`，生成时换成世界里 `cat.name`（不走全局）。
   - 没读到卡（单元测试、没有猫的角色）：猫叫「猫」，没有城市；正则里只少了专有名字那一项。
2. **不必带名字的改成通用说法**：QQ 个性签名「楼下的猫又胖了」、心里念头的主题「楼下的猫」、照片货架的日志和控制台标签「猫」、照片筛选的理由「她学校那边没有的东西」、承诺提取提示词的举例「说好一起回老家」、控制台各开关的说明。
3. **注释改成通用说法**：真实 NPC 写成「室友」「闺蜜」，猫写成「猫」，城市写成「学校那边」「老家」「本地」。取证的原话照旧保留，只换名字。
4. **真实资料只改了一处**：家所在地点的 name 从带区名的写法改成城市名本身（只用在日志、状态和上面的正则里；坐标和缓存 id 不变）。
5. **测试**：真名换成合成角色的（猫「团子饼」、室友「许小禾」、闺蜜「林小满」、雾岚市、溪口镇、云杉学院）。要测认出猫名 / 城市名的测试先调 `test/fixtures/card.ts` 的 `useSyntheticTerms()`。
6. **不改的**：
   - 菜名「土豆牛腩饭」是菜，不是猫。
   - 日常小事的 id `ed_jn_*` / `ed_yt_*`（真实 NPC 名字的缩写）：id 进哈希和事件账，改了会改写过完的日子（ADR 0334）。
   - 角色自己的名字和 `LifeEvent.actor` 的 `'linmengyao'`：项目本身就以她命名（`CLAUDE.md` 开头），卡文件名、记忆库前缀都用它，不在这次范围。
   - `packages/bot/sim/*.json`：模拟器场景按设计跑真实卡，写的是真实卡推出来的日子，和角色资料一样是私有数据。
   - `characters/` 下的角色资料本身。

## 验证（11-06）

- 名字从真实卡记下之后，重写的正则和文案与原来写死的逐字相同：认猫的三条正则、照片说明的地名表、「你倒是回 X 了」的两条正则、相机五步、照片的叫法（一次性脚本逐条断言）。按同学、男朋友、陌生人的顺序读真实卡：读完同学档只记下了猫（它的卡上本来没有城市），读完男朋友档猫和两座城市都在，再读陌生人档也没有被清空。
- 行为指纹（同 ADR 0334）：真实卡 7 个档位 × 约开/关 × 2026-09-01 到 2027-01-31 每天 6 个时刻，世界与选择器的输出在改动前后哈希一致。
- 全仓 `npm test`：bot 3442 项通过 3435 项，失败的 6 项仍是 Claude 应用沙箱里的 `EPERM`；character-tools 18、koishi 插件 51、移动服务 40、PWA 4 全过。`npm run test:real` 43 项通过。全仓类型检查、`git diff --check` 通过。
- `packages/` 下除 `sim/`、`test-real/` 和菜名外，搜不到真实的猫名、两个 NPC 的名字、两座城市名和 NPC 的拼音 id。

## 后果

- 行为上有意改了的只有通用说法那几处（签名、念头主题、日志、控制台文字、提示词里的一个举例）；其余对真实角色逐字不变。
- 新写的文案、正则、注释里要提猫或城市时，用 `character-terms.ts` 或通用说法，不写真名；测试用合成角色的名字。
- git 历史里旧版本的源码和测试仍有这些名字；要清除得改写历史，由用户决定（仓库是私有的）。
