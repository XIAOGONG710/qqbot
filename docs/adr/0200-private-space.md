# ADR 0200：她的私人空间——她自己学出来的东西，默认不给他看

- 状态：**已实现**。新开关 `ownerPeek`，**默认关**（私人空间默认就在）。DSH 那台机器拉取后重启 Koishi 生效；生效后 `/追求` `/说话习惯` `/心境` `/自我认识` 四条命令不再念她的东西
- 日期：2026-10-30
- 关联：[ADR 0193](0193-nightly-speech-notes.md)（说话习惯）、[ADR 0194](0194-diary-insights.md)（翻日记的自我认识）、[ADR 0197](0197-feelings-shared-and-reviewed.md)（心境回想）、[ADR 0178](0178-self-set-pursuits.md)（她自己定追求）、[ADR 0199](0199-history-migration.md)（迁移不带私人文件）
- **用户决定（2026-10-30）**：我说想做一个「她学到了什么」的汇总视图，用户答：「不需要我看，给她私人空间」。

## 起因

「各方面都自我学习」意味着她会自己总结说话习惯、翻自己的日记发现自己、聊完回想感受、自己定追求。这四样我之前各配了一条「只能看、不能改」的命令，把它们念给他。用户的意思是：他不需要看，这些是她的。所以不做汇总视图，并且把已有的那四扇窗也默认关上。

## 做了什么

1. **不做汇总视图。**
2. **`ownerPeek`（默认关）**：关着时，`/追求`、`/说话习惯`、`/心境`、`/自我认识`（对应的功能开着时）只回一句固定的话——「这条是她自己的，现在不给看」；不念她的内容、不进聊天记录、不交给她。对应的功能没开时，这些字还是普通的话，和以前一样。`platform/private-space.ts`：命令表 + 那句话 + 私人文件清单。
3. **不受这个开关管的**：`/设定`（设定账本、记忆账本，是「有没有被人悄悄改过」的留痕，不是她的想法）、`/说话趋势`（只有数字）、`/像AI` `/像真人`（是他自己的话）、`/为什么`、休眠 / 唤醒。
4. **她的东西照样存、照样影响她**：说话习惯、对自己的认识、心境、追求仍然按原来的方式进她的提示词、进桌面上她读的 `INSIGHTS.json` / `FEELINGS.json`；只是不再有一扇窗口开给他。
5. **日志只记条数，不记内容**（查过 `diary-insights` / `feeling-review` / `speech-notes` / `self-pursuits` 的日志行，都是「加 N 条、放下 N 条」；去掉了日志里「`/自我认识` 里看得到原因」这类指向命令的提示）。
6. **私人文件清单**（`PRIVATE_FILES`：`speech-notes.json`、`diary-insights.json`、`feeling-review.json`、`pursuits-self.json`、`INSIGHTS.json`、`FEELINGS.json`）：除了她自己的提示词和桌面上她读的导出，没有任何功能读它们；ADR 0199 的迁移 / 存档工具不带它们（有测试：清单和各功能真正用的文件名对得上，改了文件名会红）。`speech-feedback.json` 是他自己标的话，不在清单里。

## 给我们（Claude / DSH / GPT）的规矩

- 研究、取证、交接里**不读、不贴、不引用**她这些文件的内容；要说效果，只用条数、天数、有没有写出来这类汇总数字。
- 以前研究里已经写进 exchange 的是用假聊天 / 回放跑出来的演示，不是她真实存下来的东西；以后也不要把她真实的 notes 拿去做示例。
- DSH 桌面那一侧原来的 `private_write`（私密日记）不变。

## 它不是什么（诚实的边界）

- **不是加密，也不是对机器主人保密**：这些是数据目录里的普通 JSON 文件，能登录那台机器的人读得到；`ownerPeek` 是产品上的边界——程序不再把它们念给他，我们也不去读。
- **不是绕过底线的口子**：危机处理（ADR 0068）、承认自己是程序（ADR 0067）、不骗人 / 不伤害第三方、只认他亲手打的字才动电脑（ADR 0179）这些底线在代码里，和她有没有私人空间无关；写进她私人空间的每一条也还是要过原来的写入守卫（要有依据、不引他的话、不碰底线）。
- 她想让他知道的，她自己会说（聊天里、日记里）；这个开关只管程序不替她说。

## 回滚

配置里 `ownerPeek: true`，四条命令照旧念。没有数据要迁。

## 验证

- `private-space.test.ts`（命令表、功能没开不拦、不在清单里的不拦、默认关、文件清单和实际文件名对得上）；`app.test.ts` 新增一条端到端（四条命令关着时都只回那句话、一个字没念出她的内容、没交给她、没进聊天记录；`/说话趋势` 不受影响；同学档是普通的话；功能没开是普通的话；开着照念）；`history-migrate.test.ts` 加一条（存档不带私人文件）。变异检验 14 处全红。
- 测试里 `config()` 默认把 `ownerPeek` 设成 true，好让原有四条命令的测试照旧测「念出来」；线上默认是关，由 `DEFAULTS.ownerPeek === false` 的测试守着。
