# ADR 0221：她每天回顾聊天，找出自己说的内容上的问题，学着改（chatReview）

- 日期：2026-11-02
- 状态：**已实现，新开关 `chatReview`，默认关**；要名单里有男朋友档。DSH 那台机器拉取、加 `chatReview: true`、重启 Koishi 才生效
- 相关：ADR 0193（每晚总结说话习惯：看的是说话的「样子」）、ADR 0195（他标像 AI / 像真人；指令收敛后已不用）、ADR 0200（私人空间）、ADR 0212（看他的反应，复用它的「他回个嗯」判法）、ADR 0220（太顺的尺子：量出来她说得太满）
- 用户：11-02「让她每天回顾聊天，找出自己聊天内容上的问题并学习改进」

## 和 ADR 0193 的分工

0193 看的是**说话的样子**：几条、多长、短反应、问号占多少，再和真人女生的同一组数字比。这里看**说的内容**：
- 他当场说她说错、没听懂
- 她说了一大段，他只回个「嗯」
- 一条里连问好几句
- 比他说的长出好几倍
- 同一件事一天说了好几遍

两份笔记各自独立。

## 先问了她本人（`scripts/ask-her.mjs`，两遍）

她愿意，条件都写进了代码：

1. **「别搞成打卡那种……听着像写检查」「别指望我天天能挑出毛病来」**：没觉得哪里不对就输出 `{}`，不硬凑；记的是一句话，提示词写明「不用写检讨」
2. **「真说了什么让你不舒服的，你当场跟我讲，比我自己瞎琢磨强」**：他当场说她说错、没听懂的，排在最前面，写明「最要紧」
3. **「不想变成嘴上说要改，第二天还是老样子」**：每晚把她之前记下的那几条，和前几天同样的个数一起给她看，改没改她自己对得上
4. 她以为自己最大的毛病是「装死、回个嗯就晾着」，可 ADR 0220 量出来正好相反：她**说得太满**（完整接话 78%，真人 51%；字数中位 18，真人 10）。所以**不让她凭印象挑**：给她的是当天真实聊天里数得出来的几处，带前后原话，她自己判断是不是问题、写什么。提示词也写明「你可以嘴硬、可以损他、可以拒绝，这些不算毛病」

## 决策（`language/chat-review.ts`）

1. **数得出来的几处**（`reviewFlags`）：她这一天（到凌晨 2 点）和他的聊天，同一个人连着说的算一段，每类最多给她看 2 处：
   - **他当场说她说错、没听懂**（`HE_CORRECTS`）：「你说错了」「我不是这个意思」「答非所问」「你在说啥」「你刚才不是说……」……
     - 在 VM 三周的真实聊天里补了他实际用过的几种：「[？]」「你咋知道我有……」「你是啥子」「这不是还有……吗」
     - 玩笑会误抓，由她晚上自己判断
   - **她说了一大段（≥30 字），他只回个嗯**（ADR 0212 的 `reactionTo`）
   - **一条里连问 2 句以上**
   - **比他长出 3 倍以上、自己超过 25 字**
   - **同一件事**（作业、土豆、相机、快递、小测、外卖、熬夜）在 3 段以上不同的聊天里都提了
2. **每晚 22 点以后一次**（和 0193 同样的到点、重试规矩），一次模型调用。今天她一句没回过就不看。给她看四样：
   - 那几处的前后原话
   - 今天各类的个数
   - 前几天同样的个数（留 7 天，只有数字）
   - 她之前记下的
   
   她输出 `add`（一晚最多 3 条，6–60 字，带上是哪一类）和 `retire`（放下要说理由）
3. **底线**（同 0193）：碰底线的不收（承认是程序、危机、事事顺着他、骗人 / 真钱）；照抄他最近 7 天的原话不收（「不能变成他」）；和已有的太像不收；最多留 12 条
4. **聊天里**：放她记下的最多 2 条，新的在前，写明「是你自己的想法，不是设定；不用每句都想着它，碰上了再用」。他在难受、危机、只想一想、小别扭的轮次不放
5. **私人空间**：`chat-review.json` 进 `PRIVATE_FILES` 和免费网关禁读名单；没有命令念给他；日志只记个数（「聊天回顾：晚上看了一次（回了 N 次；……）——记下 N 条、放下 N 条」）

## 用真实聊天数一数（VM 10-06 到 10-26，只数个数）

聊过的 20 天，她回了 461 次：
- 比他长好几倍：33 处
- 他只回个嗯：6 处
- 他当场说她说错 / 没听懂：5 处（补规则前是 0）
- 连问：2 处
- 同一件事说好几遍：1 处
- **8 天一处都没有**：那几晚她多半写 `{}`，正合她说的「别指望天天能挑出毛病」

## 真模型探针（合成的一天，3 遍，关思考，只读）

她写的（3/3 都解析成功）：
- 「他说不舒服时我一口气问了三句，下次先问一句，等他答了再问」
- 「我说食堂和作业一大串，他只回个哦，下次先说一句，留点空给他」
- 「作业今天提了三回，下次说一遍就够了，别翻来覆去」

都是第一人称、具体、一句话，没有写检讨。

**要说清楚的**：3 遍都**没记**「他当场说她说错」那一处（「你刚才不是说你去过吗」）。可能她觉得回「我都不记得了」不算错，也可能是一晚最多 3 条、她挑了另外三处。这是她的判断，不硬改；上线后看日志里「他当场说你说错」的个数，和她记的条数对不对得上。

## 这一版不做的

- 事实检查标出来的矛盾、编造：只在模拟器里有记录，线上没存。以后存下来再加进依据
- 把她记下的那几条按「这一轮是什么情况」挑着放（比如他发得短时才放「别说太多」）：先放最新的两条，看效果
- 主动跟他说「我今天回头看了看……」：她说「我自己想起来哪句不对，也会跟你说的」，由她自己
