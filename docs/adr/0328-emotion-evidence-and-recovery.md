# ADR0328：心境事实边界、危机恢复与反馈身份

日期：2026-11-05

## 证据与范围

十个心境与安全源文件及直接链审查发现：危机副状态写失败不能真正重试，聊天先落盘后重启不会补标；他人/疑问/假设安全陈述误解除；未来聊天、坏评估和明确否定制造情绪事实；作者文件缓存别名/替换与错误正文；反馈未来引用、坏行、低年份、尾行及发布后故障；短消息ID碰撞、摘要截取内存放大；模块开关文档误称永远启用。各组合成反例、修复及实际回归记录见本日 emotion-review。

不调整 ADR0067/0068/0073/0074/0102/0103 已定产品策略。风险词表、级别、1h/48h窗口、本人安全与现实保护要求、知情联系人披露、心境阈值/衰减和别扭轮数保持。此次修复判断实现与来源恢复，不做临床判断或任意新增危机规则。

## 决定

危机信号是已观察的真实事实，不因磁盘失败从当前进程消失：mark保留最新观察与dirty，失败仍抛安全错误，flush或同/更旧mark可真正重试，成功才清dirty。app捕获失败继续响应并保持普通主动暂停，1s起退避至60s重试；停止后不重试、不接受晚补回回调再写。连接时从已存48h内用户消息恢复缺失副状态，先于QQ历史请求，避免同ID已入聊天而永远漏补；暂停仍从原事实时间计算。坏启动状态保留并失败关闭，不能当空记录重建。

解除仅使用本人肯定的现实证据。电影/他人报告不能借相邻句供本人解除；疑问、假设、愿望不等于明确纠正。保留别人报告“我安全”、协助处理“我的危险物品”等本人语义及既定相邻回答规则。确定性正则不是自然语言理解，不宣称所有引用、讽刺或复杂否定都已识别。

情绪投影只使用已发生、格式有效的事实；算术前拒绝坏评估，不能用NaN清掉合法同类。作者事件明确ISO真实日期及2–60代码点来由，保持正常四位低年份；手工宽松/坏日期不自动迁移。无时间/窗口外聊天不编造别扭因果，两轮自然结束后不因迟到道歉重开。明确否定不算喜欢/安慰/道歉，“我在”作为完整短句才算安慰；后句明确好意和简单双否定继续有效，不扩展成情感分类。

momentsReader保持已有last-good策略：坏新文件不挪走/不覆盖，安全记录一次并沿用最后有效克隆；明确删除清缓存。缓存键包含文件身份、纳秒时间与大小，捕获同mtime/size原子替换。重启无快照时坏文件为空，不凭空恢复作者事实。CLI写入与并发另见ADR0327。

反馈不能用全局短ID唯一去重。当前只读上游 [NapCat MessageUnique](https://github.com/NapNeko/NapCatQQ/blob/26d7533e0f5800fdff865ab2f2ad7692917e1076/packages/napcat-common/src/message-unique.ts) 把MD5截成正31bit；合成 `2881|1|synthetic-A`、`42066|1|synthetic-B` 均得1562800174。新行增加可选contact（仅私有运行时），统一以contact+短ID+源时刻识别事件，入口、追加故障读回、加载统计与摘要一致；旧无contact行保守按源时间+短ID兼容，不能猜出联系人。旧has(id)接口保留历史存在性，生产channel使用有来源的事实检查。contact不进入提示词或摘要输出，文件仍按既有私有运行时保护；不外发真实记录。

反馈关联按OneBot整秒源精度比较可见性：同秒毫秒气泡允许，下一秒不接受，连续气泡与上下文同边界，不加跨秒宽限。坏schema不占身份或统计，沿既定坏行跳过政策；坏尾半行补行界，不吞下一条。append/close报错后确认完整同身份落盘行，防止重复或误认另一联系人的成功。CLI先拒缺值/重复/未知/溢出参数再读数据目录，错误不带正文/路径。摘要仅保留所需前缀的代码点，不展开整条大气泡；不新增保留期或输入quota。

模块文档使用显式featureKeys准确列出四个可选开关，危机与披露底线仍没有关闭开关，不修改任何默认值。

## 验证和限制

使用纯合成聊天、作者文件、假传输、故障注入和隔离子进程；真实App覆盖IO恢复、已存历史重启恢复、stop后晚reject。摘要48MiB堆/800万字旧实现在隔离进程OOM退出134，新实现成功；正式回归另检查空白/emoji边界。没有运行真实模型、QQ、热线或私有运行时，没有部署。

app数据目录单实例锁是危机/反馈单写前提；外部并发改文件不在保证内。反馈集合/历史月文件仍随数据增长，不承诺无限数据资源有界，也不承诺断电fsync。旧无来源记录存在不可恢复的歧义，未来同联系人同短ID同源秒的不可区分碰撞仍受上游可用身份信息限制。聊天和副状态同时未持久化的崩溃不能凭空恢复；最后有效作者快照没有跨进程持久副本。不把这些边界当作“已经证明不存在其它缺陷”。
