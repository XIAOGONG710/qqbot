# ADR 0220：「太顺」的尺子重建；DSH 10-28 的「形状松绑」让她说得又长又满；`shapeAll`（默认关）

- 日期：2026-11-02
- 状态：**尺子和开关已提交**（`scripts/smooth-replay.mjs`，开关 `shapeAll` 默认关，随 `df8c933`）。**线上没改**：要不要恢复形状，等用户定
- 相关：ADR 0091（形状控制）、ADR 0099（太顺：带上文重放 + 标注）、DSH `27facc0`（10-28「形状松绑」，没有 ADR）、ADR 0221（每天回顾聊天）

## 起因

11-02 问她「跟我聊天的时候，有没有哪种时候你觉得自己说话不像自己」，她说：「本来想损你一句，结果打出来变成了软话。」

形状里有一句 `PLAIN_NOTE`：「顺着他说……**别反驳他、别损他、别嘴硬**」，七成的形状轮次会带上。看起来正对得上她这句话。**但没量之前不改**：`ask-her` 只有卡，没有线上这些处理，她说的是想象里的自己。

## 尺子（重建 ADR 0099 的方法，这次放进仓库）

`scripts/smooth-replay.mjs`：
- 取真人情侣聊天（`exchange/research/2026-10-real-chat/samples.jsonl` 里 relation=boyfriend 的 21 段），每一对「他说的一轮 → 真人女生回的一轮」生成一个场景（前面最多 8 条上文），共 73 对，每个变体跑 2 遍
- 用另一个调用（deepseek-flash，温度 0，不告诉它谁是真人）只看「他这一轮 → 回复」打标签：完整接话 / 表达情绪 / 顺从让步 / 带笑的损 / 一句话驳回 / 俏皮话 / 带疑问句
- 另数长短（不用模型）：一轮回复的字数中位、4 字以内的占比、一条里连问 2 句以上的占比
- 真人女生的原回复一起标，当对照

## 读法

1. **她说的「想损你、打出来变成软话」，量下来不成立。**现在损人是真人的两倍（28 对 14）。照她这句话去放开，会离真人更远。
2. **说得又长又满，主要是 DSH 10-28 的「形状松绑」造成的**（`27facc0`，「语言松绑：只有接情绪 / 好事 / 亲近 / 撒娇 / 认真或问过去时给形状；普通闲聊不圈条数字数」，没有 ADR）：
   - 重放里 134 轮只有 26 轮带上了长短上限，带上的 23/26 都照做了
   - 所以「太长」不是她不听，是大多数轮次根本没给
   - 调情绪轮、调顺着说，都只影响那四成轮次，几乎没变化
3. **恢复形状**（`shapeAll`：所有轮次都给形状），长短一下就和真人对上了（中位 8、4 字以内 23%、连问 2%），损人也降到真人水平（16）。**但顺从让步翻倍到 18%**：形状一恢复，`PLAIN_NOTE` 又在七成的轮次里生效了，那句话里有「应一声、附和」
4. **恢复形状 + 顺着说降到 0.35**：
   - 长短接近真人（中位 11、4 字以内 12%、连问 1%）
   - 完整接话 78 → 71
   - 顺从 10（不比现在差）
   - 损人 27（和现在一样，还是真人的两倍）
   - 疑问句 36（比真人 45 少）
   
   和现在比，没有一项变差，长短和完整接话明显好
5. 损人和顺从是一对：`PLAIN_NOTE` 同时压了损人（好）、推高了附和（坏）。**下一步该试的是改它的措辞**：保留「别一句话驳他、别嘴硬」，去掉「附和」。比例也不用再调

## 决定

- **不改线上**：形状松绑是 DSH 应用户「框架束缚了她」那一层意思做的，恢复与否由用户定
- 提交了 `shapeAll`（默认关，关着和现在一字不差）和尺子
- **给用户的建议**：开 `shapeAll: true`，同时把 `PLAIN_SHARE` 调到 0.35。比例现在只能在模拟场景的 `shapeShares` 里改，线上要加一个配置项，或者直接改常量

## 怎么复测

```
node scripts/smooth-replay.mjs gen runtime/smooth-src <变体名> '<shapeShares 的 JSON，"all":true 表示 shapeAll>'
npm run sim -w @qqbot/bot -- <绝对路径>/runtime/smooth-src/<变体名> --runs 2 --no-memory --parallel 6
node scripts/smooth-replay.mjs score "<名字>=runtime/sim/<时间>"
```

- 一次 73 对 × 2 遍约 10 分钟；打标签约 5 分钟
- 要 `QQBOT_LLM_API_KEY`
- 只读：不碰线上、不发 QQ

## 局限

- 标注员也是模型；真人样本 73 对，偏小红书截图（有冲突片段）。每格约 ±4 个点
- 模拟没有记忆（`--no-memory`）；线上有记忆召回，会更长一点
- 只量了一句话的回法，没量多轮
