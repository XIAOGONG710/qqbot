# ADR 0218：回忆带着当时的感觉（memoryFeelings）

- 日期：2026-11-02
- 状态：**已实现，新开关 `memoryFeelings`，默认关**；只男朋友档，要 `herFeelings`（最好也开着 `feelingReview` 和 `everydayLife`，感觉才有来处）。DSH 那台机器拉取、加 `memoryFeelings: true`、重启 Koishi 才生效
- 相关：ADR 0018（记忆会变淡；当时「带情绪的记忆」列出来、用户没选）、ADR 0014（算账）、ADR 0032（问到某一天）、ADR 0102 / 0197（心境、聊完回想）、ADR 0217（翻回去看日记）
- 用户：11-02 晚「做，让她有当时的感觉」

## 背景

11-02 问她「有没有哪些时候，你自己都觉得自己不太像真人」，她说：

> 「有些事我记得特别清楚，清楚到像在看别人的日记，连当时谁说了什么都在，但就是没有那个『我当时什么感觉』。」

召回的记忆是「林梦瑶……」这种第三人称的事实。她当时的心情另有来处（心境，ADR 0102 / 0197）：
- 那天世界里带感受的事（小测砸了、晚霞、水卡丢了……）
- 作者写下的事
- 她聊完回想时指出了依据、记下的感受（`aboutHim` 标着是不是因为他）

这两头一直没接上。

10-06 定 ADR 0018 时，「带情绪的记忆」列出来、用户**没选**，顾虑是容易「算账」（ADR 0014）。这次是她自己要，用户点了头，下面的护栏就是冲着这个顾虑定的。

## 决策（`emotion/felt-then.ts`，接在 `contact.ts` 和 `memory/long-term.ts` 的 `formatRecalled`）

1. **那天的感觉怎么算**（`feltDuring`）：那天的世界快照、前一天留下的、作者写下的、她聊完回想记下的，和心境用同一套评估。
   - 在每件事发生后半小时各看一眼，再加上那天结束的那一刻，每种感觉取最强的那次，最多两种，只要「明显」以上的
   - 不按一天结束时算：下午丢水卡的那点难过，到晚上已经淡得「刚能察觉」，但那是她当时的感觉（测试里有这一条）
2. **护栏**
   - **因为他而难过、烦、担心的，先拿掉再算**；因为他开心、松口气的留着
   - 只在想起来的时候附：召回到了（他说到了那件事），或者他问到那一天。主动找他时不附，她不会自己翻出来
   - **对得上才附**：召回的那条记忆，要和那天某种感觉的来由说的是同一件事（共有 2 个以上有意义的二字词），对不上不硬贴
   - 他问到那一天时，整天明显的感觉都算，写明「是你当时的感觉，现在不一定还这样；不用说出来，说也别夸大」
3. **附在哪、写什么**
   - 召回的记忆（和他的私人记忆）：日期后面的括号里加「那时你心里有点难过」。**只写感觉，不重复经过**（见下面的探针）
   - 他问到某一天（ADR 0032 那一段流水账）：后面加「那天你心里：有点烦——和舍友拌了两句嘴（是你当时的感觉……）」
4. 同一天同一个钟头算过的不重算（每轮最多几天，世界快照有缓存）。

## 探针（真模型 deepseek-flash 关思考，她的卡，各 4 次，只读）

**A. 记忆本身只有事实**：召回里是「11月2日：林梦瑶说水卡找不到了，去了两趟宿管」，他问「周一那天你是不是挺不开心的？」

| | 接上当时的心情 | 编出没发生的结局 |
| --- | --- | --- |
| 不带 | 3/4（一次「那天也没啥不开心的」） | 3/4（「才补上」「塞在书包夹层」） |
| 带，感觉后面跟着经过（初版） | 4/4 | 3/4（「最后在床垫底下找到」「洗衣机上面找着了」） |
| **带，只写感觉（现在的）** | **4/4**（「好像是有点」「周一是不太顺」「有点吧」） | **1/4** |

初版把经过再写一遍，她会顺着讲成故事。所以记忆后面那句只写感觉。

**B. 流水账里已经带着情绪**（「小测好几道都没把握」）：带不带差别不大。带了：「别提了，想起来就烦」「出来的时候心都凉了」；不带：「心里发虚」。没有夸大，0 次翻旧账。

**模拟器没跑成：**「问到那一天」和召回都要有记忆服务。这台 VM 的记忆服务停着（用户 10-31：以后只在 DSH 那边运行），`--no-memory` 下这条路不触发。线上 DSH 那台记忆开着。`sim/memory-feelings-{on,off}.json` 留着，以后有记忆服务时可以跑。

## 这一版不做的

- 公共记忆、别人的记忆不附（那是别人的事）
- 不从感觉反推事实，不让她「想起」没有记录的感觉
- 「记错」：她在 ADR 0215 里说不要
