# ADR 0032：问到过去哪一天，她记得自己那天过的事

- 状态：实现，真模型验证中（2026-10-07）
- 日期：2026-10-07
- 关联：[ADR 0017](0017-long-term-memory-like-a-person.md)（问她过去的事、日记）、[ADR 0018](0018-memory-fades-and-promises.md)（7 天记得清楚）、
  [ADR 0021](0021-her-world.md)（她的世界）、[ADR 0026](0026-diary-of-her-day.md)（日记写进她的一天）、[ADR 0031](0031-her-routine.md)（日常）、

## 背景

实施方案的封板验收：三天没人跟她说话，三天后聊起来，她说的要和事实账一致。先用模拟器 `life-72h` 量了一次现状（`20261007-232500-life72h-baseline`，3 次）：
10-12（周一）早上起一条消息都没有，10-15（周四）晚上他来问。

- 「周一你那快递拿了没」：**3/3 答「还没拿」**——周一 12:20 她取了洗面奶。「周一」「礼拜三」「12 号」都不算问她过去的事的线索，她不去想那天。
- 「昨天下雨了吗」：**2/3 答「昨天没下」**——10-14 下了一天。1 次还把没喂猫的原因说成「下午有课回来就懒了」（其实是下雨）。
- 问今天的事都对（今天的世界就在提示词里）；「最近忙啥」「前天」能想起日记，但日记按 ADR 0026 每天只挑一件她那边的事，召回时还会被别的条目挤掉。

真人被问到这周一、昨天，自己那天过的事是记得的，不用靠翻日记。

## 决策

1. **周几、几号、天气算线索**（`people.ts`）：「（上）周一 / 星期三 / 礼拜天」「12 号 / 3 日」算问她过去的事，时间窗是最近过去的那一天（今天是周一，问「周一」就是今天；「上周三」往前一周；几号还没到就是上个月的；「周一晚上」问的是周一）；
   经历词加上「拿了、取了、收到、喂了、写完、做完、下雨、下雪、天气」。
2. **那天她那边的事直接给**（`world.ts` `recapDay`、`contact.ts`）：他问到过去的某一天，而且是 7 天以内（ADR 0018 的「清楚」期），按这个联系人这一档的卡算那天快结束时的世界，
   放一段 `[那天（10月12日 周一）你那边的事（你自己过的这一天，记得；他问到了照实说，用不上就别提）：没下雨，12–22℃；19:16 下楼喂了土豆；12:20 去驿站取了快递（洗面奶）；熬夜写完了计算机网络技术的作业；22:35 去洗了澡]`。
   天气、喂没喂猫、快递、那天写完的作业、和家里视频、小事、洗澡、身上不舒服都写——和日记不同，这里不挑。同学档看不到的（闺蜜、宿舍、课名、生理期）照样没有。
3. 7 天以前的不给：那时候靠日记和记忆变淡（ADR 0018）。今天的不给：时间块里本来就有「你那边」。
