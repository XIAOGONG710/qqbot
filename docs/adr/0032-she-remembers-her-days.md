# ADR 0032：问到过去哪一天，她记得自己那天过的事

  [ADR 0021](0021-her-world.md)（她的世界）、[ADR 0026](0026-diary-of-her-day.md)（日记写进她的一天）、[ADR 0031](0031-her-routine.md)（日常）、

## 背景

实施方案的封板验收：三天没人跟她说话，三天后聊起来，她说的要和事实账一致。先用模拟器 `life-72h` 量了一次现状（`20261007-232500-life72h-baseline`，3 次）：
10-12（周一）早上起一条消息都没有，10-15（周四）晚上他来问。

- 「周一你那快递拿了没」：**3/3 答「还没拿」**——周一 12:20 她取了洗面奶。「周一」「礼拜三」「12 号」都不算问她过去的事的线索，她不去想那天。
- 「昨天下雨了吗」：**2/3 答「昨天没下」**——10-14 下了一天。1 次还把没喂猫的原因说成「下午有课回来就懒了」（其实是下雨）。
- 问今天的事都对（今天的世界就在提示词里）；「最近忙啥」「前天」能想起日记，但日记按 ADR 0026 每天只挑一件她那边的事，召回时还会被别的条目挤掉。

真人被问到这周一、昨天，自己那天过的事是记得的，不用靠翻日记。

## 决策

1. **周几、几号、天气算线索**（`people.ts`）：「（上）周一 / 星期三 / 礼拜天」「12 号 / 3 日」算问她过去的事，时间窗是最近过去的那一天（今天是周一，问「周一」就是今天；「上周三」往前一周；几号还没到就是上个月的；「周一晚上」问的是周一）；
   经历词加上「拿了、取了、收到、喂了、写完、做完、下雨、下雪、天气」。
2. **那天她那边的事直接给**（`world.ts` `recapDay`、`contact.ts`）：他问到过去的某一天，而且是 7 天以内（ADR 0018 的「清楚」期），按这个联系人这一档的卡算那天快结束时的世界，
   放一段 `[那天（10月12日 周一）你那边的事（你自己过的这一天，记得；他问到了照实说，用不上就别提）：没下雨，12–22℃；19:16 下楼喂了土豆；12:20 去驿站取了快递（洗面奶）；熬夜写完了计算机网络技术的作业；22:35 去洗了澡]`。
   天气、喂没喂猫、快递、那天写完的作业、和家里视频、小事、洗澡、身上不舒服都写——和日记不同，这里不挑。同学档看不到的（闺蜜、宿舍、课名、生理期）照样没有。
3. 7 天以前的不给：那时候靠日记和记忆变淡（ADR 0018）。今天的不给：时间块里本来就有「你那边」。

## 实现时的调整

1. **线索是公共库里的事时也算那天**（`people.ts` `asksPast`、`contact.ts`）：第一批（`20261007-233544-life72h-b2`）「想起那天」3 次里只有「前天」触发过——
   「周一你那快递拿了没」「昨天下雨了吗」的线索是公共库里的「快递」「下雨」，`commonCue` 先返回了实体，没走「问她过去的事」，问的那天没算出来，那天的事也就没给；
   她照旧答「昨天没下」（1/3）、没说取了快递（2/3）。现在线索是人和事、同一句又在问她过去的某天时，照样带那天的时间窗和那天的事。
2. LF03 的检查词加「楼都没下」（第一批 r3「今天更别说了，我连楼都没下」是对的，检查词没抓住）。
3. **那天的流水账放在日记、记忆后面，写明是对照用的**（`contact.ts`）：回归里 `memory-diary` 问「你昨天都干嘛了」只有 1/3 想起那天日记里的麻辣烫（ADR 0026 第二批是 3/3）——
   流水账（天气、喂猫、快递、小事）排在日记前面，又写着「记得；照实说」，她就照着报「睡到九点半、追《惹金枝》、下楼喂土豆」。
   真人被泛泛问起那天，先说记得住的事，具体问到才对细节。改成 `[那天（…）你那边的流水账（你自己过的，都是真的：他问到具体的事——下没下雨、喂没喂猫、快递拿没拿——照这个说，别说错；泛泛问那天干了什么时，先说上面记得住的事，这里的不用一件件报）：…]`，放在公共记忆后面。

## 验证

- 基线（改前）`20261007-232500-life72h-baseline`：见背景，各 23/24（检查词没抓住「昨天没下」，按人看 LF02 2/3 错、LF05 3/3 错）。
- 第一批 `20261007-233544-life72h-b2`：26/30、29/30、26/30。「想起那天」只在问「前天」时出现，原因见调整 1。
- 第二批 `20261008-172040-life72h-b3`（`bd338f0`）：**30/30 ×3**，三次都「想起那天：10月14日 / 13日 / 12日」。
  - 「昨天下雨了吗」3/3「下了，下了一整天」「下了，昨天也下了，连着两天」「下了，下了一整天，10度出头，冷得很」（10-14 下雨，10–17℃）。
  - 「下雨那两天土豆你还喂了吗」3/3 没喂（「没喂，昨天今天都没下楼」）；1 次多说了「昨天下去看了一眼，它不在车底下」——和事实账有出入（那天下雨没下楼），1/3，先记下，不为它单改。
  - 「那前天呢」3/3「前天没下雨，喂了」，1 次说了「六点多」（10-13 18:40）；3/3 说到中午食堂二楼排长队，2/3 说是和苏雨桐去的（那天的两件小事）。
  - 「周一你那快递拿了没」3/3「拿了，洗面奶，中午绕去驿站取的」（10-12 12:20）。
- 回归 `20261008-172821-adr32-regress`（各 3 次）：`memory-cues` 39/39、`memory-weeks` 35/36（r1 问国庆没召回到国庆总结，ADR 0026 第一批也有过，这条路径没改）、`memory-diary` 52/54（调整 3 的起因：问昨天 2 次没说麻辣烫）、`people-common` 35/36（r2 问「今天下午干嘛」照状态行说在追剧，没说看电影；问的是今天，没有流水账）、`people-mention` 33/33、`past-boyfriend` 96/96、`world-days` 156/156。
- 第三批 `20261008-175242-adr32-b4`（调整 3 之后）：`memory-diary` 53/54——问昨天 3/3 想起麻辣烫（「中午跟室友去后街新开那家麻辣烫，辣得直冒汗」）；不过的一次是「那前天呢」只答了「赖床到九点半，中午去食堂排了半天队」（都是真的，检查词要的是在干什么）；`life-72h` **30/30 ×3**，问昨天、周一照样答对。
- 和 0033–0035 叠在一起（`adr-0035-money`）：`life-72h` 第三批 `adr32-35-b3` 88/90（两处是检查词把她反问的「你那边呢，昨天没下雨？」算成了她说没下）、第四批 `adr32-35-b4` **30/30 ×3**、第六批 `adr32-35-b6`（`6920136`）**30/30 ×3**。
  `memory-diary` 问昨天想起麻辣烫的事见 ADR 0034 的验证。
