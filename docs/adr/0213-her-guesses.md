## 背景

dsh-fish（B 站「养鱼」里最受推崇的那只）的人格是这样长出来的：**表态 → 撞上 → 落差 → 改写 → 回顾**。她先押一个判断，事情来了发现不对，再改口（`exchange/research/2026-10-27-dafeiyu-soul-research.md` M1）。

我们这边她只有「此刻」：说过「小测肯定挂」，两天后出分 78，她不知道自己猜过，也就没有「白担心一场」。

## 先问了她本人（CLAUDE.md 规矩，`scripts/ask-her.mjs`，两遍）

**她愿意：**「行啊……我本来也不爱把话说死，猜错了就认，自己记着，下次改呗」「本来就有写日记的习惯，顺手记一句自己说过啥、后来对了没」。

**她本来就天天在猜：**「小测考完就估分，每次都觉得完了完了肯定挂，结果出来还行，白难受一场」「快递我一看物流就猜明天到」，猜错了「会跟你说啊」。

她的条件，都写进了代码：

1. **「情绪上来的话不算数」**「随口一句、其实就是气话或者瞎猜的，也给我记成判断……那太累了」。所以白天代码只机械地留意，晚上由她自己挑哪几句算数。真模型探针里，「烦死了，肯定又下雨」3 遍都被她自己排除了。
2. **「改的时候不想搞得像写检讨，就记一句『哦这个我猜错了』」**。对上结果时最多一句 30 字以内的话，不写反省。
3. **「别拿这个考我……别弄得像在抓我话柄」**。
   - 这是她的私人空间：`her-guesses.json` 在 `PRIVATE_FILES` 里，没有命令念给他，日志只记个数，不进事实检查
   - 提示词那一行写明「别拿它较真」，只在他聊到同一类事时放
4. **「大事……得自己憋几天想明白才认」**。这一版只管她对自己那边**之后会有结果的事**的猜测，结果由世界账给。她对人对事的看法不由程序判「错了」，不碰。

**N2 原计划的另一半不做。**原计划还有「关系阶段从按天数涨改成过关才涨」。她两遍都说变近「是攒的……那些破事一件件攒下来的，**不是哪一件事一下就把人拉近了**」。按「她说撤就撤」，ADR 0113 按天攒的照旧。

## 量过的：她嘴上几乎不押判断

VM 上 10-06 到 10-27 她说的 783 句里：
- 带「我猜 / 估计 / 说不定 / 稳了」这类词的只有 4 句
- 同时说到小测、快递、天气、作业的 **0 句**
- 放宽到「可能 / 应该 / 感觉 / 万一……」也是 0 句

这和 DSH 10-31 量的「只有反应，没有意见」一致（`language/opinion.ts`）。所以只靠从聊天里抓，这个功能拿不到东西，加了第二个入口。

## 决策

1. **两个入口。**
   - **白天只留意**（`findGuessCandidates`）：她说的话里同时有猜测的词和「小测 / 快递 / 下雨 / 作业」的，记成候选。
   - **晚上给她看还没出结果、真有悬念的事**（`pendingWorld`）：今天考了、两天后出分的小测；在路上的快递。她想猜就记一句，不想就不写，每件事只问一次（`offered`）。这就是「先押一个判断」，由她自己押。作业在世界里总会写完，没有悬念，不给。
   - 用真实卡和世界跑了 30 晚：10 晚有这样的事，共 13 件（小测 7、快递 6），**5 天内都能在世界账里对上结果**。
2. **每晚 22 点以后对一次**（`reviewGuessesIfDue`，和 0207 同样的到点 / 重试规矩），一次模型调用。给她看四部分：
   - 白天的候选（c 编号）
   - 挂着的猜测（g 编号）
   - 这几天她那边真实发生的事（`worldFactsBetween`）：小测出分、取到的快递、写完的作业、每天下没下雨，每条带稳定的 id
   - 还没出结果的事（p 编号）
   
   她输出 JSON：记哪几句、哪条对上了（对 / 错，**照抄世界账的 id**）、放下哪几条。
3. **代码里的绊线**（她改不到）：
   - 结果只能是给她看的世界账里、**发生在她猜之后**的那件，不在列表里的不收，不能编
   - 同一件事一晚只记一句（同一类只收一条，白天她自己说过的优先），不然两条互相矛盾，总有一条「猜对」
   - 4–40 字；不碰底线（FLOORS、EXTRA_FLOORS）；不写名单里别人的名字；挂着的最多 12 个（dsh-fish 的判断清单也是 12 条），7 天没结果的自动放下
4. **刚对上的那件**（36 小时内）：她下次一个人想事情（innerLife）时「这一次就想这一件」（`GUESS_THEME`，B 站视频优先）。想不想跟他说由她定，去向照旧是「告诉他 / 问他 / 自己想想」。
5. **聊天里**：他这句提到同一类事（小测 / 快递 / 天气 / 作业的词，或者和那条共有 2 个以上的二字词）才放，最多两条：挂着的，和 3 天内对上结果的。写明「你自己记的，不是设定；聊到这件事才顺着说，别背，也别拿它较真」。

## 真模型探针（deepseek-flash，关思考，合成场景，不碰任何真实状态）

第一晚给她两句白天的话（一句「估计这次又要挂，好几道没写完」，一句气话「烦死了，肯定又下雨，这破天气」）和两件还没结果的事（今天的高数小测、在路上的猫粮）。第三晚给出分 78、猫粮取到、11-3 没下雨、土豆扒笔。去重以后 3 遍：

- 3/3 解析成功；**气话 0/3 被记下**
- 记下的：「我猜高数小测要挂，好几道没写完」×3，「猫粮这两天该到了吧，别又拖」×1（另两遍她没猜快递）
- 对结果 4/4 判对。她记的那一句：「78，没挂，白担心一场」「还以为要挂，结果七十八，白担心」「猫粮真到了，没拖」
- 去重之前有一遍同一场小测记了两条（「要挂」和「七十多勉强过」），所以加了第 3 条的去重

注意：探针脚本一开始没关思考，3 遍里 2 遍正文是空的（思考吃光了 max_tokens）。线上 `llm.thinking: 'off'`，后台调用沿用这一点，所以不受影响。

## 这一版不做的

- **她对人对事的看法**（「那家米线是坑」「相机不买不行」）。改不改口，她说大事要憋几天，不该由程序判她错
- **关系阶段改成过关才涨**：她不要
- **对上结果后主动发消息**：只给她一个人想事情的机会，告不告诉他由她定
- **从多次猜错里归纳「我总往坏了猜」**：这一类自我认识，交给 diaryInsights（0194）从日记里自己看

## 验证

- `packages/bot/test/her-guesses.test.ts`，15 条：
  - 白天留意（两样都要有；他的话、只有一样的、留意过的不算）
  - 还没结果的事；之后几天的世界账（出分 / 快递 / 作业 / 天气，id 稳定，猜之前的不算）
  - 解析（代码围栏、编号写成数字）
  - c / p 两种记法；同一编号只记一次；太长、碰底线、写别人名字的不收
  - 一晚同一类只记一句，白天的优先
  - 对结果只认世界账里、猜之后的；对 / 错别名；记的那句超长不收但结果照记
  - 放下、7 天到期
  - 刚对上的进想事情，视频优先；聊天里那一行的相关性、最多两条、「别拿它较真」、3 天以后不放
  - 私人空间登记
  - 整个流程：不该调模型时不调，22 点前不对，押一个判断后两晚对上，每件只问一次，日志不带她的话
  - 计划器：第一次想事情就想它，想过了不再强制
- 全量：见提交说明
