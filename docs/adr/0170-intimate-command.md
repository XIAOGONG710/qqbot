# ADR 0170：`/亲热` —— 十条回复临时黏一点

## 状态

2026-10-27 采纳（用户要求）。

## 背景

她平时按自己的性格回话，不主动腻。用户想要一个“现在黏我一点”的开关，作用有限、会自己到期，不是永久改人设。

## 决定

- 他（男朋友档、`deviceOwner`）发**纯文字 `/亲热`** 时：
  1. 记下“接下来 10 条回复”；
  2. 这条命令本身照常交给她回（那条回复也算 10 条里的第 1 条）；
  3. 之后每生成一条回复，提示词里多一行：「他刚让你亲热一点：接下来这几条，说话软一点，主动要抱抱、亲一下、说想他都可以；只限这几条，别腻到不像你，也别每条都撒娇」；
  4. 数到 0 自动失效，无需再发命令。
- 状态存 `<dataDir>/intimacy.json`（按 QQ 分开，`{remaining, armedAt}`），**重启不丢**；再发一次重置为 10。
- 只对**回他**的回合生效：主动找他、危机回合、想一想（内心）不消耗也不加这行。
- 不新增配置开关：命令本身是显式请求，和 `/主动` 一样只认男朋友档的他。

## 后果

- 影响只在提示词一行 + 计数，不改角色卡、不改温度、不进世界书；
- 数到 0 或重新扫码/换数据目录时自然重置；
- 若以后想“按条数/按时长”变体，可扩展 `armIntimate(dataDir, qq, count)`（已支持第二个参数）。
