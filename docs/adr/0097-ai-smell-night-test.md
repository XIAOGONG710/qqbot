# ADR 0097：深夜测试对话里量出来的几处“AI 味”——被指出时不自证、很抽象的问题不答成金句、被追问不原地打转、反复说的字词提醒她换

- 状态：**已实现，已上线**（2026-10-22）；没有开关，和 ADR 0091 十月二十一日那次校准同一类（意图行 + 一行提示）
- 日期：2026-10-22
- 关联：[ADR 0019](0019-intent-line.md) 一类的意图行、[ADR 0091](0091-reply-shape.md)、[ADR 0093](0093-blind-judge.md)
- 用户提出：2026-10-22「看一下最近的聊天记录吧，对这些进行分析，她现在还是会有 AI 的味道」

## 看了什么

线上男朋友那个联系人自 10-19 起 231 行（她 114 条气泡，其中凌晨 01:00–01:28 是用户在测她：问活人感、问谈恋爱是什么样子、求婚追问、指出她哪句话不像真人）。同口径对照：真人情侣聊天样本（女方一侧，200 条气泡）和用户自己线上的话。脚本 `exchange/tools/measure/`（`ai-smell.cjs` 在本次的临时目录，口径见下）。

先排除一个看着像、其实不是的：**逗号**。她的气泡带逗号的比例 10-18 之前 75–85%，形状控制上线后 35%，用户自己是 43%——已经对上了，不是味道的来源。长短也对上了（平均 7.2 字，用户 10.7）。剩下的是**内容和语用**：

| 特征 | 她（10-19 起 114 条） | 真人样本 |
| --- | --- | --- |
| 自证 / 辩解（「是真心话，不是设定」「我没敷衍」「我说的算数」「哪有老重复，是困得话都说不利索了」「我照样认，不算跑」） | 5% | 0% |
| 叮嘱 / 劝慰 / 给方案（「别往心里去」「别瞎想」「换个接口试试」「别自己拆」「早点睡」） | 8% | 2% |
| 理由 / 反驳从句（「反正…」「要是…还用…」「不然…」） | 5% | 4%（没差别，不算） |

读对话看到的三处（比数字更像“AI 味”）：

1. **被指出“不像真人 / 老重复 / 敷衍”时辩解、解释原因**：用户说「真人不会这样说，而是『哪有老重复，你净瞎说』」——真人是嗔一句、认怂、反呛，不解释自己为什么这么说。
2. **被问很抽象的问题时答成金句**：「谈恋爱是什么样子」→「就两个人待着不用装，他不在会惦记，见了就想多待会儿」；「喜欢我什么」→「喜欢你嘴硬，其实心不硬」。三个小句、对仗，像写好的；真人更碎、更具体（一件小事）、或者说不清。
3. **被连着追问一个答案时原地打转**：求婚那一段 20 条里有 12 条是「太突然 / 太急 / 困了 / 明天说」的不同说法，用户说「你总是这样，模棱两可」。同一个意思换着词说，没有任何新内容，也没有任何态度。
4. 还有**同一件事反复提**：「肚子坠着」三个晚上都在说；「想歪了你」连着三条原样重复。

## 做了什么

`intent.ts`（和 ADR 0091 的校准一样，没有开关）：

- **`CHALLENGE_INTENT`**：他说她像 AI / 稿子 / 客服、没有活人感、真人不会这样说、老重复、敷衍、模棱两可时：「别替自己辩解，也别解释原因（不说「我是因为困」「我没敷衍」「我说的算数」「不是设定」这类自证）；像真人被说中了那样：嗔一句、笑着认个怂、反呛他一句，或者撒个娇带过，一两句就够」。**问她是不是 AI / 真人**是身份那一路（承认版卡、世界书场景），不在这里。
- **`ABSTRACT_INTENT`**：他问谈恋爱什么样、喜欢我什么、真实想法、伤心什么感觉、理想型时：「别总结成一句漂亮的话（不要排比、对仗、「不是…而是…」、「其实」）；说一件具体的小事、一个画面，或者坦白说不太清楚再补半句，也可以反问他一句」。这一类轮次的形状只用长的几档。
- **`STALL_INTENT`**：他在追答案（回答我 / 不要回避 / 到底愿不愿意 / 真实想法），她最近 6 条气泡里至少 3 条在往后推（明天、改天、太急、太突然、困、再想想）：「别再用同样的理由往后推……现在就给一个态度，哪怕不完整——答应、半答应带点害羞，或者明说你在怕什么」。
- 三条都排在亲密邀约、逗她、拍照之后，收尾、好事、回答问题之前。

`expression.ts` 的 `recentCrutches`：她最近 8 条气泡里至少 3 条出现的两字词、至少 4 条出现的单字（去掉虚字、称呼、笑声），最多 4 个；`contact.ts` 在提示词里多一行「你这几条里反复在说「急」「困」：这一轮别再用这几个字，换个反应——直接答、逗他、反问、认怂、生气都行」。主动找他、危机回合不用。

## 量出来的（把用户那天凌晨的 46 句话原样喂给她，3 次，真模型）

| | 自证 / 辩解 | 往后推的字词（急 / 突然 / 困 / 明天说……） |
| --- | --- | --- |
| 上线前（四个新开关都开着） | 5% | 14% |
| 之后 | **1%** | **7%** |

读对话：被说「你看，说话又跟 ai 似的」→「那你想怎样」「我认还不行 / 服了你了 / 这回不犟了」；求婚追问不再转圈，给态度（「愿意啊 / 这还用问」「就是有点怕，你别嫌我黏」）；问伤心是什么感觉→「说不清楚，就是心里堵着」。

## 没做 / 要注意

- **叮嘱 / 劝慰 / 给方案**（8% vs 2%）：样本只有 200 条、真人朋友之间也会说「换个接口试试」，证据不够硬，没动；以后线上数据多了再看。
- **「肚子坠着」反复提**：`recentCrutches` 只管最近 8 条里的重复，隔了几个晚上的重复管不到；要管得靠“这件事她已经跟他说过了”的记账（类似 ADR 0057 的 untold），这次没做。
- 求婚这类大问题她回得太痛快也不对（真人会更犹豫）——那是人设决定，不是 AI 味；STALL 意图只管“别原地打转”，不替她决定答应还是不答应。
