# ADR 0023：挂着的事——在等他说的、她问了没答的、说好没成的

## 背景

真人心里总挂着几件没了结的事：他说明天面试，第二天晚上她会想知道结果；她问的话他岔开了，过一天她会再问一次；说好的事没成，第二天她还记得，
但不一定说出来。现在她只记得自己答应的事（ADR 0018 决策 2），其余的要么被长期记忆召回、要么忘了，不会在合适的时候自己冒出来。

作者 10-06 的裁决（DSH 侧代记）给了边界：

- 二·2、二·3：意图行（ADR 0019）里要能产生「在等他说某件事」，**只写想要什么、在等什么（期待），不写介意（委屈）**；复用意图行，不新增机制。
- 三·1「跨天累积」：**跨天存的是账（事实），不是情绪**。记进去的必须是别人能听懂「发生了什么」的事；当天的底色每天重新算，输入多一路「未了结的事实」；
  系统里从来不存情绪，ADR 0018 用户定的「不做带情绪的记忆」边界不破。

## 取证（10-07，只读代码）

- `promises.ts`：每段聊天结束（安静 45 分钟）一次模型调用抽她答应的事，状态在 `<数据目录>/promises/<QQ>-<档位>.json`，有到期、提醒、划掉、忘掉；
  抽取时把还没做的给模型，这一段做了的写进 `resolved`。它已经是「一段聊天结束后整理一遍」的唯一入口，加三类东西不用多调一次模型。
- `intent.ts`（ADR 0019，已上线）：按线索给一行「这一轮你想」，顺序是收尾 → 他直接问 → 他说自己的事 → 她答应的事 → 书 → 手上的事 → 忙。
- 心情（`her-days.ts` 的 `moodAt`）按日子和作息抽，每天重算，不存任何东西；时间块里在状态行后面。
- 长期记忆里有他的计划（ADR 0017 写成绝对日期、标「打算 几号」），但召回是按他这次的话查的，他不提就不出现；「她问了他没答」更是只有聊天原文里有。

## 决策

### 1. 三类「挂着的事」，和她答应的事同一次抽取

| 类 | 是什么 | 例子（写法） | 什么时候放 | 多久放下 |
| --- | --- | --- | --- | --- |
| `waiting` 等结果 | 他说的、之后会发生、她会想知道结果的事 | 「阿明周四下午字节面试」（带日子） | 有日子的：那天 18 点以后到之后 3 天；没日子的：抽出它的那段聊天之后 | 有日子的过了那天 3 天；没日子的过了说的那天 7 天 |
| `unanswered` 没回答 | 她问了他一个真问题，他岔开了 | 「周末要不要一起去拍银杏」 | 之后的聊天 | 说的那天之后 3 天 |
| `unsettled` 没了结 | 说好的事没成、一件事没说完就断了 | 「10月7日说好一起看电影，他临时加班没看成」 | 之后的聊天 | 说的那天之后 3 天 |

- 抽取：`promisePrompt` 多要这三类，同时把「还挂着的事」（id 以 `a-` `q-` `u-` 开头）给模型，这一段里有了结果、他回答了、事情了结了的写进 `resolved`。
  **只写发生了什么**，提示词明说不写感受、不要「难过」「委屈」「介意」「失望」这类词；解析时再兜一层：带情绪词的整条丢掉（日志「写成了情绪、没记 N 条」）。
- 「她问了他没答」用模型判断，不用规则：反问、玩笑、他隔了几句才答的，规则分不清；而这一次调用本来就要跑，不多花钱。
- 存在同一个状态文件的 `loops` 里（旧文件没有这个字段，读成空的）；抽出它的那段聊天里不放（原话就在眼前）；这一段她回了 3 次还没提就不放（同 ADR 0018，说明里的话不能一直挂着）。
- 名单外不做（同她答应的事）。

### 2. 用法：两类进意图行，只表达期待；一类放在心情后面，只给事实

- 意图行（`intent.ts`）新的顺序：收尾 → 他直接问 → **等他说结果的** → 他说自己的事 → 她答应的事 → **她问了他没答的** → 书 → 手上的事 → 忙。
  - 等结果：「这一轮你想：知道「X」后来怎么样了，随口问一句；他不想说就算了，不追问」。排在他说自己的事前面：他一开口，最自然的就是先问那件事。
  - 没回答：「这一轮你想：上次问他「X」他没顾上回，轻轻再问一次；他不接就算了，不追究」。排在她答应的事后面，不抢。
  - 两条都只写想知道、再问一次（期待），**不写介意**（作者裁决二·3）；收尾、他直接问时照样让路（ADR 0019 改后回归的教训）。
- 没了结的：时间块里心情后面一行「你心里还记着、没了结的事（只是发生过的事，不是要你说的话）：X。不用特意提，也不翻旧账；他说到相关的事时你记得」。
  这就是作者说的「情绪层的输入多一路未了结的事实」：心情照旧每天重算，这一行只是同一个时间块里的事实，**不写情绪、不存情绪**。
- 主动消息（ADR 0011）这次不接：主动找他时意图行本来就不放（`initiating`），「等结果」进主动消息的「待跟进」之后再议（见「后果」）。

### 3. 不做的

- 不存「她什么感觉」：没有情绪字段，带情绪词的抽取结果丢掉；跨天的只有事实。
- 不让「没了结」进意图行：意图行是「这一轮要做的事」，放进去就成了「这一轮要提那件事」，离翻旧账只差一步。
- 不新加模型调用、不新加状态文件。

## 实现时的调整（10-07）

1. **「没回答」抽得太宽**（第一批）：「他今天几点下班」「你今天是干什么了」「吉他什么型号」「哪个窗口菜咸」都挂上了，第二天她追着问「哪个窗口」；
   真正被岔开的「周末要不要一起去拍银杏」反而进了「没了结」。提示词改成只记她真想要答案的（约他、问打算或决定、对她要紧的事），列出不算的随口问句；
   她约他没接茬的归「没回答」、不归「没了结」；一段聊天最多一条（解析时也只留第一条）。
2. **写法带相对日子**：「宝宝明天下午去字节二面」第二天再看就错了。提示词要求 what 不写「明天」「下周」，日子写在 date 里。
3. **抽取偶尔是空的**：开思考时思考也算在 max_tokens（4096）里，想太久正文就是空的——第一批 4 次、第二批 6 次，线上 10-07 13:34、13:39 同一段也连着两次（第三次才抽成）。
   后台抽取（她答应的事、挂着的事、主动消息的待跟进）的输出上限放到 8192（`llm.ts` `forExtraction`，同一个模型），截断时日志写「模型输出被截断：思考用完了 max_tokens」。
   第二批 `open-loops-unanswered` r2 就是第二段连着被截断两次，他答应去拍银杏也没了结。

留给作者看的（不改行为，作者取向「证据优先」）：

- **他先提起没看成的电影时，她 3/3 接一句带笑的埋怨**：「你哪天不加班啊，别再放我鸽子」「我还以为你就这么算了……这次再放我鸽子，土豆都不给你」「别再临时放我鸽子了，我可记着账呢」。没了结的那一行只写事实、写了「不翻旧账」，出口检查的算账规则也没判违规；这是真人常有的玩笑式埋怨，但贴着作者二·3「不写介意」的边。要不要收紧（例如「他提起时也不埋怨」）请作者定。
- **她约他、他答应了，她反而「先别定死」**（三批里 2 次）：卡上「线下见面不约具体时间地点」（她到不了）的约束在起作用，不是这份 ADR 的问题；场景里的「一起去拍银杏」本身是她兑现不了的约。

## 备选方案

| 方案 | 不选的原因 |
| --- | --- |
| 新开一路模型调用专门抽「挂着的事」 | 多一倍调用；和她答应的事看的是同一段聊天，一次就够 |
| 「她问了没答」用规则（她上一条有问号、他下一条没接） | 反问、玩笑、隔几句才答都会误判；抽取本来就要跑 |
| 存「她对这件事的感受」，第二天按感受调心情 | 作者裁决三·1：跨天存账不存情绪；ADR 0018「不做带情绪的记忆」 |
| 没了结的也进意图行（「这一轮你想：提一下昨天没看成的电影」） | 等于叫她翻旧账；放成事实，他说到时她记得就够 |
| 从长期记忆里按日期查「他之前说过的计划」 | 每轮都要多一次召回，还要猜哪些是「她想知道结果的」；抽取时顺手记下更准、更省 |

## 后果

- 每段聊天结束的那次模型调用输出变长一点（多三个数组），不多调用。
- 写进状态文件的都是事实；以后要做「情绪惯性」时，输入从这里来（作者裁决三·1 的落地要点 ②）。
- 主动消息还不会因为「等结果」而主动来问（ADR 0011 的待跟进是另一套）；之后可以把到点的「等结果」作为主动消息的一种时机，单独评估频率。
- 抽取靠模型，可能漏抽或把玩笑当成问题；漏了就是没挂上，最坏是她再问一次他已经答过的（了结也靠同一次调用）。

## 确认记录（2026-10-07）

- 作者 10-06 裁决（DSH 侧代记，`author-replies.md`）：二·2 意图行试运行，加「在等他说某件事」；二·3 只写期待、不写介意，复用意图行；三·1 跨天存账不存情绪，底色每天重算、多一路未了结的事实。
- 用户 10-07：「允许多开子代理，以达成让林梦瑶成为真正的人」；之前 10-06 定的「暴力推进，要选的按推荐定」。以下按推荐定：
  1. 三类（等结果、没回答、没了结）和她答应的事同一次抽取，存同一个文件。
  2. 「她问了没答」用模型判断，不用规则。
  3. 等结果、没回答进意图行（只表达期待）；没了结的放在心情后面，只给事实，不进意图行。
  4. 期限：等结果有日子的那天 18 点后到之后 3 天，没日子的 7 天；没回答、没了结 3 天。
  5. 主动消息这次不接。
