## 差距

真人说了“等下，我去拿个外卖”就会回来说一声“回来了”。她说完“等下”就没有下文，要等他再开口。线上 676 条她的话里这类话只有 3 条，所以单看今天收益小；但有了追求（修片先弄完这一小段）和日常小事（ADR 0106）之后这类话会多。

## 做了什么

1. **新的主动时机 `back`**（`proactive.ts`；`withBack` 在运行时加，不改角色卡）：她**最后一句**是短暂离开（`stepsAway`：“等下 / 等我一下 / 稍等 / 马上回来 / 去拿 / 倒 / 接 / 开 / 关 / 收 / 晾 …… / 我去…一下 / 弄完这张再说 / 十分钟就回来”；排除“你等下”（叫他等）、晚安 / 睡了 / 拜拜 / 去忙了 / 先这样 / 明天、洗澡），之后谁都没说话，是她的**同一天**说的：过 `BACK_MIN`（4–14 分钟，按那句话的时刻取哈希）回来。id 带那句话的时刻（`<她的一天>:back:<毫秒>`），每句话只回一次。
2. **自己的规则，不套主动的老闸**：到点再查只看这件事本身——那句话之后又有人说过话（他说了：先回他，走“有没回的消息”；她又说了）就不回；超过 40 分钟（bot 停着、断线之后）不回。**不查**“一小时内聊过”、每天条数、“他没回就停”；**不算**每天的主动条数（`usedOn`），**不算**“他没回”的条数（`unansweredRecords`）；`planFrom` 里不被每天上限挤掉（和重要的日子一样自成一类）。
3. **提示词**：「你前面跟他说了要离开一下（看上面最后几句：你去弄什么），现在回来了：说一声回来了，顺带说一句刚才那件事弄得怎么样了（只用你前面说的和「你现在」那一行写着的，没写的别编），不要他回应」；也带上 ADR 0108 的“开头直接说事，别先叫名字”。

## 没做 / 要注意

- 只认她**最后一句**；说了“等下”又说了别的，不回来。
- 她说“去洗澡 / 去睡 / 去上课 / 去忙了”这类长离开不算（她回来的时刻不是几分钟）。
- 夜里 00:30 以后、她在睡觉 / 上课时照主动的老规矩不发。

## 验证

- `come-back.test.ts`（7 个）：哪些话算 / 不算短暂离开（9 + 7 句）；候选时间在 4–14 分钟、同一句每次一样、id 带时刻；没开 / 他最后说 / 不是离开的话 / 昨天说的都没有；到点再查（他说了话先回他、她又说了不回、隔太久不回、不受一小时内聊过 / 每天满额 / 他没回的闸）；不算条数、计划里不被上限挤掉；提示词。
- 模拟（真模型，`sim/come-back.json`，4 次）：全部通过——她说“等下，我去拿外卖”、他没说话，20 分钟内她各回来一次；他回话后不再单发。
