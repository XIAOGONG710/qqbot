# ADR 0057：她那边刚有件事，主动告诉他

- 状态：已实现，待上线（分支 `news-occasion`）
- 日期：2026-10-11
- 关联：[ADR 0011](0011-proactive-messages.md)（主动消息）、[ADR 0050](0050-rain-message.md)（下雨了主动找他）、[ADR 0053](0053-buying-the-camera.md)（买相机）、[ADR 0036](0036-conversation-naturalness.md) 调整（2026-10-10 夜）

## 背景

主动消息的时机（早安、下课、睡前、冷场、待跟进、重要的日子、下雨）都是「到点了 / 想起他」，没有一种是「我这边刚有件事，想第一时间告诉你」。
真人女朋友攒了几个月钱，买到相机走出店门，第一件事就是给男朋友发「买到了！」。10-11 下午她去山大路科技市场买相机（ADR 0053），正是这种时刻。

## 决策

1. **新时机 `news`（她那边的事）**，优先级排在重要的日子之后、待跟进之前；男朋友档开（`tiers.yml`），每天的总条数照旧（2 条）。
2. **事从世界里来**（`world.ts` 的 `worldNews`）：现在只有一件——买到相机，时刻是那一趟了结的时候（16:30）。以后有别的值得说的（考试出分、比赛结果）往这里加，每件带 id，一件一条。
   计划器看到明天这一刻为止的世界（`proactive-planner.ts` 的 `newsFrom`，app.ts 和模拟器共用），挑了结在她的今天、明天的。
3. **时刻**：了结后 5–20 分钟（在回去的路上掏出手机）。
4. **拦法**：照常的都在（睡觉、上课、说过睡了、有没回的消息、今天已经 2 条、上一条主动的他没回）；
   「正聊着」放宽到 10 分钟（`NEWS_RECENT_MS`，别的时机是一小时——这种事等不了一小时）；**那之后两人聊过**就不发（状态行里有，聊天里多半已经说了，不再单发一条）；
   到点时世界里没有这件事了（钱不够没买成）就不发。
5. **说明只给事实和方向**：「你刚在山大路科技市场买到了二手索尼 a6100 加 16-50 套机镜头（4280 元，攒的钱买的），想第一时间告诉他：说说这件事（看「你那边」那一行），就说这一件；那一行里没写的细节不编」。
   不写引号里的台词（ADR 0036 调整（2026-10-10 夜）的教训）。

## 一起修的两处（做模拟时发现）

- **「你今天的打算」不知道买相机这一趟**：同一个时间块里「你那边」写着「今天 14:00 要去山大路科技市场买」，打算却写「下午在图书馆赶作业」，后面还注明「他问起照这个说」——
  模拟里他问「今天干嘛」，她说「下午去图书馆赶作业」。现在世界里定好了几点去做的事（`worldErrands`，现在只有买相机那一趟）占掉的那一段，打算里写这件事（「下午 14:00 去山大路科技市场买相机」），
  状态行和日记都用；行动账（`life-selector.ts`）不动，它已经把那一趟当成占时间的事。
- **买完回来那一会儿**：16:30 买完，状态行回到作息里下午那段，16:39 她说「相机搁宿舍呢 我现在人在图书馆」。现在买完后一小时内是「刚买完相机回到宿舍，在摆弄新相机」（`occupationAt`，只进状态行；行动账那边没加，Codex 那条线以后对齐）。

## 验证

- 单元测试：候选时刻（了结后 5–20 分钟）、别的日子没有、卡上没开没有、说明里不带台词；到点没发生不发、那之后聊过不发、10 分钟内聊过不发、隔了半小时照发；
  一天只剩一条时先留它；`worldNews` 10-11 出门前就知道 16:30 了结、钱不够没有；打算里写买相机那一趟、只在那一天；买完 10 分钟、30 分钟是「刚买完相机回到宿舍」，一小时以后照作息。
- 真模型（不带记忆）新场景 `sim/proactive-news.json`（头天转了 2000，10-11 上午聊几句，之后没人说话）：
  - 改打算前 3 次：两次 16:39 主动「宝宝，相机买到了 / 二手索尼a6100，4280，我攒的钱全没了[捂脸]」「相机买到了 / 二手a6100，套机，4280」；一次他那句「买到了跟我说」挂着没回，主动那条让给了回复「买到了」。
    上午问「今天干嘛」2 次没提买相机，其中一次说「下午去图书馆赶作业」（上面第一处）。
  - 改后 3 次：都在 16:39 主动说了（「宝宝 相机买了 / 二手a6100 加套头 4280 / 心疼死我了 攒的钱一下没了」「宝宝 / 相机买到了 / 二手的，a6100，加个套机头，4280」）；
    上午 2 次说了下午去山大路（「下午去趟山大路」「下午去山大路买个东西」）；一次 16:39 说「我现在人在图书馆」（上面第二处，之后修的）。第二天没有再为这件事单发。
