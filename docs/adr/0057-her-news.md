# ADR 0057：她那边刚有件事，主动告诉他

- 状态：已实现，待上线（分支 `news-occasion`）
- 日期：2026-10-11
- 关联：[ADR 0011](0011-proactive-messages.md)（主动消息）、[ADR 0050](0050-rain-proactive.md)（下雨了主动找他）、[ADR 0053](0053-buying-the-camera.md)（买相机）、[ADR 0036](0036-conversation-naturalness.md) 调整（2026-10-10 夜）

## 背景

主动消息的时机（早安、下课、睡前、冷场、待跟进、重要的日子、下雨）都是「到点了 / 想起他」，没有一种是「我这边刚有件事，想第一时间告诉你」。
真人女朋友攒了几个月钱，买到相机走出店门，第一件事就是给男朋友发「买到了！」。10-11 下午她去山大路科技市场买相机（ADR 0053），正是这种时刻。

## 决策

1. **新时机 `news`（她那边的事）**，优先级排在重要的日子之后、待跟进之前；男朋友档开（`tiers.yml`），每天的总条数照旧（2 条）。
2. **事从世界里来**（`world.ts` 的 `worldNews`）：现在只有一件——买到相机，时刻是那一趟了结的时候（16:30）。以后有别的值得说的（考试出分、比赛结果）往这里加，每件带 id，一件一条。
   计划器看到明天这一刻为止的世界（`proactive-planner.ts` 的 `newsFrom`，app.ts 和模拟器共用），挑了结在她的今天、明天的。
3. **时刻**：了结后 5–20 分钟（在回去的路上掏出手机）。
4. **拦法**：照常的都在（睡觉、上课、说过睡了、有没回的消息、今天已经 2 条、上一条主动的他没回）；
   「正聊着」放宽到 10 分钟（`NEWS_RECENT_MS`，别的时机是一小时——这种事等不了一小时）；**那之后两人聊过**就不发（状态行里有，聊天里多半已经说了，不再单发一条）；
   到点时世界里没有这件事了（钱不够没买成）就不发。
5. **说明只给事实和方向**：「你刚在山大路科技市场买到了二手索尼 a6100 加 16-50 套机镜头（4280 元，攒的钱买的），想第一时间告诉他：说说这件事（看「你那边」那一行），就说这一件；那一行里没写的细节不编」。
   不写引号里的台词（ADR 0036 调整（2026-10-10 夜）的教训）。

## 一起修的三处（做模拟和预览时发现）

- **「你今天的打算」不知道买相机这一趟**：同一个时间块里「你那边」写着「今天 14:00 要去山大路科技市场买」，打算却写「下午在图书馆赶作业」，后面还注明「他问起照这个说」——
  模拟里他问「今天干嘛」，她说「下午去图书馆赶作业」。现在世界里定好了几点去做的事（`worldErrands`，现在只有买相机那一趟）占掉的那一段，打算里写这件事（「下午 14:00 去山大路科技市场买相机」），
  状态行和日记都用；行动账（`life-selector.ts`）不动，它已经把那一趟当成占时间的事。
- **买完回来那一会儿**：16:30 买完，状态行回到作息里下午那段，16:39 她说「相机搁宿舍呢 我现在人在图书馆」。现在买完后一个半小时内（盖到傍晚）是「刚买完相机回到宿舍，在摆弄新相机」。
- **出门前那一会儿**：拿线上世界的副本预览 10-11，13:30 还「在图书馆赶作业」，14:00 就到了山大路。现在出门前一个半小时内（吃饭排在前面）是「在宿舍准备出门，14:00 去山大路科技市场买相机」。
- 后两处都在 `occupationAt`，只进状态行；行动账那边没加，Codex 那条线以后对齐（影子账审计会把这几段当成「此刻在做别的」，不算分叉）。

## 验证

- 单元测试：候选时刻（了结后 5–20 分钟）、别的日子没有、卡上没开没有、说明里不带台词；到点没发生不发、那之后聊过不发、10 分钟内聊过不发、隔了半小时照发；
  一天只剩一条时先留它；`worldNews` 10-11 出门前就知道 16:30 了结、钱不够没有；打算里写买相机那一趟、只在那一天；买完 10 分钟、30 分钟是「刚买完相机回到宿舍」，一小时以后照作息。
- 真模型（不带记忆）新场景 `sim/proactive-news.json`（头天转了 2000，10-11 上午聊几句，之后没人说话）：
  - 改打算前 3 次：两次 16:39 主动「宝宝，相机买到了 / 二手索尼a6100，4280，我攒的钱全没了[捂脸]」「相机买到了 / 二手a6100，套机，4280」；一次他那句「买到了跟我说」挂着没回，主动那条让给了回复「买到了」。
    上午问「今天干嘛」2 次没提买相机，其中一次说「下午去图书馆赶作业」（上面第一处）。
  - 改后 3 次：都在 16:39 主动说了（「宝宝 相机买了 / 二手a6100 加套头 4280 / 心疼死我了 攒的钱一下没了」「宝宝 / 相机买到了 / 二手的，a6100，加个套机头，4280」）；

## 调整（2026-10-11 夜）：没说成的，这一天后面的主动顺带说

10-11 那条没发出去以后，晚上 23:37 的睡前只有「跟宝宝道个晚安」：「你那边」写着今天买了相机，可没有一处告诉她这件事还没跟他说过。
上午他问过「你的相机什么时候去买？」，她说「今天下午去，两点，山大路那边」——真人买到了没顾上说，晚上道晚安时会顺带说一句。ADR 0011 调整 14（再试）只管以后，这一条那天已经「不再试」了。

1. **什么算没说成**（`untoldNews`）：她的这一天了结了的那件事，那条主动的记录不是「发了 / 试运行发了」、也不在等着再试（没连上模型三次、错过了、没排上都算），
   而且**那之后两人没说过话**（和 `blockReason` 同一个判断：聊过的，状态行里有，聊天里多半说了）。只看这一天：第二天不带。
2. **哪几种时机带上**：早安、下课、冷场、睡前（问候、找他说话的这几种）；日子、下雨、待跟进各有要说的那一件，不带。
3. **说明里加一句**：「……道个晚安；你今天在山大路科技市场买到了二手索尼 a6100 加 16-50 套机镜头，还没跟宝宝说过，这次一起说（看「你那边」那一行，没写的细节不编）」。
   只给事实和方向，**不给没说成的原因**（她那边的人不知道断网，给了原因会编出「下午网不好」）。日志：「主动：睡前（准备睡了）顺带说没说成的事：……」。
4. 发出去以后，那条消息本身就在「那件事之后」的聊天里，后面的主动不再带。
5. **那件事的说法去掉「刚」和钱的来历**：`worldNews` 的 what 是「在山大路科技市场买到了……」，单发那条说明里写「你刚……」，顺带说的写「你今天……」；
   钱从哪来只写在「你那边」那一行，按是谁在看说（ADR 0053 调整三）。

模拟器加了 `proactiveOffline`（这几种时机生成时都当没连上模型），新场景 `sim/proactive-news-untold.json`：她那边的事、冷场都断网，看睡前那条。

**聊天里也一样**（同一晚，分支 `untold-chat`）：他先来了消息、主动那条还没轮上时，「你那边」里有相机，可意图行只看他说的——他多半开口就问「在干嘛」，
那一条是「先直接回答他刚问的，不另起话题」，正好把这件压下去。现在 `contact.ts` 算出她的今天了结了、那之后她一句话都还没说过的事（主动那条发出去了也算说过），
意图行「先回他刚说的；你今天……，还没跟他说过，接着就说这件（看「你那边」那一行，没写的细节不编）」排在「先回答」前面；他难过、收尾、要亲近、报好事时让路。先只给男朋友档（意图行里写的是「他」）。
她回过一句以后就不再带（不管她说没说）。

- 新场景 `sim/news-untold-chat.json`（她那边的事、冷场都断网，晚上他来一句「在干嘛」）3 次 13/13：「在宿舍捣鼓相机呢，今天下午买到了」「在宿舍研究相机呢，宝宝 / 今天下午买了，二手索尼a6100，4280，拿下」「在弄相机呢，今天去山大路买了一台二手的」；
  之后睡前没再带这件。问「多少钱啊」：「4280，二手的，a6100 加套机镜头 / 攒了好久，总算到手了」「4280，不是跟你说过了」「4280，二手的a6100，加个16-50的套机头」——没照抄、没说成到账（这一组跑的时候称呼还是「对方」，三次都没抄）。
