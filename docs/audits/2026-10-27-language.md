# 模块审计 1：language（她每轮到底被注入了什么）

日期：2026-10-27 · 只读审计，不改代码
范围：`src/language/` + `platform/contact.ts` 的提示词拼装（763–815 行）

## 一、每轮几乎必有的（“事实组”）

| 注入 | 来源 | 条件 | 说明 |
| --- | --- | --- | --- |
| 时间/距离上一条 | `describeTime` | 总是 | “现在几点、距上条多久” |
| 她的状态 | `describeState` | `state` 存在 | 在干嘛、在哪 |
| 心情 | `describeMood` | `mood` 存在 | 今天底色（爱笑/话痨/安静…） |
| 身体 | `body` | `body` 存在 | 困/饿/不舒服 |
| 她那边 | `world` | `world` 存在 | 天气、猫、快递、钱、作业 |
| 今天打算 | `plansLine` | `plans` 存在 | “晚上打独立游戏” |
| 形状 | `describeShape` | `shape` 开且非危机/贴纸/照片/打断/想一想 | **每轮给字数和条数** |
| 长短 | `describeLength` | 形状没开/被挡时 | “回短一点/话多一点” |
| 意图 | `intentLine` | `intent` 有值（大多数轮） | “这一轮你想：…” |
| 质感上下文 | `textureNow` | `texture` 开、男朋友档 | 影响发送前的语气处理 |

> 结论：**“事实组 + 形状/长短 + 意图”几乎每轮都在**；她每轮都被重新告知“你是谁、你现在怎样、这一轮该怎么回”。

| 注入 | 条件 | 频率 |
| --- | --- | --- |
| 小梗 `jokeNow` | 男朋友档、非主动、非危机、非小别扭、随机 | 中低 |
| 成语 `idiomNow` | 同上 | 中低 |
| 梗图 `memeNow` | 同上 | 中低 |
| 看过的视频 `watchedNow` | 当天看过、非主动 | 低 |
| 连续未完成 `continuityLines` | 有未完成的事 | 低 |
| 打断 `interruptLine` | 随机 | 低 |
| 重复词提醒 `crutchLine` | 最近反复说某些词 | 中 |
| 已说过 `toldLine` | 她主动说过的事 | 中 |
| 开场词 `openerLine` | 主动且开头重复 | 低（仅主动） |
| 引用 `quoteLine` | 他引用了一句 | 低 |
| 内心 `innerNow` | 有内心活动、非主动 | 中 |
| 亲热 `intimateNow` | `/亲热` 剩余次数内 | 低 |
| 照片/贴纸/设备菜单 | 条件满足 | 低 |
| 摘要/召回/回顾 | 记忆开启且触发 | 中低 |

## 三、问题（为什么“像被束缚”）

1. **形状 + 意图每轮双保险**：`shape` 管“多长、几条”，`intent` 管“这一轮你想什么”，两个都常驻，等于每轮把“说什么、怎么说”都圈了一遍。
2. **事实组四条并列**：时间、状态、心情、身体、世界、打算——信息全给，她只能“照着过”，没有取舍空间。
3. **心情是断言不是叠加**：`describeMood` 直接说“你今天心情：爱笑”，不是“底色 + 今天发生的事可以改变它”。
4. **“每轮提醒”太多**：重复词、已说过、开场词、质感、形状，叠在一起，她的发挥空间被压到“措辞”一层。
5. **随机项（小梗/成语/梗图）反而成了“表达来源”**：因为她的偏好没有别的出口，只能靠这些随机注入显得有花样。

## 四、可调的点（按风险从低到高）

| # | 调整 | 风险 | 验证 |
| --- | --- | --- | --- |
| 1 | **形状降级**：自由时间/纯闲聊轮次不给 `shape`，只给“可以多说一点” | 低 | 同一组 20 问，看句长分布 |
| 2 | **意图瘦身**：`intentLine` 只在“他问了具体事/情绪明显/有冲突”时给，闲聊不给 | 低 | 盲评“像不像在听人说话” |
| 3 | **事实组合并**：world/body/mood/plans 合成 2 行，只留“今天最相关的一两件” | 中 | consistency 测试 |
| 4 | **心情改成叠加层**：底色 + 今日事件，允许被事件改变 | 中 | 与 emotion 模块联动 |
| 5 | **随机项限频**：小梗/成语/梗图每天上限，避免“靠随机显得活” | 低 | 日志计数 |
| 6 | **鱼八股检测**：模板腔重写，接在 exit-check 后 | 低 | 模板句检出率 |

## 五、建议

先做 1 + 2（不动事实、不动心情），两周观察：看“句长分布”和“盲评像不像在听人说话”。
如果有效，再做 3 + 4；5、6 是长期卫生，随时可加。
