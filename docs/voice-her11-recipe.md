# 声音模型 her11 配方（2026-11-12）

当前线上模型：**her11**（GPT-SoVITS v2，32k，s2 40 轮 + s1 40 轮）。

## 数据

- 训练集：**1282 条 / 134 分钟**
  - `her9`：895 条（旧的分离素材，已按 YIN 复核音高，剔除男声与异常音高）
  - `her10`：387 条（10 条新下载视频，重新按词边界切分，句尾留 0.35 s）
- 切片规则（`out/gpt-sovits/slice_v5.py`）：
  - 按标点或 >0.55 s 停顿断句，超长时在词边界断开，**每段只带自己的文本**
  - 句尾最多多留 0.6 s 自然衰减 + 0.35 s 静音
  - 只剔 f0 < 200（男声）与几乎无高频的片段
- 体检：新切片的 `end_db` 中位 **−25.1 dB**（旧版 −6.5，属于硬切）

s2: 1282 条，216 步/轮，40 轮，约 4 小时（RTX 5060 Laptop 8 GB）

## 生成

`out/gpt-sovits/gen_her11.py`：4 个 seed 生成，按 HNR 择优，再走提亮 + 高频激励：

```
treble=g=9:f=6000,equalizer=f=120:t=q:w=1:g=-2,
asplit=2[a][b];[b]highpass=f=4000,volume=0.5[exc];
[a][exc]amix=inputs=2:duration=first:weights=1 0.6
```

实测三条：HNR **5.5~6.1 dB**（her9 是 2.2~3.4），f0 236~247（素材 230）。

## 结论与边界

- 用户 2026-11-12 确认「很像了」，定为线上模型（api_v2 / 9880 加载 her11）。
- 剩余边界：素材本身 HNR −1 dB（气声+分离残留），32k 声码器高频上限，这两条不改素材就跨不过去。
- 下一步可选项：聊天语音接入「多 seed 择优 + 提亮」；换更干净的干声源；上 48k 路线。
