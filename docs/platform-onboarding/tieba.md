# 百度贴吧接入边界

## 当前结论

贴吧官方公开页面仍提供合作型开放 API，能力包括指定吧内容展示、精华贴数据和账号登录发帖，但页面要求先申请合作 API（`tiebasdk@baidu.com`），没有可直接用于普通个人机器人的稳定公开 REST 接口。

因此本项目暂不通过网页抓取、移动端私有接口或模拟点击实现贴吧自动化。这样做会绕过平台授权边界，也会让登录、风控和接口变更直接影响 QQ 回复链。

## 允许的第一阶段

- 控制台增加“贴吧：关闭 / 只写草稿 / 官方接口”三档配置；默认关闭；
- “只写草稿”只生成待发布内容，不登录、不发帖、不读取用户私信；
- “官方接口”只有在获得百度合作 API 凭证后启用；凭证只放在密钥存储，不写普通日志；
- 所有发布动作都要经过人工确认、频率限制和审计；
- 失败时保留草稿，不影响 QQ 和 DSH 的正常回复。

## 后续实现条件

收到百度官方 API 的应用标识、授权方式、接口地址和权限清单后，再实现 `listForumPosts`、`createPost` 等适配器，并为每个接口补超时、重试、熔断和字段脱敏。
