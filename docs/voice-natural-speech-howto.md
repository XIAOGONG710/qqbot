# 用素材的音色说出自然的话：操作手册（2026-11-09）

接 `docs/voice-training-notes.md` 和 `docs/reports/2026-11-09-voice-clone-report.md`。
目标只有一个：**她的音色 + 自然的说话方式**。在 DSH 本机执行。

## 思路

声音拆成两层：**音色**（像不像她）和**韵律**（语调、停顿、轻重，决定自不自然）。
没有哪个模型能从 55 分钟表演腔素材里把两层都学好，所以分开做：

```
文本 ──► 前端 TTS（负责说得自然） ──► 对齐音高 ──► RVC her3（负责换成她的音色） ──► 响度归一 ──► wav
```

- RVC 实测音色最像，之前「含着东西」的原因在源音：ChatTTS 约 230 Hz，比她低一个八度，
  硬升 12 个半音导致共振峰错位，再加上 ChatTTS 本身吐字糊。换成正常女声源音、只偏几个半音，就能解决。
- 前端 TTS 只要说得自然、是正常女声即可，音色不像没关系，RVC 会盖掉（F5 的「尖」也一样）。

## 第 0 步：恢复 RVC 推理环境

`runtime/chattts` 已被删，RVC 要重装。

1. 重装 RVC WebUI（建议放 `runtime/rvc/`，不要再放进会被清理的目录）。
2. 从 `Desktop\清理工作\音色模型备份\` 取回 `her3` 的 `G_2333333.pth`。
   这是**训练检查点**，不能直接推理：WebUI「ckpt 处理 → 提取小模型」，
   采样率填训练时的值，「是否带音高」选是，版本选训练时的 v1/v2，输出到 `assets/weights/her3.pth`。
3. `.index` 特征索引随训练目录一起丢了。先不用索引（`index_rate = 0`）；
   第 5 步重训时会重新生成。

## 第 1 步：挑参考音频

前端 TTS 会模仿参考音频的节奏和语气，**「她说话的感觉」主要靠这一步**。

从 `out/gpt-sovits/wavs/` + `her.list` 里挑 3 段候选，要求：

- 5～10 秒，**一个完整的句子**（开头结尾不在字中间）；
- 日常平静语气，不耳语、不撒娇、不笑不哭，没有背景音残留；
- 中位基频接近 280 Hz（素材中位数），用下面的脚本测，240～320 Hz 都可以；
- 文字**逐字人工核对**（whisper 转写不能直接用，错一个字对齐就乱）。

测基频（`out/` 下任意 Python 环境，需要 `librosa`）：

```python
# f0.py  用法: python f0.py a.wav b.wav ...
import sys, numpy as np, librosa
for p in sys.argv[1:]:
    y, sr = librosa.load(p, sr=32000)
    f0, voiced, _ = librosa.pyin(y, fmin=80, fmax=800, sr=sr)
    f0 = f0[voiced]
    S = np.abs(librosa.stft(y, n_fft=1024)) ** 2   # 513 个频点，每点 31.25 Hz
    hi = S[256:].sum() / S.sum()                    # 第 256 点 = 8 kHz
    print(f"{p}\tf0中位 {np.median(f0):.0f} Hz\tp10 {np.percentile(f0,10):.0f}\tp90 {np.percentile(f0,90):.0f}\t8k+能量占比 {hi:.3f}")
```

（8k+ 占比用来对比发闷/发尖，只看和素材的相对值；报告里素材参考约 0.056，但算法不一定相同，先用这个脚本重测一次素材作基准。）

把 3 段候选和对应文字记进 `out/voice-ab/refs.txt`。

## 第 2 步：前端 TTS 出「自然的原声」

先用已装好的 **F5-TTS** 验证整条链路，跑通后再试 CosyVoice 2 / IndexTTS2（见第 6 步）。

- 参考音频 + 核对过的参考文字 + 要说的句子（测试集见下）。
- 参数先用默认（`nfe_step 32`、`cfg_strength 2`、`speed 1.0`）；听着太端/太夸张把 `cfg_strength` 降到 1.5 试试。
- **一句一合成**，不要把整段回复一次塞进去；多句回复按句拆开，合成后拼接，句间留 0.2～0.4 秒静音。
- 输出放 `out/voice-ab/<日期>-<前端>-<参考名>/front/`。

## 第 3 步：对齐音高

用 `f0.py` 测 `front/` 下所有输出的中位基频，取平均记为 `F`，RVC 的变调：

```
半音 = round(12 × log2(280 / F))
```

例：F5 输出 350 Hz → `12 × log2(0.8) ≈ -3.9` → 填 `-4`。
**不要按耳朵猜**；结果超出 ±6 说明前端声音本身不合适，换参考音频或换前端。

## 第 4 步：RVC 换音色

WebUI「模型推理」，批量处理 `front/` → `rvc/`：

| 参数 | 值 | 原因 |
| --- | --- | --- |
| 变调 | 第 3 步算出的值 | 只偏几个半音，避免共振峰错位 |
| 音高提取 | `rmvpe` | 最稳，少破音 |
| 检索特征占比 `index_rate` | 0（有索引后 0.3～0.5） | 太高吐字会糊 |
| 保护清辅音和呼吸 `protect` | 0.4～0.5 | 低了会把 s/sh/c/x 也强行转换，是「含糊」的来源之一 |
| 响度包络融合 `rms_mix_rate` | 0.25 | 保留前端的轻重变化 |
| 中值滤波 `filter_radius` | 3 | 默认 |

然后统一响度：

```
ffmpeg -i in.wav -af loudnorm=I=-16:TP=-1.5:LRA=11 -ar 32000 out.wav
```

## 测试集（固定不变，每改一处都全量重出）

日常聊天句子，覆盖短句、问句、语气词、齿音：

1. 嗯，我刚到家，今天好累啊。
2. 你吃饭了没有？别又随便对付一口。
3. 诶，你怎么现在才回我？
4. 好啦好啦，不生气了。
5. 外面下雨了，你出门记得带伞。
6. 我想想啊……那就周六吧，下午三点。
7. 这首歌真的好听，你也听听看。
8. 晚安，明天早上我叫你起床。
9. 哈，你说得对，是我想多了。

## 怎么评估

每一版在 `out/voice-ab/` 下一个目录，和素材原声片段放一起盲听，再记一行数字：

| 版本 | 前端 / 参考 | 变调 | f0 中位（目标 ~280） | 8k+ 占比（对比素材） | 吐字（1–5） | 自然（1–5） | 像她（1–5） |
| --- | --- | --- | --- | --- | --- | --- | --- |

- f0 明显高于 280 → 偏「夹」；8k+ 明显低于素材 → 发闷，明显高于 → 发尖。
- 结果写回 `docs/reports/`，延续现有报告的格式。

## 第 5 步：还含糊 → 重做 RVC 数据（只学音色，不用转写）

1. **分离换 BS-Roformer**（audio-separator 里的 `model_bs_roformer_ep_317_sdr_12.9755.ckpt` 等），
   不再用 MDX-NET Inst_HQ_3（会把 6～10 kHz 的齿音当伴奏削掉）；分离后再过一道 UVR DeReverb 去混响。
2. 切片 3～10 秒，然后**人工或按规则剔除**：笑、哭、撒娇、喘息、耳语、背景音残留、
   f0 中位 > 380 Hz 的片段。宁可剩 20～30 分钟干净的，也不要 55 分钟混杂的。
3. 只用 `*Vocals*`，确认没有 `(Instrumental)` 混进数据集（her2 吃过这个亏）。
4. 训练：`rmvpe` 提取 f0，300～400 轮，每 50 轮存一次，用测试集逐个 AB，挑最好的一档，
   并「训练特征索引」生成 `.index`。

## 第 6 步：F5 链路通了但不够自然 → 换前端

依次试，替换第 2 步，其余不变：

- **CosyVoice 2**（`FunAudioLLM/CosyVoice`）：零样本模式，中文韵律好。
- **IndexTTS2**（`index-tts/index-tts`）：零样本，可单独给情绪参考，日常用平静参考，撒娇另配一段撒娇参考。

装法照各自 README；装在 `runtime/` 下，按 `voice-training-notes.md` 的经验，
torchaudio/torchcodec 版本冲突用 soundfile 顶掉 `torchaudio.load/save`。

## 文本端：给 TTS 的句子要像说话

链路再好，读书面长句也像念稿。接进机器人时：

- 每句不超过 ~20 字，用逗号制造停顿；
- 保留「嗯」「啦」「诶」「哈」这类语气词；
- 括号里的动作描写、表情、颜文字在送 TTS 前去掉；
- 数字、时间写成要念的样子（「三点」而不是「15:00」）。

## 什么时候放弃这条路

两段式做到「音色像、吐字清」，但语调仍不像她本人的习惯时，
再用第 5 步筛出的**干净平静句（带人工核对转写）**重训 GPT-SoVITS：
s2 8～15 轮、s1 10～15 轮（不要 40 轮），推理 `temperature 0.5`、`top_k 5～10`，
用 2～3 段平静参考做多参考融合。
