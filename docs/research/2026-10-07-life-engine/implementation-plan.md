# 虚拟人生引擎：当前实施方案

- 状态：执行中
- 基线：ADR 0020–0028 已上线；ADR 0027 世界回写、ADR 0028 情绪惯性已经完成
- 目标：林梦瑶不是「收到消息才运行的聊天角色」，而是持续生活在一个可重放、可审计、有因果后果的虚拟世界中的居民

## 1. 产品判据

“像真正的人一样生活”在本项目中不表示宣称意识或感受，而表示以下五个可验证性质：

1. **连续性**：此刻能追溯到过去的状态和事件，重启不失忆、不改史。
2. **自主性**：没有用户消息时，她仍会计划、行动、遇事和改变计划。
3. **受约束性**：行动消耗时间、精力、钱和物品；不能靠一句台词改写现实。
4. **社会性**：别人有自己的日程、目标和秘密；关系会因共同经历改变。
5. **成长性**：技能、习惯、偏好、目标和自我认识会随经历缓慢变化。

最终验收问题不是「她回得像不像」，而是：**三天不和她说话，她是否仍然度过了三个不同、连续、可以解释的日子；三天后聊起时，所说与事实账一致。**

## 2. 研究结论如何落到本项目

| 一手研究 | 对本项目的直接启示 |
| --- | --- |
| [Generative Agents](https://arxiv.org/abs/2304.03442) | 观察、计划、反思缺一不可；每日计划要能被新观察打断和重排 |
| [Concordia](https://arxiv.org/abs/2312.03664) | 角色提出行动，独立的世界裁判检查可行性并结算后果；LLM 不能直接宣布事实 |
| [Voyager](https://arxiv.org/abs/2305.16291) | 自主探索需要自动课程、可复用技能、环境反馈和成功验证，而不只是更长上下文 |
| [CoALA](https://arxiv.org/abs/2309.02427) | 记忆要分层，内部动作和外部动作要有结构化空间，决策循环单独建模 |
| [FAtiMA](https://arxiv.org/abs/2103.03020) | 情绪由事件相对于目标、价值和关系的意义产生，不用随机情绪词代替机制 |
| [Homeostatic RL](https://elifesciences.org/articles/04811) | 身体和需要偏离正常范围时形成行动动机；困、饿、压力应改变选择，不只是进入台词 |
| [LIFELONG-SOTOPIA](https://arxiv.org/abs/2506.12666) | 长期互动中直接塞全部历史会降低可信度；结构化召回有帮助，困难社会场景仍需专门验证 |
| [SOTOPIA](https://arxiv.org/abs/2310.11667) | 秘密、规范、拒绝、竞争和协作要分维度测；不能只让另一个 LLM 给总分 |
| [Project Sid](https://arxiv.org/abs/2411.00114)、[AgentSociety](https://arxiv.org/abs/2502.08691) | 独立 NPC、社会认知和持续互动才能产生关系演化、分工与涌现，不靠每天随机几条小事 |
| [Generative Agent Simulations of 1,000 People](https://arxiv.org/abs/2411.10109) | 具体人生访谈和价值判断比几个人格标签更能约束个体行为；资料层应继续积累经历而非形容词 |

## 3. 总体架构

```text
世界时钟 / 事件队列
        ↓
局部观察（她知道什么，不等于世界全部事实）
        ↓
身体需要 + 目标项目 + 关系 + 价值观
        ↓
选择意图（规则处理日常，LLM 只处理有意义的岔路）
        ↓
类型化行动 → 世界裁判检查前置条件、耗时、资源和冲突
        ↓
行动结果 / 意外 / NPC 反应
        ↓
事实事件账 → 记忆、日记、关系、技能、重新计划
```

四条架构纪律：

1. **事实只有一个权威来源**：世界状态、日记、记忆和聊天描述都从事件账派生。
2. **事实、信念、传闻分开**：她可以记错、误会，世界不能跟着她一起错。
3. **低频调用 LLM**：普通推进用规则；早晨规划、重要岔路、社会互动、晚间反思才调用模型。
4. **所有状态可重放、可审计**：随机种子、行动来源和结算结果都能在模拟器中复现。

## 4. 当前基线

已经拥有：

- 作息、课表、地点、回复时机；
- 身体事实和事实落地的心情；
- 天气、猫、快递、作业、相机基金、小事和 NPC 素材；
- 她说过的喂猫、取件、写作业、家庭视频会回写全局世界；
- 日记、周记、阶段总结、长期记忆、前瞻承诺、未了事项；
- 披露分级、出口检查、主动消息和真实模型模拟器。

当前最大断层：

- 世界会按规则走，但她还没有一个通用的“观察—选择—执行—结算”循环；
- ADR 0027 只回写四类**聊天里声称已经完成**的动作，不能代表无人聊天时她主动生活；
- 长期项目没有统一目标模型，行动也没有统一的时间、资源和失败语义；
- NPC 主要是事件素材，还不是独立生活者；
- 技能、习惯、自我认识不会因为经历而演化。

## 5. 实施批次

### 批次 A：生活内核——先让她真的能行动

#### A1. 统一事件账本（已实现，ADR 0029）

新增 append-only 语义的世界事件账。首版实际数据形状：

```ts
interface LifeEvent {
  id: string;
  actor: 'linmengyao';
  kind: string;
  target?: string;
  startedAt: string;
  endedAt: string;
  source: 'simulation' | 'conversation' | 'external';
  result: 'succeeded' | 'failed' | 'interrupted';
  subject?: string;
  target?: string;
}
```

- 现有 `world/actions.json` 迁移为事件账的一类来源，不丢兼容性。
- 状态是事件重放的投影，不能反向随意改事件。
- 每条事件带来源、执行结果和可见范围。

#### A2. 类型化行动与世界裁判

第一批行动：睡觉、吃饭、上课、学习、休闲、读书、喂猫、取快递、联系家人、和 NPC 聊天。

每种行动定义：

- 前置条件；
- 持续时间；
- 时间 / 精力 / 钱 / 物品消耗；
- 成功、失败和被打断的结果；
- 对世界、目标、身体、关系的影响。

LLM 只能从当前可用行动里选择意图；世界裁判拥有最终决定权。

#### A3. 自主生活执行器

用事件驱动，不做每分钟 LLM tick：

- 起床时生成粗计划；
- 课程、截止时间、约定等确定事件进入队列；
- 到计划结束、冲突、意外或重要选择点时重新决定；
- 普通动作由规则选，重要岔路才调用模型；
- 晚间产生当天反思和未完成事项。

批次 A 的封板场景是“72 小时无用户消息”。

### 批次 B：动机与长期项目

- 连续需要：精力、饥饿、健康、压力、社交需要、独处需要、好奇 / 无聊、金钱余量；
- 长期目标：相机基金、课程项目、读书 / 摄影技能、照顾土豆、关系维护；
- 目标结构：进度、下一步、期限、资源、阻碍、延期 / 放弃条件；
- 身体与需要改变行动概率，不只改变说话方式。

先做三个能成功、失败、延期或被替换的项目，不追求数量。

### 批次 C：社会生态

- 先做少量独立 NPC，不追求大规模：家人、两位已定 NPC、室友 / 同学群体；
- 每人有自己的日程、目标、知识边界和对她的认识；
- 支持离线互动、信息传播、拒绝、迟到、忘记和改变主意；
- 慢变人物印象与短期关系温度分库存储，避免一次争执永久污染印象。

当前作者裁决继续有效：室友暂不命名；需要更多稳定 NPC 时另开资料裁决。

### 批次 D：成长、自传和技能

- 重复行动形成技能和习惯；
- 结果反馈改变下一次策略；
- 成功验证后才写入程序 / 技能记忆；
- 周 / 月反思把经历组织成自传章节，但不能改写事实账；
- 稳定人格限定变化范围，不冻结成长。

### 批次 E：结构化意外与媒介层

- 意外按“地点 × 时间 × 天气 × 身体 × 当前目标”触发；
- 每条连锁必须有明确因果，不做纯随机戏剧；
- 真实天气、番剧 / 小说更新、校园和兴趣新闻按天缓存；
- 外网失败退回已缓存或确定性世界，不破坏可重放。

### 批次 F：有限的不完全配合

先有真实动机和关系状态，再逐条放开拒绝、走神、改话题和不想聊。出口检查继续保留两条硬底线：

- 不像助手；
- 不承诺做不到的事。

每放一类都用冲突、秘密、疲惫、竞争场景证明不会退回“你倒好”“你怎么不说”式算账。

## 6. 72 小时封板验收

无人发消息，让虚拟时钟运行三天：

| 指标 | 目标 |
| --- | --- |
| 每天有后果的生活事件 | 3–8 件，不靠堆随机小事 |
| 长期目标 | 至少 1 个有真实进展 |
| 计划修订 | 至少 1 次因冲突或意外修改 |
| 社会生活 | 至少 1 次离线 NPC 互动 |
| 资源守恒 | 时间、地点、钱、物品、精力无矛盾 |
| 对话一致 | 三天后询问，回答与事件账一致 |
| 披露一致 | 不同联系人看到同一事实的不同可见投影 |
| 重启一致 | 重启后重放得到相同结果 |
| 上下文纪律 | 不把三天全部原文塞进提示词 |

同时保留人工盲评，分别打：因果、连续、自主、社会分寸、角色一致、自然度。自动 LLM 评审只作辅助。

## 7. 决策边界

- **跨天情绪**：ADR 0028 当前采用“事实跨天、情绪每轮重算”；不持久化委屈 / 生气数值。未来若要独立运行态的衰减情绪，另写 ADR，不进 Hindsight，并提供状态审计和清零能力。
- **不完全配合**：保持“先有真实来源，再逐条放开”的裁决。
- **NPC 命名**：沿用 ADR 0021，室友不命名；已定的陈佳宁、苏雨桐保持 NPC 身份。
- **真实性声明**：这是可解释的虚拟人生模拟，不宣称程序具有生物意义上的意识。
