## 结论摘要

1. **她现在动不了自己的世界。** `packages/bot/src/world.ts` 是确定性纯函数重放（`simulateWorld` 从 `startDay` 一天天推到今天，
   随机全部来自 `unit()` 的 FNV-1a 哈希）。好处是可重放、重启一致；代价是**她的行为不进入世界**——
   这正是 W3「言行一致」缺失的根因，也是项目自己文档里写的「像人的关键一跃」。
   → 解法不是加 tick，是在重放之上加一层**外部覆写**（`overrides.json`）。见 [feasibility.md](feasibility.md) 第 2 节。
2. **还剩六块**：世界回写（W3）、挂心的事生命周期（W4）、情绪惯性（S2 剩余）、关系温度（S3 剩余）、
   意外与连锁（S1 剩余）、媒介层（W5）。自我形象演化（S6 剩余）更靠后。
3. **可行性：技术高、资源中、流程是瓶颈。** 新增子系统几乎不吃内存（纯计算 + JSON），
   吃内存的是验证方式（并行模拟器，10-07 已两次 Postgres OOM）。真正的成本在真模型模拟器批次。
4. **三件事要用户先定**：情绪跨天累积（撞 ADR 0018）、不完全配合（被作者裁决搁置）、室友起名。
   见 [decisions.md](decisions.md)。
