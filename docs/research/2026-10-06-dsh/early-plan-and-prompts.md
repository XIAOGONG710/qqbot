## 0. 这份文档要解决什么

目标不是「说话像人」，而是**像一个真正意义上存在的人**。两者是不同的东西：

- **说话像人**：文风、口癖、长度、标点。这是提示词层的事，已经做得很好了。
- **像一个存在的人**：她有**自己的世界**、**会变化的状态**、**想要的东西**、**连续的记忆**。
  这三样决定的是——**当你不在的时候，她是否还在过她的人生**。

现在的问题不在文风。实测（见附录）证明，把参数调回默认值，她的句子立刻变得具体、自然、有诉求：

> 在学校啊，宿舍瘫着呢 / 刚下课回来，感觉整个人被Linux掏空了
> 想我啊？那你倒是来学校看我啊，我在宿舍闲得抠脚

**缺的不是文笔，是「存在」的结构。**

## 1. 判断标准：「像一个人存在」的四层

这四层就是验收标准，后面所有规划都往这里落。

| 层 | 含义 | 可观测的判据 |
| --- | --- | --- |
| **① 世界的持续性** | 你没说话的时候，她那边也在发生事情 | 跨天对话里她**主动**提起你没问过、而你在场时没发生过的事 |
| **② 状态的惯性** | 情绪有连续性，会被事件和你的话改变 | 她今天的情绪能被昨天/上午的某件事解释；你哄她一句，下一句就软 |
| **③ 意图与好奇** | 她想从你这里要/知道点什么 | 真问句占比；一次对话里她至少**主动转移话题**一次 |
| **④ 连续性** | 记得你、也记得自己最近在忙什么 | 提起 >24 小时前的事且**正确**；有自己的「最近挂心事」 |

**现在最缺的是 ① 和 ②**：现有机制全部是「你说话的那一刻才现算」（当前时间 → 查作息 → 抽心情 → 拼提示词）。这天然产生两件事：
- 她只能**复述状态注脚**（因为注脚就写在提示词里，且写成了可以照抄的句子）
- 她**没有「刚才」**（没有你不在时发生的事可提）

## 1.5 与 ADR 0018 的衔接（2026-10-06 晚拉取后更新）

拉取到对面当天的 18 个提交（ADR 0018 第 1–5 步 + ADR 0017 收尾）。**④ 连续性这一层他们做得比本规划细**，①②③ 仍是空白。

| 本规划的四层 | 对面（ADR 0017 / 0018） | 差在哪 |
| --- | --- | --- |
| ① 世界的持续性 | 日记、周记、阶段总结给了「她过去几天/几周在干嘛」的**回顾素材** | **「今天发生了哪些小事」仍然没有来源**——回顾有了，当天没有 |
| ② 状态的惯性 | **明确不做** | 空白 |
| ③ 意图与好奇 | **没有** | 完全空白 |
| ④ 连续性 | 变淡与再认（7/30 天）、她答应的事、周记与假期总结、名字写成「你」、herDay | 已超出本规划的设想 |

### 边界：他们明确「不做」的两件事，直接约束本规划

ADR 0018 文末确认记录写着，用户没选、这次不做：

1. **她无缘无故自己想起旧事**（召回分数分不出相关和无关）
2. **带情绪的记忆**（容易变成 ADR 0014 的「算账」）

**所以本规划必须落在边界内。这两条不冲突，但要说清区别：**

| 他们拒的 | 本规划要的 | 区别 |
| --- | --- | --- |
| 从**记忆库**里随机捞旧事来说 | 她**今天**真的发生了这件事，所以她说得出 | 前者是「想起」，后者是「发生」。**不碰记忆库**，只让当天有内容 |
| 让**记忆**带情绪（存进去、以后召回带情绪） | 她**当天**有底色，情绪**不进记忆库** | 前者是持久化情绪，后者是当天的时间块 |

**结论：本规划的 P0 / P1 全部落在「当天」这一层（时间块 + 提示词），不碰记忆库、不碰召回逻辑，因此与 ADR 0018 的决定并行不悖。** 这也正好补上他们留下的那两个空白。

## 3. 提示词工程（P0：零代码，只改提示词与数据措辞）

### 3.1 现在提示词的动态部分（模拟器实测原文）

```text
[当前时间：2026-10-05 星期一 14:00]
[距上一条消息：不到 1 分钟（上一条在今天 14:00）]
[你现在：国庆节放假，没抢到回青岛的票，留在学校，一个人待着也挺自在；修昨天拍的片子；宝宝回青岛过国庆了（放假前就跟你说好的，以后放假你们一起走），他在家玩得开心，你也替他高兴]
[你今天的心情：玩梗（今天放假，人一松下来就爱乱接梗）。今天满脑子都是梗：接话爱往好笑的地方拐，冷不丁冒出一句没头没尾的玩笑]
```

**四个结构性毛病：**

1. **只有状态，没有意图** → 她只能「报告自己」，不能「对你做点什么」。
2. **状态行写成了可以照抄的句子**（`一个人待着也挺自在`）→ 她一定照抄。
   实测：`[你现在：…一个人待着也挺自在；在图书馆赶作业；…]` → 她发出「我一个人在图书馆写作业写到想掀桌」。
3. **心情只有「表演指令」，没有「情绪底色」**（`接话爱往好笑的地方拐`）→ 产出的是**表演**，不是情绪。
4. **没有「此刻她的注意力在哪」** → 她不会主动提起任何事，只能被动接话。

### 3.2 七条原则（逐条 before / after）

#### 原则 1：状态写「约束」，不写「措辞」

**判据：任何可以在回复里原样出现的句子，都不该出现在状态区。**

| | |
| --- | --- |
| ❌ 现在 | `留在学校，一个人待着也挺自在` |
| ✅ 改成 | `在学校` |
| ❌ 现在 | `他在家玩得开心，你也替他高兴` |
| ✅ 改成 | （删掉。这是**情绪指令**——被要求的情绪，出口一定是反的） |

#### 原则 2：把「她在干嘛」升级成「这件事的进度」

进度里天然带着细节、未完成的意图和对象——**细节不用编，进度里就有。**

| | |
| --- | --- |
| ❌ 现在 | `修昨天拍的片子` |
| ✅ 改成 | `修昨天拍的片子——挑了 3 张，第 2 张在调色，本来想发给他看` |

这一条是**成本最低、收益最大**的一条：它同时喂饱了 ①（有具体的事）和 ③（有未完成的意图）。

#### 原则 3：加一层「这一轮你想要什么」

**这是七条里最重要的一条。有目的，她才像人。**

```text
[这一轮你最想要的一件事：让他问你今天拍了什么（但你不主动说）]
```

建议的意图池（每轮抽一条，可加权）：

| id | 内容 |
| --- | --- |
| `want` | 想从他要一件具体的小东西（奶茶、照片、一句夸），直接开口要 |
| `curious` | 对他上一条里的某个细节好奇，问一个**具体**问题（不要问「你在干嘛」） |
| `share` | 你手上刚发生的一件小事想讲给他，**只讲这一件** |
| `hold_back` | 你有点不高兴，但你不打算说，于是你只说别的 |
| `leave` | 你正忙着，说一句短的就想走 |
| `comfort` | 你今天不太好，想让他多陪你说两句（不解释为什么） |

有了 `curious`，「她的问号全是反问」这个问题自动消失。

#### 原则 4：心情写成「底色 + 它怎么影响你说话」，不是风格模板

| | |
| --- | --- |
| ❌ 现在 | `今天满脑子都是梗：接话爱往好笑的地方拐，冷不丁冒出一句没头没尾的玩笑` |
| ✅ 改成 | `今天有点飘（放假太久，人都松了）。说话会轻，但被问到家的事会突然安静一下` |

区别：前者要求**表演幽默**（产出的是段子），后者描述**一个真实状态如何影响表达**（产出的是人）。

#### 原则 5：给她「没说出口的东西」

真人的话里永远有潜台词。

```text
[你没打算说出口的：其实有点介意他一个人玩得挺开心（别让他看出来，也别直接抱怨）]
```

**这条有一个必须小心的地方，见 3.4。**

#### 原则 6：上下文里要「补全对方」

实测发现她看到的记录是**错位**的：她自己的话是连续的，对方的话是碎的（对方的消息只有经过机器人的那部分才在记录里）。这直接造成「自说自话」。

**提示词里应该把「对方最近几条的原话」独立成一个区**，并且保证它完整，让她能**对着你**说话。

#### 原则 7：few-shot 示例要「窄」

卡片的示例覆盖了几乎所有常见话题（食堂约饭、自拍、双排、晚安、早）。真实对话一定会撞上这些话题，撞上就复述。

**实测证据**：`pinExamples: true` 时，输入「下课一起去食堂吃饭吧」，她输出
> 今天不行，这节是Linux… / **你先去吃，吃了啥回来交作业**

而卡片的示例是
> 今天不行，下了课我还得去趟图书馆 / **你先去吃，吃了啥回来跟我说**

——几乎是逐字复述。改成默认的 `pinExamples: false` 后，同样的输入她输出的是别的内容。

**建议：示例只留「语气」，删掉「内容型」示例**（尤其是有明确触发场景的：食堂、自拍、游戏、晚安）。数量控制在 5 组以内。

### 3.3 改造后的提示词长什么样

```text
[当前时间：2026-10-06 星期二 14:24]
[上一次说话：昨天凌晨 02:14，她最后一条是 [爱你]]
[你现在：国庆放假第 6 天，在学校；他在青岛]
[你手上正在做的事：修昨天拍的片子——挑了 3 张，第 2 张在调色，本来想发给他看]
[今天的底色：有点飘，也有点闷。说话会轻，但被问到家的事会安静一下]
[这一轮你最想要：让他问你今天拍了什么（你不主动说）]
[你没打算说出口的：有点介意他一个人在青岛玩得开心]
[对方最近三条：…（原话）]
```

对照现在的版本：**多了「进度（带细节）」「底色（会怎么影响说话）」「意图」「潜台词」四个区**，少了「可直接照抄的情绪句」和「情绪指令」。

### 3.4 ⚠️ 一个必须说清楚的张力：潜台词 vs 阴阳

原则 5 和出口检查（不许算账、不许怪对方）**表面上冲突**。区分在这里：

| | 阴阳（现在的毛病） | 分寸（想要的） |
| --- | --- | --- |
| 情绪来源 | **系统塞的**（`一个人待着也挺自在`、`你也替他高兴`） | **有具体来源**（他没带我回青岛） |
| 她知不知道 | 不知道，所以只能漏出来 | **她知道**，并且**选择不说** |
| 读者的感觉 | 莫名其妙的挤兑 | 有分寸的沉默 |

**结论：不是「不让她有情绪」，而是「情绪必须有来源、而且她要有说与不说的选择权」。**
「不让她算账」是对的（嘴上），「不让她有账」是错的（心里）。

## 4. 让世界在她那边继续（P1）

### 4.1 她的一天（day timeline）

**现在**：你说话的那一刻，现算她在干嘛。
**改后**：她这一天**提前生成好一条行程**，聊天只是「从行程里取出当前这一段」。

```jsonc
// runtime/<dataDir>/days/2026-10-07.json
{
  "date": "2026-10-07",
  "weather": { "text": "阴，17-23 度", "source": "api" },
  "spine": [                                    // 骨架：按作息，确定
    { "at": "07:40", "doing": "起床，磨蹭" },
    { "at": "08:20", "doing": "上Linux（机房课）", "place": "知行楼612" }
  ],
  "beats": [                                    // 肉：3-5 件具体小事
    { "at": "09:15", "what": "机房的键盘有个键帽掉了，她在那敲半天" },
    { "at": "12:10", "what": "食堂二楼新出了一个窗口，排队排到门口" },
    { "at": "15:30", "what": "回宿舍路上看到一个学长在发社团传单" }
  ],
  "open_threads": [                             // 欠着的账（第二天会自然接上）
    { "what": "论文开题还没动", "since": "10-05" },
    { "what": "快递还没取", "since": "10-06" }
  ]
}
```

**关键点：`beats` 里的事在你不在的时候发生了** → 她可以主动提起、可以说「刚才」「上午那会儿」。这就是「世界的持续性」。

### 4.2 事件从哪来（四条路，不必手写池子）

现在 `scenes.yml` 是人工池（`source: 线上原话 + 自拟`），**这是最贵的一条路**。四条替代：

| 路线 | 做法 | 人工 | 真实感 | 自洽 | 备注 |
| --- | --- | --- | --- | --- | --- |
| **A 外部真实数据** | 天气 API（济南）、微博/知乎热搜、番剧更新表、节气/节日/调休、校园通知 | 0 | **最高** | 中 | 世界本身就是随机的 |
| **B 每天生成一次** | 早上或当天首次开口前调一次：按作息/地点/季节生成 4 件小事，附「最近 7 天已用过」去重 | 0 | 高 | 低 | ≈0.001 元/天 |
| **C 维度叉乘** | 只写维度：`地点 × 人物 × 物 × 遭遇`。`20×20×20×20 = 16 万种` | 小 | 中高 | 中 | 手写 = 4 个列表 |
| **D 环境状态机** | 给几件**会自己推进**的东西：土豆（该喂了）、快递（明天到）、奶茶券（3 天过期）、作业（deadline） | 小 | 高 | **最高** | 唯一能结构性解决「说的和正在做的不一致」 |
| **E 已有素材具体化** | 书单/番/游戏/摄影/宠物 → 「今天看到那一段」 | **0** | 中 | 高 | **今天就能做** |

**推荐组合：D + E + A。** 状态机给**自洽的骨架**，已有素材给**具体的肉**，外部数据给**每天的随机性**。B 只当兜底。

**E 的例子**（零新机制）：书单里是 `药屋少女的呢喃 第 7 卷`，让她主动讲一句
> 刚看到翡翠宫那段，那杯毒酒我是真服了

现在她的书单只用来「被问时报进度」，**没用来主动讲**——这是最便宜的一块肉。

## 5. 状态惯性（P2）

**现在**：心情一天抽一次，全天不变，不影响内容。
**改后**：情绪是一个**连续值 + 衰减**，会被两件事改变：

| 输入 | 效果 |
| --- | --- |
| 早上的 `beats`（好事/坏事） | 设定当天底色 |
| 你的话（哄 / 敷衍 / 冷淡） | 接下来 2–3 轮偏移 |
| 时间（深夜、饿了、上完课） | 基线漂移 |

心理上的要点：**真人的情绪有惯性、会被打断、会恢复。** 不是均匀撒在一天里的。

## 6. 主动性（P3）

`proactive` 现在关着，而这是**「存在感」最强的一层**——她会**先开口**。

建议开启顺序：试运行（记日志不发）→ 只开「冷场」一种时机 → 再放开「想他了 / 看到有意思的东西 / 有事要说」。
判据：**她先开口的比例 ≥ 20%**。

## 7. 可测的验收指标

沿用他们现有的 `npm run sim`（场景文件 + 检查项），加一组「像一个人存在」的检查：

| 维度 | 指标 | 目标 |
| --- | --- | --- |
| 世界持续 ① | 跨天对话里主动提起「你不在时发生的事」 | ≥ 1 次/天 |
| 状态惯性 ② | 情绪变化能被上文解释 | 人工判 |
| 意图 ③ | 每轮回复服务于一个明确目的 | 人工判 |
| 好奇 ③ | **真问句占比**（排除反问） | ≥ 1/3 |

## 附录：本次实测证据（附配置污染说明）

**方法**：用仓库自带的模拟器 `npm run sim`（`packages/bot/sim/schedule-boyfriend.json`，10-05 国庆、他回青岛），各跑 3 次。

**⚠️ 配置污染说明（重要）**：第一轮跑用的是 DSH 侧影子配置，`temperature 1.3`、`pinExamples: true`、`promptPostProcessing: semi`、`maxContext 16384`——**都不是默认值**。第二轮改回默认值（`temperature 1`、`pinExamples false`、`maxContext 8192`）。两组**同一场景**对比：

| 影子配置（非默认） | **默认值** |
| --- | --- |
| 修图呢，昨天拍的那堆，一上午就没翻出两张能留的 | **修图呢** |
| 你那头在家舒坦吧，顿顿有饭吃，**我在这边啃食堂剩菜** | 昨天拍了几张，光线贼好，不修可惜了 |
| 今天不行，**你先去吃，吃了啥回来交作业**（抄示例） | 这课的老师特别敬业，敬业到我不好意思当着他面打瞌睡 |
| 光说一遍不够我的**算力** | **想我啊？那你倒是来学校看我啊，我在宿舍闲得抠脚** |
| 我就要动用 **cmd** 扣你了 | 对着黑框框敲命令，敲到怀疑人生 |
| **你猜** | **在学校啊，宿舍瘫着呢** |

默认配置那一轮的关键词计数：`我先去吃 0 · 吃了啥回来 0 · 算力 0 · cmd 0 · 你猜 0 · 你倒好 0 · 啃食堂 0 · 带我份儿 0`。

**结论：**
1. 「抄示例」「AI 腔（算力/cmd）」「你猜」**全部由非默认参数造成**，不是项目的问题。**默认值就是更好的基线。**
2. 线上那句「我一个人在图书馆写作业写到想掀桌」同样出自非默认配置，**不能算作项目的问题**；但它暴露的机制（**状态行里可以照抄的情绪句**）**是真实的结构问题**，见原则 1。
3. 仍存在的真实问题两条：状态区的 `一个人待着也挺自在`（她会复述）；`在家当小少爷当得挺舒服吧` 这类**轻对照**（出口检查抓句式不抓意思）。
4. `schedule-boyfriend.json` 的 S01 检查项写的是「国庆节放假，**没回青岛**，留在学校」，而数据是「没抢到回青岛的票，留在学校，一个人待着也挺自在」——**场景期望没跟着数据改**，3 次全挂这一项。跟配置无关。
