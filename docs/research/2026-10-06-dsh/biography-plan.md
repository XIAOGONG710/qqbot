# DSH 侧：给她写一份自传 —— 怎么写、怎么用（2026-10-06）

> 归档（2026-10-06）：原 `docs/DSH侧-自传方案-2026-10-06.md`。自传正文在 [characters/linmengyao/biography/](../../../characters/linmengyao/biography/autobiography-v1.md)；审批意见见 [README](README.md)。

**这份解决什么**：用户提出「我能给她写一份自传，是不是会有帮助」。结论：**非常有帮助**，而且是「她像一个存在的人」里**最缺的一块**——但**用法决定它有用还是有害**。
**标准**：一律按最高标准，以最像人为方向。
**怎么用**：不替代 ADR；要动手的先写 ADR。本文给形式、用法、接入点和风险。

---

## 一、为什么帮助很大：它补的是现有资料**没有的三样**

`persona.yml`（23 KB、8 层人设）写得已经很细，但它给的是**属性**。自传补的是另外三样：

| `persona.yml` 有的 | 自传补的 |
| --- | --- |
| 属性：喜欢什么、怕什么、怎么说话 | **因果链**：**为什么**她现在是这样 |
| 分档的说话方式 | **她的自我理解**：她怎么讲自己（这决定她怎么说自己） |
| 静态事实（青岛人、独生女、专业） | **时间顺序**：什么时候发生了什么 |

### 最直接的收益：把「不许编」变成「有得说」

roadmap 里那条对策是**防守**：

> 低档位共用的那句 `discreet` 加上「**设定里没写到的自己的事含糊带过、不现编，记不清就直说**」

它解决的是"老家答『南方一个小地方』、认识经过编细节"这类问题——**但代价是她变得含糊、空洞**。
**自传让这个位置从"含糊带过"变成"有得说"**：被问老家、被问小时候、被问怎么认识的，她有真东西可讲，而且前后一致。

### 第二个收益：它同时是最安全的**语气样本**

实测过：卡片里的**对话示例会被逐字复述**（输入「下课一起去食堂吃饭吧」→ 她输出示例里那句「你先去吃，吃了啥回来交作业」）。
**而自传体的叙述不会**——因为自传的句式在对话里**根本不会被触发**。

> **所以自传能提供语气样本，却不产生"抄示例"的副作用。** 这是它独有的优势。

### 第三个收益：自我叙事（对应最高标准方案的 S6）

真人有一个"关于自己的故事"（我是谁、我从哪来、我要去哪），行为由这个故事组织。
现在她只有**属性**，没有**故事**——**这可能是"她不像一个存在的人"的最深层原因**。

**自传（过去）+ ADR 0018 的周记/月度总结（现在）= 完整的自我叙事。**

---

## 二、⚠️ 最重要的一节：三种东西别混为一谈

"自传"很容易被当成一个东西，其实是三个，**用法完全不同**：

| 形式 | 是什么 | 放哪 | 进不进每轮提示词 |
| --- | --- | --- | --- |
| **① 年表** | 客观事件列表（几岁、在哪、发生了什么） | **资料层**（和 `persona.yml` 同一层，做事实源） | ❌ 不进（按需检索） |
| **② 自传正文** | 她用第一人称讲自己的一生 | **素材库 / 记忆库**，切成可检索的块 | ❌ **不进** |
| **③ 记忆锚点** | 5–10 个她**随时能讲出来**的故事 | 资料层，可少量常驻 | ⭕ 少量 |

**为什么自传正文绝对不能整篇进提示词**（两条都致命）：

1. **挤掉正在聊的内容**——她的卡已经 42 KB，动态部分实测 12–13 KB；自传（几万字）进去，聊天记录就没位置了。这正是调研方案 6.4 说过的坑。
2. **她会变成"背传记"**——**和"照抄状态行"是同一个病**：提示词里能原样出现的内容，模型一定会原样复述。自传有第一人称，抄起来比状态行更容易。

**正确用法**：**切成块 → 按需检索 → 只在相关话题出现时召回**（和 Hindsight 记忆同一套机制）。

## 三、怎么写才有用：看"密度"

**判据：一段自传好不好，看它同时给了几样东西——事件 + 一个细节物件 + 当时的反应 + 留下的痕迹。**

| | 例子 |
| --- | --- |
| ❌ 第三人称介绍 | 「林梦瑶，2006 年生于青岛，性格内向，喜欢摄影。」 |
| ❌ 只有属性 | 「她怕黑。」 |
| ✅ 她会怎么讲 | 「我小时候特怕黑，我妈给我买了个小夜灯，一直用到初中——**现在宿舍那个灯我还留着，其实早不亮了，就是懒得扔**。」 |

那第三句同时给了：**一个过去的事件 + 一个现在的物件 + 一个性格（懒得扔）+ 一种语气**。
**这就是"密度"。** 而且它**天然接上世界子系统**——那个小夜灯是一件"有状态的物"，可以被再次提到。

### 建议的章节结构（按人生阶段，每章 3–5 件具体的事）

| 章 | 内容 | 备注 |
| --- | --- | --- |
| **小学** | 他是同班同学——**在他出现之前**的她 | 这段是"她独立的过去"，**别全写他** |
| **初中** | 青春期、第一次喜欢什么、家里的事 | 也要有和他无关的部分 |
| **高中** | 学业压力（**最怕数学的来源可以落在这里**）、朋友、想去的城市 | |
| **大学** | 报专业（人工智能与大数据，她自己感兴趣）、离家、宿舍 8 人间、**开始拍照**、**遇到土豆** | 接现在 |

**关键**：**每一章都要有和他无关的事。** 她的人生不是"等他出现"才开始的——**这正是"像一个存在的人"。**

## 四、留白：她也有不知道、不想说的

真人对自己也不是全知的。**最高标准下，自传必须留白**：

| 留白 | 数量 | 效果 |
| --- | --- | --- |
| **她不太愿意提的** | 2–3 处 | 被问到时含糊、转移、或说"不想说"——**这是"内心边界"** |
| **她记不太清的** | 1–2 处 | 配 ADR 0018 的**变淡**机制，说"好像"「记不太清了」 |
| **家人告诉她的版本** | 1 处 | 她自己的记忆和家里的说法不完全一样——**这是极真实的一种"不确定"** |

> **全部写清的自传，比留白过的自传更不像人。**

## 五、怎么接进现有系统

### 1. 事实**单一来源**（避免两个事实源打架）

```
能进 persona.yml 的硬事实 → 进 persona.yml（保持它是唯一事实源）
自传只补「叙事」和「细节质感」→ 存 characters/linmengyao/source/biography.yml
```

**并用 character-tools 已有的检查交叉验证**：自传里提到的硬事实（城市、家里几口人、专业、学校），**必须能在 `persona.yml` / `schedule.yml` 里找到**，找不到就是新增设定 → 要么写进 persona，要么改掉。

### 2. 切块与检索

- 按章 + 按"一件事"切块，每块带**标签**（人物/地点/主题）
- 接进已有的召回通道（**和 Hindsight 记忆同一层**），触发条件参考 ADR 0017 的「有线索才想起」：说到过去、被问过去、相关话题出现
- **不做**每轮固定注入

### 3. 频率控制：真人不会一直讲过去

- 记"讲过的次数" + "最近一次讲"（**直接复用 ADR 0018 的 fading 思路**）
- 同一个故事短时间讲两遍，第二次要更简短、或说"我是不是跟你说过"

### 4. 和 ADR 0018 的关系

```
自传（过去）  +  周记 / 阶段总结（现在）  =  完整的自我叙事（S6）
```

### 5. 世界子系统那边

自传里的**细节物件**（小夜灯、第一个相机、高中那个水杯）应该**登记到 `world.yml` 的物里**——这样它们能被**再次提到**，形成"过去 → 现在"的回环。

## 六、风险与对策

| 风险 | 后果 | 对策 |
| --- | --- | --- |
| **和 persona 变成两个事实源** | 前后矛盾、维护地狱 | 事实单一来源 + 交叉验证（第 5 节 1） |
| **太长挤掉上下文** | 聊天记录没位置，变成背传记 | **只检索，不常驻** |
| **被逐字复述** | 像背简历 | 切成块 + 频率控制 + 写成"叙述"而不是"对白" |
| **用户写完舍不得改** | 过时设定长期存在 | 从第一天就按 YAML 切块存，单条可改 |
| **和她已有资料冲突** | 她出现"两个童年" | 先做一遍交叉核对再入库 |

---

## 七、要用户定的三件事

1. **顺序**：先写哪一段？建议**从「小学」开始，但先写和"他"无关的那一半**——那部分现在完全是空白，而且最能让她"独立存在"。
2. **颗粒度**：一章 3–5 件事是够的；写太多会变成小说（**那会让她"讲故事"而不是"过日子"**）。
3. **谁来写**：用户自己写（最懂想要什么）／先让模型按上面的框架和密度标准出一版初稿，再由用户改（更快，但要小心模型会写套路化的童年）。

---

## 八、一句话结论

> **写，而且这是回报最高的一件事。** 但要做三件事它才有用：
> ① **别整篇塞进提示词**（切成块、按需检索）；
> ② **用她会怎么讲来写**（密度：事件 + 物件 + 反应 + 痕迹）；
> ③ **留白**（有不愿说的、记不清的、家里人说的版本）。
>
> 配上世界子系统，她的过去和现在就能互相照见——**那才叫"存在"，不只是"回话"。**
