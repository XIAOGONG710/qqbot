## 一、问题清单（用户提出，9 条）

### 1. 状态行里写着可以照抄的句子

- **现象**：线上她发出「我一个人在图书馆写作业写到想掀桌」。
- **根因**：这句是状态行三块拼出来的——`schedule.yml` 假期的 `where` 写着「留在学校，**一个人待着**也挺自在」+ 下午空闲活动「在图书馆**赶作业**」+ 当天心情「搞怪」。`schedule.ts:222` 把 `[你现在：…]` 直接放进提示词，**句子写成什么样，她就会照抄**。
- **改法**：状态行只写**约束**，不写**措辞**。「一个人待着也挺自在」→「留在学校」。
  判据：**任何可以在回复里原样出现的句子，都不该出现在状态区。**

### 2. 情绪指令（「你也替他高兴」）

- 同一个 `where` 块，`partner` 写着「他在家玩得开心，**你也替他高兴**」。
- **被要求出来的情绪，出口一定是反的**——她要么明着抱怨（「你倒好，在家吃香的喝辣的」），要么暗着扎（「我一个人在图书馆…」）。删掉这句。

### 3. 出口检查抓句式，不抓意思

模拟器实测（`schedule-boyfriend`，3 次）：

| 同一件事的写法 | 出口检查 |
| --- | --- |
| 你倒好，一个人回家吃独食 | ✅ 拦住并重写 |
| 我在这边**啃食堂剩菜** | ❌ **漏过** |
| 出门玩都**没带我份儿**吧 | ❌ **漏过** |
| 我一个人在图书馆写作业写到想掀桌（线上） | ❌ **漏过** |

- **改法**：加一条「**对照结构**」判据（`我在这边…你在那边…`、`你有…我没有…`、`我只有X，你倒Y`）。把这 4 句当回归用例进 `speech-check.test.ts`。

### 4. 她的问号全是反问，没有一个真问题

- 最近 10 条里**真问句只有 1 个**（「那你伞拿没拿啊」），其余问号全是反问（「不睡觉是吧」「科班的怎么了」「这不是我们老家小少爷吗」）。
- **她从不问**：你在老家好不好玩、几点的票、吃了没、累不累。
- **根因**：提示词里有心情、有书单、有作息，**唯独没有「这一轮她想要什么」** → 她只能报告自己，不能对你做点什么。

### 5. 生活素材池太小，而且跨人复用

- 道具只有：作业 / 被窝 / 看番 / 游戏（三螳螂）/ 土豆。**对男朋友和同学用同一批**（10-05 19:03 对鸽鸽「赶作业呢」，10-06 14:28 对你「作业还一个字没写完」）。
- **改法**（四条路，见第二节 P1）：外部真实数据 / 每天生成一次 / 维度叉乘 / **环境状态机** / **已有素材具体化**。

### 6. 分档位披露没做

- **已做**：① 所有人的聊天进公共库（`<前缀>-common`，陌生人档除外）；② 个人聊天时有线索才调用（`long-term.ts:486`，去掉这个人自己的片段）。
- **没做**：③ **分档位决定是否透露**。ADR 0016 明确写了「不按档位收紧（用户定）」，后果一节也承认「男朋友档聊天里的事，同学档那边也可能想起来」，保密只剩卡上说明 + 禁用词兜底。
- **关键区分**：ADR 0016 拒掉的是**收紧召回**（想不想得起来）；现在要的是**披露分级**（想起来了，说不说）。**两件事不冲突，可以叠加。**
- **好消息**：不用动记忆层。公共库每条已带来源（`document_id` 带是谁的、`context` 写「林梦瑶和鸽鸽」），**只需在进提示词前给每条标一句「这条是谁的」，再加一段披露规则**。
- **建议三档策略**：明说 / **含糊**（「好像听谁提过」「记不太清了」）/ 不说。
  **「含糊」这一档最重要**——现在是「收紧召回 = 真想不起来」，遇到相关话题只能愣住或瞎编；而「知道但含糊」是真人每天都在做的事。
  **并且不要用删行实现它**：删掉一句会让剩下的话断因果（实测：删掉「想起我啦」后，剩下两句变成莫名卖惨）。

### 7. 名单外的人跟她说话没有回应

- **是刻意的**：`unlistedFriends` 关着。roadmap 里写着「测完先关，**要常开再加频率限制**」。
- **开启的前置条件 = 成本闸**：每个号每天的调用上限、全局预算（ADR 0003 后果一节）。
- 另外提醒：`unlisted` 档**没有长期记忆、不抽承诺**（`contact.ts:131`），这是设计，但用户要知道对陌生人她「不记得上次聊过什么」。
- **加一个人不需要写新卡**：档位卡 7 张已存在，个人差异用 `contacts[].persona`（一行数据）。**只有需要一整套不同说话方式时才新增档位**（那要改 `CONTACT_TIERS` + `tiers.yml` + 重新生成全部 8 张卡）。

### 8. 热聊时回复太快，来不及连发两条

- **现象**：用户发完第一条想发第二条时，她已经回了，只能把两条写成一大段。
- **实测链路**（你发完第一条到她第一条气泡）：连发合并 `quietMs=2000`（`responder.ts:23`）+ 正聊着「看到」延迟 **0**（`reply-timing.ts:109` 的 `at: first`）+ 生成 1–3 秒 + 打字 1–2.4 秒 = **约 4–9 秒**。
- **根因**：发第二条只有 `quietMs` 那 2 秒窗口，**2 秒打不完一句话**。
- **建议改法**：

```ts
// A（对症，首选）responder.ts:23
export const DEFAULT_SETTLE = { quietMs: 4000, maxMs: 12000 };   // 现在 2000 / 6000

// B（配合，顺便更像人）reply-timing.ts:109 —— 只加在「正聊着」这条分支
if (lastReply && first - Date.parse(lastReply.time) <= HOT_MS) {
    return { at: first + pick(seed, 'react', [1500, 5000]), reason: '正聊着' };
}

// C（可选，长回复才像人）reply-timing.ts:125
const base = Math.min(8000, Math.max(1200, 900 + 120 * [...text].length));   // 现在上限 4000
```

- A+B 之后：她第一条气泡约在你发完后 **8–14 秒**（真人 5–15 秒，对得上），热聊里完全不会觉得慢。
- **注意**：这是对 ADR 0013「气泡之间的额外停顿不加（用户：热聊要快）」的一次修正——不是要慢，是**热聊时也要给他把话说完的时间**。
- **另外**：`PART_GAP_MS = 1000` 在开回复时机时**不生效**（`responder.ts:280` 是 `timing ? typingMs(part) : PART_GAP_MS`），气泡间隔由 `typingMs` 决定。

### 9. 她主动说起别人的事（隐私取舍）—— 用户定：**会**

但要给四条边界，否则会撞 ADR 0003 的档位保密、ADR 0017 的「她眼中的 X」、ADR 0018 的「她答应的事」。

| 信息 | 例子 | 主动提起 |
| --- | --- | --- |
| **她自己的经历** | 「今天鸽鸽跟我说他组长又找他茬了」 | ✅ 可以（这是她的一天的一部分） |
| 第三方的大面事 | 「鸽鸽下周要考试」 | ⚠️ 有由头时可以 |
| 第三方的私事 | 「鸽鸽跟我说他跟他爸吵架了」 | ❌ 不主动 |
| 她答应过别人的事 | 「我答应给他讲那个结局」 | ❌ 不主动（ADR 0018 的 promises 已管） |
| **她对某个人的看法** | 「我觉得鸽鸽这人有点轴」 | ❌ **永远不主动** |

> ⚠️ **最后一条必须单独写死**：ADR 0017 给每个人建了「她眼中的 X」，里面是**她对那个人的真实评价（可能是负面的）**。不管住这条，她会把背后议论说出来。**真人不会跟 A 说"我对 B 的看法"。**
> 并且**主动提起要叠加档位过滤**：跟同学档不能主动提「我有男朋友」。

**提示词片段（可直接用）：**

```text
[你可以主动提起别人的事，规矩是：]
可以说你自己跟谁聊过、聊了什么大面上的事——那属于你自己的一天。
别人自己的私事（他跟你说的事、他的难处）不要主动说。
你对某个人有什么看法不要说出口，那是你自己的念头。
和某个人之间的事，只跟那个人说。
```

## 二、未来规划：让她**像一个人存在**

目标不是「说话像人」（那是文风，已经做得很好了），而是**像一个真正存在的人**。判断标准四层，所有改动都往这里落：

| 层 | 含义 | 判据 | 现状 |
| --- | --- | --- | --- |
| **① 世界的持续性** | 你没说话时她那边也在发生事 | 她**主动**提起你没问过、你在场时没发生过的事 | 日记/周记给了**回顾**素材，**当天仍无来源** |
| **② 状态的惯性** | 情绪连续，会被事件和你的话改变 | 今天的情绪能被上午的事解释；你哄一句下一句就软 | **空白** |
| **③ 意图与好奇** | 她想从你这里要/知道点什么 | 真问句占比；至少主动转移话题一次 | **空白** |
| **④ 连续性** | 记得你，也有自己的「最近在忙什么」 | 提起 >24h 前的事且正确 | ADR 0017/0018 已做得比本规划细 |

> **注意边界**：ADR 0018 明确「不做」两件——**她无缘无故自己想起旧事**、**带情绪的记忆**。本规划**不冲突**，因为区别在于：
> - 他们拒的是「从**记忆库**随机捞旧事」；本规划要的是「她**今天**真的发生了这件事」（**不碰记忆库**）。
> - 他们拒的是「让**记忆**带情绪」；本规划要的是「她**当天**有底色」（情绪**不进记忆库**）。
>
> **所以 P0/P1 全部落在「当天」这一层（时间块 + 提示词），不碰记忆库和召回逻辑。**

### P0（零代码，只改提示词与 YAML 措辞）

七条原则：

1. **状态写「约束」不写「措辞」**（见问题 1）
2. **「她在干嘛」升级成「这件事的进度」**——`修昨天拍的片子` → `修昨天拍的片子——挑了 3 张，第 2 张在调色，本来想发给他看`。细节不用编，进度里就有。
3. **加一层「这一轮你想要什么」**（最重要）——
   `[这一轮你最想要：让他问你今天拍了什么（你不主动说）]`
   意图池：`want 要东西 / curious 好奇 / share 分享 / hold_back 憋着 / leave 想走 / comfort 要陪`。**有 `curious`，「问号全是反问」自动消失。**
4. **心情写「底色 + 它怎么影响你说话」，不写风格模板**——
   ❌`满脑子都是梗，接话爱往好笑处拐`（要求表演幽默，产出段子）
   ✅`今天有点飘（放假太久人都松了）。说话会轻，但被问到家的事会突然安静一下`
5. **给她「没说出口的东西」**——`[你没打算说出口的：其实有点介意他一个人在老家玩得开心]`
   ⚠️ 与出口检查不冲突，区别在：**阴阳**是系统塞的情绪（`一个人待着也挺自在`）、她不知道所以漏出来；**分寸**是有来源的情绪、她知道并**选择不说**。
   **原则：不是「不让她有情绪」，而是「情绪必须有来源、且她要有说与不说的选择权」。不让她算账是对的（嘴上）；不让她有账是错的（心里）。**
6. **上下文要「补全对方」**——实测她看到的记录是错位的（她的话连续、对方的话碎），要把「对方最近几条原话」独立成一个完整的区。
7. **few-shot 示例要「窄」**——实测 `pinExamples: true` 时，输入「下课一起去食堂吃饭吧」，她输出「你先去吃，吃了啥回来交作业」，而卡片示例就是「你先去吃，吃了啥回来跟我说」——**逐字复述**。建议只留语气，**删掉有明确触发场景的内容型示例**（食堂/自拍/双排/晚安），控制在 5 组内。

### P1：她的一天（让世界在她那边继续）

**现在**：你说话的那一刻现算她在干嘛。**改后**：这一天**提前生成好一条行程**，聊天只是取出当前这一段。

```jsonc
// runtime/<dataDir>/days/2026-10-07.json
"spine": [ { "at": "08:20", "doing": "上Linux", "place": "知行楼612" } ],     // 骨架：按作息
"beats": [ { "at": "12:10", "what": "食堂二楼新窗口，排队排到门口" } ],        // 肉：3–5 件具体小事
"open_threads": [ { "what": "论文开题还没动", "since": "10-05" } ]            // 欠着的账
```

**`beats` 在你不在的时候发生了** → 她能主动提起、能说「刚才」。这就是 ①。

**事件来源（不必手写池子；`scenes.yml` 那条路最贵）：**

| 路线 | 做法 | 人工 | 真实感 | 自洽 |
| --- | --- | --- | --- | --- |
| **A 外部真实数据** | 学校那边天气 API、热搜、番剧更新表、节气/调休、校园通知 | 0 | **最高** | 中 |
| B 每天生成一次 | 按作息/季节生成 4 件小事 + 「最近 7 天已用过」去重 | 0 | 高 | 低 |
| C 维度叉乘 | `地点 × 人物 × 物 × 遭遇`，4 个列表 = 16 万种 | 小 | 中高 | 中 |
| **D 环境状态机** | 土豆该喂了 / 快递明天到 / 奶茶券 3 天过期 / 作业 deadline | 小 | 高 | **最高** |
| **E 已有素材具体化** | 书单/番/游戏/摄影/宠物 → 「今天看到那一段」 | **0** | 中 | 高 |

**推荐 D + E + A**：状态机给**自洽的骨架**，已有素材给**具体的肉**，外部数据给**每天的随机性**。
D 还是唯一能结构性解决「她说的和正在做的不一致」的路（模拟器里抓到过：状态说「修片子」，她说「躺着赶作业」）。
E 的例子（零新机制）：书单里是 `药屋少女的呢喃 第 7 卷` → 她主动说「刚看到翡翠宫那段，那杯毒酒我是真服了」。**现在书单只用来"被问时报进度"，没用来"主动讲"。**

### P2：状态的惯性

情绪从「一天抽一次、全天不变」改成**连续值 + 衰减**：早上的 `beats` 设当天底色；你的话（哄/敷衍/冷淡）让接下来 2–3 轮偏移；深夜、饿了、上完课让基线漂移。
要点：**真人的情绪有惯性、会被打断、会恢复**，不是均匀撒在一天里的。

### P3：主动性

`proactive` 现在**开着**（用户 10-05 15:59 打开），但第一条真发的主动消息还没出现过（roadmap 待核对）。
下一步顺序：试运行 → 只开「冷场」→ 再放开「想他了 / 看到有意思的东西 / 有事要说」。判据：**她先开口的比例 ≥ 20%**。

## 附：顺手发现（非用户提出）

### A. `schedule-boyfriend.json` 的场景期望过期了

```json
// packages/bot/sim/schedule-boyfriend.json（S01）
"timeBlock": "你现在：国庆节放假，没回老家，留在学校；.+；宝宝回老家了"
```

数据侧现在（`schedule.yml:28`）是「没抢到回老家的票，留在学校，一个人待着也挺自在」。
**3 次跑全部挂在这一项**（21 通过 / 1 不通过），与配置无关。ADR 0018 第 6 步跑之前先修掉，否则报告里会一直带一个假失败。

### B. ⚠️ 配置污染提醒：别用 DSH 侧那份影子配置当基线

DSH 侧实测时用过一份非默认配置（`temperature 1.3`、`pinExamples: true`、`promptPostProcessing: semi`、`maxContext 16384`）。同场景对照：

| 影子配置（非默认） | **默认值** |
| --- | --- |
| 你今天拍的那堆，一上午就没翻出两张能留的 | **修图呢** |
| 你那头在家舒坦吧，我在这边**啃食堂剩菜** | 昨天拍了几张，光线贼好，不修可惜了 |
| 今天不行，**你先去吃，吃了啥回来交作业**（抄示例） | 这课的老师特别敬业，敬业到我不好意思当着他面打瞌睡 |
| 光说一遍不够我的**算力** | **想我啊？那你倒是来学校看我啊，我在宿舍闲得抠脚** |
