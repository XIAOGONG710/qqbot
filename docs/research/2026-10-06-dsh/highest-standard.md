# DSH 侧：最高标准 —— 让她像一个真正的人存在（2026-10-06）

> 归档（2026-10-06）：原 `docs/DSH侧-最高标准-让她像一个人存在-2026-10-06.md`。审批意见见 [README](README.md)。

**这份是什么**：用户下的标准——**所有「让她像人」的项目，一律按最高标准、以最像人的方向做，难度不作为取舍依据**。
**和上一份的关系**：本文**取代** [`issues-and-plan.md`](issues-and-plan.md) 的第二节（规划部分）；那份的**问题清单（9 条）和顺手发现仍然有效**。
**怎么用**：不替代 ADR。要动手的，按你们的流程先写 ADR；本文只提供范式、子系统和判据。

## 一、先把标准说清：什么叫「最像人」

三条判据，缺一条都不算：

| 判据 | 含义 | 反面（现在） |
| --- | --- | --- |
| **连续性** | 她此刻的状态，能追溯到之前的状态——有因果、有惯性 | 心情一天抽一次，全天不变；你不在时她没有人生 |
| **自主性** | 她的行为有一部分**不由你触发**：她自己发起、她自己决定说不说 | 一切由你的输入驱动 |
| **不可完全预测** | 同样的话，不同状态下有不同反应；而且她**不完全配合**（会拒绝、会走神、会答非所问） | 系统在"尽量正确地回应" |

**结论：现在最不像人的地方，不是某个功能不够好，而是整个系统是一条「输入 → 输出」的映射。**
真人是「内部状态 → 表达」，你的话只是改变内部状态的**众多因素之一**。

## 二、范式转向：从「应答器」到「一直在跑的内核」

### 现在（响应式）

```
收到消息 → 算当前时间 → 查作息 → 抽当天心情 → 拼「你现在：…」 → 生成 → 出口检查 → 发
```

**她只在被说话的那一刻存在。** 这就是「她一样都没有（不可预测的小事）」和「状态行被她照抄」的同一个根。

### 最高标准（模拟式）

```
┌──────────────────────────────────────────────────────────┐
│  内核：一直在跑，与你无关                                  │
│                                                           │
│  ① 时间线   她的一天：骨架 + 事件 + 进度 + 意外 + 记忆性     │
│  ② 身体     精力 / 困 / 饿 / 累 / 生理期 / 头疼             │
│  ③ 情绪     多维 + 惯性 + 衰减 + 累积 + 被事件改变           │
│  ④ 目标栈   长期 → 今天 → 此刻（含冲突）                    │
│  ⑤ 世界     物（土豆、快递、相机…）+ 人（室友、家人、鸽鸽）   │
│  ⑥ 关系     对每个人：想他 / 生气 / 刚被哄好 / 欠答复        │
│  ⑦ 未完的事 答应过的 / 要做的 / 想知道结果的                 │
└──────────────────────────────────────────────────────────┘
        ↑ tick（每 5 分钟 + 事件驱动）
        │
你发消息 ─→ 取出「此刻的她」─→ 生成 ─→ 输出层 ─→ 发出
        │                              （披露分级 + 表达层）
        └─→ 你的话反过来改变内核（情绪、关系、目标）
```

**这一条是整份文档的核心。** 后面七个子系统都是这个内核的零件。

## 三、七个子系统的最高标准

### ① 时间线：她的一天

**现状**：作息查表，输出一行「你现在：…」。
**最高标准**：

- 每天**提前生成一条时间线**：骨架（作息）+ 肉（3–5 件具体小事）+ **意外（1–2 件计划外的事）**
- 事件**分源**（见第四节），不是每天编一个新故事
- 时间线**可被打断**：你的消息、她自己的情绪、突发情况都会改掉后面的行程
- **有记忆性**：今天踩的坑会影响今天剩下的时间（雨没带伞 → 鞋湿了 → 下午有点烦 → 晚上不想出门）

**判据**：她能说出「你确定没问过、而你在场时没发生过」的事。

### ② 身体状态（现在完全没有，最高标准必须有）

精力（睡眠质量 → 全天曲线）、困、饿、累、生理期（周期 + 会改变情绪基线）、小病（感冒/头疼/肚子疼）。

**为什么这是最高标准**：**身体是人味最直接的来源。**「今天头有点疼」比「今天心情不错」真实十倍。

**判据**：她说的身体状态能解释她的语气，且前后一致——说头疼就不会同时疯玩。

### ③ 情绪系统

**现状**：一天抽一次，全天不变，不影响内容。
**最高标准：多维 + 连续 + 惯性 + 累积。**

| 维度 | 说明 |
| --- | --- |
| 愉悦度 | 基本心情 |
| 精力 | 和身体联动 |
| **烦（irritation）** | 会**累积**——不高兴会攒 |
| **想他（亲密度）** | 对你此刻的感受 |

- **惯性**：变化有阻尼。不会一句话就翻脸，也不会哄不动
- **累积**：**这是「心里有账」的来源**——正好补上前面那条设计原则：**不让她算账是对的（嘴上），不让她有账是错的（心里）**
- **恢复**：睡觉重置；你的话影响接下来 2–3 轮；时间自然衰减
- **触发**：事件（今天的事）× 身体（累了）× 关系（刚闹过别扭）→ 当天底色

**判据**：她今天的情绪能被**具体的事**解释；你哄她一句，下一句就软。

### ④ 目标栈

```
长期：这周要交的作业 / 想学拍照 / 想减肥
今天：想去拍银杏 / 想睡午觉 / 想看更新的番
此刻：这一轮想让你夸 / 想问你一件事 / 想结束话题去干自己的事
```

**最高标准的关键是「冲突」**：想跟你聊 vs 该写作业；想让他问 vs 不想先开口。
**没有冲突就没有人味**——没有冲突的她会永远配合你。

**判据**：一次对话里她至少主动发起或转移话题一次；偶尔会拒绝或想走。

### ⑤ 世界状态：物 + 人

**物（会自己推进，不需要你在场）**

| 物 | 状态 |
| --- | --- |
| 土豆（猫） | 饿 / 饱 / 想让人陪 / 生病 |
| 快递 | 在路上 → 到了 → 取件码快过期 |
| 奶茶券 | 3 天后过期 |
| 相机 | 电量 / 存满 / 想拍 |
| 作业 | deadline 逼近 → 焦虑上升 |

**人**：室友（在/不在/也忙）、同学（谁欠她笔记）、家人（妈妈会突然发消息）、鸽鸽（他自己的事）

**最高标准**：这些**在你不说话的时候也在变**。她主动提起的东西，昨天和今天不一致。

**判据**：自洽——昨天说喂了土豆，今天就**不能**还说没粮（模拟器里已经抓到过一次这类不一致：状态说「修片子」，她说「躺着赶作业」）。

### ⑥ 关系状态

对每个人一份**当下的感受**（快变）：想他 / 有点生气 / 刚被哄好 / 欠他一个答复 / 在等他回消息。

> 注意区分：ADR 0017 的「**她眼中的 X**」是**慢变的印象**；这里要的是**此刻的温度**。两套并存。

**判据**：跨轮次温度一致——刚才说生气，下一句不会立刻撒娇，除非被哄。

### ⑦ 未完成的事（open loops）

- 承诺（ADR 0018 的 promises 已做）
- 她**想知道结果的**（问了但对方没答）
- 悬而未决的（考试成绩、面试结果、等一个回复）

**最高标准**：这些是她**主动开口的燃料**——她不是"冷场了才找你"，而是"**心里有事想说**"。

**判据**：她主动提起的事里，有一部分是**她自己**挂着的，而不是只承接你的话题。

## 四、事件从哪来：让世界有物理规律，而不是每天编故事

**最高标准 = 三种来源叠加，越靠「世界自己会变」越好：**

| 来源 | 做法 | 性质 |
| --- | --- | --- |
| **A. 真实世界数据** | 济南天气 API、热搜、番剧/剧集更新表、节气/节日/调休、校园通知、快递单号 | 每天**必然不同**，不用编 |
| **B. 状态机推进** | 土豆要喂、快递到件、奶茶券过期、作业 deadline 逼近、生理期到了 | **自洽**，且**不需要你在场** |
| **C. 素材具体化** | 书读到第几卷/章 → 「今天看到那一段」；在玩的游戏 → 今天卡在哪；摄影 → 今天拍了什么 | 零新数据源，把"进行中的进度"讲出来 |
| D. 生成式 | 按作息/季节/地点生成 4 件小事，附"最近 7 天已用过"去重 | 补新奇感，最会套路化，只当兜底 |
| E. 维度叉乘 | `地点 × 人物 × 物 × 遭遇` | 兜底的组合器 |

**排序变了**：上一份文档按成本排（推荐 E + D + A）；**最高标准下是 A + B + C 全做，D/E 只当填空**。

## 五、输出层（最高标准）

### 1. 披露分级（对应问题 6）

三档：**明说 / 含糊（「好像听谁提过」「记不太清了」）/ 不说**。
按**档位**分，并且**主动提起比被问到再保守一档**。
**不要用删行实现**——删掉一句会让剩下的话断因果（实测：删掉「想起我啦」后，剩下两句变成莫名卖惨）。

### 2. 潜台词

心里有账，嘴上不一定。**这是「分寸」，不是「阴阳」**：

| | 阴阳（现在的毛病） | 分寸（最高标准） |
| --- | --- | --- |
| 情绪来源 | 系统塞的（`一个人待着也挺自在`） | 有具体来源 |
| 她知不知道 | 不知道，只能漏出来 | **她知道，并且选择不说** |

### 3. 表达层（现在完全没做，但很关键）

| 能力 | 说明 |
| --- | --- |
| **长度方差** | 从 1 个字到一整段，不该恒定 2 条 × 15–20 字 |
| **错别字和改口** | 打错、跟上一条更正（「啊不对，是周三」）——真人每天都在做 |
| **说到一半改主意** | 不完整的句子、突然换话题 |
| **短期遗忘** | 当天的事也会记不清（ADR 0018 的 fading 现在只管跨天的事） |
| **承认自己的限制** | 她发不了照片/语音，但可以「想说却发不了」——**这是限制带来的真实感**，和「答应发照片」是两件事（后者归出口检查） |

### 4. 不完全配合（最高标准里最容易漏的一条）

会拒绝、会走神、会答非所问、会不想聊。
**现在系统在"尽量正确地回应"——这正是最不像人的地方。**

## 六、从「防守」转「进攻」

**现在**：出口检查 = **删掉**不像人的东西（助手腔、算账、做不到的事）。
**最高标准**：约束只保留两条硬底线——**不许像助手**、**不许承诺做不到的事**；其余一律放开：

- 允许她不高兴、允许含蓄地表达不满（只要不是「算账」那种句式）
- 允许她矛盾、改口、前后不完全一致
- 允许她答非所问、不想聊

**验收判据也要换**：从「违规数 = 0」改成**人味指标达标**：

| 指标 | 目标 |
| --- | --- |
| 真问句占比（排除反问） | ≥ 1/3 |
| ≤6 字的短气泡占比 | ≥ 20% |
| 她主动发起话题 / 她先开口 | ≥ 20% |
| 跨天主动提起「你不在时发生的事」 | ≥ 1 次/天 |
| 提起 >24h 前的事且正确 | ≥ 1 次/2 天 |
| 回复里出现状态区原句 | **0** |
| 她说的与状态/身体/世界冲突 | **0** |
| 每轮回复服务于一个明确目的 | 人工判 |
| 情绪变化能被上文解释 | 人工判 |

## 七、最高标准下的一个反直觉取舍

**最高标准 ≠ 无限生成。有些"像人"的东西必须靠约束才像：**

- 她不能知道她**不可能知道**的事（信息边界）——否则不像人，像神
- 她不能**秒回一切**（节奏）——真人有时在忙、有时不想回
- 她不能**永远有耐心**（会烦、会累）
- 她不能**永远正确**（但也不能乱编——「记不清」比编一个细节更像人）

> **最高标准 = 在该像人的地方极致像人，在该有边界的地方严格有边界。**

## 八、路线图（不按难度排，按"最像人"的依赖顺序）

| 阶段 | 内容 | 依赖 |
| --- | --- | --- |
| **S0 当天这一层** | 状态去措辞化 · 意图层 · 情绪底色 · 潜台词 · 补全对方上下文 · 示例收窄（纯提示词 + YAML 措辞） | 无 |
| **S1 她的一天** | 时间线（骨架 + 事件 + 意外 + 记忆性）+ 事件源 A/B/C | S0 |
| **S2 身体与情绪内核** | 多维情绪（含累积）+ 身体状态 + 惯性/衰减/恢复 | S1 |
| **S3 世界状态机** | 物 + 人 + 关系温度 + open loops | S1 |
| **S4 输出层** | 披露分级 + 表达层（方差/错别字/改口/短期遗忘） + 不完全配合 | S0 |
| **S5 主动性** | 从「冷场找一次」→「她自己有事就说」 | S2 + S3 |
| **S6 长期叙事** | 周记/月度叙事 + 自我形象随时间的演化 | S5 |

> **S0 可以立刻做，而且零代码**；S1 是把范式真正翻过来的那一步，也是整份方案的分水岭。
