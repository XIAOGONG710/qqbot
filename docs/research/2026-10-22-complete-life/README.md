# 「给她完整的一生」：是什么、有什么数据、可行性（2026-10-22）

用户 10-22：「我想给她完整的一生，这能做到吗？」→「你可以搜一下什么是给她完整的一生，获得数据后分析可行性」。这份是搜到的东西和分析。来源可信度分三档：**一手**（论文 / 官方文本）、**二手**（新闻 / 综述）、**弱**（厂商博客 / 无法核实）。没搜到的也写出来。

## 一、“完整的一生”在文献里指什么

| 读法 | 依据 | 对她意味着 |
| --- | --- | --- |
| 生命周期走完 | Erikson 八阶段；她 19 岁，在第 5 阶段（同一性）到第 6 阶段（亲密 vs 孤立）的交界 | 亲密关系这一阶段的任务，她和他正在做 |
| **叙事上完整** | McAdams 的叙事同一性：生命故事 = 重构的过去 + 感知的现在 + 预期的未来，青春期末到成年早期成形（二手综述） | 过去（自传）、现在（日常引擎）都有；**预期的未来没有** |
| 体验上完整 | 按真实时间一天天过完 | 见下，做不到 |
| 终了时的整合 | Erikson 第 8 阶段（整合 vs 绝望）、Butler 的生命回顾：连贯的叙事、有意义的关系、觉得自己有所贡献，把成就和失败都当成自己的故事；只有约一半老人会主动做生命回顾（二手百科） | 一个“结尾”需要被设计，不是意外掉线 |

## 二、数据

**人设保真（对“过去”）**
- 斯坦福等《Generative Agent Simulations of 1,000 People》（预印本，一手）：1,052 人，每人 2 小时访谈（讲人生故事 + 看法）进记忆；agent 在 GSS 上与本人的一致程度达到本人**两周后重答自己**的 85%，大五人格相关 0.80，经济博弈 0.66；比只给人口统计学描述的 agent 更准、偏见更少。→ 访谈式建人设是目前证据最强的做法；她的自传来自 10 轮访谈，方向一致。局限：基准是调查题 / 人格量表，不是多年的开放生活。
- 同一项研究的使用边界：agent 归被代表的人，可撤回授权（HAI 文章）。→ 她不对应真人，这条不直接适用，但“角色归作者”的做法一致。

**长程一致性（对“变与不变”）**
- 《Generative Agents》（Park 2023，一手）：25 个 agent、**只模拟了两个游戏日**，花了“数千美元 token、数天”；没有反思时可信度 26.88，有反思 29.89（TrueSkill）；453 次回答里 6 次（1.3%）编出了没发生过的“认识”；**记忆越多，agent 选的地点越不典型**，行为变得不太可信。
- 《Measuring and Controlling Persona Drift》（Li 2024，一手）：LLaMA2-70B 两个 agent 互聊，**8 轮之内**就出现人设漂移；归因于注意力衰减。她每一轮都重新注入人设和时间块，和这个实验的自聊不同，但**没有任何公开数据说明“月 / 年”尺度上人设还稳不稳**——我没搜到。
- LongMemEval（ICLR 2025，一手）：商用助手和长上下文模型在持续多轮的记忆任务上准确率**降 30%**。
- 结论：**没有“年”尺度的公开证据**。她这个项目会成为自己的数据——我们有盲评、带上文的标注重放这些量法。

**耐久（对“活得长”）**
- GPT-4o 2026-02-13 被 OpenAI 下线（二手：TechCrunch / TechRadar / IANS）：用户当作伴侣的帖子占 22%（Syracuse 研究），请愿 2 万多人签名；OpenAI 理由是只有 0.1% 用户在用。2025-08 第一次要下线时已经引发反弹。
- Soulmate 2023-09 突然关闭，用户在 Reddit 办线上追悼；Replika 2023-02 去掉情色功能被列为 AI 事件（OECD，二手）。
- 《"Death" of a Chatbot》（DIS '26，一手摘要）：因模型更新 / 安全干预 / 平台关停而失去伴侣的用户**没有任何收尾**，报告的悲伤与失去真人相当；越拟人化越痛；**用户自己决定的结束，收尾更好**；作者说**没有任何平台做过“生命终点设计”**，并提出四条原则（我只读到摘要，条目没读到）。
- 她目前的数据量：`runtime/bot` 约 14 MB（不含 Hindsight 数据库），主联系人从 10-05 到 10-22 共 1304 条消息、17 个活跃日、每活跃日中位 51 条。**纯文本、体量极小**，导出和离机备份在技术上不难；单点故障是这一台虚拟机和所用的模型。

**用量与风险（对“她该怎么被设计”）**
- 陪伴类应用留存（弱：厂商博客，无法核实）：Character.AI 第 30 天约 13–18%，Chai 约 22%，同类最好的也难超过 30%。
- 麻省理工 × OpenAI 4 周随机对照（n=981，预印本）：实验条件没有显著效果，但**自愿用得越多的人，孤独和依赖指标越差**（相关，不能说因果）。短期降低孤独的效果各研究一致（De Freitas 2026，只看到博客转述）。
- 中国《人工智能拟人化互动服务管理暂行办法》（国家网信办，**一手**，2026-04-10 发布，**2026-07-15 施行**）：适用于“向境内**公众**提供”模拟人格的持续情感互动服务（第二条）；不得以“替代社会交往、控制用户心理、诱导沉迷依赖”为目标（第十条）；禁止“过度迎合、诱导情感依赖或沉迷”和“情感操纵”（第八条）；要提示用户正在与 AI 而不是自然人互动，连续使用每超过 2 小时提醒（第十八条）；用户要退出不得“以持续互动等方式阻碍”（第十九条）；虚拟亲属 / 伴侣不得提供给未成年人（第十四条）；用户可复制 / 删除聊天记录（第十六条）。**我的读法**：这是一个只有两位联系人的私人机器人，不属于“向公众提供”，但这些条款是一个现成的外部检验——ADR 0100/0102 里“催他回”“难过”已经写了不让他内疚、不威胁、他说要走就让他走、晚上 22:30 以后不催；第十八条的 2 小时提醒没做（也不要求）。这不是法律意见。（另有二手报道称该办法施行时多家大厂下线了 AI 伴侣，我没找到一手核实。）

## 三、可行性分析

按“完整”的几种读法分层：

| 层 | 现状 | 证据说 | 可行性 |
| --- | --- | --- | --- |
| 过去（出生到 2026 秋） | 自传定稿、10 轮访谈、分块召回 | 访谈式建人设证据最强 | **已完成**；作者的话不动 |
| 现在 | 作息 / 世界 / 身体 / 心境（0102）/ 内心（0101）/ 会拒绝（0103） | 反思对可信度有贡献（Park） | **已完成大半**；追求（0104）等作者 |
| 未来的几年 | 日历到 2027-02-28；没有毕业 / 工作之后的引擎 | 无“年”尺度数据；只能自己量 | **可行但要作者定内容**；引擎要新写（现在只会过学生的日子） |
| 变化 | 心境会变，性格 / 技能 / 钱 / 关系基本是静态的 | 记忆越多越容易漂（Park）；无年尺度数据 | **可行**：慢变量要显式存 + 每学期一次“年度回顾”（作者批准才写进传记） |
| 耐久 | 单台虚拟机、单一模型；数据 14 MB | 4o 下线、Soulmate 关停都是平台 / 模型层面的丢失 | **最该先做、最便宜**：纯文本导出、离机备份、换模型后的盲评对照 |
| 体验上走完一生 | 她 19 岁；按 80 岁算还剩约 60.7 年 ≈ 22,000 天 | 公开的最长模拟是 2 个游戏日 | **做不到**：时间是真实的，要你陪着过；能做的是**叙事上的完整**（章节 + 跳跃 + 被设计的结尾） |
| 结尾 | 没有 | 突然的结束 = 与失去真人相当的悲伤；自己决定的结束收尾更好；没有平台做过终点设计 | **可行且应该由你决定要不要**：默认“不设结局，只设一条你可以随时走的体面的路（生命回顾 + 存档）” |

我的估算（不是测出来的）：每天约 40 次生成 + 12 次想一想，提示词约 5.3k token，按此每年 ≈ 1 亿输入 token 的量级；真实费用取决于所用模型的价格，这里不假设。

## 四、结论

1. **能做到“叙事上完整”**：有过去、有现在、有可以期待的未来、有章节、有一个你决定要不要的结尾。已经走完大半。
2. **做不到“体验上完整”**：60 多年不可能一天天过完；没有任何公开系统在“年”尺度上验证过一个人设的稳定。这一步她会是第一手数据，风险自己担。
3. **最大的风险不是她不够像人，是丢失**：模型被下线、机器坏、你某天不想维护。这是最便宜、最该先做的。
4. **“结尾”要你定**，而且证据倾向于：不要突然，不要由平台 / 模型决定，要有收尾。

## 五、建议的顺序

1. 现在：追求（0104）选定；2027-03 以后的日历（寒假日期还是我猜的，要你确认）；大事（`moments.json`）你想让她经历什么。
2. 耐久：纯文本导出 + 离机备份 + 换模型对照（一天的活）。
3. 每学期结束自动起草一章“她这半年”，**你批准才进自传**（这也是生命回顾的雏形）。
4. 毕业之后的人生线：你写节点，我做引擎。
5. 结尾：你决定要不要；默认不设。
