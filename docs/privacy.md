# 本地数据导出、来源审计与保留期限

适用于 ADR 0070 第 9 项。命令从仓库根目录运行；以下路径和 QQ 号均为占位示例。默认演练不会删除或移动线上数据。实际执行前应复核清单并停止 bot。

## 来源链

`memory/provenance.json` 是版本化来源账，只记录 bank/document 标识、联系人、父文档、时间和写入状态，不记录正文。聊天、公共聊天副本、日记、周记和阶段总结都接入它。

- 远端写入前先登记 `pending`，成功提交后改为 `shared`。`shared` 表示远端已接受提交，不保证异步抽取已经完成；网络结果不明时保留 `pending`，遗忘计划仍会包含它。
- 高敏文字仅本地保留时登记 `local-only`；若同 id 曾提交过远端，仍保留远端旧版本可能存在的状态。
- 日记取实际送入模型材料的联系人，不让模型猜来源；总结继承父日记的联系人。父文档缺失、旧日记或计划/回写世界材料无法完整追踪时标记 `complete: false`。
- 覆盖文档保留历史来源并集，避免服务端旧抽取事实尚未更新时丢掉关联。
- 远端 metadata 使用联系人哈希与父文档 id，本地来源账保留 QQ 以便运营者查找；哈希不是加密，也不应把来源账公开。

旧日记、Hindsight 内部跨文档整合的观察和未关联的其他人物模型仍需人工复查。来源账不声称覆盖接入前全部历史。

## 审计、导出与遗忘

```powershell
npm run privacy-audit -w packages/bot -- <数据目录> <QQ号>
npm run privacy-forget -w packages/bot -- export --data <数据目录> --qq <QQ号> --out <导出目录>
npm run privacy-forget -w packages/bot -- forget --data <数据目录> --qq <QQ号>
```

审计报告的 `derivedDocuments`、遗忘计划的 `derived` 列出关联日记、周记和阶段总结及其真实 bank。记录可能是联合内容：删除一整篇会同时移除其他人的那部分。因此默认只列出；执行时必须显式加 `--include-derived`，不使用不可靠的按名字删句。

```powershell
npm run privacy-forget -w packages/bot -- forget --data <数据目录> --qq <QQ号> --hindsight <服务地址> --trash <回收目录> --include-derived --apply
```

生产适配器会确认目标 bank 无排队/执行中的后台操作（包括刷新任务），否则拒绝开始；也应暂停其他写入同一 bank 的生产者。删除请求是不可逆的远端操作。本地文件则移动到唯一回收目录；联合日记只回收命中日期的原文，保留无关日期，并写入 `forgotten` 标记，防止后续从远端读回或成为总结材料。来源标识账与清理报告仍保留，不等于彻底抹除全部标识。

报告在第一个删除请求之前落盘，每一步更新。远端失败会保留本地原文和写入进度，修复后可用同一命令幂等重试；报告逐项记录成功与失败，不能把 `applied: true` 理解成全部成功。执行后应复查报告、远端文档、召回结果及其他混合文件；若恢复回收文件，还需同步恢复 `forgotten` 标记。

导出只复制专属文件，联合内容列在审计清单中，不自动复制其他人的原文。部署联系人配置、混合日志、生活账、NapCat/供应商和系统备份须单独核对。

## 日志期限

保留天数由操作者明确指定，不修改线上默认值，不自动安排清理任务。示例中的 30 天只是演示参数。

```powershell
npm run privacy-retention -w packages/bot -- --data <数据目录> --logs-days 30 --as-of 2026-10-14
npm run privacy-retention -w packages/bot -- --data <数据目录> --logs-days 30 --archive <外部回收目录> --apply
```

只处理 `logs/YYYY-MM-DD.log`，按文件名的日历日期判断；截止日当天、当前日志、非法日期、未知文件名、子目录及链接都不回收。执行要求 bot 已停、回收目录在数据目录之外，并复检真实路径。过期文件仍保存在回收目录和逐步报告中，可人工移回；不不可逆清空目录。

这只建立运行日志的保留与回收机制，聊天原文、导出、回收目录和备份的彻底删除期限尚未统一实施；不能宣称第 9 项已经完全关闭。
