# 首次启动检查

1. 使用 Node 24，并在正式配置之外保存密钥；仓库、日志和控制台不得出现令牌。
2. 先运行 `npm ci`、`npm run typecheck`、`npm test`、`npm run release:check`。
3. 运行 `npm run verify:cross-end`，确认 QQ、DSH、手机上下文与重载演练全部通过。
4. 在 Koishi 中文控制台点击“一键体检”。它是只读检查，不会重启或发送消息。
5. 先保持外部平台为关闭或只写草稿；手机动作沿用白名单、确认和审计。
6. 真正启动、登录 QQ、连接手机或调用外部服务前，按现场变更流程单独确认。

首次启动不等于完成真实环境验收。AI 生图、Android 真机、隔离数据库和官方平台账号分别按发布说明验证。
