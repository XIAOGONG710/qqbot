# 升级流程

1. 记录当前提交和 `release/manifest.json` 版本，确认工作区没有来源不明的改动。
2. 先生成完整备份，并用 `restore:drill` 校验状态归档；涉及长期记忆时再向名称以 `qqbot_restore_drill_` 开头的空库执行隔离恢复。
3. 在待发布提交运行全量类型检查、测试、跨端演练和 `release:check`。
4. 对照发布说明检查协议版本、Android `versionCode` 和状态格式；不允许跳过未知迁移。
5. 经当次上线确认后再重启。启动后查看中文控制台体检，不通过则停止扩大流量。

升级不会自动发布外部草稿、批准照片、安装 APK 或删除旧备份。
