## 一、三套传统，各给什么

| 传统 | 来源 | 核心要求 | 对我们要什么 |
| --- | --- | --- | --- |
| **自传 / 回忆录** | [Reedsy：How to Write an Autobiography](https://reedsy.com/studio/resources/how-to-write-an-autobiography/) | 完整；按时间顺序（**ab ovo**，"从蛋里写起"）；**大量细节**；**诚实——不回避失败与后悔**（"没有错误的自传不是自传，是宣传稿"） | **beats 清单 + 时间顺序 + 不许只写好的一面** |
| **人物小传（小说）** | [小桥老树：类型小说如何写人物小传和故事梗概](http://cqwriter.com/web/article/1397412001227104256/web/content_1397412001227104256.html) | 基本信息（姓名/性别/年龄/外貌）+ 特殊要素（性格/人际关系/能力/喜好/**语言风格**）；**"小说可以虚构但不能失去真实"**；**避免过于追求完美**；梗概要有重大事件和**转变节点** | **她是虚构人物 → 人物小传是更贴的形式**；**不要完美** |
| **人物小传（史传）** | [漆永祥：浅谈古代人物小传的撰写](https://www.chinawriter.com.cn/n1/2022/0421/c442005-32404730.html) | **"寥寥数语，高度浓缩传主的一生"**；要有画龙点睛的评价；**最忌原文抄撮、袭用套路**；**不宜过度美化**；引据要有出处 | **只留有用的，不写全**；**忌套路** |
| **写作技艺** | [要展示，不要叙述](https://zh.wikipedia.org/zh-mo/%E8%A6%81%E5%B1%95%E7%A4%BA%EF%BC%8C%E4%B8%8D%E8%A6%81%E5%8F%99%E8%BF%B0)、[Jane Friedman：How Scene Writing](https://janefriedman.com/how-scene-writing-helps-you-lose-control-and-find-your-memoirs-story/) | **场景（scene）** vs **概述（summary）**：关键处写成场景，其余概述 | **"写多少"的解法：八二开**（见第三节） |

## 二、关键判断：她需要的不是"自传"，是这三样的组合

| 组成 | 形式 | 用途 | 量 |
| --- | --- | --- | --- |
| **① 年表** | 客观事件列表 | **事实源**（防止现编） | 全 |
| **② 关键记忆（8 个左右）** | 第一人称**场景** | 可以被"讲出来"的故事 | 8 个场景 |
| **③ 自我理解** | 第一人称一两句**评价** | 她**怎么理解自己**（漆永祥的"画龙点睛"，但换成她的口气） | 每章 1 句 |

**"完整的一生"不是目标。** 漆永祥那条最关键：**"寥寥数语，高度浓缩"**——她资料里已经写了 23 KB 的属性，自传要做的是**给这些属性装上因果**，不是再写一本小说。

## 三、最有用的一条技术：**场景 vs 概述，八二开**

这是搜索里收获最大的一点，也直接解决"写多少才合适"：

| | 写成**场景** | 写成**概述** |
| --- | --- | --- |
| 什么内容 | **8 个左右关键记忆 + 转变节点** | 其余全部 |
| 特征 | 有时间、地点、一个动作、一句对话、**一个物件** | 一两句话 |
| 例 | 「高一那次月考，我数学考了 47 分。发卷子那天下午我自己在楼道坐了一节课，那张卷子我到现在还夹在旧练习册里——不是舍不得，是懒得整理。」 | 「高中三年过得挺闷。」 |

**判据（一段自传好不好，看它同时给了几样）**：
> **场景 + 一个细节物件 + 当时的反应 + 它留下的痕迹（今天还在）**

上面那段的四样：**场景**（发卷子那天楼道）、**物件**（那张卷子）、**反应**（坐了一节课）、**痕迹**（卷子还在，且"懒得整理"这层性格）。
**最后那个"懒得整理"就是"自我理解"**——不用单独写一句"我是个恋旧又懒散的人"。

## 四、写作流程（八步）

1. **列 beats**（用人物的版本，见附录）：不是为了全写，是为了**不漏掉"转变节点"**
2. **先做年表底稿**：把已经确定的事实按时间摆好（我可以从现有资料抽出来，你不用从零开始）
3. **标出转变节点**（小桥老树那条）：每个节点必须落在**一个具体事件**上，不能是"她慢慢变得……"
4. **选 8 个左右的场景**：把最重要的节点写成场景（时间 + 地点 + 动作 + 一句对话 + 一个物件 + 今天的痕迹）
5. **其余一律一句话概述**
6. **每章加一句"她现在怎么看这件事"**（自我理解；**用她的口气，不是作者评论**）
7. **留白**：2–3 处不愿提的、1–2 处记不清的、1 处"家里人说的版本不一样"
8. **交叉核对 + 切块**：自传里的硬事实必须能在 `persona.yml` / `schedule.yml` 里找到；然后切成可检索的块

## 五、针对她的 beats 清单（改造自 Reedsy 的经典清单）

| 章 | 写什么 | 特别注意 |
| --- | --- | --- |
| **出生与家** | 青岛、独生女、爸妈都在体制内、每周视频 | 已有事实，一两句带过 |
| **幼儿园 / 小学低年级** | **他出现之前**的她 | ⚠️ **这段现在是纯空白，也最重要**——她的人生不是等他出现才开始的 |
| **小学** | 和他成为同班；第一印象；什么时候开始不一样 | 补上"认识经过"（就是她编出"群里加的那一嘴"的地方） |
| **初中** | 青春期、她自己的朋友、家里的事、第一次喜欢的东西 | 必须有**和他无关**的部分 |
| **高中** | 学业压力、**"最怕数学"的根因**、想去的城市 | 这是"怕数学"的因果落点 |
| **大学** | 报专业（人工智能与大数据，自己感兴趣）、离家、**8 人间宿舍**、**开始拍照**、**遇到土豆**、**关系是什么时候变的** | 这一章与现在直接相连 |
| **现在** | 在读的书、攒钱买相机、日常 | 一两句，别占篇幅 |

**转变节点候选（每个都要落成场景）**：
1. 第一次意识到喜欢他（小学还是高中？）
2. **最怕数学的起因**（那件事）
3. **开始拍照的起因**（第一部手机？谁给的相机？）
4. **遇到土豆的那天**
5. 一个和家里有关的节点（比如第一次离家、第一次被爸妈不理解）
6. 一个和朋友有关的节点（闺蜜是怎么来的）
7. 一次**她做错的事**（Reedsy 那条"诚实"：不回避失败）
8. 关系从"同班同学"变成"男朋友"的那一刻

## 六、写完的自检清单

| 检查 | 不合格的样子 |
| --- | --- |
| **有因果吗** | 读了以后还是不知道她为什么怕数学 |
| **有物件吗** | 全篇没有一个能被"随手提一句"的东西 |
| **有痕迹吗** | 过去的事和现在完全断了 |
| **有不好的一面吗** | 全篇都是"我很善良我很努力"（Reedsy：**没有错误的自传是宣传稿**） |
| **有套路吗** | "从小就很懂事""别人家的孩子"（漆永祥：**最忌袭用套路**） |
| **完美吗** | 她没有任何缺点（小桥老树：**避免过于追求完美**） |
| **全是场景吗** | 每一段都写成小作文（→ 她会变成"讲故事的人"，而不是"过日子的人"） |
| **全没有他吗** | 检查"他"的占比——**我建议大半没有他** |

## 七、给我们的三条特殊约束（普通自传没有）

1. **不要整篇进提示词**——会挤掉正在聊的内容，而且**她会变成背传记**（和"照抄状态行"同一个病）。**切块 + 按需检索。**
2. **第一人称口语**——它同时是**语气样本**，而且**不会像对话示例那样被逐字复述**（自传的句式在对话里不会被触发）。这是它独有的优势。
3. **留白比写全更像人**——真人对自己也不是全知的。
