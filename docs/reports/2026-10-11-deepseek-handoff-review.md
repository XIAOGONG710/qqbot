### 遇到具体问题再索取

| 触发条件 | 最小材料 | 处理边界 |
| --- | --- | --- |
| 本地无法复现线上问题 | 目标行为、输入、期望输出、失败判定 | 先查仓库与测试；只问用户独有事实 |
| 提示词或角色状态导致行为偏差 | 相关 `last-prompt.json` 段落 | 稳定替换标识符；删无关历史；默认不提交 |
| 需要确认调用链、失败或重启 | 时间、模块、错误类型、关键帧、脱敏输入输出摘要 | 只取必要日志行，不交整份日志 |
| 怀疑环境配置差异 | 与问题相关的配置键和值 | 密钥 / token 用占位符；不取全量环境变量 |
| 真实对话才能重现 | 最少上下文轮次、期望 / 实际结果 | 优先合成复现；真实原话需单独允许外发 |
| `world` / `promises` / `memory` 引发不一致 | 相关条目、必要字段、时间戳 | 去掉无关对象和真实标识；默认不提交 |
| 真模型或盲评回归失败 | 场景、评分维度、失败样本、运行参数 | 不把网络失败、空正文或权限拒绝算通过 |

DS 明确表示不应索取或提交密钥、token、cookie、私钥、真实账号标识、完整聊天、完整日志、完整数据库、全量环境变量或与任务无关的私人数据。

2. 把全仓成功基线同步为 747 项；
