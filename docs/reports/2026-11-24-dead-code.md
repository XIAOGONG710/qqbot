# 2026-11-24 死代码盘点（packages/bot/src）

减法这一轮（`docs/plans/2026-11-24-subtraction-round.md`）的一项：把 `packages/bot/src`（约 8 万行、486 个文件）里没人用的代码找出来，

## 怎么找的（可重跑）

- **导入图**：扫全仓受 git 管的 `.ts/.tsx/.mjs/.js/.cjs`（`packages/` 全部包、`scripts/`、`dsh-plugins/`、`apps/`、`docs/` 里的复现脚本；不含 `vendor/` `runtime/` `characters/`），
  用一个小词法器去掉注释后，解析静态 `import` / `export … from` / `import * as` / `await import()` / 类型位置的 `import('…').X`，把相对路径解析到文件，
  得到「每个导出被哪些文件按名字引用」。`import * as` 和 `export *` 算全部用到。分出三类：哪里都没人引用、只有测试引用、整个文件没人 import。
  脚本没提交（一次性工具；TypeScript 7 的 npm 包只有 Go 版编译器，没有稳定的 JS API，所以用的是正则 + 词法器）。
- **未用的局部**：`npx tsc -p packages/bot --noUnusedLocals`（不改 tsconfig，只是临时加参数跑一遍）。
- 每一条删之前再 `git grep` 全仓（含 docs）核对一遍名字，并看文件头注释和 `git log -S` 确认是不是「做好了还没接线」或「开关后面」。
- 数字：`src` 共 3970 个导出。只在自己文件里用、多写了 `export` 的约 1080 个（不是死代码，没动）；只有测试引用、但本文件里也在用的约 940 个（正常）。
