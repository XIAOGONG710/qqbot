## 已经实现并在线

### 1. QQ 运行与联系人

- Koishi + NapCat 的 OneBot 11 私聊闭环。
- 白名单联系人和 boyfriend / bestie / girl_friend / known / classmate / stranger / unlisted 七档角色卡。
- 各档通过“不写进低档卡”隔离隐私；联系人支持称呼、人设、关系档位和换档起点。
- 启动 / 重连补回漏掉的消息，按 QQ 消息 ID 去重；生成期间来了新消息会放弃旧草稿并带上新消息重生成。
- 非名单好友的处理代码已存在，但实际开关保持关闭。

### 2. 记忆与关系

- 每个联系人独立私人 bank，另有名单成员共享的公共 bank。
- 召回会区分是谁说的、哪天发生、只是计划还是已经发生；凌晨未睡时的“明天”按她的一天解释。
- 记忆随时间变淡；长期、重要、重复提到的事实保留更久；给出实体或日期线索时可以重新想起。
- 最近想起的记忆可在后续几轮沿用。
- 每个人都有动态的“她眼中的 X”；他提起她认识的人时可以结合介绍、对方私人记忆和公共经历回答。
- 每日日记、周记、假期总结、她答应的事、等结果的事和没被回答的问题均已接入。

### 3. 她自己的生活

- 课表、睡觉、地点、上课、饭点、食堂 / 外卖、洗澡和空闲活动。
- 困、累、饿、生理期、小感冒和现实压力对当日状态的影响。
- 每日心情和三本在读书的进度；没有读到的情节不会编。
- 天气、楼下的猫、快递、作业、和家里视频、生活费、消费和相机基金。
- 两位朋友的感冒、忙碌、一起吃饭、帮拍板书和微信聊天等近况。
- 一天的打算会因下雨、身体不舒服和截止时间改变；能回答最近几天自己做过什么。

### 4. 回复行为与安全出口

- 睡觉、上课、洗澡时延迟看到；热聊等待和连续消息合并避免抢答。
- 按行拆成 QQ 气泡；有回复长度变化、偶发同音错字和改口。
- 区分直接提问、明确难过、亲密话、撒娇要求、对方近况和收尾，不在关键轮次机械转去讲猫、书或摄影。
- 一段对话里同类作息 / 吃饭叮嘱只说一次；已经通过后续聊天确认的行程不再追问。
- 出口检查会拦做不到的照片 / 电话 / 语音承诺、动作描写、档位禁用词、助手腔、算账、怪对方没联系、重复口癖和过长回复。

### 5. 主动消息与恢复能力

- 早安、下课、睡前、冷场和待跟进时机；每日数量限制、错过不补、上一条没回就暂停。
- 她说“睡了”会跨联系人保持一致；上课和截止时间可以打断普通行动。
- 行动队列先原子落盘、结束后再进事件账；崩溃和重启不会重复结算。
- NapCat、Hindsight、Koishi 有独立启动脚本和总服务守护；Hindsight 连接池及坏连接回收已处理内存事故。

## 已上线但仍是影子能力

### 自主生活行动账

`autonomousLife=true` 会在没人聊天时推进睡觉、吃饭、上课、学习、休息、读书、休闲、NPC 互动和摄影项目。行动有稳定 ID、持续时间、成功 / 失败 / 中断及硬事件打断；72 小时和中途重启逐事件一致。

它目前只维护行动队列和事实账。摄影进展、NPC 行动及精力 / 饥饿 / 压力还没有进入提示词、日记和用户可见状态，所以不能把“后台有账”误写成“聊天已经表现出来”。

### 连续需要

精力、饥饿、压力从版本化锚点、时间和事件账纯投影；低精力让柔性行动先休息，高压力暂缓摄影，课程、吃饭、NPC 约定和截止时间仍优先。14 天回放与第 7 天重启的事件形状一致。

## 已实现但未启用

难过、亲密、收尾时可以并行生成 1–5 个候选，按句数、跑题、客服式约定、重复和出口问题扣分。线上保持 `candidates=1`；调研和权重尚未完成前不承担三倍调用成本。

### 最近轮次 + 旧聊天摘要（ADR 0043）

最近 N 轮保留原文，更早聊天后台整理成事实要点；已有 60 秒超时、失败回退、五分钟重试、持久缓存、成本日志和单联系人灰度。线上保持 `contextTurns=0`，因为还缺六类长历史场景 A/B、“计划写成已发生”的专门探针和匿名人工盲评。
