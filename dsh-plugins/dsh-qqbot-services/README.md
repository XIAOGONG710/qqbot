# 林梦瑶 · QQ 桥接

DSH 的「林梦瑶 · QQ 桥接」设置页与桌面侧边栏的「服务管理」共用一份控制台。总览提供现有启动操作，连接页显示 NapCat、Hindsight 和 Koishi 的端口及状态，系统页提供按白名单字段生成的诊断报告与近期后台事件。

设置页入口、渐变名片、标签栏和卡片主题移植自 [灵犀 QQ 桥接](https://github.com/2524034412-boop/DSH-QQ/blob/edf9f853341ac049708dc4c68ed432c74f2ad6d4/plugin/dsh-qq-bridge/lib/client.js)，上游 `dsh-qq-bridge` 包声明 MIT 许可。样式使用独立命名空间，随 DSH 明暗主题切换。控制台连接仓库现有的 Windows 服务探测与启动锁。

- 单项启动直接调用相应服务的现有脚本。批量启动按 NapCat → Hindsight → Koishi 检查并补齐缺失服务，等前一项就绪才继续。
- 面板、守护和 Windows 登录启动都通过 `scripts/start-managed-service.ps1` 进入三项服务。每项使用独立的 Windows 独占文件句柄，前台脚本退出后系统自动释放。
- 接口只接受回环连接，并要求 DSH 宿主验证浏览器会话。桌面主进程代理负责附加宿主签名 Cookie，状态接口不签发或返回面板令牌。日志视图只展示日期、服务和事件类型。面板触发的启动输出写进 `runtime/boot/*-panel.log`。
- Windows 自启和守护仍由宿主机管理。关闭 DSH 后，已拉起的服务继续运行。
- 「连接」页读取本机 Koishi 的私聊名单和显式配置的群聊、主动消息、桌面联动模式，通过宿主认证后才提供姓名、QQ 号和关系档，支持导出这部分配置。
- 「系统」页复用守护的备份完整性判定，显示最近 14 份备份。可按日期校验制品并调用项目已有的文件级隔离恢复演练，演练不恢复数据库、不覆盖线上数据。版本显示本地提交与本地记录的 `origin/main`。
- 「读书」复用本地 QQ 角色卡和读书进度计算，展示书名、作者和进度，私人读后感未接入。「灵魂」从本地索引读取表情及通过撤回与换档校验的梗。
- 「记忆」读取本地 QQ 写入的 owner-bank 登记状态，并从本机 Hindsight 读取公共库的条数和文档数。不会发出私有库查询，面板不会返回库名、记忆正文或人物实体。
- 聊天页通过本机 NapCat OneBot WebSocket（`127.0.0.1:3001`）读取当前 QQ 账号、好友、群及所选会话的近期消息。DSH 进程可通过环境变量 `QQBOT_ONEBOT_TOKEN` 提供凭据。聊天数据只经宿主认证的本地接口返回，不进入诊断、模型或记忆。仅在点击展开时，经本机代理读取允许的 QQ HTTPS 图片或浏览器可播放的语音，其他媒体保留文本占位。
- 聊天区移植 [灵犀 WebChat](https://github.com/2524034412-boop/DSH-QQ/blob/edf9f853341ac049708dc4c68ed432c74f2ad6d4/qq-bridge/webchat/public/index.html) 的头像配色、左右气泡和输入栏，在窄面板内把会话列表放到消息上方。每个账号下的每条会话可在本机选择读取最近 15、30 或 60 条。
- 手动发送只允许向 Koishi 配置里唯一的 `boyfriend` 联系人发私聊。面板展示服务端给出的账号、收件人和实际正文，确认后提交绑定本次会话与正文的两分钟一次性确认单。服务端消费确认单，再核验联系人，在同一条 NapCat 连接上重新核验账号后才发送。消息带可见的「【本人手动代发】」标记，Koishi 补回、引用和合并转发都跳过这个账号发出的带标记正文。部署时先让 Koishi 加载过滤逻辑，再更新 DSH 插件。发送测试只用模拟连接。
- 「会客室」**默认关**：插件配置 `companionRoom: true` 才建房间（ADR 0349；打开要用户点头）。没开时面板显示怎么开，不建房间、不调模型、不开局域网监听。
- 「会客室」是独立的本机网页房间。邀请 15 分钟内可兑换一次，来宾只能看加入后的房间消息。房间最多保留 100 条进程内消息，关闭会撤销邀请和来宾权限。来宾凭证不能访问主人面板、她的家、QQ 或记忆。房间发言触发独立模型判断（使用 DSH 宿主环境的 `QQBOT_LLM_API_KEY`，可选插件配置 `roomModel`），没人说话时不调用模型，没有密钥时只保留人之间的聊天。每次最多交给模型最近 12 条房间发言，房间模型没有工具、私聊或个人记忆上下文，消息不回写 QQ 或记忆。邀请链接使用宿主回环地址，目前限本机浏览器。
- 「她的家」移植 [灵犀的 3D 几何场景](https://github.com/2524034412-boop/DSH-QQ/blob/edf9f853341ac049708dc4c68ed432c74f2ad6d4/qq-bridge/src/space-page.js) 的房间、家具与相机做法，重新布置林梦瑶的客厅、厨房、书房、阳台和花园。支持旋转、缩放和恢复全景；网页本地加载 Three.js r160，[MIT 许可](https://github.com/mrdoob/three.js/blob/r160/LICENSE)见 `home-scene/LICENSE.three`。
- 场景和状态接口均要求主人浏览器会话。唯一状态来源是记忆插件单独写出的 `HOME-PUBLIC.json`。她可在确认的桌面专用私聊主动发布预设地点和活动，或收回展示。状态一小时后失效；未公开、已失效或只公开「在外面」时，场景中无位置标记。面板不读取日记、私聊或通用状态文件。

待批准部署时，把本包接入 DSH 桌面 profile，并使用 `cordis.patch.yml` 登记。通过仓库目录链接安装时可自动识别仓库根；从其他位置加载时在插件配置里设绝对路径 `repoRoot`。

## 灵犀功能的本地接入

- 名单和模式可从面板导入、预览并保存到 Koishi YAML。执行前校验配置版本，同步保留原文件备份。保存会重新生成 YAML 排版，原注释只保留在备份中。编辑不接受 oneDiary 字段，也不能更换本人 QQ。
- 系统页可显式查询远端 Git 提交，读取本地运维事件和脱敏召回日志。公共记忆页显示 Hindsight 分类统计，读取范围不含私有库。
- 备份清单可在独立目录验证并保留一次文件级恢复副本。验证不通过时清理该次演练目录；操作不替换 Koishi 状态目录，也不恢复线上数据库。
- 会客室附件留在内存，每个最多 512 KB。附件只能由见过该消息的房间成员读取。图片和语音二进制不交给模型、不进记忆。
- 可选 roomLan 配置接受 host、port、certFile、keyFile。只有配置了指定私网 IPv4 和来宾设备信任的 HTTPS 证书才开来宾监听。来宾监听仅开放房间入口，主人面板仍使用 DSH 的回环接口。
- 原创低模角色只按她公开的活动做读书、休息、做事或原地步行动作。未公开、已过期或只报「在外面」时，屋内不显示角色。

| 上游功能 | 本地接入状态 |
| --- | --- |
| 总览、桥接状态、服务操作 | 使用本项目的探测、启动锁和守护。 |
| 连接和模式 | 名单和模式查看、导入、导出、预览及原子保存。 |
| 聊天 | QQ 历史、媒体预览、本人代发。邀请制网页会客室支持开启独立的局域网 HTTPS 及房间媒体。 |
| 她的家 | 3D 场景、原创角色和基于公开活动的动作。 |
| 灵魂、记忆、读书 | 已接梗、表情、公共库分类统计和书架进度。独立人设编辑器、逐条记忆关系图与文本摘要待接入。 |
| 系统 | 备份清单、文件级隔离恢复演练、远端版本检查与结构化日志。覆盖线上数据的恢复和更新安装待接入。 |

在仓库根运行 `node --test scripts/dsh-qq-chat.test.mjs scripts/dsh-service-panel.test.mjs`。Windows 的启动锁检查使用临时目录和假启动脚本。
